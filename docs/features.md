# 已实现功能

## 操控

- **左键点击**地图位置 → 选中飞机飞向该点，显示虚线航向指示
- **右键点击** → 取消当前指示，飞机回正直飞
- **滚轮**缩放地图（0.1x ~ 5.0x）
- **中键拖拽**平移相机
- 启动时自动选中第一架友方飞机

## 飞机物理

- 不使用 Godot 物理引擎，全部在 `_physics_process` 中自行演算
- 内部单位：米、m/s；显示单位：km/h
- 地图比例：1 像素 = 2 米（`PIXELS_PER_METER = 0.5`）
- **转弯**：标准协调转弯，`ω = g × tan(bank_angle) / speed`
- **G 力极限转弯**：有目标时直接拉到 `max_g` 对应的最大 bank 角转弯，快对准时（<0.1 rad）才减小力度防过冲
- **滚转速率限制**：bank 角变化受 `roll_rate`（rad/s）限制
- **G 载荷**：`G = 1 / cos(bank_angle)`
- **失速**：`V_stall = V_stall_base × √G`，低于失速速度时丢高度、逐渐恢复速度
- **高度影响**：空气密度比 `σ = e^(-alt/8500)`，影响最大速度
- **到达判定**：距离 < `max(50px, speed × PIXELS_PER_METER × 1s)`，避免高速过冲振荡

## 视觉

- **飞机图标**：代码绘制（`_draw()`）的极简线框战斗机轮廓，友方绿色/敌方红色
- **滚转变形**：转弯时水平压缩图标（`scale.x *= cos(bank_angle)`），模拟侧视
- **高度缩放**：`scale = lerp(0.6, 1.4, altitude / max_altitude)`
- **选中环**：选中飞机周围显示半透明圆环
- **航向虚线**：从飞机到目标点的虚线 + 目标点十字标记
- **网格背景**：200px 间距的半透明绿色网格

## HUD

- 屏幕左上角显示选中飞机数据：速度(km/h)、高度(m)、航向(°)、G 力、状态(OK/STALL)、HP

## AI

- `AIController` 附加到敌机节点上，按矩形航路点巡逻
- 默认生成以初始位置为中心、半径 500px 的矩形路线
- 支持自定义航路点和巡逻高度
