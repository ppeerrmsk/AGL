# 2026-08-01 — 机体专属技能成长与功勋商店分类

## 玩家可见变化

- 每 3 级升级仍提供斗士 / 骑士 / 策士三张普通卡；若已购买当前机体的专属许可，首次符合条件时有 90% 概率追加第四张机体专属卡。
- 每架机每局只有一次机会。第四卡出现后选普通卡等同放弃，该机本局不再重复出现；进化到另一架机时按新机独立计算。
- 4 级（CLASSIFIED）卡与机体专属卡完成入场后边框闪亮一次；专属卡只播放洋红闪边，不叠加第二次稀有度闪边。
- 生涯商店改为【战术学说】【机体专属】【战场支援】【机体与后勤】四分页。
- 41 条专属许可按机体 Tier 定价 500 / 600 / 700 / 800 / 900 功勋。只有亲自获得过的机体才揭示技能；未知机体仅显示匿名 `???`。
- 友军 AWACS 改为 3000 功勋的“预警支援协定”。正式局未购买时不调度，购买后沿用原 90~150 秒入场、180 秒在站与现有 buff。
- 实机复核后移除专属商品卡和局内第四卡的“机体背景”段，避免与机体名、技能说明重复。
- F-14 起手档案显式覆写长机主导弹上限为 2；即使底层资源以后调整，也不会重新回到 4 发。

## 工程变化

- `SurvivorData` 统一维护 41 机映射、F-14“围猎”特例、普通池排除谓词与 90% 边界判定；旧 ×2.5 权重乘区退役。
- `SurvivorMode` 新增逐机逐局专属出示账本，并在普通三轴抽取完成后独立追加第四卡。
- `MetaShop` 用既有 `owned` 集合持久化 41 条专属许可和 AWACS 权益；商品揭示实时读取 `AircraftCodex`。
- 起手机与玩家进化的发现写入统一经过正式局闸；bench、boss debug 与僚机进化不污染图鉴。
- `SurvivorUpgradeUI` 预建最多四列，并使用一次性 Tween 实现 0.55 秒闪边，不增加帧循环。
