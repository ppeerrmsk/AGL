# 2026-05-03 — A-10 玩家机 + 玩家版 RKT（扇形 + 近炸 AOE 全自动）

## 设计哲学新增

[DESIGN_PHILOSOPHY.md](../DESIGN_PHILOSOPHY.md) 第 10 条：**全武器自动开火 — 不存在玩家"扣扳机"**。

所有武器一律根据自身 CD + 触发条件自动开火。玩家通过移动飞机进入"该开火的状态"。绝不允许"按 R 发射火箭"这类手动按键。Litmus 测试也加了第 10 项检查。

## 新增

### A-10 Warthog 主角（实验机型）
- `resources/playable_a10.tres` / `playable_a10_base.tres`
- 武器：GAU-A 加强机炮（伤害 +25% / 射程 +15% / 弹量 +30%）+ Hydra 70 火箭弹
- 故意留空：`missile = null` / `secondary_missile = null` / `flare = null`
- **速度调性**（用户调整）：max_speed 1050（略低于 F-86 的 1100）/ cruise 780
- **加减速调性**（用户调整：亚音速但加减速优秀）：acceleration 65 / deceleration 110 / thrust_to_weight 0.95
- 其他：HP 140 / armor 0.15 / max_g 7.0 / roll_rate 3.2 / 无加力
- 起始僚机 0
- 注册到 `survivor_select.gd::PLAYABLE_LIST` 第 4 槽

### 火箭弹机制：全自动扇形齐射 + 近炸引信 + AOE
设计调整（按用户反馈重做）：
- **去掉手动触发**（之前的 KEY_R 已删除），改为全自动扫描齐射
- 扫描条件：机头前 `fire_cone_half_angle`（A-10 设 35°）锥内 `[min_range, max_fire_range]`（200-1400m）有任意敌方单位
- 满足时：发射 `burst_count_max` 枚（A-10 设 8 枚）火箭弹，从机翼左右挂点交替出膛
- 角度沿 `[-spread_angle, +spread_angle]`（A-10 设 ±18°）等距扇形分布
- 不需要锁定、不需要 `combat_target`，不需要任何手动操作
- 进入 `burst_cooldown`（A-10 设 4s）等下次扫描

### 近炸引信 + AOE
- `RocketParams.proximity_fuse_radius_m`：> 0 启用，火箭弹接近敌方至此距离即引爆（A-10: 80m）
- `RocketParams.aoe_radius_m`：引爆后 AOE 半径（A-10: 120m）
- `RocketParams.aoe_damage`：AOE 内统一伤害（A-10: 30，与直接命中 25 dmg 独立）
- `BulletManager._explode_rocket(b, world_pos, exclude_unit)` 统一处理 VFX 缩放 + AOE 杀伤；直接命中时 `exclude_unit` 跳过已扣血的目标避免双计

定位："容错率很高的近身武器" — 8 发扇形 + 近炸 + AOE，机头大致对着敌人就能糊死。

## 后续微调（同日二次反馈）

按用户反馈进一步调整：

### 火箭弹判定为独立武器（非导弹）
- `Aircraft.take_damage:1718-1721`：`survivor_missile_damage_cap` 只在 `kind=="missile"` 时套用，火箭弹/AOE 类（kind="rocket"）走完整伤害不被卡
- `BulletManager.spawn_rocket` 顶部加注释明确"不被 CIWS / Laser 拦截"（结构上原本就是 — rockets 在 _bullets[]、CIWS/Laser 只看 Missile 实例 — 这里加注释钉死）
- 寿命 clamp 上限从 6s 放宽到 10s，容纳高速长射程

### 火箭弹寿命 + 速度（A-10）
- `muzzle_velocity` 320 → **600 m/s**（接近 1.9 倍）
- `max_range` 1800 → 4500 → **3800 m**（寿命 ≈ 6.3s；4500 实测略偏远，回调一档）
- `max_fire_range` 1400 → **2200 m**（自动扫描触发距离更远）
- `spread_angle` 18 → **14°**（扇形稍微朝内收一点，密度更高，远端 miss 率降低）

### A-10 转弯性能拔尖（攻击机定位）
- `max_g` 7.0 → **9.5**（高于 F-16 的 9.0，亚音速但极致机动）
- `max_g_structural` 9.5 → **12.0**
- `roll_rate` 3.2 → **4.8**（高于 F-16 的 4.0，桶滚极快）

## 后续可扩展
- 给 F-16 / F-14 / X-02 等其他主角挂火箭弹时，只需在 `*_base.tres` 加 `rocket = ExtResource(...)`，并在对应 `.tres` 设 prox/aoe 数值即可。设计原则 10 保证了它们也是全自动。
