# 2026-05-04 — 火箭弹 / 漂浮雷武器专属升级

新增 4 个升级条目，**按 `requires` 装备过滤**，任何挂载 `rocket` / `torpedo` 的飞机都能 roll（**不限机型**）。当前只有 A-10 挂这两件武器，未来若 F-16 / F-14 加挂火箭弹，也能直接享用同一升级池。

## 升级清单

| ID | 名称 | 类型 | 依赖装备 | 效果 |
|---|---|---|---|---|
| `skill_torpedo_aoe_jam` | 雷阵警讯 | skill_flag (1 层) | torpedo | 漂浮雷引爆时再放一圈 800m JAM 5s |
| `rocket_firerate_range` | 火箭弹·急速延伸 | 数值 (2 层) | rocket | CD ×0.75，max_range/max_fire_range ×1.25 / 层 |
| `skill_rocket_homing` | 火箭弹·寻迹引导 | skill_flag (1 层) | rocket | 火箭弹获得 1200m 弱追踪 + 35°/s 转向 |
| `torpedo_tracking_boost` | 漂浮雷·猎手感应 | 数值 (2 层) | torpedo | scan ×1.6，turn_rate ×2.2 / 层 |

## 实现要点

### 1. 漂浮雷范围干扰（雷阵警讯）
- 镜像 `SKILL_FLARE_AOE_JAM` 的实现路径
- 在 `BulletManager._explode_torpedo` 末尾检查 `source.upgrade_stacks[SKILL_TORPEDO_AOE_JAM]`
- 命中则调 `AOEBroadcast.apply_status_in_radius(JAM, 800px, 5s)`
- 干扰半径 800px / 持续 5s（比热诱弹 600px/5s 略广）— 漂浮雷散布投放，多颗叠加可形成持续干扰带

### 2. 火箭弹射速 + 射程（急速延伸）
- 数值类升级，stat = `rocket_firerate_range`
- `survivor_player.apply_upgrade` 新 match 分支：duplicate rocket 后 `burst_cooldown ×0.75 / max_range ×1.25 / max_fire_range ×1.25`
- min_damage_mult 不动 → 远端衰减保留，"快射 + 远 + 末端略弱"配置
- 2 层叠加：CD ×0.5625（≈ 4s → 2.25s），射程 ×1.5625（3800m → 5938m）

### 3. 火箭弹弱追踪（寻迹引导）
- 镜像漂浮雷追踪机制，参数比鱼雷略快（35°/s vs 20°/s）但比导弹弱很多（导弹通常 35G ≈ 数百°/s）
- 实现：
  - `BulletManager.mark_last_rocket_homing()` — 把最新 spawn 的火箭 dict 标 `homing_active=true`
  - `_launch_rocket` 在 spawn 后检查玩家技能 → 调上面的 marker
  - 物理循环开头：homing_active 的火箭做 retarget（节流 0.4s）+ vel 旋转（限速）
- 复用 `_torpedo_pick_target_in_range`（接受任意带 "pos" 的 dict）
- 性能：火箭活跃数远小于子弹，每 0.4s 一次 scan ≈ 可忽略

### 4. 漂浮雷追踪强化（猎手感应）
- 数值类，stat = `torpedo_tracking_boost`
- duplicate torpedo 后：`tracking_scan_range_m ×1.6 / tracking_turn_rate_dps ×2.2`（每层）
- 第 1 层：scan 1500→2400m，turn 20→44°/s — 进入"中等追踪"档
- 第 2 层叠加：scan ×2.56，turn ×4.84 → 接近真追踪导弹的转向能力（但仍受漂移速度上限制约）

## 设计契合度

| 原则 | 契合方式 |
|---|---|
| 1) 一击毙命 | 不破坏既有 dmg cap；JAM 不杀，强化"输出窗口"而非堆数值 |
| 3) 信息察觉 | JAM 有可见图标 + 雷达消失；火箭弧线追踪可见 |
| 5) 武器抽象 | rocket_firerate_range 直接乘 CD/range，无现实分类约束 |
| 7) AI 演戏 | JAM 让敌方 AI 进入"瘫痪"状态，玩家可见敌方变木头 |
| 10) 全自动开火 | 4 个升级都不引入手动键，被动改变武器表现 |
