# 更新日志 — 2026-04-20

## 地图流水线重构：OSM 真实底图 + 矢量数据烘焙 + Tacview 风格化

本次主要重构生存模式地图的数据源与渲染架构，从"完全手画几何 + 程序化海岸"切换到"OSM 真实地理数据 + 真实底图 PNG + Tacview 风格后处理"。

### 1. 新数据流水线（工具链）

**新增** `scripts/tools/bake_tokyo_bay.py` — OSM GeoJSON 烘焙器
- 从 Overpass Turbo 导出的 GeoJSON 读入，分类提取 coastline / landuse / highway / aerodrome
- 固定投影：`FIXED_LAT_C=35.44, FIXED_LON_C=139.76, 1px=2m`，对齐游戏世界坐标系
- Douglas-Peucker 简化 + 世界矩形裁剪 + 长度过滤
- `shapely.unary_union` 把 1172 个城区/道路外扩多边形合并成 **3 个大块**（overdraw 减少 ~400×）
- 输出 `resources/maps/tokyo_bay.json`（~100KB）

**新增** `scripts/tools/download_basemap.py` — 底图下载器
- 按 bbox + zoom 从 CartoDB Voyager no-labels 拉瓦片拼接
- 输出 4608×4608 px 无文字底图 + 元数据 JSON
- 游戏坐标系对齐参数随元数据保存，渲染器自动缩放定位

### 2. 重写 `MapGeographyData` 为 JSON 加载器

之前直接把 8000 行 `static var ... = [Vector2(...), ...]` 塞在 .gd 文件里，Godot 4 的 GDScript 解析器在 @tool 编辑器上下文**不触发 static var 懒初始化**，class member 查询返回空数组。

改为 JSON + `ensure_loaded()` 显式加载：
```gdscript
static func ensure_loaded() -> void:
    if _loaded: return
    var file := FileAccess.open(DATA_JSON_PATH, FileAccess.READ)
    var parsed = JSON.parse_string(file.get_as_text())
    URBAN_POLYGONS = _unpack(parsed.get("urban", []))
    # ...
```

`_unpack` 里同时做清洗：去连续重复顶点、去首尾闭合重复、丢面积过小的退化多边形 —— 根除 `draw_colored_polygon` 的 "Invalid polygon data, triangulation failed" 狂刷。

### 3. 主地图渲染器（`MapFeatureRenderer`）

**新增 Sprite2D + ShaderMaterial 路径**：底图以 Sprite2D 形式挂在 MapFeatureRenderer 下，配合 `basemap_tacview.gdshader` 做 Tacview 风格后处理。

**新增 Shader** `resources/shaders/basemap_tacview.gdshader`：
- 饱和度 / 亮度 / 对比度（Inspector 实时调）
- **Sobel 边缘检测** — 海岸/道路/建筑边界自动描边
- **动态噪点** — CRT 颗粒感

**@export 参数**（Inspector 拖滑条即时生效）：
```gdscript
basemap_tint:        Color(0.78, 0.82, 0.80, 1.0)   # 中性冷灰
basemap_saturation:  0.40
basemap_brightness:  0.70
basemap_contrast:    1.25
basemap_edge_strength: 1.2
basemap_noise:       0.03
basemap_covers_vectors: true  # 纯底图，不重绘矢量层
```

`_process()` 每帧同步 @export 到 shader uniform —— Inspector 里改参数玩家立刻看到。

### 4. 战术缩略图（`TacticalMap`）风格化

- `clip_contents = true` 自动裁剪溢出面板外的绘制
- 绘制最后叠扫描线 + 暗角后处理（纯 `draw_line` + `draw_rect`，不用 shader）
  - 每 3 px 一条暗扫描线（alpha 0.18）
  - 三层递进暗角框边
- 底图缩放贴图 + 中性 modulate —— 与主地图风格一致
- 坐标变换缓存（size 不变不重算）—— 修复 FPS 从 120 降到 40 的问题

### 5. 手画覆盖层（`scenes/map_manual.tscn`）

- Root + Background (`@tool` 脚本) + 用户添加的 Polygon2D
- `MapManualBackground` 是编辑器实时预览，显示 OSM 数据作为描边参考
- 运行时游戏加载场景扫描 Polygon2D 子节点，累加绘制
- Background 节点（Node2D）被自动跳过，不会当成游戏地块

### 6. 判定逻辑确认（`is_on_land`）

仍然工作，且增强了：
```gdscript
static func is_on_land(pos: Vector2) -> bool:
    ensure_ready()
    # OSM mask 优先（精确）
    for poly in MapGeographyData.LAND_MASK_POLYGONS:
        if Geometry2D.is_point_in_polygon(pos, poly): return true
    # 手画 LAND 兜底（覆盖无 landuse 的山林）
    for poly in get_land_polygons():
        if Geometry2D.is_point_in_polygon(pos, poly): return true
    return false
```

调用方 `map_feature_renderer._draw_tacview_crosses` + `zone_mission` 的"只在陆上刷"逻辑不变。

### 7. 性能优化

- **道路 bands 缓存**（`MapGeography.get_road_bands()`）—— `offset_polyline` 只做一次，存在 static var
- **缩略图变换缓存** —— size 不变就不重算 1172 个多边形的顶点投影
- **缩略图 draw_polyline 替代 per-segment draw_line** —— 1012 条路径，draw call 从 3000/帧 降到 1012/帧
- **land mask 从 1172 个小 halo 合并成 3 个大块** —— GPU overdraw 显著下降
