# 更新日志 — 2026-04-08

## 1. 战术 AI 系统（BFM 决策树）

全面重写 `AIController`，从简单巡逻升级为三状态状态机：**巡逻 → 交战 → 导弹规避**。

### 状态机

| 状态 | 触发条件 | 行为 |
|------|----------|------|
| PATROL | 默认 / 冷却中 | 沿航点巡逻，周期性扫描敌机 |
| ENGAGE | 发现可交战目标 | 基于 BFM 决策树选择战术机动 |
| EVADE_MISSILE | 检测到来袭导弹 | 急转规避，释放热诱弹 |

### 战术机动（8种）

基于 Shaw《Fighter Combat》BFM 理论实现：

- **Lead Pursuit** — 前置追踪，积极闭合距离
- **Lag Pursuit** — 滞后追踪，保持后半球位置
- **Lead Turn** — 迎头时抢角度
- **High Yo-Yo** — 拉高减速防冲过（分阶段：拉高 → 恢复追踪）
- **Low Yo-Yo** — 俯冲加速闭合
- **Break Turn** — 被咬尾时急转防御（分阶段：急转 → 反转迎头）
- **Extension** — 加速脱离拉开距离
- **Scissors** — 近距反复交叉

战术选择基于：距离、角度差、相对速度、高度差等态势参数，并受飞行员能力和性格影响。

### 飞行员能力与性格系统

每个 AI 飞行员拥有独立的能力属性和性格特征：

**能力参数：**
- `skill_level` (0~1) — 战术水平，影响判断精度
- `composure` (0~1) — 抗压能力，决定压力对技能的衰减程度

**性格参数：**
- `focus` (0~1) — 目标专注度（低=容易分心切换目标）
- `self_preservation` (0~1) — 自保意识（高=优先脱离，低=死缠不放）
- `aggression` (0~1) — 攻击倾向，影响交战决策

**压力系统：**
- 被雷达锁定、来袭导弹、受伤、高G持续等会累积压力
- 脱离威胁后压力逐渐恢复
- 压力影响有效技能：`effective_skill = skill × (1 - stress × (1 - composure))`
- 压力推升自保意识：冷静度低的飞行员在压力下更想逃跑

**判断误差模拟：**
- 位置漂移噪声（低技能/高压力飞行员瞄不准）
- 速度估算误差
- 高度判断误差
- 漂移幅度和重采样频率受有效技能调控

### AI 战术覆盖机制

新增 `Aircraft.ai_override_pursuit` 标志，当 AI 战术机动激活时跳过 aircraft.gd 内置的自动追踪逻辑，由 AI 直接控制 `target_position` 和 `target_speed`。

**涉及文件**：`scripts/ai_controller.gd`（重写）、`scripts/aircraft.gd`

## 2. 热诱弹系统（Flare / Countermeasure）

### 新增 FlareParams 资源

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_flares` | 30 | 携带总量 |
| `burst_count` | 2 | 每次释放数量 |
| `cooldown` | 1.5s | 释放间隔 |
| `base_jam_chance` | 0.55 | 基础干扰成功率 |
| `aspect_bonus` | +0.20 | 导弹从侧/后方追来时加成 |
| `maneuvering_bonus` | +0.15 | 大幅机动（>4G）时加成 |
| `close_range_penalty` | -0.35 | 导弹极近（<150m）时惩罚 |
| `low_energy_bonus` | +0.20 | 导弹发动机熄火后加成 |

### 飞行员释放策略

- `nervousness` 参数决定释放时机（0=冷静，1=慌张）
- 冷静飞行员等到导弹 250m 内才释放，慌张飞行员 800m 就开始丢

### 导弹侧变更

- `Missile` 新增 `is_flare_jammed` 标志，被干扰后永久失去制导
- 干扰判定后于 SARH 照射检查

### 视觉效果

- 释放时生成黄色粒子向后扩散，带衰减和减速

**涉及文件**：`scripts/flare_params.gd`（新增）、`resources/default_flare.tres`（新增）、`scripts/aircraft_params.gd`、`scripts/aircraft.gd`、`scripts/missile.gd`

## 3. 飞行物理改进

### 失速行为重写

- 失速时不再直接修改 altitude/speed，改为设置 `vertical_speed` 强制俯冲
- 失速严重程度按速度比例计算，影响俯冲率（-100 ~ -250 m/s）
- 失速中侧倾不稳定（随机抖动）
- 失速时强制回正 bank_angle（机翼失去升力）

### 低速操控性衰减

- 速度低于失速速度时，转弯率按平方衰减
- 低速时滚转速率同步下降
- 防止失速飞机仍能灵活转向的不合理行为

### 速度安全下限

- 自动速度控制不再允许主动减速到失速速度以下
- 安全余量设为 130% 基础失速速度

### 最大侧倾角限制

- 新增速度相关的 bank angle 上限
- 防止低速时拉过大G导致立即失速
- 速度接近失速时仅允许约 11 度温和转弯

### 坠地检测

- 高度降到 0 时触发坠毁销毁

### 高度缩放改进

- 飞机图标缩放改用 5000m 为基准（scale=1.0）
- 低空使用 sqrt 曲线让变化更明显
- 范围从 0.65（地面）到 1.4（最高空）

**涉及文件**：`scripts/aircraft.gd`
