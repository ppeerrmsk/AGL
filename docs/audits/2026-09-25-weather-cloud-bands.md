# 军事风格云带：低成本样板

对应[天气表现规格](../specs/systems/weather-volume-presentation.md)。2026-09-25 用户批准试做概念图 A 的云带轮廓与 C 的疏密，并要求验证性能。默认关闭，尚不代表概念图级画质或严格60 FPS完成。

## 实现与取舍

单个闭合云壳192三角形，候选2×4/块，最多1536面/块。固定世界格点、权威密度和确定性形状变化；CPU只在分块生成时构建几何。GPU继续承担风漂和小幅起伏。通过顶点alpha在同一壳体内羽化边缘，背面剔除；无新增纹理、多层雾片、实时体积雾或云影。沙尘沿用9月18日版本。

初轮72面硬壳在实机中像石块，已否决。最终版增加轮廓分段、柔化明暗和边缘，并减少候选数量、变化长宽和朝向。当前仍可看到重复的扁长云块，云团之间并未融合成概念图中的自然云带；碎雾、真实体积散射均未实现。美术仍是样板，不以生成概念图冒充实机。

WeatherSystem保留天气判定权威。展示缝隙不代表传感器判定为空；不得通过云几何反向修改战斗密度。

## 验证

最终天气 focused：0 fail、wrapper 0。最终 Visual：沙漠/海岛、多缩放与旋转、暂停、材质预热通过，wrapper 0。这里只代表运行正确，不代表美术完成。

性能对照：同一工作区状态、机器、GL Compatibility、地图/天气种子、36混合战场及8段镜头，AGL_WEATHER_STORM_TEST=1，AGL_WEATHER_VOLUME=on/off。计划三组成对30秒Visual及一组显式render timing诊断；实际完成两组后发现外部GPU负载，已中止第三组和计时诊断。on包括本轮云与既有3D沙尘，off为原2D天气，因此差值是整个天气表现路径差值，不可称为单独云shader耗时。

完整局、净内存峰值、冷启动/LOD严格零尖峰仍未验收。
