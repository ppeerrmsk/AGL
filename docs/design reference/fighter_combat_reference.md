## 1. 核心概念与术语

### 基础几何概念

| 术语 | 英文缩写 | 定义 |
|------|---------|------|
| **角偏量** (角偏角) | AOT (Angle Off Tail) | 目标机尾部与攻击者的夹角 |
| **角偏量（鼻端）** | AON (Angle Off Nose) | 攻击者鼻端与目标的夹角 |
| **目标纵横角** | TAA (Target Aspect Angle) | 目标速度矢量与LOS的夹角（0°=正面，180°=正后方） |
| **视线** | LOS (Line of Sight) | 攻击者与目标之间的连线 |
| **轨迹交叉角** | TCA (Track Crossing Angle) | 两机速度矢量的角度差 |
| **转弯半径** | RT | 飞机做水平圆周运动的半径 |
| **转弯速率** | TR | 单位时间内转弯的角度数（°/秒） |
| **过载系数** | G / n | 作用在飞机上的法向加速度倍数 |
| **拐角速度** | Vc (Corner Speed) | 在最大G力下能获得最小转弯半径的速度 |
| **比剩余功率** | Ps (Specific Excess Power) | 飞机在保持速度的同时可爬升的能力 |

### 位置术语

- **前象限 (Forward Quarter / FQ)**：目标前方 ±90° 区域
- **后象限 (Rear Quarter / RQ)**：目标后方 ±90° 区域
- **六点方向 (Six O'clock)**：正后方死角
- **冷侧 (Cold Side)**：目标转弯外侧（攻击者看目标腹部）
- **热侧 (Hot Side)**：目标转弯内侧（攻击者看目标背部）

## 2. 武器系统

### 2.1 机炮 (Air-to-Air Guns)

#### 射击原理

机炮命中需要同时满足三个条件：
1. **距离条件**：在最大/最小有效射程之间（现代约 150m–900m）
2. **瞄准条件**：子弹飞行时间内的提前量计算正确
3. **射击持续时间**：有足够时间射出足以击毁目标的子弹量

#### 射程参数（游戏化参考）

| 参数 | 数值范围 | 备注 |
|------|---------|------|
| 最大有效射程 | ~900m（3000 ft） | 受瞄准精度、弹道、目标脆弱性限制 |
| 最小安全射程 | ~150m（500 ft） | 防碰撞与碎片伤害 |
| 最优跟踪射程 | 200–600m | LCOS准星约30°–60° AOT处 |
| 子弹飞行时间 | 0.1–0.5秒 | 取决于射程和弹速 |

#### 射击类型

**跟踪射击 (Tracking Shot)**
- 准星稳定在计算瞄准点上
- 效果最好，但要求：射手飞行轨迹可预测、持续时间约1秒以上
- 战术代价：暴露时间长，注意力集中在目标上

**快照 (Snapshot)**
- 准星仅短暂扫过瞄准点
- 低G快照：提前量大，飞直线等目标飞过
- 高G快照：接近跟踪射击，G力最大化减慢相对运动

#### 机炮防御

| 防御动作 | 效果 | 时机 |
|---------|------|------|
| **延伸机动** (Extension) | 拉开到最大射程外 | 探测到攻击者较远时 |
| **急转弯** (Break Turn) | 增大AOT，将攻击者推向前象限 | 攻击者进入射程时 |
| **离面翻滚** (Out-of-Plane Roll) | 打断攻击者的瞄准，造成错过 | 攻击者即将开火时 |
| **急动机动** (Jink) | 不规则方向改变破坏瞄准 | 距离较近时持续使用 |
| **不协调飞行** (Skid/Slip) | 给攻击者错误视觉线索 | 补充其他防御 |

> **游戏化设计**：急动机动的方向变换应每次间隔 90° 以上，且不要形成规律。

### 2.2 导弹 (Guided Missiles)

#### 导弹类型

| 类型 | 制导方式 | 特点 | 典型例子 |
|------|---------|------|---------|
| **后象限红外** (RQ IR) | 被动红外追热 | 只能从后方发射，追尾焰 | AIM-9B |
| **全向红外** (All-Aspect IR) | 先进红外，可追机体热 | 任意角度发射 | AIM-9L/M |
| **半主动雷达** (SARH) | 发射机持续照射目标 | 发射后发射机不能自由机动 | AIM-7 Sparrow |
| **主动雷达** (ARH) | 导弹自带雷达制导 | 发射后不管，最优选 | AIM-120 AMRAAM |

#### 导弹飞行轨迹类型

```
纯追踪 (Pure Pursuit):    弹头始终指向目标当前位置 → 效率低，转弯多
前置追踪 (Lead Pursuit):  弹头指向目标前方 → 较高效
碰撞航向 (Lead Collision): 弹头指向预计相遇点 → 最优，直线飞行
比例导引 (Proportional Nav): 实用型，消除目标LOS角速率
```

#### 导弹发射包线 (Firing Envelope)

关键边界：

| 边界 | 原因 | 影响因素 |
|------|------|---------|
| **最大动能射程** | 导弹推力/气动极限 | 高度、目标/发射速度、方向 |
| **最小射程** | 导弹解锁时间、制导反应、引信武装 | 目标速度、高度 |
| **向上看要求区域** | 多普勒地波杂波 | 仅雷达制导导弹 |
| **引信失效区** | 侧向拦截角、引信延迟 | 横侧方向拦截 |

> **关键设计规则**：
> - 目标机动时，前象限射程远远大于后象限（约5:1）
> - 目标转向会产生"热侧"（大射程）和"冷侧"（小射程）的不对称
> - 低空后象限射程大幅下降

#### F-极（F-pole）/ 站立距离

- 导弹命中时，发射机距目标的距离
- 半主动雷达导弹需要此距离最大化以保持发射机在远处
- 技巧：先加速再减速可拉大F-极

#### 导弹防御

**基本原则**：消耗导弹性能的任意子系统即可破坏拦截

| 防御动作 | 针对什么 | 说明 |
|---------|---------|------|
| **高G急转弯** | 制导/动能 | 导弹需要约5倍目标G才能拦截，目标满G急转后导弹压力极大 |
| **向威胁方向急转** | 制导 | 增大LOS角速率，测向速率超过导弹跟踪极限 |
| **离面机动** | 制导/引信 | 导弹冲过去，横侧拦截引信失效 |
| **减速（红外威胁）** | 红外特征 | 减小喷气温度，降低引导信号强度 |
| **转向太阳** | 红外 | 太阳干扰红外导引头 |
| **箔条 (Chaff)** | 雷达 | 产生假目标或噪声干扰 |
| **曳光弹 (Flare)** | 红外 | 高强度点热源，比喷口更亮 |

> **游戏化时机关键**：
> - 过早机动效果差（导弹跟踪时间充足）
> - 过晚机动无法完成（动能不足）
> - 最佳时机：目标接近时开始，导弹约在3–5秒内命中时最有效

## 3. 基础战斗机动 (BFM)

### 追逐曲线 (Pursuit Curves)

三种基本追逐关系定义攻击者速度矢量（机头）指向位置：

```
前置追逐 (Lead Pursuit)：机头指向目标前方
  → 增大接近速度，适合拉近距离
  → 会增大AOT（角偏量）

纯追逐 (Pure Pursuit)：机头直指目标当前位置
  → 产生接近速度，稳定AOT
  → 导弹常用此轨迹（效率低）

滞后追逐 (Lag Pursuit)：机头指向目标后方
  → 减慢/停止接近，保持在后象限
  → 用于控制距离，能量更高效
```

**游戏化提示**：AI可以通过 LOS 角速率来判断当前应用哪种追逐——当 LOS 向前漂移，用滞后追逐；向后漂移，用前置追逐；稳定，用纯追逐。

---

### 核心机动动作详解

#### 高大摆 (High Yo-Yo)

**使用场景**：在目标转弯内侧，速度过快即将超越目标，AOT 适中（30°–60°）

**步骤**：
1. 向目标转弯平面的垂直方向拉高（改平后拉 up）
2. 爬升减少水平速度分量，阻止超越
3. 到达高点后，向目标前方滚转（前置/纯/滞后，取决于需要的距离）
4. 利用重力协助拉回目标方向

**效果**：消耗高度换取角度，而非消耗速度（能量更高效）

```
常见错误：
- 太晚开始拉：需要更高鼻端姿态，目标可能趁机俯冲逃跑
- 太早俯冲：攻击者鼻端过低，目标可垂直拉起反制
```

---

#### 低大摆 (Low Yo-Yo)

**使用场景**：在远距后象限滞后追逐位置，没有足够转弯率拉起机头

**步骤**：
1. 向目标转弯方向内侧俯冲（水平转弯分量变大）
2. 重力辅助 + 低头时的法向力分量，增加水平转弯速率
3. 在目标前下方生成大量前置量
4. 改平后从下方拉起至目标后方

**效果**：用高度换角度，快速拉近后象限距离

---

#### 滞后位移翻滚 (Lag Displacement Roll)

**使用场景**：以高速在近距强位置，防止超越目标

**步骤**：
1. 改平机翼，机头拉起（离开目标转弯平面）
2. 爬升减速，同时保持对目标的视觉接触（缓慢向目标方向滚转）
3. 以倒飞姿态越过目标的正上方
4. 从高处重力辅助拉到目标后方

```
变体 - 桶滚攻击 (Barrel-Roll Attack)：
从远距前象限开始，拉高翻滚，最终落到目标后象限
适用：目标转向攻击者时（否则会错过）
```

---

#### 领先转弯 (Lead Turn)

**使用场景**：对向接近的前象限情况

**原理**：比对手提前开始转向目标飞行轨迹，因此到达有利后象限位置时对手还没完成转弯

**关键参数 - 飞行路径间隔 (Flight Path Separation)**：
- 间隔越大，领先转弯收益越大
- 间隔 < 转弯半径：速度是决定因素
- 间隔 ≈ 一个直径：半径是决定因素
- 间隔 > 一个直径：几乎无优势

---

#### 平面剪刀 (Flat Scissors)

**使用场景**：两机在同一平面，交替超越，争夺后方位置

**本质**：鼻对鼻转弯的重复循环

**胜者条件**：
- 更慢的飞机（更小转弯半径）
- 更快的滚转速率（减少中立时间）
- 更早的翻转时机（产生更小TCA，更好的角度）

**AI 设计**：让飞机在超越后立即翻转，反应越快越好；速度越低角度优势越大

---

#### 滚转剪刀 (Rolling Scissors)

**使用场景**：高速垂直超越后的三维螺旋争夺

**本质**：在垂直面上互相绕对方的飞行路径做桶滚

**胜者条件**：
- 能量管理（控制最大/最小速度的时机）
- 过顶时用最大可用 G
- 底部用持续 G（省能量）
- 正确的前置滚转（类似鼻对鼻选位）

**逃脱方法**：达到反向头对头，然后全力延伸

---

#### 防御螺旋 (Defensive Spiral)

**使用场景**：被近距追逐，已无法脱身，垂直旋转下降

**目的**：利用反复改变机动平面来破坏攻击者的跟踪解算

**关键**：最小化加速度（怠速、减速板、反推力、高迎角）让攻击者速度更快、被甩到前面

---

#### 鼻对鼻 / 鼻对尾转弯

| 参数 | 鼻对鼻 | 鼻对尾 |
|-----|------|------|
| 关键性能因素 | 转弯**半径** | 转弯**速率** |
| 角度增益来源 | 飞行路径间隔 + 半径差 | 速率优势 |
| 视觉遮蔽 | 短暂盲区 | 较长盲区 |
| 适合武器 | 炮（需靠近） | 导弹（可稍远） |

## 4. 1v1 战术

### 角度战 (Angles Fight)

**目标**：先获得位置优势（角度），再维持到火力参数

**核心原则**：
- 使用鼻对鼻几何，效率最高
- 俯冲转弯（用高度换速度维持能量）优于水平转弯
- 目标：每次相向而过获得 20°–30° 优势
- 不能过贪（速度掉太多 → 失去机动性）

**连续过程**：
```
缩短距离 → 鼻对鼻转弯 → 超越 → 翻转领先 → 逼对手急转(失速) → 快照机会
```

**结束游戏**：
1. 对手能量耗尽，被迫向下逃跑
2. 攻击者从下方对缓慢目标进行快照
3. 或对手拉高时跟上，在顶部造成超越对手的快照机会

---

### 能量战 (Energy Fight)

**目标**：先建立能量（速度/高度）优势，再转化为位置优势

**核心原则**：
- 鼻对尾或鼻对鼻中让对手拉高G
- 自己维持有利的持续G转弯
- 等对手能量耗光后俯冲爬高（pitch-back）
- 在滚转剪刀中利用能量优势占位

**结束游戏**：
```
对手G耗能过大 → 攻击者在合适时拉高 → 俯冲快照 → 或滚转剪刀优势
```

**vs 角度战**：
- 角度战更快直接
- 能量战更安全但需要更长时间
- 选择依据：武器系统、飞机性能差异、环境危险度

---

### 武器场景适配

#### 纯机炮场景

- 必须达到后象限 30°–60° AOT 的跟踪区域
- 角度战更优先（需要近距、后象限位置）
- 关键：从下方攻击（防止对手利用高度逃脱）

#### 纯后象限导弹 (RQ AAM)

- 目标：带尾焰的后象限发射位置
- 对手可用向前飞行增速脱离后象限威胁
- 角度战（维持对手在后象限）或延伸-回马枪

#### 全向导弹 (All-Aspect AAM)

- 大幅增加速度战的危险性（对手可以任意角度发射）
- 角度战必须维持近距（防止对手达到最小发射距离以外）
- 全向导弹让 "keep inside min-range" 成为主要目标

## 5. 不对称飞机对抗

### 关键性能参数

| 参数 | 翼载荷 (Wing Loading) | 推重比 (T/W) |
|------|---------------------|-------------|
| **低值** = | 优秀瞬时/持续转弯 | 优秀加速/爬升 |
| **高值** = | 差转弯（能量战优） | 差加速（角度战优） |

### 对抗矩阵

| 场景 | 低翼载飞机策略 | 高翼载飞机策略 |
|------|-------------|-------------|
| 低翼载 vs 高推重比 | 角度战（内圈圈死对手） | 能量战（拉高脱离） |
| 高翼载 vs 低翼载 | 能量战（无转弯优势） | 角度战（小心用）|
| 双重优势 | 角度战（最快速制） | 能量战 + 祈祷 |
| 双重劣势 | 无好选择 | 全力逃跑/等待失误 |

### 实战案例参考

**F-4 vs MiG-17（越战）**：
- F-4 高推重比但高翼载
- MiG-17 低翼载低推重比（炮）
- F-4 理论上应用能量战，但训练不足和无法锁定导致接近缠斗
- 结果：MiG-17 的角度优势发挥，F-4 较劣

**P-47 vs Spitfire IX（模拟演练）**：
- P-47 高速/高质量（俯冲加速优）
- Spitfire 翼载低（转弯/爬升优）
- Johnson 利用滚转性能防御，俯冲加速 → 跃升快照获胜

## 6. 编队战术

### 6.1 基础队形

| 队形 | 特点 | 适用 |
|------|------|------|
| **战斗横队 (Combat Spread)** | 并排，约1个转弯半径间距 | 最佳互相掩护，默认队形 |
| **楔形 (Echelon)** | 斜行排列 | 追击、进攻 |
| **纵列 (Trail)** | 前后排列 | 顺序攻击，互相掩护弱 |
| **吸入纵列 (Sucked Echelon)** | 翼机拖后 > 45° | 接近攻击队形 |

### 6.2 2v1 战术

#### 战斗翼 (Fighting Wing)
- 翼机跟随长机，不独立机动
- 长机负责进攻和防御机动
- 翼机负责目视掩护长机后方
- **适合**：简单操作、训练期

#### 双重攻击 (Double Attack)
- 一机进攻，一机自由覆盖
- 进攻机: 机动攻击目标
- 自由机: 防止目标攻击进攻机，时机到了接手
- **核心**：轮流攻击目标

#### 松散双机 (Loose Deuce)
- 两机半独立机动
- 互相中和对手的攻击，再攻击另一威胁
- 更强的进攻效率，需要更高训练和协调
- 通讯至关重要

### 6.3 2v1 攻击手段

#### 夹击 (Bracket/Pincer)
```
两机分别从目标两侧绕过 → 目标必须应对两个方向
最优：无论目标转向哪里都能被另一机攻击
```

#### 拖饵战术 (Drag)
```
一机诱敌（假装不知道被追） → 另一机从侧面切入攻击追击者
风险：诱饵机暴露时间长
```

#### 三明治 (Sandwich)
```
目标被前后包夹 → 无论逃哪里都进入另一机的射界
```

### 6.4 2v2 战术

#### 初始接触

**钳制攻击 (Pincer)**:
```
双机分别从两侧绕过对方编队的两翼 → 分别攻击对面的目标
"心形进攻" → 两攻击机在中间差点相撞（需要高度分离）
```

**拖饵 (Drag)**:
```
一机假装不知道，诱一个目标跟进 → 另一机从侧面切入
```

#### 交战中

**打击-重编-打击 (Strike-Rejoin-Strike)**:
```
攻击 → 成功/失败后立即回到防御横队 → 再次寻机攻击
```

**防御切换 (Role Switch)**:
```
当进攻机受到威胁时 → 自由机立即介入攻击威胁 → 
进攻机变为自由机 → 新进攻机继续
```

### 6.5 4机编队（师 Division）

#### 手指四机 (Finger Four)

```
  2  1  3  4
（类似手指尖的排列）
1 = 长机
2 = 1号僚机
3 = 第二双的长机
4 = 3号僚机
```

优势：视觉互相覆盖、间距约1个转弯半径

#### 战壁 (Wall)

```
4  3  2  1（并排，更宽间距）
```

二战晚期德军最爱，最佳防御视野

#### 交叉翻转 (Tac Turn / Cross-Over Turn)

编队翻转标准动作：
1. 长机开始转弯
2. 同侧僚机立即急转跟上（从长机后下方穿过）
3. 对面双机跨越长机，分步骤完成

### 6.6 乱战 (Gaggle) 战术

当四机编队面对多于两倍敌机时：
- 放弃紧密协调
- 每双机按双重攻击/松散双机运作
- 避免一对一缠斗延续
- 进攻后立即重编，不超出攻击参数就退出
- 自由掠过乱战边缘，寻找暴露目标

## 7. 大规模战术

### 1v多 (One-versus-Many)

**核心原则**：不延长缠斗
- 速度是第一防御（高速降低后象限被攻击概率）
- 高度选择：极高或极低（避免中等高度）
- 蛇形机动检查盲区（每次 60°–90° 翻转）
- 仅打快照/首发即走
- 遇到危险立即逃离，不贪恋可能的击杀

**机动窗口建议**（游戏数值）：
- 无线视野内能发现的目标：约 4,500m
- 后象限攻击者出现到进入武器射程：≥ 15秒
- 每次蛇形检查盲区的翻转持续时间：1–3秒

### 几vs多 (Few-versus-Many)

- 双机战斗横队，高速/极高/低飞行
- 战斗横队视觉掩护互补
- 限制回头：只发射前向武器，避免后象限转弯
- 攻击后快速重编（不延伸超过 90° 转弯）

### 多vs多 (Many-versus-Many)

- 每双机按 few-vs-many 运作
- 乱战边缘巡逻，不加入平衡中的乱战
- 监视有明显占优的退出者
- 统一频率，极度精简通话

## 8. 战斗任务类型

### 战斗机扫荡 (Fighter Sweep)

**目的**：主动在敌占空域消灭敌方飞机

**策略**：
- 高低双层（低层打目标，高层掩护）
- 交错出发（分钟间隔的多波次）
- 进入退出时速度最大化
- 真实目标/假冒轰炸机骗敌升空

### 要地/区域防御 (Point/Area Defense)

**目的**：保护固定目标或空域

**策略**：
- 战斗空中巡逻 (CAP)
- 地面控制截击 (GCI) 引导
- 最小化暴露时间：仅拦截已确认威胁
- 不深入敌占区（会失去 GCI 覆盖）

**拦截方式**：
| 方式 | 前象限 | 尾部转换 | 单侧偏置 | 钳型 |
|------|------|---------|---------|------|
| 速度 | 最快 | 稳定 | 快速 | 最灵活 |
| 暴露 | 短 | 长 | 短 | 短 |

### 护航 (Strike Escort)

**目的**：保护攻击机免遭敌战斗机拦截

**内圈护航 (Close Escort)**：
- 直接跟随轰炸机
- 限制机动，非常脆弱
- 仅在没有其他选择时

**交叉护航 (Cross-Cover Escort)**：
- 分成几组轮流掩护
- 每组有可机动的空间

**扫荡护航 (Escort Sweep)**：
- 护航战斗机在轰炸机前方扫清敌机
- 最有效但对轰炸机的即时保护弱

## 9. 飞行性能参数

### 转弯性能

| 参数 | 公式/关系 | 游戏实现提示 |
|------|---------|------------|
| 转弯半径 | Rt = V²/(g × GR) | GR = 法向加速度 |
| 转弯速率 | TR = g × GR / V | 与速度成反比 |
| 拐角速度 | 在此速度下可产生最大G最小Rt | 是最优机动速度 |
| 持续转弯 | 在当前速度下可无限维持的G | 随高度增加而降低 |
| 瞬时转弯 | 短时间内最大G（消耗速度） | 受结构G极限限制 |

### 能量状态

```
比剩余功率 (Ps) = (推力 - 阻力) × 速度 / 重量

正 Ps：可加速或爬升
零 Ps：维持当前速度和高度（持续G边界）
负 Ps：在消耗能量（减速或下降）
```

### 重力影响

- **向下转弯**：增加 GR，减小转弯半径（重力辅助）
- **向上转弯**：减少 GR，增大转弯半径（对抗重力）
- **垂直面**：平均效果与水平持平，但允许极端使用

### 实用速度范围（现代战斗机典型）

| 状态 | 空速 | 备注 |
|------|------|------|
| 失速速度 | ~130 kts | 1G构型 |
| 最优能量速度 | ~350–450 kts | |
| 拐角速度 | ~400–500 kts | 最小转弯半径 |
| 持续转弯速度 | ~350–450 kts | 最优持续G |
| 最大平飞速度 | 750–1400 kts | 取决于飞机 |

### 视觉优先级设计

```
最危险信息（必须显眼）：
1. 后方威胁导弹来袭
2. 即将超出边界（失速/过G）
3. 敌机在6点位

重要信息（明显但不干扰）：
1. 武器参数（在包线内/外）
2. 能量状态趋势
3. 翼机位置

参考信息（需要时查阅）：
1. 具体距离数值
2. 速度/高度
3. 雷达图
```

## 附录：关键战术原则总结

### Boelcke 法则（历史第一套战斗机战术规则，1916年）

1. 尽量保持高度和速度优势再攻击
2. 一旦攻击开始就要坚持到底
3. 只在近距离确认对手在瞄准线内才开火
4. 不要被战术欺骗，始终盯着目标
5. 任何形式的攻击都要从目标后方进行
6. 若敌人俯冲攻击，不要规避，迎头飞向他
7. 在敌方领土时，时刻注意撤退路线
8. 以4–6机编队进攻，乱战后不要多打一个

### 现代格言

> "在空战中，最先看到对方的人获胜" — 视觉优势

> "速度是生命" — 能量管理

> "最好的防御是有效的进攻" — 攻击性思维

> "如果不能击败对手的飞机，就以另一种打法攻击" — 灵活战术

> "你怎么训练，就怎么打" — TOPGUN 格言
