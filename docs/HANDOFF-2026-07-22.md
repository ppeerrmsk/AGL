## 1. 本批做了什么（用户需求 → 落地）

### ① 战场节奏批（解决冷场）— spec `systems/battlefield-tempo-pass`

**诊断出的根因**（不是"敌人太少"，是结构性的）：
1. `reinforcement-ingress` 改造后，**所有**增援都是"边缘 → 中央锚点驻空绕环"，没有任何一类敌机以玩家为目标进场；
2. 主动压力唯一来源是 ROE 热度的 hunter 配额，但 hunter 只能**抽调场上已有的 PATROL 闲兵**——玩家附近抽调池空时，配额再高也造不出压力；
3. → 玩家远离锚点/战区 → 无击杀 → XP 停滞 → 高价值敌机不解锁 → 更冷（正反馈）。

**落地**：
- **拦截波**：hunter 配额缺口 ≥ `INTERCEPT_QUOTA_GAP(2)` 时，本波旅途增援改为拦截使命——玩家 heading **±90° 前方扇区**边缘入场、TRANSIT 航点=玩家位置每 8s 修正、**永不转 ONSTATION**（`reinf_intercept` meta）。在途拦截队计入占额（`_count_hunter_pressure`）防连刷过压。
- 单杠杆自平衡：冷场（缺口大）必来、交战中（配额满）必不来，无概率旋钮、无档位。
- **选型/token/间隔全不变**——只改"去哪"，不改"刷什么"。
- **新战区 F/G**：F 荒川北岸 `(-1500,-11000)` r2200 ground（陆地占比 1.00）/ G 千叶中部 `(10800,-1800)` r2500 air。候选池 4→6。

**刻意没做**：任何热度数值旋钮（token 预算/刷怪间隔/XP 曲线/任务规模）。理由：`60km-density-pass` 两轮旋钮还没 playtest，本批只做结构性增压，**保住归因能力**。playtest 后若仍冷，第一杠杆是 density-pass 的 `TRAVEL_SPAWN_INTERVAL`，不是给拦截波加倍率。

### ② 王牌支援中队 — spec `events/ace-support-squadron`

`ace-squadron-tier` 早就预留了"非 BOSS 王牌中队"的位置，本批是**第一个实例**。

- **Su-35 ×5**（KNIGHT×2 + SNIPER×3 沿用基类角色分配），金橙涂装区分杂兵；`AceSupportSquad extends AceSquad`，`category="ace_support"`（**不打 boss**），tier 待遇全走 `AceTier.mark` **实例打标**。
- **热诱弹 2 命**（BOSS 档 4 命的支援降档——命数是 tier 唯一强度杠杆，本批把它**分档**了）+ jam 恒 1.00 + HP 100 + 耗尽不规避。击杀序列：2 骗 → 残血 → 第 4 发死。
- **全灭 = `grant_time_extension(60)`**（`game_time -= 60`，与出界补给时间税同机制反方向）→ HUD 战区倒计时**当帧 +1:00**；外加 100 XP/架。
- 进场即 `engage()` PURSUIT 锁玩家，**无待机相**；警告横幅"敌军支援"三语 + Tab 金橙菱形标记。
- 调度：首支 `game_time≥240s` / 前支结束后 ≥150s / 540s 截止 / 同场 1 支 / BOSS 阶段不触发（已在场的转撤离，被打回头应战、出界静默释放且**不给**时间奖励）。
- 顺带落了 tier 层欠账：`ace_gun.tres`（15 伤/1400m/1.0°散布/600 发，每项 ≥ 杂兵天花板 `enemy_gun_v8`）。

### ③ 战区奖励军械库 — spec `systems/zone-reward-arsenal`

- **武器进池**：子池新增 **火箭弹 / 电磁炮 / 激光**（★ 区不出电磁炮·激光）。领取即挂载即自动开火，进 `weapon_inventory` **换机/进化全继承**；roll 侧过滤"已持有同类"，领取侧降级 QMAAM 兜底。
- **次世代技能出卡池**：全仓恰好 4 条 `NEXT_GEN`（导弹蜂群/雾隐机动/凝视压迫/数据链）全部 `evolved:true` 移出三选一，改为奖励**第四类 nextgen**（★15/★★30/★★★40）。候选按可用性/stacks/跨区去重过滤，空则降级 weapon。
- **顺带修了个欠账**：`missile_swarm` / `evasion_stealth` 早在 720 批就被移出卡池但奖励链从未接通，是**拿不到的孤儿技能**——本批接通了。
- 火箭归类问题（`inrun-weapon-inventory` 的开放点）一并回答：**奖励得来的火箭**带 `inrun_reward` meta → 入库继承；**机型自带的火箭**（A-10/A-7）仍是底线武器随机体走、不入库。

## 6. 关键设计决策（避免接手人重新纠结）

1. **拦截波为什么用"hunter 配额缺口"当触发器**：它是现成的、已经反映"玩家当前受到多少压力"的量，且天然自平衡（拦截队被收编后占配额 → 缺口消失 → 不再触发）。用时间/概率触发都会引入需要调的第二个旋钮。
2. **为什么王牌中队走 `AceTier.mark` 实例打标而不是把 SU35 加进 `is_ace_type()`**：`is_ace_type` 是**按机型**判定，加进去会让**普通旅途刷出的杂兵 Su-35** 也拿到 tier 待遇（100 HP / 不吃 LOD / 无缩放）。`ace-squadron-tier` §4.1 明确要求非 BOSS 王牌不得假设 `category=="boss"`，本批走通了这条路径。bench 里有断言守着。
3. **为什么 +1 分钟是 `game_time -= 60` 而不是加 `WARZONE_PHASE_DURATION`**：后者会改**全局常量**影响所有局；前者是既有的时间税机制（出界补给 `+15`）的反方向，单点注入、HUD 零改动自动跟随。
4. **为什么 nextgen 走实体奖励 roll 而不是复活 `ZoneRewardRegistry`**：那个注册表是"一区一奖"的**覆盖**制且全仓无调用点（死表），复活它会覆盖掉战区的实体奖励，而且没有 build 可用性过滤——可能发出玩家吃不到的技能。走实体池天然带去重与过滤。
5. **为什么不动热度旋钮**：见 §1① 末段——保 `60km-density-pass` 的归因能力。
