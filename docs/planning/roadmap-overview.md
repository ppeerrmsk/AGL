## 项目现状（2026-04）

AGL 目前已经是一个可玩的俯视 2D 空战沙盒。**沙盒模式**用作实验场与调试入口，**生存模式**是主玩法循环。战斗底层（飞行物理 / BFM 战术 AI / 雷达锁定 / 武器系统 / 编队与地面单位）已经基本成型，敌人谱已经覆盖 9 种敌机（UAV / UCAV / J-7 / MiG-29 / MiG-23 / MiG-31 / F-86 / F-100 / Sentinel 指挥机），并拥有一套成熟的 Token 预算刷怪系统。

接下来的主力方向是**生存模式**：把"被动应对波次"升级成"玩家主动规划 Build / 选择战区 / 应对挑战"的完整循环。

---

## 下一阶段核心目标

1. **让战斗手感更诚实** —— 玩家应该能明确感知自己的武器射程、敌人的威胁方向、AI 的反应合理性。
2. **让 Build 有发挥的舞台** —— 中后期有配得上玩家投入的挑战。
3. **让一局与一局之间有差异** —— 通过战区选择与局外进度，避免重复感。
4. **让模式边界清晰** —— 沙盒与生存不应互相污染。

---

## 阶段路线图

按**优先级 + 开发顺序**分四个阶段。Phase 之间可以少量并行，但重心按顺序推进。

### Phase 1 · 基础体验修复（2~3 周）

目标：消化玩家反馈，补齐战斗体验上的明显短板。不引入新内容，只改手感与 AI。

- 敌人 AI 要能察觉机炮追尾
- 玩家能清楚感知自己机炮的有效射程
- 后期 UAV 刷新数量收敛
- 火箭弹敌人补 1~2 款

### Phase 2 · 内容扩展（1~2 个月）

目标：补充生存模式的内容密度，让每局体验有差异。

- 大地图战区系统（最核心，最大模块）
- 新敌人：非攻击性杂鱼（直升机 / 运输机 / 侦察机）
- 新敌人：精英变体 / 王牌飞行员
- 僚机招募与离队系统

### Phase 3 · 深度系统（2~3 个月）

目标：拉开不同 Build 的差异，建立长期游玩动机。

- BOSS 战：巨型 Boss + 王牌中队
- 技能树重做（层级 / 稀有度 / 机型独特）
- 经验曲线与奖励多样化
- 新机型持续加入
- 局外全局升级系统

### Phase 4 · 表现与打磨（并行 + 收尾）

目标：视听层面的完成度，对外发布前的最后一公里。

- 飞机图标表现升级 / 受击特效
- 音效与动态音乐
- 本地化（中英双语起步）

## 反馈优化（玩家体验）

以下是收集到的具体反馈，都放在 **Phase 1** 处理。

### 1. 敌人对机炮追尾没反应

玩家从 6 点钟位置用机炮追击敌人时，敌人 AI 只按照既定战术（前置射击 / 滞后追击）飞行，没有任何规避动作。**后果**：战斗失去紧张感，机炮变成"站桩射击"。

**方向**：AI 的威胁感知目前只响应"被导弹锁定"，需要补上"后方机炮威胁"的判定 —— 敌人在自己后方 60° 范围内、距离在其机炮射程的 1.5 倍以内、其速度矢量对准自己，就触发急转规避。

---

### 2. 玩家对自己机炮射程没感知

玩家不知道机炮什么时候打得到目标，盲射浪费子弹，命中率体验差。

**方向**：HUD 层面给反馈。可选方案：
- 目标距离小于机炮有效射程时，敌机图标染色
- 锁定目标时显示准星/射程圆圈
- 发射按钮颜色区分"可击中 / 不可击中"

这个优化沙盒模式也要同步做，两边都会受益。

---

### 3. 后期源源不断的 UAV 刷新

到了后期波次，敌人几乎全是 UAV，玩家 Build 没什么发挥空间，体验单调。

**方向**：
- 给 UAV 的 Token 预算占比设上限（每波 UAV 不能超过 X%）
- 高等级后 UAV 不再作为主力刷新源，只出现在编队护航、地面拦截等特定情境
- 配合后面"大地图"系统，把 UAV 封装成"无人机战区"的特色敌人

---

### 4. 对得起 Build 的挑战

升级 Build 成型后，缺乏配得上玩家实力的敌人，中后期"爽感"不足。

**方向**：这个问题在 Phase 1 只做缓解（把现有敌人的难度曲线拉陡一点），根治方案是 Phase 3 的 BOSS 战与精英系统。

---

### 5. 更多使用火箭弹的敌人

目前火箭弹机制（F-86 的 FFAR）登场频率低，这个机制的表现力没被充分利用。玩家希望多看到几架"泼洒弹幕"的敌人。

**方向**：新增 1~2 款携带火箭弹的敌人，候选参考：Su-7 / MiG-19 / A-1H Skyraider 这类空地兼用的老式机型。

## 核心特性规划

### 大地图战区系统（Phase 2 的主干）

**是什么**：生存模式开局选一张"战区"，每张战区有自己的敌人池、奖励池、环境特色。

**为什么要做**：目前所有局的刷怪规则是同一套，玩家没有"选择攻略方式"的感觉。战区系统能让每张地图感觉完全不同。

**战区初步设想**：

| 战区 | 特色 | 主打敌人 | 环境差异 |
|------|------|----------|----------|
| **开阔海域** | 反舰 / 舰载机战斗 | UAV 舰载群 + SAM 船 | 无遮蔽，视距极远 |
| **山谷走廊** | 低空突防 | AAA 密集 + 地面车队 | 地形遮蔽，雷达锁定困难 |
| **城市 / 工业区** | 高价值目标打击 | 护航编队 + 关键设施 | 附带平民伤亡惩罚？ |
| **冰原 / 极地** | 恶劣环境 | 老式战机 + 雷达干扰 | 能见度低，导弹命中率下降 |
| **沙漠基地** | 对抗预警网络 | AWACS + 护航王牌 | 空战节奏最强 |

现状：`survivor_map_select.tscn` 已经占位好了 5 个卡片槽，只有第 1 张解锁。Phase 2 把这 5 张填起来。

**奖励差异化**：每张地图通关解锁专属升级 / 机型 / 装备，和 Phase 3 的技能树稀有度和 Phase 3 的局外升级联动。

---

### 敌人生态扩展（Phase 2）

生存模式敌人目前全是战斗机。需要两个方向的补充：

**方向 A · 非攻击性杂鱼**（直升机 / 运输机 / 侦察机）：
- 高经验，低威胁
- 不主动攻击玩家，只巡逻
- 作为"填充 + 练手 + 经验奖励"的角色存在
- 可以作为某些地图的特产（运输机 → 补给战区）

**方向 B · 精英 / 王牌系统**：
- 精英版：属性 ×1.5 + 武器升级，随机生成
- 王牌：独立呼号与涂装，独立 AI 个性（冷血射手 / 机动大师 / 狡猾诱饵），击杀有额外奖励

---

### BOSS 与王牌中队（Phase 3）

解决"对得起 Build 的挑战"问题的根治方案。

**巨型 Boss**：
- 多阶段 / 多部位 / 对小口径武器有抗性
- 候选参考：Su-34、B-52、AC-130 这类"空中堡垒"概念
- 每 N 波触发一次，或作为战区终点战

**王牌中队**：
- 4~6 架精英战机组成的编队，每架都有呼号和独立 AI 个性
- 作为 Boss 战的"人形替代"，适合更注重缠斗的战区

---

### 技能树重做（Phase 3）

当前升级表是扁平的（20+ 升级平铺），需要重构成有结构的技能系统。

**四个扩展方向**：

1. **共通技能** —— 所有机型都能选，作为底层基础
2. **机型独特技能** —— F-14 的僚机控制、F-16 的多目标交战等，体现机型个性
3. **稀有度** —— 普通 / 稀有 / 史诗 / 传说四档，影响升级 UI 颜色和刷新概率
4. **地图专属技能** —— 某些升级只在特定战区刷出，和大地图系统联动

**前置 / 互斥**：当前代码已经有 `requires` 和 `exclusive_to` 字段占位，重做时直接用上，不需要底层改动。

---

### 经验曲线与奖励改善（Phase 3）

当前经验只靠击杀获得，后期升级节奏会略显平淡。

**改进方向**：
- 经验来源多样化：击杀、任务完成、支援友军、护僚机存活
- 连杀奖励：短时间内连续击杀触发倍率
- 等级曲线重新评估（当前是否过陡 / 过缓需要实战数据）

---

### 僚机生态（Phase 2）

目前僚机只能在开局由玩家选定，中途无法增减。这是个遗憾。

**目标**：
- 玩家可以在战斗中**招募**（招降的敌方 UAV / 地图事件奖励）
- 僚机可以**主动离队**（被击落后离场、弹药耗尽返航、任务完成返航）
- F-14 的"僚机指挥"独特技能和这个系统联动

现有的 Sentinel 指挥机的招募机制已经验证了技术可行性，Phase 2 把它抽成通用系统。

---

### 新机型陆续加入（Phase 2~3，持续）

候选清单：
- F-18（多用途战机代表）
- Su-27（重型空优对照 F-14）
- Mirage 2000（中轻型灵活代表）
- F-4 Phantom（老式多用途，机炮/导弹混合风格）
- A-10（对地特化，独特玩法）

每款机型加入前先定位"玩法上有什么独特性"，避免重复功能。加新机型有完整的 12 步流程（见 `docs/reference/playable-aircraft-workflow.md`），不会太难但要走全。

---

### 局外全局升级（Phase 3）

让"失败的一局"也有意义，玩家每局积累资源，局外永久解锁东西。

**风格参考**：Hades、Rogue Legacy 这类 roguelite 的元进度系统。

**解锁内容**：
- 新机型
- 局外起始升级（开局就带 1~2 个升级）
- 新战区
- 小额属性加成

---

## 表现层打磨（Phase 4）

这些不是玩法，但影响完成度。可以穿插在前面的 Phase 中零散推进。

- **飞机图标升级**：从纯线框 → 2D 精灵或多角度帧动画（保留俯视线框美学）
- **受击特效**：爆炸分级、火光、烟柱、击落慢动作
- **音效**：引擎 / 机炮 / 导弹 / 锁定告警 / 命中 / UI
- **动态音乐**：主菜单 / 战斗 / Boss / 紧急，基于战斗压力切换
- **本地化**：中英双语起步，Godot 内置 CSV 导入，需要先把硬编码字符串抽成 `tr("KEY")`

---

## 长期愿景

一年后的 AGL 应该是这样的体验：

> 玩家打开游戏 → 主菜单看到局外进度和已解锁的机型 → 进入生存模式 → 选一张战区（"今天想打海战"） → 选机型（"带 F-14 带 2 架僚机"） → 进入战斗 → 应对逐渐升级的敌人 / 遇到王牌中队 / 被 Boss 压力测试 Build → 死亡或通关 → 局外进度结算 → 解锁新东西 → 下一局。

每局 15~30 分钟，每次体验都因为**战区 × 机型 × Build × 王牌 / Boss 的随机性**而不同。
