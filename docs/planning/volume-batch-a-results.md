三种飞机共享缓存与材质，替换原型中相应机型的通用代理；当前总源模型 2180 三角、7 个 MultiMesh 批次，单共享视图。未知或未适配机型仍走现有代理/旧显示，不列为专属制作完成。没有修改飞机参数、AI、武器、库存/CD、伤害或实体数量。

可编辑导出在 `bench/results/`：`f14_batch_a.glb`、`a10_batch_a.glb`、`f47_batch_a.glb`、`desert_batch_a.glb`。制作源为 GDScript 几何，不是 `.blend` 工程；GLB 可供 Blender 导入编辑。分发时携带 `volume_batch_a_manifest.json`：含原始 source_url、许可与改作说明。A-10 参考归属 Kaboldy / CC BY-SA 3.0，F-14 参考标注 US Army 公有领域，F-47 为项目原创概念；没有复制 Tacview 模型。

Windows / Godot 4.7.2 Steam / GL Compatibility / RTX 3080，真实 Visual。旧原型与本批都保留三维地图、现有光照/阴影与战斗层，**不是纯二维正式版本对照**。前 3 秒预热，性能窗口中不额外读回 PNG。
