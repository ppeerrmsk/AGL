# 王牌中队 VULTURE / 秃鹫（MiG-31 × 8）—— 骑士 / Lancer 风格

> 玩家视角：无线电里一句"发现目标，准备开始交战"，Tab 图上八个亮点排成一道横墙从边缘
> 压来——快得离谱。一波导弹兜头罩向你的**每一架**飞机，然后它们头也不回地掠过战场飞远，
> 在天边画一个大弯，再度加速冲回来。你追不上它们；你只能等它们回头的那一刻。

## 1. 设计意图（Why）

- **用户需求（2026-07-26）**：第二支非 BOSS 王牌中队，与斗士 Su-35 队做**风格区分**
  （tier §3.7 风格库骑士位）：8 架 MiG-31，标准的高速骑士战术——高速飞过并向玩家小队
  **所有成员**发射一波导弹，掠远后转弯回来进行下一波；**没有机炮，只有导弹**；
  特点是速度极快，玩家需要想办法**贴近、近身**来击败它们。
- **风格差异化**：斗士考核"被咬住时怎么办"（防守、周旋、反杀）；骑士考核"追不上时
  怎么办"（拦截几何、时机选择）。两队合起来覆盖空战攻防两个半场，重复刷出也不腻。
- **Litmus 自检**：
  - 单杠杆：骑士的强度只有**速度**一根杠杆（机体档案原生 3200 km/h，全场最快）。
    不加血、不加机制、不加数值魔改；
  - 效果即反馈：8 机横列压过来 + 一波齐射的尾烟本身就是演出，无需 HUD 中介；
  - 确定性：本队零 flare、一发命中即死；齐射每波每机固定 1 发；分配算法保证
    玩家每架存活成员都被点名——"全队都要躲"是确定承诺，不是概率события；
  - 可学习（tier §3.7 反制答案）：直线追不上 → 玩家的答案是抓**回转段**减速窗口贴身强杀 /
    迎头对射窗口 / 齐射来袭帧的 flare 纪律。
- **反模式规避**：无二阶机制（无阶段转换/护盾/隐形）、无等级缩放、不占 token、
  编成固定（看到即认识）。

### 2.2 生存模型（2026-08-01 TTK 平衡修订）

**一发死 + 0 flare**：`max_hp` 不豁免 cap（≤75，一发死）；`max_flares = 0`，不补充、
**不做规避机动**。全队 8 机 = 8 DU。高速追击、掠远和回转重获窗口另收 `access_s=40`，
预计击破时间 `40 + 8×5 = 80 s`。旧配置 8 枚 flare 会变成 16 DU、预计 120 秒，因明显超过
60~90 秒上限而取消。骑士的防御只有速度，不再叠确定性命数。

## 3. 行为与公式（How）

### 3.1 队级状态机（掠袭循环）

| 相 | 进入 | 行为 | 退出 |
|---|---|---|---|
| CHARGE 冲锋 | 入场 / 回转完成 | 全队加力直线冲向玩家小队质心，横列保持（编队物理优雅：靠 bank/盘旋自然归位） | 最近距离 ≤ `R_volley` → VOLLEY |
| VOLLEY 齐射 | 距离窗口开启 | 按 §3.2 分配目标，各机对准即射（1 发/机）；**不减速** | 全员已射 / 窗口超时 2 s → EXTEND |
| EXTEND 掠远 | 齐射完成 | 保持航向直线掠过玩家队飞远（加力） | 与玩家队距离 ≥ `D_extend` → TURNBACK |
| TURNBACK 回转 | 拉开完成 | 减速至角点速度，物理回转对准玩家质心，重整横列 | 机头对准 ±30° → CHARGE |
| WITHDRAWING | 全队弹尽 / BOSS 解锁 | 复用支援中队撤离契约（直飞边界；被伤害回头应战；出界静默释放） | 终态 |
| ELIMINATED | 存活 = 0 | 时间奖励 + 通报（撤离中除外） | 终态 |

**被打断不改相**：被锁定/被咬不触发任何转相（tier：不做规避机动）。骑士的防御是速度与
那 1 枚 flare，不是机动逻辑——这保证整个循环从头到尾只有一套可学习的行为。

### 3.2 齐射目标分配（覆盖玩家全队）

```
VOLLEY 窗口开启帧：
  targets = 玩家小队存活成员列表（含玩家操控机，按 squad_slot 排序）
  attackers = 本队存活成员（按横列位次排序）
  attacker[i] 的目标 = targets[i mod targets.size()]
```

- 玩家满编 9、攻方 8：至多 8 人被点名（漏掉 1 人，可接受——弹幕语义是"全队都要动"）；
- 玩家 4 机：每人被 2 发点名（8 = 4×2），压力均匀；
- 发射条件：机头对准分配目标 ±20°（横列冲锋几何下自然满足）；2 s 窗口内不满足 →
  该机本波放弃（**不追着拧机头**——武器对准优先级铁律的反面特例：骑士宁可空过也不破坏
  掠袭直线，否则循环退化成缠斗）；
- 分配只在窗口开启帧算一次，不做弹道中重分配。

### 3.3 与既有系统的关系

- **单机层**：复用 joust attack-run 的 RUN_IN / BREAK 两段速与折返基建（MiG-31 杂兵
  已是 Lancer 打带跑机型，[systems/joust-attack-run](../systems/joust-attack-run.md)）；
- **队级层**：新增独立小模块（横列保持 / 齐射窗口 / 目标分配 / extend-turnback 触发），
  走 AceSquad `_tactics_*` 钩子（同 wraith_tactics / poltergeist_tactics 的挂法，但**只有
  一套循环、无多相战术升级**——那是 BOSS 专属待遇）；
- **flare / 被锁**：既有 aircraft_flares 链路自动生效（jam 1.00 tier 分支已在）。
