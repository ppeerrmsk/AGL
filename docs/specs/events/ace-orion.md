# 宿敌 ORION / 猎户座（原创机体 Cre ×1）—— 跨局成长的独狼

> 玩家视角：没有无线电，没有横幅，没有任何提示。战场中段，一架看上去平平无奇的敌机
> 混在杂鱼里——但它不打你的僚机、不打第三方、不理会战区，它只朝着**你正在操控的那一架**
> 飞。你随手打掉它。下一局，它又来了，机号从 Cre-01 变成了 Cre-02，动作利索了一点。
> 第三十次，你发现你已经开始害怕这架"普通"的飞机了。

## 1. 设计意图（Why）

- **用户需求（2026-07-27）**：原创机体 Cre-01，代号 Orion。虽然是王牌中队但**只有一个人**。
  登场不会有提示，只是存在地图里、一直坚持追踪玩家正在操控的飞机。每次登场冲着玩家来，
  被击坠后计数 +1（**全局存档**），飞机变成 Cre-02~Cre-99。一开始非常弱（初始敌机级别），
  被击败次数越多越强——武器越来越好、AI 越来越高级。
- **tier 落位**：[ace-squadron-tier](../systems/ace-squadron-tier.md) §3.8 **宿敌条款唯一实例**
  （六项白名单豁免：单机 / 静默登场 / 伪装涂装 / 跨局成长 / 机号即呼号 / 无时间奖励）。
- **设计价值**：这是整个王牌体系里唯一一条**跨局叙事线**。其他中队每局重置，Orion 记仇。
  它把"玩家变强"镜像成"敌人变强"——你每一次随手的击坠都在喂它。成长曲线的读感目标：
  前十局是背景噪音，中间三十局是"这家伙有点东西"，五十局后是全场最危险的单机。
- **Litmus 自检**：
  - 单杠杆：强度只随**生涯被击坠计数 N** 单调爬升，无随机成分；同一 N 下每局完全一致；
  - 效果即反馈：变强的方式全部可观察（新武器挂出来 / 机动变利索 / 开始躲机炮），
    机号 Cre-XX 本身就是进度条，**不加任何成长 HUD**；
  - 确定性：档位表（§2.3）公开可推；击坠必 +1，无"白打"判定。
- **反模式规避**：不做局内缩放（局内从头到尾同一档）；不做二阶机制（无阶段转换，
  高档解锁的是**装备与数值**，不是新行为模式）；涂装伪装是宿敌条款豁免，不外溢。

  it should already have won.
- ja: Cre系対抗学習試作機。発注書の要求はただ一行——**負けたら学べ。学んだら戻れ。**
  撃墜された機体は最後の三十秒のデータを次の機体へ残す。契約は99号機まで。
  試算では、その頃にはもう勝っているはずだった。

## 3. 行为与公式（How）

- **追踪**：PURSUIT 玩家 `controlled_aircraft`（0.5 s 软维护重取，切控即换目标）；
  永不脱离、无 leash、无战区归属；
- **武器**：按档位挂载，行为走各武器既有 AI（机炮 / 导弹 / QMAAM 均为现成链路，
  Orion 零新机动代码——"AI 越来越高级"= 四维参数爬升，让既有战术层自己变强）；
- **档位应用**：spawn 时读 `orion_kills` → 查 §2.3 表 → 写 params/AI/装备，一次成型；
- **与杂鱼共处**：不参与中队/编队系统（squad = 独机）；不吃 hunter 配额、不占 token。

## 4. 结构与组成（Structure）

- `OrionNemesisEvent`（GameEvent 子类，独立轨道调度；模板参照 AceReinforcementEvent
  但**不挂**提示/台词/时间奖励）；
- `resources/enemy_cre.tres` 新建（基线 = 初始敌机级别；档位乘数运行时应用）；
- 成长表数据外置（`ace_squad_profiles` 同批的数据文件里放 Orion 档位表，调数值不碰代码）；
- CareerArchive 加 `orion_kills` 字段 + 宿敌区块渲染。

## 5. 验收标准（Acceptance / Litmus）

- [ ] **静默**：入场无任何台词/提示条/Tab 特标；EventLogger 有记录（调试可查）
- [ ] **死咬操控机**：全程只攻击玩家当前操控机；1-4 切控后 ≤1 s 内换咬新操控机
- [ ] **计数与进位**：击坠 → `orion_kills` +1 落盘；下局机号 +1、档位表生效；
      N=98 后机号恒 Cre-99
- [ ] **档位一致性**：同一 N 反复进局，武器/AI/性能完全一致；局内全程不变身
- [ ] **弱起点**：N=0 时玩家起手机可轻松击落（≈杂鱼下位档强度）
- [ ] **强终点**：N≥50 时为全场最难缠单机（顶格 AI + 0.50 闪避 + 满武装），但仍一发死
- [ ] **无奖励时间**：击坠不改 `game_time`；XP 按档发放
- [ ] 宿敌条款豁免面之外 tier 待遇齐全（LOD / token / 一发死 / BOSS 闸撤离）
- [ ] 档案页宿敌区块（机号 / 徽章 / N / 首遇日期；N=0 剪影）
- [ ] 性能：单机 LOD 豁免开销可忽略；bench / debug 局不入档
