# 王牌中队 GOOFIGHTERS / 怪火（Su-47 ×2）—— 眼镜蛇斗士双机

> 玩家视角：两架前掠翼的怪东西缠上了你。你咬住其中一架的六点，扣下扳机——它猛地
> 立起来，像被钉在了半空。你从它旁边冲了过去。等你反应过来，它已经落在**你的**六点，
> 格斗弹的告警响成一片。雷达兵报告说轨迹不像任何已知机型。老兵们管这叫：怪火。

## 1. 设计意图（Why）

- **用户需求（2026-07-27）**：中期登场。Su-47 ×2，装备格斗弹，会眼镜蛇。斗士型，
  狗斗为主。
- **考核命题**：**过冲管理**。斗士家族的第三课——MARATHON 考"甩不甩得掉"，
  GOOFIGHTERS 考"**收不收得住**"：它们会用眼镜蛇急减速把你的咬尾变成过冲，
  反手格斗弹补刀。习惯了无脑咬尾压扳机的玩家在这里翻车。
- **风格落位**：斗士 `gladiator` ×2（最小编成）；"眼镜蛇 + 格斗弹"是**装备特色**而非
  新战术——tier"一队一套战术"不破：战术仍是缠斗死咬，只是缠斗工具箱更毒。
- **机制复用**：眼镜蛇 = 既有 `CobraManeuver` 装备件（equipment 声明自动挂载；
  来袭导弹 ≤300 px / 咬尾者 ≤900 px 开火即自动触发，~3.3 s 机动窗 + 25 s 冷却）——
  Su-47 params 声明即得，零新机动代码。格斗弹 = QMAAM 派生（宽锁定锥 HOBS，
  [weapons/qmaam](../weapons/qmaam.md)），敌用降档。
- **Litmus 自检**：单杠杆（难缠度全来自"眼镜蛇 + 格斗弹"这对组合拳，机体不魔改数值）；
  效果即反馈（眼镜蛇是全场最醒目的机动，看见一次就懂发生了什么）；确定性
  （cobra 触发条件与冷却固定，玩家可以数它的冷却窗）。
- **反模式规避**：无二阶机制 / 无缩放 / 不占 token；cobra 是既有装备件不是 BOSS 特权。

### 2.3 分层防御：flare → 眼镜蛇（2026-07-27 用户定档）

它既有 flare 又有眼镜蛇机动，**用完热诱弹以后，才会使用眼镜蛇机动**。cobra 的全部
自动触发（来弹 / 咬尾）整体 gated on `flares_remaining == 0`：

| 层 | 状态 | 防御行为 |
|---|---|---|
| 第 1 层 | flare 在手 | 1 枚必躲 flare（tier 默认档）——第 1 发导弹**必定**被骗，命数读数纯净；**cobra 沉默** |
| 第 2 层 | flare 耗尽 | **cobra 解锁**：来袭导弹在冷却窗外可能被眼镜蛇甩掉（300 px 近触发），**冷却窗内（25 s）导弹必中即死**；机炮咬尾被反转过冲 + 格斗弹补刀 |

读感：**骗掉它的 flare，它才开始跳舞**——防御被剥一层，威胁升一档。这不是相位切换
（行为库从头到尾同一套，只是解锁顺序），与 tier"耗尽后防御归零"的默认语义是同构的
偏离：GOOFIGHTERS 耗尽后防御不归零，而是换成一件**有 25 s 冷却、可被数出来**的备胎。

### 2.4 玩家反制答案（写给 playtest 验收）

1. **第 1 发导弹是必赚的**：骗掉 flare 前它就是普通斗士——标准命数开局照常；
2. **flare 掉了就换打法**：别贴脸硬咬（900 px 触发圈），保持能量优势打外圈逼它先出招；
3. **数冷却**：骗出一次眼镜蛇（假咬尾 / 远弹逼跳）→ 数 25 秒，窗内导弹必中即死；
4. **拉开就赢一半**：它没有中距弹——脱离近界它只能追，追击战里格斗弹够不着你。

  （玩家侧竞选规则现成，敌侧开通道）；
