# AF-03（电磁炮狙击无人机 · Schemer）

> 一架紫黑色高速无人机，远距（5–8 km）用电磁炮（railgun）狙击玩家：2 秒充能扇形预警 →
> 0.5 秒预测提前量 → 一发 hitscan 闪电（60 伤、穿透）→ 退到 8 km 外冷却 9 秒再来。
> 定位：远距压力源 + 走位/环境惩罚，逼玩家贴近到机炮距离（它近战无防御）。

## 1. 设计意图（Why）

- **体验目标**：制造一个"你必须冲进去"的远程威胁。AF-03 在 BVR 距离几乎无法被空空导弹拦
  （高速 + 退场），玩家学到的解法是**贴脸**——它没有近战手段。同时充能扇形是明确预警，给
  玩家"读招—变招/钻云/拉低空"的反应窗口。
- **Litmus 自检**（docs/DESIGN_PHILOSOPHY.md）：
  - 威胁有清晰预警相（2s 扇形收缩）+ 可被环境/走位降低命中 → 过"惩罚先给预告"。
  - 有明确正解（贴近到机炮距离）→ 过"可读可解"。
  - 不是隐形墙：射程/冷却/命中规则全部可学习。
- **反模式规避**：电磁炮**伤害恒定 60、不随等级缩放**（HP 缩放但火力不缩放）——避免后期变成
  "一发秒杀"的数值海绵式难度；难度来自距离与节奏，不是伤害膨胀。

## 3. 行为与公式（How）

### 3.1 充能 → 锁定 → 开火（AT_FIRE_TIME 模式）

```
进入开火意图（目标在雷达锁定 is_locked、±8° 锥内、2000–14000 m）：
  → 开始充能：扇形 UI 从 30° 半角收缩，charge_duration = 2.0 s
  → 充能中若目标脱锁 / 出锥 / 丢失 → 取消（charge_persistent=false）
充能完成（progress ≥ 1.0）：
  → AT_FIRE_TIME：aim_pos = 目标当前位置 + 目标速度 × fire_delay_after_lock(0.5)
     （预测提前量；直线匀速目标会被精准命中，变速/转向会偏）
  → 等待 fire_delay_after_lock 0.5 s
  → _fire()：见 §3.2
开火后 cooldown 9.0 s 才能再次充能
```

> ⚠ **与"敌人版充能即锁死"的区别**：枚举有两档——`AT_CHARGE_START`（充能瞬间锁死旧位置，
> 玩家可靠简单机动躲掉）与 `AT_FIRE_TIME`（开火时按当前位置 + 速度预测）。AF-03 用
> **AT_FIRE_TIME**，所以"直线飞=被打中"，主要反制是**变速/急转打乱提前量**与**环境失手**（§3.2），
> 不是简单侧移。

### 3.2 开火与命中判定

```
_fire():
  aim_pos = locked_aim_pos
  miss_chance = base_miss_chance(0.15)
  若目标在云中:   miss_chance += cloud_miss_bonus(0.30) × 云密度
  若目标 altitude < 3500 m:  miss_chance += low_alt_miss_bonus(0.20)
  roll: 若命中失败 → 在最终方向加横向角度扰动（打偏，仍发射束）
  发射 hitscan 闪电束：从机口沿 aim_pos 方向延伸到 max_range_m
  穿透：束路径上所有 CombatUnit / Missile / GroundUnit 受 60 伤
  视觉：4 段抖动闪电，红橙色，1.0 s 消隐
```

高速散布（仅 `fast_target_*`）AF-03 关闭（max_chance=0），故只有环境 miss 起作用。

## 4. 结构与组成（Structure）

普通 Aircraft（非 boss）：`AircraftParams(enemy_af03.tres)` + 一件 `RailgunEquipment`，挂
`AIController`。无挂点系统、无子控制器。电磁炮逻辑全在 `RailgunEquipment.tick/_fire`（state 走
`equipment_state["railgun"]` 字典，不写实例字段，多 mount 复用同一 .gd 类）。silhouette 用默认
fighter（未覆写）。受 7000 px 远距清理（未设 `skip_far_cleanup`）。

## 5. 验收标准（Acceptance / Litmus）

- [x] 充能扇形恰好 2.0 s 收缩；脱锁/出锥即取消
- [x] AT_FIRE_TIME：直线匀速目标被精准命中；急转/变速可偏掉
- [x] 开火后冷却 9.0 s，期间不再充能
- [x] 2000 m 内不充能；超 14000 m 不接战；±8° 锥外不开火
- [x] 命中 roll：晴空 15% / 满云 45% / 低空满云 65%；束穿透并摧毁路径上导弹
- [x] 电磁炮伤害恒 60，跨等级不变；HP 按 `90×(1+0.15(L-1))` 缩放
- [x] 同时最多 1 架（instance_cap=1）；Lv8 起 5%→18% 概率；单机不编队
- [x] radar_range 与 max_range_m 对齐（7000 px = 14000 m）
- [x] Archetype 名（Schemer）不出现在 UI / display_name（见 feedback_ai_archetype_internal）
- [x] 性能：单机 + hitscan，无每帧全场扫描；Lv8+ 压测 FPS 掉幅 < 15
