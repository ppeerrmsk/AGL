# SNOWBLIND「雪幕」支援机（范围隐形 Schemer）

> 一架藏在移动灰色风雪区中心的无武装电子战支援机：圈外只能看见圆心处不可交互的本体轮廓，
> 看不见可选择、锁定或攻击的实体；任一直属飞机闯入雪幕后，整支直属小队才会看清圈内编成与真实本体。

`SNOWBLIND / 雪幕` 是工作名；改名不改变本 spec 的机制与数值。

## 1. 设计意图（Why）

- **体验目标**：给“在安全距离建立锁定、逐个清空所有敌机”的超视距打法加入一个空间题。
  玩家能预先看见危险区域与圆心轮廓，却不知道里面的精确编成；必须决定绕开、整队压入或派侦察机破幕。
- **角色定位**：`Schemer / ew`。它本身不输出伤害，唯一价值是改变敌机能否被发现、锁定和远程制导；
  被侵入后只会逃离入侵者，绝不转入缠斗，也不获得攻击兜底。
- **编队玩法**：单机玩家必须亲自进入雪幕；多机玩家可以派一架飞机破幕、让外圈成员通过共享数据链接战。
  多机的侦察优势由 `squad-xp-threat-balance` 的经验稀释、热度和 Token 响应共同支付，不在本敌人内额外惩罚。
- **Litmus 自检**：
  - 信息察觉：灰色移动风雪、不可交互的圆心轮廓、破幕显形和核心坍塌都肉眼可见。
  - 可读可解：正解是“进入半径后锁定真实本体”，不是在圈外点击轮廓；雪幕没有不可见边界。
  - 一击毙命：本体 HP 55，不是血牛；玩家破幕并建立有效锁定后，一发导弹即可结束机制。
  - AI 演戏：保护、被侵入后逃逸、失去被保护对象后撤离，行为与普通绕圈战机不同。
- **反模式规避**：不做全图隐形、不随等级扩大半径、不让隐形敌人从圈内无风险射击圈外玩家、
  不把“看不见”同时偷换成无敌、不用每帧全场扫描或 CPU 随机雪花。

### 2.4 视觉规格

| 状态 | 填充 | 边缘 | 风雪层 | 圈内单位 |
|---|---|---|---|---|
| 圈外观察/未破幕 | 冷灰白，主体 alpha `1.00` | 220px 软羽化，外缘 alpha `0.92` | 连续低速雾团 + 稀疏斜向雪带 | 全部实体隐藏；圆心只画静态本体轮廓 |
| 已破幕 | 同色 alpha `0.08–0.12` | 外缘 alpha `0.12` | 低对比残留风雪 | 全部显形，正常标签/尾迹；shader 圆心轮廓消失 |
| 坍塌 | 以上数值在 `0.80s` 内缓出到 0 | 同左 | UV 漂移同时减速到 0 | 从坍塌开始永久显形 |

- 边缘使用约 `440m = 220px` 羽化带；不画硬色墙。
- 风雪完全锚定雪幕本地坐标：两层连续 value noise 低速漂移形成实体雾团，叠加低对比度斜向雪带；
  禁止按固定 Hz 重抽整屏 hash、使用屏幕坐标噪点或高频 alpha 跳闪。
- 世界视图与 Tab 战术图都显示灰色覆盖；世界视图的同一个雪幕 shader 在圆心绘制暖灰红静态机体轮廓，
  只表达“这里有始作俑者”。该轮廓没有独立节点、碰撞、标签或目标身份，不能选择、下令、锁定或触发自动攻击；
  真实 Snowblind Aircraft 与其他圈内敌机在破幕前仍不得泄露呼号、标签、尾迹或可交战位置。
- 未破幕雪幕必须是 alpha `1.00` 的**实体遮蔽层**，主体区域完全不透出地图与圈内单位；只有 220px 边缘羽化带允许渐透明。
  破幕后才把 `concealment` shader uniform 从 `1` 切到 `0`，降为低 alpha 残留风雪以便读取真实编成。
- 圈内隐藏飞机同时隐藏机体、数据标签、目标框、生命条、雷达点和尾迹；旧尾迹在 `0.25s` 内淡出，
  避免用残留尾迹定位。雪幕本身始终可见。
- 一个雪幕只允许一个圆形 mesh / CanvasItem；动画完全在 shader 内进行，不每帧生成噪点或调用 `queue_redraw()`。

### 2.5 敌版参数基准审计

Snowblind 不读取任何玩家飞机数据；本体直接采用现有 Sentinel 的非战斗支援基线：

| 审计项 | Snowblind | 现有普通敌人基准与裁决 |
|---|---|---|
| 飞行 | 650km/h、3G、roll1.2、accel20 | 逐字段等于 Sentinel；不再混入 A-7 战斗机性能 |
| 生存 | HP55，固定不缩放 | 等于 Sentinel；没有 BOSS/王牌 HP 豁免 |
| 雷达 | 1200px、20°、99s | 等于 Sentinel；只用于支援导航，不具备可用攻击锁定 |
| 热诱弹 | 无 | 等于 Sentinel；被破幕后没有软防御或额外命数 |
| 武器 | 无 | 不引用玩家或敌方武器；雪幕机制已经占满能力预算 |
| 战斗 AI | 完全关闭 | 等于 Sentinel：不选敌、不锁定、不攻击；BREACHED 仅是导航撤离状态 |
| 机制预算 | 4000m雪幕、动态护卫 | 支付代价为纯支援、无 flare、Sentinel 级慢速机体、HP55一发死；圈外轮廓只提示机制来源，不提供攻击捷径 |

实现审计必须断言 Snowblind 本体和视觉资源均无 `resources/player/` 依赖；动态护卫使用各自独立普通敌版参数，
不会因为进入雪幕而获得额外 HP、flare、雷达或武器加成。

## 3. 行为与公式（How）

### 3.1 破幕与共享发现

```text
每 0.20s：
  direct_intruders = 存活、直属蓝色、distance_to(core) <= 4000m 的 Aircraft

  若 field_state == CONCEALED 且 direct_intruders 非空：
      field_state = REVEALED
      reveal_elapsed = 0
      将圈内所有 shroud_concealed 清除
      对圈内敌机与直属小队双方的旧锁定轨全部清零

  若 field_state == REVEALED：
      reveal_elapsed += 0.20
      若所有直属飞机 distance_to(core) > 4500m：clear_elapsed += 0.20
      否则：clear_elapsed = 0
      若 reveal_elapsed >= 3.0 且 clear_elapsed >= 2.0：
          field_state = CONCEALED
          对圈内敌机重新施加 shroud_concealed
          清除针对这些敌机的锁定与制导
```

- “直属蓝色”使用玩家当前直属小队身份，不以 `team == 0` 代替；绿色 Allied、友军机场飞机、AWACS、
  临时第三方单位都不能免费破幕。
- 任一直属飞机破幕后，发现结果通过数据链共享给**全体直属飞机**；不做逐观察者渲染。
- 支援机本体与圈内其他敌机一样写入 `shroud_concealed`；圈外看到的轮廓完全由雪幕 shader 绘制，
  不对应可交互实体。破幕后真实本体才显形、可选、可锁；其死亡、撤离完成或被远距清理时，
  场立刻进入 COLLAPSE，所有单位的 `shroud_concealed` 永久清除。
- Snowblind 创建当帧必须主动 `register(host)`：立即给真实本体写入 `sensor_hidden`，不得等待 Token 计数重算；
  1+2 编成完成后同帧 `refresh_now()`，立即隐藏两架护卫。F5/debug、bench、正式刷怪三条入口必须同语义。
- Spawner 每帧无条件调用控制器，由控制器内部 `0.20s` 自节流；不得再用 `_token_count_by_type` 或
  `has_active_state()` 作为外层 tick 门，否则 debug 生成与现有存档单位可能永远不被接管。

### 3.2 隐藏不是无敌

雪幕使用独立状态 `shroud_concealed`，不得直接把单位写成既有 `is_cloaked`。共享查询语义为：

```text
is_sensor_hidden = is_cloaked OR shroud_concealed
```

`is_sensor_hidden` 统一用于视觉、雷达、目标选择、玩家命令和导弹制导；物理命中仍区分两种状态：

| 系统 | `shroud_concealed` 时的结果 |
|---|---|
| 机体/标签/雷达点/目标框/尾迹 | 不绘制 |
| 鼠标选中、玩家命令、AI 选敌 | 不可选；已有目标主动释放 |
| 雷达锁定进度 | 立即清零且不能累计 |
| 已发射制导导弹 | `has_guidance = false`，保持当前速度/航向直飞，不删除导弹 |
| 自动机炮/自动武器扫描 | 不把隐藏飞机列为候选 |
| 盲射子弹、火箭、无制导弹体的物理碰撞 | **仍可命中并造成正常伤害** |
| `is_cloaked` 的既有子弹穿透语义 | 保持不变；不被本 spec 修改 |

因此玩家可以向灰区盲射，但不能靠 UI、锁定或制导得到精确解；偶然命中是允许的技巧/运气，不是漏洞。

### 3.3 跨边界交战公平规则

在 CONCEALED 状态，雪幕是**双向传感器遮断**，不是隐形炮台：

- 圈外玩家/Allied 不能锁定或自动攻击圈内敌机。
- 圈内敌机不能获得、锁定或攻击圈外蓝色/Allied 飞机；既有跨边界锁定进度清零。
- 任一制导导弹的发射者与目标若处在雪幕两侧，立刻失去制导；弹体继续飞行。
- 敌机不得在圈内预先累计锁定，等破幕当帧立即发射；REVEALED 后所有锁轨从 `0` 开始。
- 一旦直属飞机进入 4000m，整场变为 REVEALED，圈内外双方按正常 ROE 接敌。

这条规则确保灰圈是一段“知道核心在哪里，但必须进入后才能交战”的信息空间，而不是玩家看不见却持续挨打的不可解惩罚。

### 3.4 Schemer 状态机

| 状态 | 进入条件 | 行为 | 离开条件 |
|---|---|---|---|
| `INGRESS` | 特殊包生成 | 与两架护卫物理飞入；雪幕从生成当帧生效 | 到达战区/巡逻锚附近 |
| `COVER` | 正常在站 | 位于被保护中队质心相对最近直属飞机的后方 `1200–2200m`；巡航，不锁定不开火 | 直属飞机破幕 → BREACHED；无可保护敌机 10s → EGRESS |
| `BREACHED` | 场变 REVEALED | 对最近入侵直属飞机取反方向，以自身普通最高速度直飞；不加力、不规避、不攻击 | 至少 `8s` 且复隐成功 → RESET；本体死亡 → COLLAPSE |
| `RESET` | 重新 CONCEALED | 返回最近可保护常规敌机中队后方，重新建立覆盖 | 距其质心 ≤2200m → COVER；再次破幕 → BREACHED |
| `EGRESS` | 连续 `10s` 无本体外存活敌机可保护，或 BOSS 阶段开始 | 以普通最高速度飞向最近世界边界外；雪幕继续隐藏真实本体和偶然进入的普通敌机，圆心轮廓随场移动 | 飞出/超时清理 → COLLAPSE |
| `COLLAPSE` | 击毁/撤离完成/清理 | 0.80s 消散；不再施加隐藏 | 释放控制器 |

可保护对象 = 存活普通敌方 Aircraft，排除本体、BOSS、王牌、Adds、演出演员和正在 EGRESS 的单位。
绑定的两架护卫死亡后，本体可在 `12000m` 内改挂最近一个合格敌方中队；没有目标时开始 10s 空场计时。

### 3.5 初始护卫与场内吸附

- 初始护卫在本体机头前方 `800m`、左右各 `600m`，三机处于同一高度档；全部在 4000m 雪幕内。
- 两个护卫槽分别从**生成当刻的常规战斗机候选池**独立抽取。候选必须通过当前热度/响应等级、
  解锁与退役、Token 余量、实例上限、生成冷却和专属排除检查；不得使用生成后的热度变化反向换机。
- 两次抽取互不要求同型：允许 `F-16 + MiG-31` 等混编，也允许两次抽到同型；第二次抽取时必须重新读取
  第一架已经消费后的 Token 余量与实例上限。
- 护卫保留自己的原型主循环，不被雪幕强行改成 Schemer；但必须遵守 §3.3 的跨边界停火。
- 雪幕会隐藏任何后来进入半径的敌方 Aircraft，不要求加入本体编队，也不改变其 Squad 归属。
- 本体只跟随一个保护中队的质心，不逐机追赶掉队者；其他敌机飞出 4000m 后立即按正常可见规则显形。

## 4. 结构与组成（Structure）

- `Aircraft` 本体：独立 Snowblind 参数和轮廓；飞行/生存/雷达逐字段采用 Sentinel 基线，无 flare、无武器、战斗 AI 关闭。
- `SnowblindShroud`：每个本体唯一的范围控制器，持有场状态、低频成员集合、破幕计时与跨边界查询；
  只扫描一次 `CombatUnit.all_units`，在集合变化时写入/清除状态。
- `SnowblindShroudVisual`：单圆 mesh + 单材质；世界视图 shader 动画与 Tab 图简化覆盖共享同一状态数据。
- `shroud_concealed`：Aircraft 的独立传感器隐藏标志；与 `is_cloaked` 合并到 `is_sensor_hidden()` 查询，
  但不继承光学隐形的物理子弹免疫。
- 刷怪层使用“特殊支援包”入口创建本体和两个独立动态护卫槽；不把这种跨机型混编包塞进常规单机型 Squad 抽取。
- 生命周期只有 Snowblind 控制器拥有隐藏状态；退出树、清理、BOSS 转阶段和本体死亡都必须统一走一次幂等清场。

## 5. 验收标准（Acceptance / Litmus）

- [ ] 圈外能连续看见一个半径 4000m 的灰色风雪区移动，圆心有清晰的 Snowblind 暖灰红轮廓，能读出“始作俑者”位置。
- [ ] 圆心轮廓不是实体：没有标签、呼号、雷达点、碰撞或独立节点，不能选中、下令、锁定或触发自动攻击。
- [ ] 圈外看不到圈内任何真实敌机，无法选中/下令/积累锁定；已有玩家锁定清零，已发射导弹失去制导后直飞。
- [ ] 隐藏单位不是无敌：向灰区盲射的子弹/火箭若真实碰撞，照常造成伤害。
- [ ] 任一直属蓝色飞机进入 4000m 后，至多 0.20s 内让圈内其他敌机对整支直属小队显形；绿色 Allied 进入不触发。
- [ ] 擦边后至少显形 3.0s；所有直属飞机离开 4500m 并持续 2.0s 才复隐，无边界闪烁。
- [ ] CONCEALED 时圈内敌机不能锁定/攻击圈外玩家；REVEALED 后双方锁定都从 0 开始，不发生破幕当帧预蓄力齐射。
- [ ] 破幕后真实本体显形，只按导航巡航/撤离，不机炮、不发导弹、不锁定、不规避、不进入 BFM；无 flare，有效导弹命中一发击毁。
- [ ] 本体击毁后 0.80s 内雪幕坍塌，所有被覆盖敌机永久显形，锁定/选敌恢复，无残留隐藏状态。
- [ ] 初始包固定为 1 本体 + 2 动态护卫；两槽从当刻热度允许的任何常规战斗机独立抽取，可同型或混编，
      并逐架消费 Token/实例上限；预算不足、冷却中、同场已有或累计达到 2 时不生成。
- [ ] 单机、3机、6机、9机各实测：单机可以亲自破幕；多机可以派侦察机破幕并由外圈队员接战；机制不要求多机才能解。
- [ ] 世界视图和 Tab 图都能读出灰区边界；连续雾雪不高频闪烁，圆心提示轮廓稳定清晰但不会被误认成可点击实体。
- [ ] 未破幕主体 alpha =1.00，地图和圈内单位完全不会透出；破幕后 alpha 降至 0.08–0.12，真实机体与标签清晰可读。
- [ ] F5 单机/普通编队两种入口刷 Snowblind：创建当帧本体不可选，编成完成当帧护卫不可见；不等待下一轮旅途刷怪 Token 重算。
- [ ] 性能：控制器严格 5Hz、同场上限 1、无每实体 `_process`/`_draw`、无 CPU 随机雪花；
      生存模式 Sentinel + Lv5/Lv15 + 9直属机压力测试 FPS 不低于 60，较对照掉幅 <15。
- [ ] 回归：F-47 既有 `is_cloaked` 仍保持子弹穿透/导弹失导语义；Snowblind 的盲射可命中不会污染 F-47。
- [ ] 回归：BOSS 阶段无雪幕残留；清理/撤离/切控/换帅不会保留已释放本体或旧直属机引用。
- [ ] i18n：图鉴名、描述、首次破幕提示（若保留）三语齐全；Archetype 名不进入玩家可见文本。
