# F-22「四锁狙击编队」常规敌版

> 克制紧密大编队的远程 Schemer：铺开不同目标、短促齐射、立刻脱离；玩家压近即可破坏它的攻击循环。

## 1. 设计意图（Why）

- **体验目标**：让九机导弹墙面对可读的远距反编队威胁，同时确保单机玩家每轮最多只承受一条锁定。
- **Litmus 自检**：威胁来自锁定提示、目标分配与 12 秒攻击通场，不靠堆血；首弹离架后暴露，玩家能主动追击。
- **反模式规避**：不复制玩家 F-22 数据；不具备机炮、持续缠斗、BOSS 抗性或多命热诱弹；四锁不能白送给全能机体。

## 3. 行为与公式（How）

### 3.1 主循环

| 状态 | 时长/触发 | 效果 |
|---|---|---|
| SETUP | 未接近 3000m，存在锥内直属目标 | 队级分配本轮不同目标，逐轨累计锁定 |
| EXECUTE | 至少 1 轨完成 | 只对完成轨道按 0.15s 间隔各射 1 发；不等待凑满 4 轨 |
| EGRESS | 首弹离架开始，末弹后至少 12s | 显形、禁止锁定/发射，以高速拉开；玩家近压也进入此态 |
| COOLDOWN | 12s 完成且恢复安全距离 | 清本轮目标集合，才允许下一轮重新覆盖相同直属目标 |

### 3.2 队级锁位

```text
F = 同一 F-22 中队存活机数
N = 玩家直属存活机数
squad_lock_slots = min(4 × F, N)
```

- 同一轮每个直属目标最多一条锁；单机玩家面对三架 F-22 仍只有一条锁。
- 候选必须同时处于各自雷达距离与锥内；绿色 Allied 不占槽。
- 某目标出锥只清该目标轨道，不影响其它轨道。
- F-22 不得在任何运行时分支转 Gladiator；被贴近只防御脱离。

## 4. 结构与组成（Structure）

- 独立 `AircraftParams` 敌版资源与一枚敌用 flare 资源。
- 每个 F-22 一个多锁控制器；同队由长机持有本轮目标分配，低频更新锁轨。
- 不新增逐机 `_process`；控制器骑 AI 决策节奏，发射队列只在活跃齐射期间更新。

## 5. 验收标准（Acceptance / Litmus）

- [x] 1/4/9 机玩家面对 1–3 F-22 时，纯函数断言单轮锁位严格为 `min(4F,N)` 且目标不重复。
- [ ] 至少一轨完成即发射，间隔 0.15s；末弹后 12s 内不能重新锁定或发射。
- [ ] 玩家进入 3000m 会打断锁定；F-22 不转入持续缠斗。
- [x] 资源审计 HP70→运行时≤75、4600px/30°/3.5s、1 flare fail0.10、无机炮，武器只走敌 V-tier。
- [x] 生成配置遵守 Token10、同场3、累计6、150s 冷却、1–3 机与三队防重复。
