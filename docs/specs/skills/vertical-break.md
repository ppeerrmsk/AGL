# 垂直越过

> 当前操控机按 R，根据所在高度自动向仍有空间的一侧做一次垂直换层：低空拉升，中高空俯冲，以能量代价换取穿越火线的窗口。

## 1. 设计意图（Why）

- **体验目标**：把 AGL 的虚拟高度变成玩家可主动使用的战术维度，并让爬升耗速、俯冲增速形成肉眼可读的能量交换。
- **Litmus 自检**：高度、图标尺度、速度和轨迹同时变化；长冷却与落点高度形成真实后果。
- **反模式规避**：不把 800–1400m/s 直接塞进既有 PE↔KE 公式；专用能量预算有硬上限，避免瞬间抽空或灌满水平速度。

## 3. 行为与公式（How）

### 3.1 高度曲线

设 `t=elapsed/1.30`，`ease(t)=3t²−2t³`，方向 `dir=+1`（LOW）或 `−1`（MID/HIGH），有效高度差为经过上下界裁切后的 `Δh`：

`altitude(t)=start_altitude + dir × Δh × ease(t)`。

动作期间由专用模块主张高度，普通 `target_altitude` 收敛不再重复推进；平面航向和前向移动继续运行。

俯视模型同步表现垂直姿态：`pitch_visual(t)=sin(πt)`，机体本地纵轴缩放为 `lerp(1.0, 0.40, pitch_visual)`，横轴保持原宽；首尾恢复 100%，尾焰锚点使用同一纵向倍率。爬升与俯冲都产生俯仰投影，高度数值和既有高度尺寸变化负责区分方向。

### 3.2 有界能量交换

- 不把瞬时 `vertical_speed=Δh/Δt` 直接交给既有 PE↔KE 反抽项。
- 爬升累计速度倍率：`lerp(1.0, 0.82, ease(t))`；但速度不低于有效角点速度。
- 俯冲累计速度倍率：`lerp(1.0, 1.15, ease(t))`；但速度不高于有效顶速。
- 专用模块必须让常规速度推进、阻力和 G 损失继续存在；倍率表达的是本技能额外能量交换上限，不是每帧重复相乘。

### 3.3 EXIT 高度语义

- 动作完成后的新高度是物理事实，不自动飞回 ENTER 高度。
- 若动作期间没有新的显式高度命令，EXIT 时把目标高度设为动作终点高度。
- 若动作期间收到新的显式高度命令，先完成动作，再按队列中的最新高度命令飞行。
- 切控后原飞机完成动作，并由其新的 AI 所有者从终点高度继续决策。

### 3.4 AI 僚机自动触发

AI 僚机满足任一条件时尝试释放，仍需技能就绪、冷却为 0、可用垂直空间 ≥600m 且未处于更高优先级动作：

- 最近来袭导弹距离 ≤1100m；或
- 有效敌机位于本机后半球、距离 ≤`1.5×gun_range`，且沿视线闭合率 >0。

LOW 档自动拉升，MID/HIGH 档自动俯冲；当前操控机不走本自动分支。

## 4. 结构与组成（Structure）

- 高度模块提交绝对高度曲线和一次性累计能量预算，不修改全局 `altitude_authority_mult`。
- 物理层提供“本帧由特殊机动主张高度/能量”的窄接口；预测路径使用同一曲线或在动作窗口内明确冻结预测，不能与实物理分叉。
- 技能的输入、命中、冷却、命令队列和清理由共享协调器承担。

## 5. 验收标准（Acceptance / Litmus）

- [x] LOW 档净拉升 900±10m；MID/HIGH 净俯冲 900±10m，均在 1.30s 完成。
- [x] 上下界空间不足 600m 时拒绝且不进冷却；空间介于 600–900m 时按合法净位移执行。
- [x] 爬升后水平速度累计损失不超过 18%，且不低于有效角点速度；俯冲增速不超过 15% 且不超有效顶速。
- [x] 动作结束保持终点高度，不出现立即反向飞回旧目标高度。
- [x] 动作中下新的高度命令，EXIT 后执行最新命令。
- [x] PE↔KE 回归中不出现水平速度瞬间归零、负值或异常顶速。
- [x] 动作首尾机体纵向比例为 100%，中点为 40%；横向翼展不因俯仰收缩，尾焰不脱离机体。
- [x] 18s 小队共享冷却不能靠切控绕过。
- [x] 与其余四种 R 技能正常卡池双向互斥，F4 可直接验收。
- [x] AI 僚机在 1100m 内来袭导弹或后半球近距机炮威胁下自动使用；切控为当前机后停止自动触发。
- [x] 三语名称、描述和冷却文本齐全。
