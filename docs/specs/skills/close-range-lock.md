# 近距捕获（斗士稳定技能）

> 越逼近敌人，主雷达锁定越快；把近距接敌本身转化为锁定优势。

## 1. 设计意图（Why）

- **体验目标**：给斗士轴一张不依赖击杀、不过量增加伤害的近战收益卡。玩家主动缩短距离后，能直接看到锁定环更快填满。
- **轴身份**：这是“用近距风险换取武器窗口”的斗士技能。它可以服务导弹，但不奖励远程滞空；只有真正逼近目标才获得收益。
- **Litmus 自检**：距离是玩家可直接控制和观察的几何杠杆；效果通过现有锁定进度即时反馈，不新增 HUD 中介层。
- **反模式规避**：不改全局 `lock_time`，不提高远距离锁定，不增加伤害，不扫描额外目标，不影响敌人锁定玩家。

## 3. 行为与公式（How）

### 3.1 动态倍率

对每一个已经通过敌我、锁定免疫、雷达锥与有效距离判定的目标：

```text
effective_range_px = max(射手当前有效雷达射程, 1)
distance_ratio = clamp(射手与目标平面距离 / effective_range_px, 0, 1)
close_lock_mult = 1 + (1 - distance_ratio) × (2.0 - 1.0)
final_lock_rate = existing_lock_rate × close_lock_mult
```

校准点：

| 目标距离 / 当前有效雷达射程 | 倍率 |
|---|---|
| 100%（雷达边缘） | ×1.00 |
| 75% | ×1.25 |
| 50% | ×1.50 |
| 25% | ×1.75 |
| 0%（理论贴身） | ×2.00 |

倍率连续变化，没有距离档位跳变。目标超出雷达锥或有效射程时仍按既有规则停止/衰减锁定，技能不能越过合法性门槛。

### 3.2 作用边界与叠加

- 只作用于**持有该技能的玩家小队 Aircraft 作为射手**时；敌机与第三方单位不生效。
- 对所有可被主雷达锁定的敌对 `CombatUnit` 生效，包括飞机、地面单位与舰船挂点；锁定免疫的舰体仍不生效。
- 只加快主雷达 `radar_targets` 的照射累积；不影响 QMAAM 等副武器独立锁定、武器 CD、导弹飞行性能或电磁炮充能。
- 与低空目标衰减、云层衰减、目标锁定抗性、签名技能、OVERLOAD、AWACS 等现有倍率**乘法叠加**；最后仍经过既有最大有效锁定时间硬下限。
- 不修改 `params.lock_time`，因此机体静态面板仍显示基础锁定耗时；战斗中的锁定进度条直接表现实际加速。

## 4. 结构与组成（Structure）

- 技能数据：稳定级、斗士显式归轴、全队发放、单层 `close_range_lock`；应用时写入飞机的倍率上限缓存。
- 消费位置：生存模式既有雷达锁定配对循环，在当前玩家锁敌倍率链中追加一次距离倍率；不得新增 `_process`、计时器或全场扫描。
- 距离基准：射手的当前有效雷达射程，包含既有高度倍率与雷达属性成长；不同机型自动归一化为相同曲线。
- 表现：复用锁定进度与锁定完成反馈，不新增独立状态图标。
