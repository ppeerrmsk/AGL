# 位移滚转

> 当前操控机按 R，自动选择更安全的一侧，用一次明显的横滚侧移穿过火线并回到近似原航向。

## 1. 设计意图（Why）

- **体验目标**：让玩家以“观察边界与来敌方向 → 主动穿越火线”的方式换位，而不是获得常驻闪避率。
- **Litmus 自检**：位移幅度、横滚姿态和弹体穿越都直接可见；15 秒冷却保证它是决策而非连按。
- **反模式规避**：该动作是明确的游戏空间侧移，不伪装成普通协调转弯；不增加永久速度/G/滚转属性。

## 3. 行为与公式（How）

### 3.1 轨迹

设激活位置为 `P0`，激活航向右向量为 `R`，安全侧符号为 `side∈{-1,+1}`，归一化时间 `t=elapsed/1.15`。

- 平滑函数：`ease(t)=3t²−2t³`。
- 侧移：`P_lateral(t)=P0 + R × side × 350 × ease(t)`。
- 普通前向运动继续由飞行物理累加；技能只叠加“本帧侧移增量”，不重写整条世界坐标。
- 表现航向偏摆：`heading_offset(t)=side × 78° × sin(πt)`；t=0 和 t=1 时偏摆为 0。
- 横滚视觉峰值在 t=0.5；动作完成后清除视觉偏移，不残留永久 bank。

### 3.2 安全侧选择

复用共享系统的激活快照与方向评分。候选轨迹以左右各 350px 的平滑侧移弧采样起点、中点和终点；任一样本越界则该侧无效。两侧均无效时拒绝释放。

### 3.3 中断

死亡/场景退出直接 ABORT；切控不打断。动作不因失去 combat target 中断。EXIT 后目标与命令按共享恢复规则处理。

### 3.4 AI 僚机自动触发

AI 僚机满足任一条件时尝试释放，仍需技能就绪、冷却为 0、轨迹合法且未处于更高优先级动作：

- 最近来袭导弹距离 ≤900m；或
- 有效敌机位于本机后半球、距离 ≤`1.5×gun_range`，且沿视线闭合率 >0。

当前操控机不走本自动分支。安全侧评分与玩家释放完全相同，不按 AI 身份改物理效果。

## 4. 结构与组成（Structure）

- 技能数据条目只声明稀有度、互斥、单层和标识。
- 位移模块只生成侧移增量与表现姿态；冷却、输入、命中和清理由共享协调器负责。
- 边界查询复用地图边界服务，不自建地图尺寸常量。

## 5. 验收标准（Acceptance / Litmus）

- [x] 无敌人且左右同样安全时固定向右，连续运行结果一致。
- [x] 靠近右边界时必选左侧；两侧均不容纳完整轨迹时拒绝且不进冷却。
- [x] 1.15s 内侧移 350±5px，结束航向与激活航向误差 ≤8°。
- [x] 普通前向速度继续生效；动作不会把飞机冻结在侧移轨迹上。
- [x] 不可命中只覆盖动作本体，1.15s 后第一帧恢复正常。
- [x] 15s 小队共享冷却不能靠切控绕过。
- [x] 与其余四种 R 技能正常卡池双向互斥，F4 可直接验收。
- [x] AI 僚机在 900m 内来袭导弹或后半球近距机炮威胁下自动使用；切控为当前机后停止自动触发。
- [x] 三语名称、描述和冷却文本齐全。
