# 陆地航母 BOSS

> 一台不依赖铁路的超大型履带式陆战平台：以低矮装甲车体、密集武器挂点和真实停机/起飞能力承担海岸线海上航母在纯陆地地图中的战场职能，但外形不是“海上航母装上履带”。

## 1. 设计意图（Why）

- **体验目标**：沙漠没有海面，仍要保留“发现航空母舰—看见甲板驻机—压制防空—阻止舰载机持续起飞”的航母体验。
- **战斗群目标**：陆地航母不是孤立巨车，而是由陆基 AEGIS、CIWS 车、SAM 车与攻城坦克组成的移动战斗群。玩家能够观察火力层次并自主决定先拆传感器、近防、远防或地面重炮。
- **身份边界**：陆地航母与超级武器列车是两个单位。陆地航母是单一连续履带舰体，不走铁路、没有逃脱即 Game Over；列车是十五节铁路编组，不能停机或放飞飞机。
- **参考图落实**：采用用户草图的低矮长车体、两侧贯穿履带、前部装甲楔面、后部装甲指挥舱/雷达桅杆、分散炮塔与武器格栅。停机能力用嵌入车体的四个停机/起降位表达；禁止贯穿式航母跑道、船艏轮廓、右舷舰岛和“海船落地”剪影。
- **Litmus 自检**：驻机必须是实际 Aircraft 实体并随甲板移动，起飞后交还标准 Aircraft AI；不能只画飞机符号或用定时器在远处凭空刷机。
- **反模式规避**：不与列车共享名称、路线或终态；不依赖海面判定；不新增高频全场扫描；防空挂点复用已有降频与火控实现。

### 2.3 防空挂点

| 类型 | 数量 | 位置/作用 |
|---|---:|---|
| CIWS | 4 | 四角，近距对空与来弹拦截 |
| VLS/SAM | 2 | 前/后甲板，远程防空 |
| 空爆炮 | 2 | 两舷中段，区域压制 |

八个挂点均为真实战斗节点，随刚体舰体移动；主体摧毁或退出场景后全部清理。本版挂点不可独立摧毁，伤害统一结算到主体 HP。

### 2.4 陆上航母战斗群护卫

护卫是航母之外的独立 `GroundUnit`，拥有各自 HP、锁定框与死亡终态；不会把伤害转移给航母。护卫只在遭遇生成时出现一次，摧毁后不补充，也不计入舰载机整场创建上限。

| 单位 | 数量 | HP | 核心装备 / 参数 | 战场职责 |
|---|---:|---:|---|---|
| 陆基 AEGIS 指挥车 | 1 | 120 | 5000px 360°相控阵雷达；每 0.5s 向 4000px 内护卫共享锁定进度，上限为接收者锁定时间减 0.5s；2 组远程 VLS、8 发、10s 冷却 | 战斗群传感器与远程火控核心；优先摧毁后，其它车辆仍可自行搜索，但失去提前锁定 |
| 陆基 CIWS 车 | 2 | 60 | 每车 1 座 CIWS；1400px 来弹拦截、1000px 对空扫射，复用既有真实弹道、目标认领与降频 | 左右翼近防；以交叉火力保护航母、AEGIS 和 SAM 车 |
| 陆基 SAM 车 | 2 | 80 | 每车 4 发 HQ-7；3000px 雷达、2.5s 锁定、6s 冷却、60 伤害 | 前后远防；迫使玩家改变高度、航向或先拆防空节点 |
| 沙漠攻城坦克 | 1 | 600 | 复用既有正式单位：对地主炮、2×CIWS、1×32km SAM、1×空爆炮 | 编队前卫；压制友军地面推进，并提供不可忽视的重型护航火力 |

编队总量固定为 6 辆护卫。陆基 AEGIS、CIWS 车和 SAM 车属于可快速拆除的普通/轻装甲目标；攻城坦克是唯一额外重装目标。不得把六辆车合并成航母的不可见属性加成。

## 3. 行为与公式（How）

| 状态 | 进入 | 行为 | 退出 |
|---|---|---|---|
| `PARKED/PRE_STAGE` | Boss 生成 | 主体在边界内生成并先向地图中心推进 1400px；4 架 F/A-18 停在嵌入式停机位；防空挂点工作 | 正式接战 |
| `PARKED/PRE_STAGE` 护卫 | Boss 生成 | 6 辆护卫从地图边缘与航母共同入场，并向各自编队槽位收拢；不得在玩家视野内凭空生成 | 正式接战 |
| `ENGAGED` | 横幅结束 | 立即放飞 2 架；此后每 120s 放飞 1 架，累计创建不超过 8；护卫保持分层防空并随航母推进 | HP=0 |
| `DESTROYED` | 航母 HP=0 | 清除驻机与舰体挂点；仍存活护卫进入正式 Boss 清场，不延迟胜利 | Boss 胜利 |

```text
deck_world_position = carrier_position + park_offset.rotated(carrier_heading)

airwing_created_total <= 8
safe_anchor = MapBoundary.clamp_inside(event_anchor, 2200px)

escort_count = 1 aegis + 2 ciws + 2 sam + 1 siege_tank = 6
aegis_shared_lock_progress = min(receiver_lock_time - 0.5s, source_lock_progress)
```

## 4. 结构与组成（Structure）

- `LandCarrierUnit extends GroundUnit`：连续履带舰体、陆地巡逻、甲板驻机刚体跟随、真实起飞、八挂点与装甲伤害。
- `LandCarrierBoss extends BossEncounter`：主体生成、首波/周期弹射、Boss 生命周期和 HUD 成员。
- 护卫编队：陆基 AEGIS 是新指挥/火控变体；CIWS 车复用既有真实 CIWS 逻辑；SAM 车复用 `SAMUnit`；攻城坦克复用现有 `Tier3SiegeTank`，但作为 Boss 护卫生成时不占普通战区唯一 3★名额。
- `BossRegistry` / Boss Debug：注册独立 `LAND_CARRIER` 身份；使用沙漠正式 MapDocument 进行直接验收。
- 海上 `CarrierShip` 仍服务海岸线/海战；两者只复用“真实驻机→解冻起飞”的已验证语义，不共享水面移动基类。

## 5. 验收标准（Acceptance / Litmus）

- [x] 同一版本中 `ARMORED_TRAIN` 与 `LAND_CARRIER` 可分别实例化，名称、外形、移动和终态互不混淆。
- [x] 陆地航母是约 620×280px 的低矮履带陆战平台，可读出装甲楔首、贯穿履带、后部指挥舱、桅杆、VLS/炮塔与四个嵌入式停机位；不得读成海上航母装履带。
- [x] 任意事件锚点都把主体钳在距边界至少 2200px 的区域并向中心内收 700px；车头出生即对准第一航点，再向地图中心推进 1400px。

- [x] 接战首波 2 架从甲板起飞；后续每 120s 1 架；整场创建上限 8。
- [x] 4×CIWS、2×SAM、2×空爆炮为真实挂点；主体死亡后驻机与挂点清理。
- [x] 导弹按真实伤害扣 HP，不会一发软目标必杀。

- [x] 生命周期：全量 `lifecycle_gauntlet` 86/86；显示成员使用 Variant 安全收窄，驻机/挂点缓存主体死亡时清空，无 runtime gate。

- [ ] 性能：以航母、6 护卫、8 舰体挂点、4 驻机和首波 2 架起飞后的全可见交战为专项 `Shadow Visual` 压力样本，硬守 60 FPS。
