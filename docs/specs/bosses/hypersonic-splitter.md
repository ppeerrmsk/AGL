# 高超音速分裂体（原创名称待定）

> 一个会预告直线高速贯穿、过热散热，并在每次被击破后分裂成两个弱一档个体的机制 BOSS；玩家必须最终消灭 16 个最弱体才算真正获胜。

> **当前定位：概念占位 / 待讨论。** 本文只固化用户已经提出的核心循环与分裂拓扑。所有标为“待定”的数值、名称、规则和表现均未获批准，也没有对应运行时实现。

## 1. 设计意图（Why）

- **体验目标**：把“极端速度”转化为玩家可读、可躲、可反击的空间机制，再用史莱姆式持续二分把单体高速威胁逐步变成多目标战场管理。
- **双核心循环**：
  1. 单个个体：读线与移位 → 躲过高速贯穿 → 连续承压 → 个体散热 → 集中攻击。
  2. 整场战斗：击破强个体 → 一分为二 → 数量增加、单体变弱 → 最终清除 16 个最弱体。
- **分裂灵感**：层级概念参考 Apple M1 系列由高集成层级向较小层级拆分的印象（Ultra → Max → Pro → 普通），但不直接使用产品名作为定稿游戏名称。当前分裂树实际有五代，最终各代名称仍待设计。
- **现实造型 / 速度灵感**：可参考 X-43A 一类无人高超音速研究飞行器的低矮升力体轮廓、极端速度与热防护语汇，但 BOSS 不直接使用 X-43A、Hyper-X 或 NASA 名称。
- **速度例外**：AGL 常规飞机速度区间不直接适用于冲刺招式；超高速只在明确预警的直线冲刺中出现。巡航、转场和散热速度另行定稿。
- **Litmus 自检**：
  - 信息察觉：攻击线、冲刺残影、散热状态、分裂代际与真正的终末体必须一眼可辨。
  - BOSS 三维：独特机制已成立；最终 spec 仍须补齐高难度与智能选线，不能只靠速度、数量和 HP。
  - 笨重 + 延迟快感：威胁先预告，伤害后到达；玩家的预判与提前走位决定成败。
  - 立即反馈：每次击破必须当帧产生明确的破裂与双生反馈，不能让玩家误以为没有造成有效伤害。
  - 60 FPS：最坏情况为 16 个活跃终末体；线、残影、热迹与分裂效果必须有硬上限。
- **反模式规避**：
  - 不做“普通敌机 × 极高速度 × 厚血”的伪 BOSS。
  - 不做无预警、不可反应的高速碰撞。
  - 不让 8–16 个个体同时各画一条独立攻击线，把机制退化成无法阅读的弹幕噪声。
  - 不把每次分裂仅表现为 HP 和尺寸下降；代际差异必须能被直接感知。
  - 不在母体或中间体死亡时提前触发 BOSS 胜利结算。

### 2.2 分裂树（已确认拓扑）

| 代际 | 同代完整数量 | 当前代称 | 被击破后的结果 | 强度关系 |
|---|---:|---|---|---|
| G0 | 1 | 完整体 | 分裂为 2 个 G1 | 最强 |
| G1 | 2 | 待定 | 每个分别分裂为 2 个 G2 | 弱于 G0 |
| G2 | 4 | 待定 | 每个分别分裂为 2 个 G3 | 弱于 G1 |
| G3 | 8 | 待定 | 每个分别分裂为 2 个 G4 | 弱于 G2 |
| G4 | 16 | 最弱体 / 终末体（暂称） | 被击破后永久消失，不再分裂 | 最弱 |

确定性拓扑：

```text
1 × G0
  └─ 2 × G1
       └─ 4 × G2
            └─ 8 × G3
                 └─ 16 × G4（终末体）
```

- 完整战斗总生成数与总击破数固定为 `1 + 2 + 4 + 8 + 16 = 31`。
- 非终末体共有 `1 + 2 + 4 + 8 = 15` 个；每击破一个，场上存活个体净增加 1。
- 当 15 个非终末体都完成分裂后，场上达到理论最大值 16 个 G4。
- 分裂按父个体独立发生，不要求同代同步清空。因此战场允许 G1、G2、G3、G4 混代共存。
- **唯一胜利条件**：所有分支均已推进到 G4，且 16 个 G4 全部被击破；等价运行时条件为“存活节点为 0、待生成子代为 0、根分裂树已完整结算”。

## 3. 行为与公式（How）

### 3.1 单个个体状态机

| 状态 | 时长 / 触发 | 当前确定的效果 |
|---|---|---|
| `POSITIONING` 选线 | 待定 | 个体等待冲刺资格并选择下一条贯穿战场的攻击线 |
| `TELEGRAPH` 画线 | 待定 | 地图显示完整危险线；尚未造成冲撞伤害，玩家可下达规避移动 |
| `DASH` 冲刺 | 穿越所需时间，待定 | 沿预告线以极高速度贯穿；与危险带重叠的玩家单位接受一次冲撞结算 |
| `RECOVER` 回转 / 重定位 | 待定 | 为下一次画线做准备；不得以普通狗斗填充此阶段 |
| `COOLDOWN` 散热 | 连续若干次冲刺后，时长待定 | 明显减速并暴露可攻击窗口；散热表现和防御变化待定 |
| `SPLITTING` 分裂 | 非终末体 HP 归零 | 本体停止战斗、播放破裂反馈并生成两个弱一代子体；不触发胜利 |
| `TERMINAL_DEATH` 终末死亡 | G4 HP 归零 | 永久移除该叶节点；仅在整棵树清空时触发胜利 |

单体循环：

```text
POSITIONING → TELEGRAPH → DASH → RECOVER
       ↑                         │
       └──── 未达到散热条件 ─────┘

达到散热条件 → COOLDOWN → POSITIONING
HP 归零：G0–G3 → SPLITTING；G4 → TERMINAL_DEATH
```

### 3.2 分裂结算

伪代码契约：

```text
on_body_defeated(body):
    从存活节点集合移除 body
    if body.generation < G4:
        在待生成账本登记两个 generation + 1 子体
        完成分裂演出后原子生成两个子体
        从待生成账本核销本次登记
    if 存活节点为空 and 待生成账本为空 and 分裂树已完整结算:
        触发唯一一次 BOSS VICTORY
```

- 两个子体必须继承父体的分支身份，并拥有稳定唯一 ID，防止重复生成、漏生成或重复结算。
- 父体死亡、分裂演出和子体出生之间存在时间差时，待生成账本必须阻止“场上暂时为 0”导致提前胜利。
- 两个子体的出生位置、朝向、初始无敌 / 无碰撞窗口与是否继承父体热量全部待定。
- 中间体击破的 XP、功勋、击杀统计和技能击杀钩子必须单独裁定，避免 31 个节点被当作 31 个普通高价值敌人刷收益。

### 3.3 伤害与命中语义

- 每次冲刺对同一玩家单位最多结算一次，禁止在高速度、多物理帧或碰撞体重叠时重复吃满伤害。
- 高速命中不得依赖离散物理帧碰撞；最终实现应以预告线同源的扫掠线段 / 危险带做一次性判定，避免穿透漏判。
- 视觉危险带、判定危险带和最终飞行路径必须同源，禁止“线画在这里、实际撞在旁边”。
- 冲刺碰撞的最终伤害、无敌帧交互、主动特殊机动能否闪避、僚机是否同样受击，全部待定。
- 个体在冲刺过程能否被锁定、能否被命中、命中后是否减伤，全部待定；不能在未确认前假定永久无敌。

### 3.4 多体选线与并发（待设计）

后续设计必须回答：

1. 1、2、4、8、16 个体阶段分别允许多少条同时预警、多少架同时冲刺？
2. 多个个体瞄准当前操控机、预测位置、小队质心，还是在小队成员间分配？
3. 是否禁止近似平行 / 重叠危险线，避免视觉看似一条却重复结算多次？
4. 如何避免把玩家逼入世界边缘后继续生成不可躲的边界平行线？
5. 混代共存时由强代优先获得冲刺资格，还是弱代更频繁但伤害更低？
6. 散热是逐个体独立发生、同代同步，还是由全场共享节拍导演？
7. 是否需要假线或中途修正？若加入，必须仍然可读，不能靠骗 UI 制造伤害。

## 4. 结构与组成（Structure）

概念上需要以下职责，最终文件与类名待实现阶段确定：

- **BossEncounter 子类**：接入 BOSS 生命周期、唯一胜利结算、登场演出与档案轮换。
- **分裂树管理器**：持有根、分支 ID、代际、存活节点、待生成账本与唯一胜利闸。
- **攻击导演**：在最多 16 个存活体之间分配预警 / 冲刺资格，限制并发并保证攻击线可读。
- **个体冲刺控制器**：持有单体状态机、热量、选线请求和单次命中集合。
- **攻击线表现层**：只负责绘制预警线、危险宽度和倒计时，不拥有伤害逻辑。
- **冲刺表现层**：残影、激波、热迹与镜头反馈；必须有界并可按代际降级。
- **分裂 / 散热表现层**：明确表达父体破裂、双生、代际降低与“现在可以打”。
- **调试 / bench 入口**：可直接生成指定代际 / 分支组合，强制画线、冲刺、散热和分裂，不必打完整 31 次才能验收。

## 5. 验收标准（Acceptance / Litmus）

- [ ] 分裂拓扑严格为 `1 → 2 → 4 → 8 → 16`，完整战斗总计 31 个节点，不重生、不漏生、不重复结算。
- [ ] 任意非终末体被击破后只生成两个弱一代子体；G4 被击破后不再分裂。
- [ ] 混代异步推进成立；先击破某一分支不会强迫其它分支同步降代。
- [ ] 母体或中间体死亡、分裂演出期间场上暂时为 0 时，不会提前触发胜利。
- [ ] 只有 16 个 G4 全部被击破且无待生成子体时，才触发唯一一次 BOSS 胜利。
- [ ] 玩家能从体型、颜色、标签或其它直接表现辨认代际，不必靠记血量猜。
- [ ] 玩家第一次见到攻击线时，能在不看说明的情况下理解“这条线马上会被高速贯穿”。
- [ ] 预警时长以玩家飞机真实转向与移动能力标定；低机动机也存在可执行的躲避方案。
- [ ] 视觉线、实际路径和危险带一致；一次冲刺对同一单位最多结算一次伤害。
- [ ] 8–16 个体阶段仍保持攻击线可读，不出现全员同时画线造成的不可解噪声。
- [ ] 连续冲刺形成压力，散热期形成至少一次真实有效的反击机会。
- [ ] BOSS 的胜负关键是读线、走位、目标管理和把握窗口，而不是追着高速目标打常规 DPS。
- [ ] 世界边缘、镜头外起终点、暂停 / 时间缩放、切控、僚机阵亡时状态机不泄漏、不软锁。
- [ ] 性能：16 个活跃终末体 + Sentinel + Lv5+ 压测维持项目 60 FPS 红线；攻击线、残影与分裂效果无无界增长。
- [ ] 已知 seam 已检查，尤其是 BOSS 生命周期、世界边缘收容、跨帧对象引用与玩家切控引用。
- [ ] i18n：所有玩家可见名称、警告、状态与无线电走 `tr()`，三语齐全。
- [ ] 文档：本 spec 已登记 `_INDEX.md`；状态与 `reconstruction_complete` 一致。
