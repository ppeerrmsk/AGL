# 局内武器库 —— 武器是玩家的外部装备，不锁机型，换机/进化全继承

> 电磁炮到手就是你的，不是这架飞机的：换机、进化，它跟着你走，强化也一并带走。
> 纯局内机制，每局清零。

## 1. 设计意图（Why）

- **问题**：旧决策"武器绑机型、不继承"（tree §3.5 注，2026-06-28）意味着进化=丢武器——
  换机的惩罚感抵消进化的奖励感；同时"局外成长解锁机型多武器 loadout"（meta-progression）把武器乐趣搬出局外，
  与 roguelike 每局成长的立意相悖。
- **新方向（用户 2026-07-19，重点调整）**：
  1. **取消"武器对应机型"**：武器是**外部装备**，属于局内玩家，不锁死在当前飞机上。
  2. **全继承**：换机/进化后新飞机自动装上你已获得的武器，**武器自身的强化属性一并继承**。
  3. **局外多武器设定作废**：meta-progression 的"局外解锁机型武器 loadout（A-10 火箭/X-02 电磁炮）"先作废；
     武器获取纯局内。
  4. ~~**不必剥武器**：进化树上飞机的固有签名武器**保留**（不做"全谱只留机炮导弹"的剥离方案）。~~
     ⚠ **作废（用户 2026-07-23）**："所有飞机都不要自带特殊武器，要从战区获取。"起因=进化到 Su-34（鸭嘴兽）
     被自动塞火箭。**改采当初被否的"剥离方案"**：全部 `player_*.tres` 只留机炮+导弹+热诱弹底线，
     火箭/电磁炮/激光/僚机/雷/QMAAM 一律**不烤入机体**，由 §2.2 的正式授予入口获取。
     "机型固有入手/首驾入库"随之作废（下方 §2.1/§2.2 已改）。
- **Litmus**：单杠杆（一份武器库、一条规则"到手即永久"）；复用既有系统（战区奖励副系统武器/装备挂载/
  evolution 换型钩子）；效果即反馈（换机后武器还在，无需任何 UI 解释）。

## 2. 数据定义（What）

### 2.1 武器两类

| 类 | 内容 | 归属 |
|---|---|---|
| **机体底线武器** | 机炮 + 基础导弹 + 热诱弹（power-curve §1.7 底线） | 机体固有，随机型定义走，不入库 |
| **特殊武器（外部装备）** | **火箭** / 电磁炮 / 激光 / 忠诚僚机（中程僚机）/ QMAAM / 尾部漂浮雷 / 后续新增 | **玩家武器库**，到手即永久（局内）；**不烤入任何 `player_*.tres`** |

### 2.2 获取来源（都走局内正式授予入口）

1. **战区奖励**：zone-reward-arsenal 的武器类奖励（火箭 / 电磁炮 / 激光 / 忠诚僚机 / 漂浮雷 / QMAAM，
   按星级 roll，zone_data 权重表），领取即入库、到手即永久。
2. **签名技能**：某些签名技能主动给武器（sig_x02 突击翼龙→电磁炮 / sig_f47·sig_x90→忠诚僚机）——
   这是玩家**选卡换来**的，不算"机体自带"。
3. **T0 起手机机场等价礼包**：仅当 MiG-21F-13 / F-104C / J 35F / EA-6B 被选择为本局起手机时，
   分别授予机炮吊舱技能 / FFAR / QAAM / ESM。礼包不烤入基参，也不在后来进化取得同型机时触发；
   其中三件特殊武器仍经本武器库入账并随换型继承。详见 `t0-low-t1-aircraft-expansion` §4.1。

### 2.3 挂载与继承规则

- 武器库内全部武器**自动挂载**到当前飞机（不设挂载上限，⏳ 见 §4）；换机/进化后由重放钩子重挂
  （与 evolution-attribute-gates §2.7 玩家层重放**同一机制、同一时点**）。
- **武器强化状态**（对该武器的升级卡/里程碑效果，如电磁炮充能提速）记在**武器身上**，随武器继承。
- 同名武器不叠加（再次入手已拥有的武器 = 无事发生；⏳ 或给小补偿，见 §4）。
- 每局清零：新局创建新武器库；若选择带机场等价礼包的 T0 起手机，再在开局装配阶段写入对应一件特殊武器。

### 2.4 作废条款（本 spec 为权威修订源）

| 旧决策 | 出处 | 状态 |
|---|---|---|
| 武器绑机型、换机型即换整套武器、旧武器丢弃 | aircraft-evolution-tree §3.5 注 / squad-upgrade-ownership §2.6 / aircraft-evolution §2.5（2026-06-28） | **作废**（特殊武器全继承；底线武器仍随机体） |
| 局外成长解锁机型多武器 loadout | meta-progression（局外轴） | **作废**（武器纯局内；meta-progression 局外层改动待其 spec 自身修订时落笔） |

## 3. 行为（How it feels）

- 拿到电磁炮 → 换开 F-22 → F-22 机头也有电磁炮，充能强化原样生效。零弹窗零解释，武器就在那。
- 进化结算界面的武器清单列"机体底线 + 你的武器库"两段（既有 UI 已显示武器清单，分段即可）。
- Tab 三轴面板（gates §3.2）旁列武器库图标行（只读）。
- Boss Debug 参考构筑从正式三星战区奖励池加权、无放回抽取特殊武器：5 次升级里程碑配 2 件，6 次配 3 件；尾雷/忠诚僚机保持机尾位互斥。武器先通过正式奖励入口挂到当前 ACE 并入库，再 roll 技能，Tab 同屏显示本局实际武器与技能；F8 重开时一起重抽。四机以上编队不复制 ACE 武器，保持正式“武器库跟当前操控机走”的归属语义。

## 5. 验收

- [ ] 继承断言：入手电磁炮（含任意强化）→ 进化/换机 → 新机拥有电磁炮且强化数值逐项不变。
- [x] **不烤入断言（当前 50 机）**：全部 `player_*.tres` 无一含 rocket/equipment/僚机/雷/QMAAM（bench `player_params`）；T0 礼包只存在于 PlayableAircraft 开局档案。
- [x] T0 礼包断言：F-104C 开局入库 FFAR、J 35F 开局入库 QAAM、EA-6B 开局入库 ESM；换型后资源引用与剩余量按正式规则补挂。
- [ ] 战区入手 → 继承：战区领电磁炮（含强化）→ 进化/换机 → 新机拥有电磁炮且强化逐项不变。
- [ ] 底线不入库：起手机机炮/导弹/flare 不出现在武器库；换机后武器库为空（若无入手）。
- [ ] 战区奖励武器走同一入库/继承路径（忠诚僚机换机后仍在）。
- [ ] 每局清零断言：新局武器库为空。
- [x] debug 链路：F4 可直接配置装备；Boss Debug 按参考等级随机搭配 2~3 件正式特殊武器，并在 Tab 显示实际结果。
