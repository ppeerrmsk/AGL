# 局内武器库 —— 武器是玩家的外部装备，不锁机型，换机/进化全继承

> 电磁炮到手就是你的，不是这架飞机的：换机、进化，它跟着你走，强化也一并带走。
> 纯局内机制，每局清零。

## 1. 设计意图（Why）

- **问题**：旧决策"武器绑机型、不继承"（tree §3.5 注，2026-06-28）意味着进化=丢武器——
  换机的惩罚感抵消进化的奖励感；同时"局外成长解锁机型多武器 loadout"（meta-progression）把武器乐趣搬出局外，
  与 roguelike 每局成长的立意相悖。
- **新方向（用户 2026-07-19，重点调整）**：
  1. **取消"武器对应机型"**：武器是**外部装备**，属于局内玩家，不锁死在当前飞机上。
  2. **全继承**：换机/进化后新飞机自动装上你已获得的武器，**武器自身的强化属性一并继承**。
  3. **局外多武器设定作废**：meta-progression 的"局外解锁机型武器 loadout（A-10 火箭/X-02 电磁炮）"先作废；
     武器获取纯局内。
  4. **不必剥武器**：进化树上飞机的固有签名武器**保留**（不做"全谱只留机炮导弹"的剥离方案）——
     激光、电磁炮、忠诚僚机（中程僚机）这些，全部是局内后期获得的东西（经进化入手或战区奖励入手）。
- **Litmus**：单杠杆（一份武器库、一条规则"到手即永久"）；复用既有系统（战区奖励副系统武器/装备挂载/
  evolution 换型钩子）；效果即反馈（换机后武器还在，无需任何 UI 解释）。

## 2. 数据定义（What）

### 2.1 武器两类

| 类 | 内容 | 归属 |
|---|---|---|
| **机体底线武器** | 机炮 + 基础导弹 + 热诱弹（power-curve §1.7 底线）+ 攻击线火箭（⏳ 见 §4 开放点） | 机体固有，随机型定义走，不入库 |
| **特殊武器（外部装备）** | 电磁炮 / 激光 / 忠诚僚机（中程僚机）/ QMAAM / 尾部漂浮雷 / 后续新增 | **玩家武器库**，到手即永久（局内） |

### 2.2 获取来源（都在局内）

1. **机型固有入手**：进化/选中自带签名武器的机型（X-02 电磁炮+激光、X-90 UAV 僚机……按 power-curve §2 矩阵），
   **首次驾驶即把该武器录入玩家武器库**——之后换任何飞机都保留。
2. **战区奖励**：zone-reward-docking 已有的"副系统武器"类奖励（忠诚僚机/漂浮雷/QMAAM），入库语义同上。

### 2.3 挂载与继承规则

- 武器库内全部武器**自动挂载**到当前飞机（不设挂载上限，⏳ 见 §4）；换机/进化后由重放钩子重挂
  （与 evolution-attribute-gates §2.7 玩家层重放**同一机制、同一时点**）。
- **武器强化状态**（对该武器的升级卡/里程碑效果，如电磁炮充能提速）记在**武器身上**，随武器继承。
- 同名武器不叠加（再次入手已拥有的武器 = 无事发生；⏳ 或给小补偿，见 §4）。
- 每局清零：新局武器库从空开始（起手机底线武器不算库存）。

### 2.4 作废条款（本 spec 为权威修订源）

| 旧决策 | 出处 | 状态 |
|---|---|---|
| 武器绑机型、换机型即换整套武器、旧武器丢弃 | aircraft-evolution-tree §3.5 注 / squad-upgrade-ownership §2.6 / aircraft-evolution §2.5（2026-06-28） | **作废**（特殊武器全继承；底线武器仍随机体） |
| 局外成长解锁机型多武器 loadout | meta-progression（局外轴） | **作废**（武器纯局内；meta-progression 局外层改动待其 spec 自身修订时落笔） |

## 3. 行为（How it feels）

- 拿到电磁炮 → 换开 F-22 → F-22 机头也有电磁炮，充能强化原样生效。零弹窗零解释，武器就在那。
- 进化结算界面的武器清单列"机体底线 + 你的武器库"两段（既有 UI 已显示武器清单，分段即可）。
- Tab 三轴面板（gates §3.2）旁列武器库图标行（只读）。

## 5. 验收

- [ ] 继承断言：入手电磁炮（含任意强化）→ 进化/换机 → 新机拥有电磁炮且强化数值逐项不变。
- [ ] 固有入手断言：首次驾驶 X-02 → 库存录入电磁炮+激光；换 F-22 仍可用；再换回 X-02 不重复入库。
- [ ] 底线不入库：起手机机炮/导弹/flare 不出现在武器库；换机后武器库为空（若无入手）。
- [ ] 战区奖励武器走同一入库/继承路径（忠诚僚机换机后仍在）。
- [ ] 每局清零断言：新局武器库为空。
- [ ] debug 链路：boss debug 可直接勾选任意特殊武器组合进场（配合全谱选机测试）。

## 4. 开放点（⏳ review 时定）

1. **攻击线火箭归哪类**：矩阵里 A-6E/A-10/狂风的火箭是机型特色——按"底线武器随机体"处理（推荐，保攻击线身份），还是也入库跟人走？
2. **挂载上限**：先不设上限（简单收敛）；若 playtest 出现"全家桶过强"，再谈槽位/取舍。
3. **重复入手补偿**：无事发生（推荐）vs 小额补偿（如该武器强化 +1）。
