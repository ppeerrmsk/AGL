# 战区友军空中支援与海上摆位硬闸

> 保留现有对地、对空、对舰战区任务；已购买对应生涯授权时，对空任务激活后由 2～4 架 F-86、非机场对地任务激活后由 2 架 A-10 第三方友军加入战斗，任务结束后幸存者物理撤离地图；对舰任务在任何地图几何下都不得生成到陆地上。

## 1. 设计意图（Why）

- **体验目标**：不改变现有战区任务池和奖励循环，用对空战斗机与对地攻击机两类临时支援增强多方交战感，并把“舰船上岸”从软警告收紧为不可能生成的硬约束。
- **现有任务分工保持不变**：随机战区继续保留 `ground / air / squadron / naval`；机场继续使用独立 `airfield` 解放任务。本 spec 不删除对地任务、不改任务权重、不改目标数量、不改奖励。
- **友军定位**：友军是“临时参战的第三方小队”，不是玩家僚机。它们能分担火力和制造多线交战，但不响应玩家命令、不加入玩家编队、不替玩家产生 XP/功勋。
- **Litmus 自检**：
  - 战场氛围：对空与对地任务从单纯的玩家小队对敌 TGT，变为两支友军力量共同压入战区；友军真实交战、会被击落、会撤离。
  - 信息可察觉：友军使用第三方绿色机体/标签，沿战区边缘物理入场；不靠隐藏数值表达支援。
  - 单杠杆：F-86 规模只由战区星级决定，A-10 固定 2 架；不叠玩家等级、热度或随机倍率。
  - 性能红线：不增加逐帧全场扫描；生命周期只维护每个已触发支援战区自己的 2～4 架引用。
- **反模式规避**：
  - 不给友军无敌或锁血；被敌方击毁即正常减员，且不补刷。
  - 不在玩家镜头内瞬间生成或消失；入场从不可见位置飞入，退场飞出地图后释放。
  - 不让友军击杀给玩家 XP/功勋，保持 `ALLY` 第三方统一契约。
  - 舰队摆位不再“找不到全水解也照刷并警告”；宁可缩圈、减护卫、原地驻泊或退化为空战，也不生成一艘落陆舰船。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 任务范围

| mission_type | 本 spec 行为 |
|---|---|
| `ground` | 已购 `support_zone_ground` 时，首次 ACTIVE 生成 2 架 A-10 对地支援 |
| `air` | 已购 `support_zone_air` 时，首次 ACTIVE 生成 F-86 友军支援 |
| `squadron` | 已购 `support_zone_air` 时，首次 ACTIVE 生成 F-86 友军支援 |
| `naval` | 无友军空中支援；启用 §2.4 海上摆位硬闸 |
| `airfield` | 完全不变；继续走机场解放与机场防空伞 |

### 2.2 友军支援规模

| 战区难度 | 支援数量 | 机型 | 编成 |
|---|---:|---|---|
| 1★ | 2 | F-86 | 1 长机 + 1 僚机 |
| 2★ | 3 | F-86 | 1 长机 + 2 僚机 |
| 3★ | 4 | F-86 | 1 长机 + 3 僚机 |
| 任意星级 `ground` | 2 | A-10 | 两机分队，各自搜索地面目标 |

- 对空支援固定使用 **F-86**：复用现有完整战斗机生成/武器/AI 管线；强度低于中后期主力敌机，职责是分担火力和制造战场感，不取代玩家完成任务。
- 对地支援固定使用 **A-10**：复用旧基础飞行参数与 GAU-8，但移除火箭和鱼雷；只允许选择 `GroundUnit`，不得跨区攻击飞机或舰船。巡航高度固定 3200m，地面交战沿用扁平高度语义。
- 每个合资格战区每次激活最多生成 **1 支**支援小队；任务重开后可在下一次激活重新获得一支。
- 两类支援均是生涯商店“战场支援”页的独立永久授权，价格各 **3000 功勋**、恒上架、不可退款。正式局只在对应授权已购时生成；bench / boss debug 等非正式局 fail-open，保持验证基线。
- 支援机阵营统一为 `TEAM_ALLY(2)`，类别保留第三方 `ally`，另写 `zone_support=<zone_id>` 作为生命周期归属。
- 支援机 `token_cost=0`、`skip_far_cleanup=true`；不计敌实例上限，不进入玩家编队，不响应点击/轮盘/数字键。
- 支援机使用 `FactionPalette` 的 `COL_FRIEND_ALLY=#59D16B` 绿色；机翼色使用既有 ALLY 转换值 `(0.22, 0.50, 0.28)`。
- 支援机击杀敌方单位：任务目标照常死亡并计入任务进度，但玩家获得 **0 XP、0 功勋**；kill feed 按第三方友军色正常显示。
- 支援机死亡：正常坠毁，不导致任务失败，不补充新机。

### 2.3 入场、驻留与退场几何

| 字段 | 值 | 说明 |
|---|---:|---|
| 入场候选数 | 8 | 沿战区中心周围等角候选 |
| 入场半径 | `max(2400px, zone.radius × 0.9)` | 从战区外缘附近切入，不从地图边界长途赶路 |
| 候选优先级 | 玩家机头前半球优先，其次全圆 | 遵守事件不从玩家身后无声生成的约定 |
| 可见性 | 候选生成范围与当前镜头不得重叠 | 若 8 个候选均可见，延后 0.5s 重试，不在镜头内 pop-in |
| 初始航向 | 指向战区中心 | 长机物理飞入；僚机按小队阵型展开 |
| 驻留半径 | `max(1200px, zone.radius × 0.48)` | 与对空 TGT 的战区盘旋尺度同源 |
| 撤离目标 | 从当前长机位置最近的地图边界外 1200px | 全队直飞出界 |
| 出界释放距离 | 地图边界外 800px | 静默释放，不走击杀/XP 结算 |
| 撤离检查频率 | 0.5s | 只扫该支援小队的存活引用 |

### 2.4 对舰任务水域硬约束

| 字段 | 值 | 说明 |
|---|---:|---|
| 默认旗舰盘旋半径 | 900px | 保持现状 |
| 盘旋半径降级序列 | 900px → 450px → 0px | 0px 表示原地驻泊 |
| 摆位圆心偏移候选 | 0px；900px 与 1800px 的八方向候选 | 保持现有搜索范围 |
| 轨道复核步长 | **40px** | 运行时与现有加密回归同精度；替代 150px 软采样 |
| 合法条件 | `land_hits == 0` | 旗舰和全部护卫的整个轨道采样均在水面 |

找不到完整编成的全水解时，按以下顺序降级，每一步都重新跑全部盘旋半径与圆心候选：

1. 完整编成，盘旋半径 900 → 450 → 0px；
2. 每轮移除轨道半径最大的 1 艘护卫，再试 900 → 450 → 0px；
3. 只剩旗舰时再试 450 → 0px；
4. 若连单舰原地驻泊也没有 `land_hits == 0` 的位置，则**不实例化任何舰船**，把该战区运行时任务类型改为 `squadron` 并生成原有对空任务。

任何 `land_hits > 0` 的候选都只能用于继续搜索，禁止进入舰船实例化阶段。降级结果写 EventLogger；正常找到完整全水解不弹玩家提示。

## 3. 行为与公式（How）

### 3.1 战区支援生命周期

| 状态 | 进入条件 | 行为 | 退出条件 |
|---|---|---|---|
| `NONE` | 合资格任务已预刷但未激活 | 无支援实体；任务可无限等待玩家 | 战区首次 `mission_triggered` 且拥有对应授权 → `INGRESS_PENDING` |
| `INGRESS_PENDING` | 任务 ACTIVE | 按 §2.3 寻找镜头外候选；不可见候选不足则每 0.5s 重试 | 找到候选并生成整队 → `ON_STATION` |
| `ON_STATION` | 整队已生成 | 飞向战区中心并绕战区盘旋；F-86 只攻击飞机，A-10 只攻击地面单位 | 任务完成、战区取消、BOSS 阶段锁区或 Debug purge → `EGRESS`；全队阵亡 → `ENDED` |
| `EGRESS` | 战区生命周期结束 | 清除当前战斗目标，写撤离航点并开启加力；受到攻击可按既有 EGRESS 自卫语义短暂还击，威胁解除后继续撤离 | 全部幸存者飞到边界外 800px 或阵亡 → `ENDED` |
| `ENDED` | 无存活支援机 | 清理引用，不再补刷 | 战区被正式 reset 并再次激活后，可建立下一轮独立生命周期 |

支援生成发生在任务真正激活之后，故玩家不进入战区时没有友军与敌方提前交战，也不会自行完成任务。

### 3.2 交战与任务结算

```text
air_support_count = {1★: 2, 2★: 3, 3★: 4}
ground_support_count = 2

任务完成判定 = 原有对空 TGT 全灭
友军击落 TGT = 正常推进任务完成判定
友军全灭 = 任务继续，玩家自行完成
任务结束 = 立即下达撤离，不在镜头内 queue_free
```

- 支援机不标 `TGT`，不加入 `_spawned_zones`；单独由战区支援生命周期表持有。
- 支援机属于正常敌对关系矩阵中的 ALLY，敌方战区中队可感知、锁定和攻击它们。
- F-86 只主动攻击敌方飞机；A-10 只主动攻击 `GroundUnit`。两者都不得攻击舰船，也不得被其他战区目标跨区拽走。
- 多个对空战区可分别拥有自己的支援小队；每队驻留锚固定为所属战区，禁止被另一战区重定向。

### 3.3 对舰生成事务

```text
先计算安全编成与摆位
if land_hits == 0:
    一次性实例化旗舰与剩余护卫
else:
    继续缩圈 / 减护卫
if 单舰驻泊仍无全水解:
    mission_type = squadron
    生成对空 TGT
```

- 摆位计算完成前不得 `add_child()` 任何舰船，避免失败候选留下半支舰队。
- 护卫删减只影响该次任务实际编成，不改战区星级、奖励或任务完成条件；旗舰仍是唯一 TGT。
- 任务完成后舰队护卫沿现有撤离/清理语义处理，本 spec 不改对舰胜利条件。

### 3.4 清理覆盖面

以下入口必须统一触发该战区支援的 EGRESS 或安全清理，不能遗留绿色飞机：

- 正常 `mission_completed`；
- BOSS 解锁时 `cancel_all_zone_missions`；
- 战区 `reset_zone`；
- Debug `purge / force_respawn`；
- 场景退出时静态引用清理。

## 4. 结构与组成（Structure）

| 组成 | 职责 |
|---|---|
| 战区任务执行器 | 在 `air/squadron/ground` 激活时查询对应购买权益并建立支援小队；维护 `zone_id → lifecycle + members`；任务结束时下达撤离 |
| 支援飞机工厂 | F-86 复用既有敌机工厂；A-10 复用基础参数并剥离鱼雷，随后统一转 ALLY |
| ALLY 转换器 | 统一保证 team、颜色、Token、选择与奖励契约 |
| 小队/AI | 复用现有 Squad 编队、战区盘旋航点、目标选择与 EGRESS 自卫语义 |
| 海军摆位器 | 用 40px 轨道步长返回严格全水候选；不负责实例化 |
| 战区海军生成器 | 按 §2.4 降级编成；只在拿到 `land_hits==0` 后事务式创建舰队 |
| 回归测试 | 水域加密复核、无水解硬闸、支援数量/阵营/一次性生成/撤离清理 |

不新增 AutoLoad，不在共享层写生存模式分支，不新增每架飞机的 `_process/_physics_process/_draw` 子节点。
