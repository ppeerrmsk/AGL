# 多目标导弹锁定数

> 把“能不能多射”的二元开关改成可逐级成长的锁定容量：玩家每多拿一点锁数，就能在一次齐射中多照顾一个不同目标。

## 1. 设计意图（Why）

- **体验目标**：把多锁多射从 on/off 悬崖改成 `+1 / +2 / +3` 的连续成长，允许普通卡、签名技、次世代技能与里程碑自然叠加。
- **Litmus 自检**：锁数直接改变一次齐射能覆盖的目标数，反馈可见；复用现有雷达锁定与导弹齐射，不增加新模式按钮；资源和冷却仍约束火力，避免免费翻倍。
- **反模式规避**：不再用“大于 1 就射向全部目标”的布尔判定；多锁不绕过导弹冷却；不引入独立的多重射击开关。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 基础与加成

| 来源 | 数值 | 叠加方式 | 范围 | 条件 |
|---|---:|---|---|---|
| 飞机基础锁定数 | 1 | 基值 | 单机 | 始终 |
| 普通技能“多目标追踪” | 每层 +1，最多 3 层 | 加算 | 全队 | 稳定级、骑士轴、需有主导弹 |
| 次世代技能“导弹蜂群” | +3 | 加算 | 全队 | 一次；另保留导弹挂载 +4、导弹追踪 G ×0.85 |
| F-22 签名技“先敌开火” | +2 | 临时加算 | 全队 | 持有技能且当前处于 STEALTH |
| 骑士 8 点里程碑 | +1 | 加算 | 全队 | 骑士里程碑进度达到 8 |

普通技能使用既有 `multi_lock` id / `UPGRADE_MULTI_LOCK_*` 文案键；稀有度为稳定，归属显式写为骑士轴。所有技能省略 `scope:"ace"` 与机体 class 限制，按默认 squad-wide 规则下发。

### 2.2 有效锁定数

`effective_locks = max(1, base_locks + permanent_skill_bonuses + milestone_bonuses + conditional_signature_bonus)`

例：基础 1 + 多目标追踪两层 2 + 导弹蜂群 3 + 骑士里程碑 1 = 7；F-22 隐身时再 +2 = 9。

## 3. 行为与公式（How）

### 3.1 齐射分配

每轮齐射先沿用既有规则筛出“已满锁、包线合法、没有过量友军伤害”的候选目标，按距离排序，并把玩家明确点选的目标提到首位。

`fire_count = min(effective_locks, eligible_locked_targets, missiles_available)`

- 每枚导弹分配给一个不同目标，不在同轮内重复目标。
- 候选目标不足时只发实际数量；只有一个目标时只发一枚。
- 自动发射关闭时仍走玩家明确目标的单发路径，不因锁数加成擅自齐射。
- 一轮发射完成后始终进入一轮正常主导弹冷却；多锁不再提供免冷却。

### 3.2 共享与重放

- “多目标追踪”“导弹蜂群”按普通全队技能路径，对当前存活全队逐机应用；晚入队僚机按既有 build 重放补挂。
- 骑士 8 点里程碑按逐机里程碑账本下发全队；换型重放与换帅规则沿用 evolution-attribute-gates。
- F-22 签名技按既有“获得后跟玩家走”的签名技规则重放，因此全队都获得条件式 +2；仅各机自身处于 STEALTH 时生效。

## 4. 结构与组成（Structure）

- 数据层：普通技能、导弹蜂群与三轴里程碑表。
- 应用层：永久加成写入飞机的最大同时锁定数字段；F-22 通过有效值 accessor 临时加算。
- 消费层：导弹齐射以有效锁定数截断候选目标列表，并统一设置正常冷却。
- 表现层：技能文案与里程碑明细显示具体 `+N`；小数 G 与装甲等效减伤百分比不得被整数格式化截断。
