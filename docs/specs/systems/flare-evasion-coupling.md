# 热诱弹与敌机规避耦合

> 热诱弹只创造一次脱离原弹道的机会；敌机必须真的改变飞行轨迹，才能把这次机会变成导弹失导。

## 1. 设计意图（Why）

- **体验目标**：玩家看到敌机投焰后，应能继续观察并判断它有没有成功 break，而不是把投焰理解为瞬时无敌按钮。
- **敌我边界**：敌我双方共享更长、向两侧抛射的视觉；玩家方只收紧自动投焰时机，不插入新的主动规避动作；敌方才实验“投焰 + 机动”耦合。
- **Litmus 自检**：结果必须来自可观察的相对运动和敌机操控水平；只要还有 flare，低级敌人也应大概率认真规避，只有小概率不投焰或执行失败，高级敌人则更可靠；但任何等级都不能在轨迹未变时凭空免疫命中。
- **反模式规避**：不增加 HP、不把普通敌机变成多命目标、不以固定动画冒充物理位移、不在投焰瞬间把导弹标为无害。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 视觉投放

| 字段 | 值 | 说明 |
|---|---:|---|
| 视觉总数 | 10 枚 | 与玩家仪表十星保持一致，不改变实际资源消耗 |
| 分波 | `2/2/1/2/2/1` | 保留六波节奏 |
| 波间隔 | 0.18 s | 完整投放持续 0.90 s；旧值 0.12 s / 0.60 s |
| 粒子寿命 | 3.0–4.8 s | 敌我共用；旧值 2.0–3.5 s |
| 初速度 | 80–140 m/s | 相对世界的视觉粒子速度 |
| 方向 | 左右交替或成对侧抛 | 双枚波左右各一；单枚波按波序左右交替 |
| 后向分量 | 0.25 | 侧向单位向量叠加 25% 后向量，形成现实感更强的斜后侧抛 |
| 方向抖动 | ±0.18 | 只做轻微散布，不允许退化成旧的纯机尾锥 |

### 2.2 玩家自动投焰时机

| 字段 | 值 | 说明 |
|---|---:|---|
| 最小闭合速度 | 30 m/s | 低于此值视为追不上或远离，不投焰 |
| TTI 主门 | ≤ 1.0 s | 由旧 1.5 s 收紧，等待导弹真正进入末段 |
| 终端距离兜底 | ≤ 200 m | 由旧 300 m 收紧；只对仍在逼近的导弹生效 |
| 玩家主动规避 | 不新增 | 当前操控与僚机行为权威保持不变 |

TTI 仍使用 `目标距离 / LOS 闭合速度`；TTI 与终端兜底满足任一即可投焰。

### 2.3 敌机脱离窗口

| 字段 | 值 | 说明 |
|---|---:|---|
| 窗口时长 | 1.25 s | 从敌机实际投焰时开始；到期未成功则本次投焰失败 |
| 航向变化门 | ≥ 22° | 从投焰瞬间航向累计计算 |
| 横向位移门 | ≥ 120 px（240 m） | 相对投焰瞬间原航迹的垂直偏移 |
| 增速门 | ≥ `max(45 m/s, 初速 × 18%)` | 加速脱离必须真实提高速度 |
| 高度变化门 | ≥ 450 m | 使用实际高度，不只检查目标高度指令 |
| 合格条件 | 四项任一满足 | 转弯、掉头、加速或换高度均可成为有效 break |

### 2.4 敌机投焰纪律与等级成功率

敌机资源中的 `fail_chance` 保留为机型/飞行员的相对纪律权重，但不再直接等同“完全不投焰”的百分比：

```text
P_no_release = clamp(fail_chance − head_on_fail_reduction, 0, 1) × 0.10
```

因此配置最差的 `fail_chance=0.85` 实际只有 `8.5%` 概率完全不投；标准 `0.50` 为 `5%`；高端 `0.10` 为 `1%`。玩家方不使用这层缩放，维持既有参数语义。

敌机执行成功率只读 AI 的有效操控水平 `S`，`S` 限制在 0–1：

```text
P_skill = 0.80 + 0.15 × S
```

样例：`S=0 → 80%`、`S=0.30 → 84.5%`、`S=0.60 → 89%`、`S=0.90 → 93.5%`、`S=1.00 → 95%`。

这次判定在投焰时仅采样一次，但只有完成 §2.3 的真实机动后才能兑现。低级敌人仍可能“没放出来”或“放了但执行失败”，只是两种都从常态降为小概率；导弹若已经太近，即使两次概率均通过，也仍可能在动作达门前命中。

| 代表档 | 配置失误 | 实际不投 | `S` | 动作执行成功 | 动作前命中之外的合并成功率 |
|---|---:|---:|---:|---:|---:|
| 低级 | 85% | 8.5% | 0.30 | 84.5% | 77.3% |
| 中级 | 50% | 5.0% | 0.60 | 89.0% | 84.6% |
| 高级 | 10% | 1.0% | 0.90 | 93.5% | 92.6% |
| 王牌 | 0% | 0% | 0.95 | 94.3% | 94.3% |

## 3. 行为与公式（How）

### 3.1 敌机状态流

| 状态 | 时长/触发 | 效果 |
|---|---|---|
| TRACKING | 导弹正常追踪 | 敌机按现有威胁入口进入导弹规避 |
| FLARE_BREAK_PENDING | 敌机投焰后最多 1.25 s | 导弹保持制导、碰撞与警告资格；敌机继续执行垂直 break、加力和高度调整 |
| JAMMED | 等级判定通过且真实机动达门 | 导弹失导并成为无害偏飞弹；敌机可退出本次规避 |
| BREAK_FAILED | 等级判定失败或窗口到期 | 导弹继续追踪并可正常命中；敌机不会获得补偿性无敌窗 |

敌机在 `FLARE_BREAK_PENDING` 期间不写 `is_flare_jammed`，也不写导弹穿透窗。导弹若在动作达门前进入引信范围，照常命中并结束本次尝试。

### 3.2 敌我分流

- 玩家与玩家僚机沿用即时热诱弹概率模型、技能钩子和现有命中语义，只改 §2.1 视觉与 §2.2 自动时机。
- 敌机统一走 `FLARE_BREAK_PENDING`；普通敌机、非 BOSS 王牌与 BOSS 均不得在投焰瞬间获得碰撞穿透。
- 王牌/BOSS 的较高 `skill_level` 让成功率自然接近上限；其 flare 数量仍表示可尝试次数，不再保证等量“命数”。
- 成功后才触发敌机滚转反馈；失败必须留下“投焰但仍被命中”的可观察可能。

### 3.3 生命周期与并发尝试

- 一枚导弹同一时刻只保存一个敌机 break 尝试；重复请求覆盖前必须仍指向同一有效目标。
- 目标销毁、释放、换目标或导弹终止时，pending 状态随导弹一起结束，不缓存已释放对象。
- 成功、失败、超时均写 EventLogger，至少包含目标、成功率与达成的动作类型，便于区分“未投焰 / 投焰失败 / 机动失败 / 成功失导”。

## 4. 结构与组成（Structure）

- 热诱弹子系统负责：玩家 TTI 门、视觉分波、敌机等级概率快照、发起 break 尝试。
- 导弹实体负责：保存投焰瞬间的航向/位置/速度/高度，逐帧判断真实轨迹变化并在成功时切换失导。
- 导弹规避子系统继续负责：敌机 break 的方向、加力与高度指令；本轮不增加玩家主动规避入口。
- 命中管理器继续只把已经确认 `is_flare_jammed` 的导弹视为无害；pending 弹不享受任何跳过。

## 5. 验收标准（Acceptance / Litmus）

- [x] 敌我双方一次投焰仍严格生成十枚视觉粒子，六波持续 0.90 s，双枚波左右各一，单枚波左右交替；粒子可见寿命落在 3.0–4.8 s。
- [x] 玩家对同一快弹在 TTI 1.2 s 时不投、TTI 0.8 s 时投；200 m 内仍逼近时兜底投，远离或闭合不足时不投。
- [x] 敌机投焰但保持原航向/速度/高度超过 1.25 s：导弹不失导并可正常命中。
- [x] 敌机在窗口内完成任一真实动作且等级判定通过：导弹才切换为失导无害；动作达门前进入引信范围仍命中。
- [x] 敌机配置 `fail_chance=0.85/0.50/0.10` 的实际不投概率严格为 `8.5/5/1%`，玩家方不受缩放影响。
- [x] `S=0/0.3/0.6/0.9/1.0` 的执行概率严格为 `80/84.5/89/93.5/95%`；确定种子批量样本呈单调提升。
- [x] 玩家方未新增转向、掉头、加速或高度命令；现有护卫投焰、技能钩子与手动 R 机动不变。
- [x] 敌机/导弹在成功、失败、目标销毁和场景退出后跨下一 SceneTree 帧无 freed-object 或残留 pending。
- [x] 性能：每枚来袭导弹仅 O(1) 保存五个快照标量并做常数次比较；不新增实体扫描或绘制提交，focused 后跑 C1 全可见混合战场门。
- [x] 已知 seam 已核对：jammed 无害契约与“仍可物理命中的未制导弹”保持分离。
- [x] i18n：无新增玩家可见文本。
- [x] 文档：本 spec 已登记 `_INDEX`，reference 索引与 ace 分层语义同步。
