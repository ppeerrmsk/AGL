# 海洋与沙漠离线接触 AO 样板

## 1. 设计意图（Why）

2026-09-08 用户批准先做海洋发射基地和沙漠工业区两处开关对照。保持军事地图简洁度、沙漠米黄色、源建筑和玩法坐标。此阶段只做贴地接触遮蔽，不宣称完成屋顶自遮蔽、全图山谷 AO 或实时动态遮蔽。

## 2. 数值与边界（What）

海洋范围 (-11850,-8000,3072,2816)，沙漠范围 (3900,-400,1792,1664)，单位为地图世界像素。每图一张 512² 单通道线性 R8 纹理，带 mip，合计原始数据不超过 700000 字节。查询实际静态结构三角形，沙漠乘既有 1.35 高度缩放，禁止改动原模型。

## 3. 行为与公式（How）

离线在 y=0.8 的接触接收面，以 32 个确定性余弦半球方向查询 64px 内三角形遮蔽；每命中权重为 1-smoothstep(0,64,d)，结果取平均。范围边缘至少 64px 无遮蔽物，因此遮蔽为零；采样使用像素中心、线性过滤及 mip。高于地面 1..10px 渐隐，只影响脚部，不将平面遮蔽投到屋顶。地表和建筑自定义光照只调制补亮项，强度 0.65；沙漠场坪原标准照明使用 AO 间接项，不修改直射光。交通线和水体不接入。

运行时只读取离线资源，没有烘焙或射线查询。资源缺失、元数据/来源不符或 AGL_MAP_CONTACT_AO=off/0/false 时无效果。来源文件和构建算法指纹写入资源；编辑器还检查生成代码，导出检查原地图数据。按当前会话共享资源，不新增永久 Object 缓存。沙漠沿用载入阶段原节点预绘制与交接；海洋在既有几何初始化时绑定。

## 4. 结构与组成（Structure）

独立离线 builder、共享只读绑定器与 shader include；海洋使用独立建筑 shader，东京湾不受影响。AO 与原高程/地图归档分离，原素材不重写。
