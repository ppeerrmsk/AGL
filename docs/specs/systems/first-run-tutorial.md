# 首次存档操作教程

> 新存档在玩家真正进入空战时解释最关键的操作；首次获得僚机时再按需补充数字键接管，不提前灌输尚不可用的功能。

## 1. 设计意图（Why）

- **体验目标**：让玩家在首批教学轰炸机上直接完成移动、攻击、加力和突击操作；僚机切控只在编队能力首次出现时教学。
- **Litmus 自检**：遵守设计哲学的“信息察觉优先”——说明效果与代价，而不只罗列键位；提示必须能由玩家操作立即消除。
- **反模式规避**：不做全键位百科，不重复提示已完成的存档教学，不让僚机提示被首批轰炸机的完成条件误结算。

## 2. 数据定义（What）

### 2.1 首局基础教程

| 项目 | 值 | 说明 |
|---|---|---|
| 持久化文件 | `user://tutorial.cfg` | 删除存档时随进度一起删除，语言和音频设置不受影响 |
| 配置段 | `survivor` | 教程状态集中在同一段 |
| 首局完成键 | `first_run_done` | 缺省为 false |
| 教学轰炸机完成数 | 3 | 击落三架后首局教程整体淡出并记完成 |
| 世界目标提示超时 | 14 s | 只限制“点击攻击”世界标定框 |
| 条目完成淡出 | 不单独淡出 | 已操作条目保留绿勾，直到首局教程整体结束 |
| 整体淡出 | 0.8 s | 首局面板与世界提示同步淡出 |

首局面板固定包含以下内容：

1. 飞机持续自动前飞，不能停车。
2. 左键点击地图位置，飞机转向并飞往标记点。
3. 左键点击敌机，下达攻击命令。
4. 雷达完成锁定后，导弹自动发射。
5. `E` 加力模式：全队极速脱离并闪避火力；代价是期间无法攻击；再次按 `E` 可提前关闭。
6. 双击敌机进入突击模式：强制切入机炮并贴身追击，直到目标被消灭。
7. `WASD` 或中键拖动平移镜头，空格恢复跟随。
8. 滚轮缩放视野。

### 2.2 首次僚机切控教程

| 项目 | 值 | 说明 |
|---|---|---|
| 完成键 | `wingman_switch_done` | 与首局完成键独立；缺省为 false |
| 触发条件 | 玩家小队首次拥有至少一架存活僚机 | 起手僚机、战区奖励、停靠赠送和复制生成均适用 |
| 提示按键 | 当前操控机之外，存活成员中最小的固定 `squad_slot` | 不按存活列表压缩号位 |
| 完成条件 | 玩家按数字键成功接管另一架存活飞机 | 空号、当前号机、自动阵亡接管均不算完成 |
| 完成淡出 | 0.8 s | 淡出开始时立即持久化，避免退出场景丢进度 |
| 未操作退出 | 不结算 | 下次再次拥有僚机时继续提示 |

## 3. 行为与公式（How）

### 3.1 首局教程状态

```text
新存档且非 bench/BOSS debug
  → 创建首局教程
  → 操作发生时对应条目打勾
  → 教学轰炸机击落数达到 3
  → 写 first_run_done=true → 0.8s 淡出
```

`E` 条目只在加力成功启动时完成；能量为零的无效按键不算完成。双击条目只在第二次点击命中有效敌方单位并进入突击分支时完成。

### 3.2 僚机切控状态

```text
wingman_switch_done=false
  + 玩家队存在另一架存活飞机
  → 显示“按数字键 N”
  → KEY_N 找到 squad_slot=N 且目标不是当前操控机
  → 执行真实接管流程
  → 写 wingman_switch_done=true → 0.8s 淡出
```

提示是静态 UI：不扫描场景树、不运行 `_process`，只在窗口尺寸变化时重新布局。

## 4. 结构与组成（Structure）

| 组件 | 职责 |
|---|---|
| 首局教程层 | 绘制基础教程、世界目标标定、记录首局完成与僚机教学持久状态 |
| 僚机教程层 | 绘制一次性固定号机提示，成功切控后淡出 |
| 生存模式输入层 | 把成功启动加力、有效双击突击、有效数字键接管通知教程 |
| 翻译源表 | 提供中、英、日三语教程文本 |
| 主菜单删档 | 删除统一教程配置文件，使两类教程恢复未完成状态 |

## 5. 验收标准（Acceptance / Litmus）

- [x] 新存档首局面板同时说明 `E` 加力的用途、禁攻代价和提前关闭方式。
- [x] 新存档首局面板说明双击敌机进入机炮贴身突击；有效双击后条目打勾。
- [x] 首次出现僚机时显示实际可切换的固定数字键；空缺号位不被压缩。
- [x] 只有成功数字键接管另一架飞机才永久关闭僚机提示；自动接管和退出本局不结算。
- [x] Bench 与 BOSS Debug 不创建教程。
- [x] 性能：僚机提示无 `_process`、无全场扫描；首局教程只增加两个常量条目。
- [x] 已知 seam：不新增玩家机引用持有者，不触碰操控真源重定向链。
- [x] i18n：所有新增玩家可见文本走 `tr()`，中英日三语齐全。
- [ ] 实机目测：720p/1080p 下两种面板不遮挡关键 HUD，英文与日文无裁切。
