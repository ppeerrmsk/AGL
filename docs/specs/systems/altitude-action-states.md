# 高度动作状态与威胁响应

> 玩家主动调整高度后，飞机明确进入“爬升”或“俯冲”动作；爬升可以用突然减速打乱已经形成的尾追机炮解和迫近导弹，俯冲继续承担速度收益。

## 1. 设计意图（Why）

- **体验目标**：把高度从后台物理数值变成玩家能命名、能观察、能围绕威胁择机使用的战术动作。
- **Litmus 自检**：对应“信息察觉优先于数值”和“笨重 + 延迟快感”；玩家按下高度指令后能看到动作名称、速度和高度同时变化，成功破坏尾追时有真实弹道与相对运动结果。
- **反模式规避**：不提供可持续滥用的无条件机炮/导弹免疫；不强制传送攻击者或伪造“飞过”，攻击者是否冲到前方由双方真实速度、航向和 AI 控制共同决定。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 高度动作

| 状态 | 普通高度调整的进入条件 | 垂直越过的进入条件 | 退出条件 |
|---|---|---|---|
| `NONE` | 无有效高度动作 | 无垂直越过动作 | — |
| `CLIMB` | 目标高度高于当前高度，且实际垂直速度 `> 30 m/s` | 垂直越过终点高于起点 | 普通调整的垂直速度回到 `≤ 30 m/s`；或垂直越过结束 |
| `DIVE` | 目标高度低于当前高度，且实际垂直速度 `< -30 m/s` | 垂直越过终点低于起点 | 普通调整的垂直速度回到 `≥ -30 m/s`；或垂直越过结束 |

- `30 m/s` 沿用现有“明显变更高度”技能门槛，不新增另一组近似阈值。
- 失速恢复强制下坠不算 `DIVE`；动作必须来自有效高度目标或垂直越过。
- 状态描述的是物理动作，不等同于 LOW/MID/HIGH 高度档；处于任何高度档都可以根据运动方向进入 `CLIMB` / `DIVE`。
- 普通动作只在实际爬升/俯冲达到门槛后生效，避免仅切换偏好但尚未改变飞行状态时提前获得收益。

### 2.2 “正在被敌机机炮咬尾”状态

`GUN_TAILED` 只在至少一架敌对 Aircraft 同时满足下列条件时成立：

1. 攻击者的 `combat_target` 是本机，且当前武器意图为 `GUN`；
2. 攻击者位于本机后向锥：本机前向与“本机→攻击者”单位向量点积 `< -0.3`；
3. 攻击者机炮存在、仍有弹药或正在完成已承诺的当前梭射；
4. 双方平面距离、高度差和攻击者的前置瞄准解均通过正式机炮开火包络；
5. 攻击者未被摧毁、未隐身，双方仍为敌对关系。

该状态表达“攻击者已经有机炮攻击意图，并且按当前解马上能够命中”，不是泛化的后半球有敌机、被雷达锁定或远处敌机选择了 GUN。

### 2.3 迫近导弹

- 复用现有玩家方运动学规避门：导弹有效、仍有制导、目标为本机、未被干扰、正在闭合，且闭合速度 `≥ 60 m/s`、预计命中时间 `≤ 3.5 s`。
- 已飞过、正在远离、太慢或仍很远的导弹不算本次爬升反制对象。

### 2.4 爬升反制窗口

- `NONE / DIVE -> CLIMB` 的进入沿开启一次 `4.0 s` 反制窗口；同一段持续爬升不重复刷新。
- 窗口内新形成的 `GUN_TAILED` 与新跨入 §2.3 门槛的迫近导弹都可被反制；窗口结束后的新威胁不受影响。
- 每架攻击者的当前已承诺梭最多冻结一次；每枚迫近导弹最多失导一次。
- 退出 `CLIMB` 时窗口立即关闭；下一次重新合法进入 `CLIMB` 才能再次开启。

## 3. 行为与公式（How）

### 3.1 动作状态机

```text
普通高度控制：
  有效目标高度差 + 实际 vertical_speed 过门槛 -> CLIMB / DIVE
  速度回到门槛内                              -> NONE

垂直越过：
  ENTER 时按 end_altitude - start_altitude 确定 CLIMB / DIVE
  EXIT 时                                      -> NONE

失速强制下坠：
  始终保持 NONE
```

- `CLIMB` / `DIVE` 是统一真源；技能不得再各自用“离开 HIGH”“`abs(vertical_speed)`”“垂直越过起终点”等不同近似条件重复定义动作。
- 需要强度曲线的技能仍可读取 `abs(vertical_speed) / climb_rate_max`，但是否处于动作必须先读统一状态。

### 3.2 爬升威胁破坏

在 `NONE/DIVE -> CLIMB` 的进入沿开启 `4.0 s` 窗口；窗口存续期间复用既有低频威胁更新：

1. 对首次满足 `GUN_TAILED` 且正在执行已承诺梭的攻击者，冻结该梭在反制发生前的最后瞄准解；不取消梭射、不修改其航向或目标。
2. 对首次满足 §2.3 的迫近导弹，立即退出有效制导并沿当前弹道飞过，不消耗热诱弹。
3. 玩家按现有飞行模型真实减速和爬升；攻击者继续执行现有 AI。若闭合率足够，攻击者会自然越过玩家；若相对运动不足，则只表现为当前梭打空，不保证必然越过。
4. 窗口结束或退出 `CLIMB` 后新获得射击解、或新进入迫近门的威胁不受影响，必须等下一次合法爬升动作或使用其它防御手段。

### 3.3 既有技能一一对应

| 现有内容 | 统一状态映射 | 保留语义 |
|---|---|---|
| 近太空冲刺 `sig_mig41` | `DIVE` 进入沿，且动作起点处于 HIGH | 8 秒 OVERLOAD、俯冲加速和 30 秒内置冷却不变。 |
| 超巡爬升 `sig_typhoon` | 高度响应强化作用于 `CLIMB / DIVE`；爬升免目标速度惩罚只作用于 `CLIMB`；机炮闪避作用于 `CLIMB / DIVE` | 文案中的“爬升”与“变更高度”分别对应，不再只看正负速度的临时表达式。 |
| 垂直机动隐身 `alt_change_stealth` | `CLIMB / DIVE` | 锁定衰减强度仍按实际垂直速度归一化。 |
| 云雾机动 `vapor_dodge` | 不消费动作状态；它提高普通 `CLIMB / DIVE` 的响应速度 | 云中锁定率效果仍由云状态决定。 |
| 垂直越过 `vertical_break` | 按起终点发布 `CLIMB` 或 `DIVE` | 专属高度曲线、能量交换和不可命中窗口不变。 |
| LOW/HIGH 常驻技能 | 不映射 | 地表狂奔、盲飞入侵、地形跟随、平流层雷达等读取高度档，不应被改成动作状态。 |

## 4. 结构与组成（Structure）

- Aircraft 持有 O(1) 的当前高度动作枚举和进入沿序号；物理更新与垂直越过共同写入，所有技能只读。
- 机炮威胁使用正式机炮包络纯函数；受击路径可按具体攻击者做 O(1) 复核，避免为一次命中再扫全场。
- 当前操控机的可见 `GUN_TAILED` 汇总可复用既有低频机炮威胁更新，不在每架 Aircraft 的 `_draw()` 中新增全场扫描。
- 迫近导弹复用既有闭合速度/TTI 纯规则；不得建立第二套“来袭”阈值。
- 当前操控机的 `CLIMB / DIVE` 作为状态栏 buff 显示；成功破坏咬尾或导弹时复用飞机现有短时战术提示。
- 动作中复用低成本机体气流视觉，不新增 Aircraft 子节点、独立 `_process()` 或 `_draw()` 全场扫描。

## 5. 验收标准（Acceptance / Litmus）

- [x] 普通升高和垂直越过向上段都只发布 `CLIMB`；普通降高和垂直越过向下段都只发布 `DIVE`；失速下坠保持 `NONE`。
- [x] Q 切换但飞机尚未达到 30 m/s 垂直速度时不提前进入普通动作状态；达到/离开门槛时状态只切换一次，不在零点附近抖动。
- [x] `GUN_TAILED` 只在敌机以 GUN 意图从后方取得正式前置开火解时成立；远处、侧向、导弹意图和无弹攻击者均不成立。
- [x] 进入 CLIMB 后只开启一次 4.0 秒窗口；同一段爬升不刷新，退出 CLIMB 立即关闭。
- [x] 窗口内触发反制后，当前敌机梭射仍生成真实弹丸但沿旧解打空；攻击者没有被传送或强制改向，闭合率足够时可自然飞过。
- [x] 只有 4.0 秒窗口内满足 60 m/s、3.5 s 门槛的迫近导弹被反制；远弹、慢弹、已过头弹与窗口结束后才来的导弹不受影响。
- [x] MiG-41、Typhoon、垂直机动隐身、云雾机动和垂直越过按 §3.3 一一对应，零技能时原飞行模型不变。
- [x] 性能：不在 `_draw()` 新增扫描；当前操控机的威胁汇总低频运行；Sentinel + Lv5+ 压测不低于 60 FPS。
- [x] 已知 seam：跨帧单位引用按 `Variant -> TYPE_OBJECT -> is_instance_valid -> typed cast` 净化；垂直越过的专属高度曲线仍能发布动作而不把虚拟速度重复送入 PE↔KE。
- [x] i18n：状态栏动作 buff 与反制提示走 `tr()`，三语齐全；动作中可见低成本气流反馈。
- [x] 文档：本 spec 已登记总表；实现后同步 reference 索引并通过当前文档校验。
