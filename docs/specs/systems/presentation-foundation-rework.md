## 1. 设计意图（Why）

- **体验目标**：待讨论确认。
- **架构目标**：在不让玩法终态依赖表现序列必达的前提下，调整表现层底层逻辑，并保持 UI、镜头、时间、舞台、无线电与演员调度的职责边界清晰。
- **既有约束**：继续遵守 `ui-transition` 的单一表演导演架构；任何序列覆盖、取消或失败都必须让玩法安全退化，不能造成流程永久等待。
- **反模式规避**：不把玩法状态写进纯表现组件；不新增重复的时间控制、镜头控制或序列运行器；不让不可见的失败吞掉玩家输入或战斗推进。

| 参数 | 值 | 说明 |

## 3. 行为与公式（How）

### DEC-001 · 雷达锁定表现采用屏幕空间恒定尺寸

| 项目 | 内容 |
|---|---|
| 确认日期 | 2026-08-08 |
| 旧行为 | 锁定图形使用世界像素；相机缩至 `0.2` 时，屏幕尺寸只剩 `zoom=1.0` 时的 20%，几乎不可见。 |
| 新行为 | 所有锁定相关符号、端点和线宽使用实际视口缩放的倒数进行补偿，在玩家缩放、平滑缩放及电影镜头缩放中保持恒定屏幕尺寸。表达距离或范围的长度继续使用世界空间。 |
| 决策理由 | 锁定状态是高优先级战斗信息，必须在所有合法镜头尺度下保持可读。 |
| 影响范围 | 飞机、地面单位、舰船、舰船挂点的主锁定框与进度弧；玩家被锁方向三角；敌方导弹锁定警告线的线宽与端点；副武器多锁括号。 |
| 兼容与迁移 | 保持当前 `zoom=1.0` 的尺寸、颜色、旋转、收缩和闪烁语义；隐形、锁定免疫、无人机等既有可见性规则不变。 |
| 风险与退化策略 | 脏刷新单位必须在实际缩放改变时重绘，但不得恢复所有单位每帧重绘；最远视角的标记重叠先通过实机 QA 观察，确认需要后再单独设计聚合或优先级。 |

行为边界：

1. 锁定图形的中心始终锚定目标世界位置；反缩放只作用于中心附近的符号几何。
2. 锁定警告线两端仍连接锁定者与玩家的真实世界位置；只固定线宽和玩家端点图形。
3. 雷达锥、射程圈、目标连线等表达真实距离的图形不纳入本决策。
4. 使用已经应用到 Canvas 的实际缩放，不使用相机目标缩放值，避免平滑过渡和电影镜头期间尺寸漂移。

### DEC-002 · 小缩放档飞机标签降级 + Alt 临时展开

| 项目 | 内容 |
|---|---|
| 确认日期 | 2026-08-08 |
| 旧行为 | 所有标签始终保持完整固定屏幕尺寸；最远缩放时大量长标签遮住机体和其它目标。 |
| 新行为 | 全部普通飞机在实际缩放进入战略档后只显示机体型号、代号和速度；地面单位只显示单位种类；按住 Alt 时在任意缩放临时显示原完整标签。 |
| 决策理由 | 战略远景优先辨认单位身份与高度，细节按需查看，避免固定屏幕 UI 淹没战场。 |
| 影响范围 | 当前操控机、直属僚机、第三方友军和敌机；无人机继续沿用既有单行极简标签。 |
| 兼容与迁移 | 锁定框、任务标记、战术 popup 与独立 HUD 不变；主菜单 `Ctrl+Alt+M` 不受影响。 |
| 风险与退化策略 | 使用 0.35/0.40 迟滞避免临界闪烁；Alt 只按住生效，窗口失焦不保存展开状态。玩家机型基础名若已以代号结尾，则配置合并层不再重复追加。 |

### DEC-003 · 世界警告改由真实在途导弹驱动

| 项目 | 内容 |
|---|---|
| 确认日期 | 2026-08-08 |
| 旧行为 | 敌方发射单位只要锁定并具备发射条件，就从机体/SAM/舰船向玩家画线并按 `locked_by` 画方向三角；持续锁定 BOSS 会长期显示。 |
| 新行为 | 只有真实敌对导弹在途且目标为当前操控机时，才从导弹当前位置向玩家画警告线，并在玩家周围画指向该导弹的独立方向三角。 |
| 决策理由 | 警告图形应回答“哪枚导弹正在飞向我”，而不是“哪个单位正在看我”。 |
| 影响范围 | 飞机、SAM、舰船等所有发射来源产生的导弹；逻辑雷达锁定和屏幕外敌机威胁箭头不变。 |
| 兼容与迁移 | `is_locked`、`locked_by`、AI、技能和火控继续使用原锁定数据；只替换世界警告绘制源。 |
| 风险与退化策略 | 有效来袭必须统一判定存活/制导/干扰/目标/阵营/航向；VLS 预末段按目标分配保留离架警告。每弹独立绘制，不新增聚合状态。 |

### DEC-004 · FLR/MSL 装填提示独立显示

| 项目 | 内容 |
|---|---|
| 确认日期 | 2026-08-08 |
| 旧行为 | 初版实现把 FLR/MSL 装填状态从全部数据框移除，仅在当前操控机左上角显示。 |
| 新行为 | 简略档仅在玩家与蓝色直属僚机左上角显示 FLR/GUN/MSL 三类装填矩形；各类别按指定双色反相。副武器不进入简略提示，完整档仍保留其装填百分比。 |
| 决策理由 | 把高时效状态从身份/飞行数据中分离，用更短的视觉提示降低遮挡。 |
| 兼容与迁移 | Railgun/Laser 状态和右下 HUD 保持原行为；副武器百分比按其既有 `cooldown × max_count` 装填时长计算。 |
| 风险与退化策略 | 只读取既有装填状态，不创建第二套计时器；闪烁使用引擎 tick，飞机既有逐帧重绘负责刷新。 |

## 4. 结构与组成（Structure）

当前沿用既有表现系统组成，具体结构改动待确认：

- `Presentation`：表现层统一入口与序列仲裁。
- `SequencePlayer`：数据驱动的步骤推进与插值。
- `TimeAuthority`：暂停、时间缩放和请求栈。
- `StageIsolator`：舞台隔离、恢复与演员处理模式。
- 表现资源：序列配置、遮罩、镜头、UI 与无线电通道。
