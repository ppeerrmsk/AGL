# 玩家科技树敌机化与常规敌机池扩充

> 玩家在科技树里认识的现实机型也会作为敌军出现；大编队和高警戒带来的不是更多同一种靶机，而是更丰富的敌方航空兵编成。

## 1. 设计意图（Why）

- **体验目标**：T1–T3 玩家科技树的每架飞机都有敌方常规版本；玩家能从线框轮廓、速度、武器和战术行为识别机型，而不是只在选机界面看到丰富机库、战场上反复打少数敌机。
- **范围裁决**：本轮覆盖 T1–T3 共 27 架成熟/现实机型；T4 六代/试验最顶、T5 原创超凡、F-47 BOSS 级机体不进入常规随机池。
- **保留旧生态**：MiG-29、F-86、MiG-23、F-4/F-4E、F-100、F-104、A-7、Q-5、UAV、Sentinel 等现有敌人全部保留；玩家科技树敌版是扩充，不是替换。
- **Litmus 自检**：每种新敌机必须有玩家可感知的身份；差异优先由几何、速度带、武器组合、编队和 AI 行为表达，不靠难以察觉的 ±5% 数值。
- **反模式规避**：不把 24 个新类型继续硬编码成概率分支；不让所有机型只是同一个 AI 换皮；不让普通五代机获得 BOSS 命数、无限热诱弹或高 HP；不因玩家使用某机型就强制生成其硬克制者。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 纳入与排除

| 科技树档位 | 数量 | 常规敌版 |
|---|---:|---|
| T1 起手 | 4 | 全部纳入 |
| T2 四代/四代半 | 15 | 全部纳入 |
| T3 五代顶尖 | 8 | 全部纳入 |
| T4 六代/试验最顶 | 6 | 排除；只允许事件、王牌、BOSS 或后续专门 spec |
| T5 原创超凡 | 8 | 排除；玩家期待机不下放常规池 |

27 架中，Su-27、MiG-31、Su-35 已在常规随机池；其余 24 架需要常规敌版或把事件专属基础资源拆出常规版。

### 2.2 三种互斥行为原型与角色桶

每架常规敌机必须且只能选择一个主行为原型。原型决定交战状态机，机型性能和特殊动作不能改变主循环。

| archetype | 中文内部称呼 | 进入交战 | 开火后 | 被玩家贴近 | 明确禁止 |
|---|---|---|---|---|---|
| `Gladiator` | 斗士型 | 主动缩短距离并争夺玩家后半球 | 留在交战区持续 BFM | 转身接战，设法反咬 | 不因完成一次发射就主动长距离脱离 |
| `Lancer` | 骑士型 | 高速闭合，寻找一次有效攻击通场 | 必须进入 EGRESS，拉开后才允许下一次攻击 | 防御规避并继续脱离，不接受持续缠斗 | 不得在运行时切换成 Gladiator 追尾绕圈 |
| `Schemer` | 策士/特殊机制型 | 按本机专属机制建立攻击条件 | 执行该机制规定的重整/冷却 | 使用专属逃生规则；没有专属规则时按远距脱离处理 | 不得同时拥有“持续缠斗”和“一击脱离”两套自由切换的最优解 |

眼镜蛇、赫尔贝特轮、隐身入场等单个动作不自动把机型变成 Schemer；只有当特殊机制接管其主要交战循环时才归 Schemer。例如 Su-27/Su-35 仍是 Gladiator，F-22 的四目标远距狙击则是 Schemer。

角色桶只用于控制敌机池构成，不代表第二套 AI：

| role | 中文解释 | 主要行为 | 响应等级 1–4 / 5–9 / 10+ 目标占比 |
|---|---|---|---|
| `dogfight` | 制空/缠斗 | 主动接近、持续 BFM、机炮与近距弹 | 25% / 30% / 30% |
| `intercept` | 截击/打带跑 | 高速闭合、一次发射后脱离重整 | 15% / 20% / 25% |
| `strike` | 攻击/突击 | 低空或重载通场，机动差但单次火力强 | 20% / 20% / 20% |
| `ew` | 航电/策士 | BVR、共享察觉、隐身或干扰，主动避免近战 | 5% / 15% / 20% |
| `legacy_fodder` | 既有低价/杂鱼生态 | UAV、F-4E、F-86 等既有来源 | 35% / 15% / 5% |

某档没有可用类型时，将该桶权重按比例分给其它非空桶。BOSS、Adds、王牌轮换、战区任务专属单位不进入这些桶。

### 2.4 多目标导弹机与 F-22 狙击规格

多目标锁定只发给表中明确登记的 Schemer，不成为所有高级敌机的默认能力。

| 敌机 | 并行锁定上限 | 单轮不同目标数 | 机制 |
|---|---:|---:|---|
| Gripen C | 3（队级） | 最多 3 | 队长分配目标；每架仍只锁/射 1 个目标，避免单机爆发过强 |
| Rafale | 2（单机） | 最多 2 | 两条独立锁定轨，向两个不同直属目标各射 1 发 |
| F-35 | 2（单机） | 最多 2 | 双锁双射后 10s 远距换位，无机炮兜底 |
| Gripen E | 3（队级） | 最多 3 | 队长数据链分配；全队合计最多 3 个不同目标，不按飞机数重复放大 |
| F-22 | **每机 4；同队共享分配** | **每机最多 4、同一轮全队不重复覆盖** | 单机仍可四锁；编队把本轮锁位优先分配给不同直属目标，下一轮攻击循环才可再次锁同一目标 |

#### F-22 常规敌版平衡硬值

| 项目 | 值 |
|---|---|
| archetype | `Schemer`，远程多目标狙击；无条件禁止转 Gladiator |
| 解锁 | `response_level >= 13` |
| Token / 实例上限 / 生成 | `10 / 3 / 1–3机`；规模读取 `squad-xp-threat-balance` 的玩家编队倾向 |
| 池内基础权重 | `0.35`（普通合格机型基准为 `1.0`） |
| 同型生成冷却 | `150s`；死亡或撤离后仍要等冷却 |
| 战区阶段累计生成上限 | `6` 架；击毁不返还累计名额，BOSS 阶段不生成 |
| 并行锁定 | 最多 4 个**不同**的存活直属飞机；不足 4 架时按实际数量 |
| 编队锁位 | `F` 架存活 F-22 的**单轮**队级锁位上限为 `min(4×F, N)`；同一轮每个直属目标最多分配 1 条，完成 12s EGRESS 后的下一轮攻击循环才可再次锁同一目标 |
| 候选范围 | 必须同时位于 F-22 雷达距离与雷达锥内；绿色 Allied 不占锁定槽 |
| 锁定时间 | 4 条轨道各自累计 `3.5s`；某目标出锥只清自己的轨道，不拖累其它目标 |
| 发射 | 锁定完成后按 `0.15s` 间隔发射，最多 4 发；每目标严格 1 发，不对同一目标补位重射 |
| 发射门槛 | 至少 1 条锁完成即可在本轮发射；不等待凑满 4 条，避免单机玩家免疫该敌人 |
| 发射后 | 首弹离架即结束 SETUP；末弹离架后强制 EGRESS `12s`，期间不锁定、不发射、不用机炮 |
| 近距规则 | 玩家进入 `3000m` 内立即中止未完成锁定并 EGRESS；不得转身缠斗 |
| 机炮 | 敌方常规版不装备机炮；所有伤害只来自远距导弹狙击 |
| 防御 | 普通敌机 HP 上限 75、有效热诱弹 1 枚；无 BOSS 导弹无敌、无额外命数 |
| XP | 普通常规敌机公式，不因四锁能力给王牌档 XP |

**对策**：大编队紧密堆叠会同时落入雷达锥，最容易让 F-22 编队铺满锁位；分散编队、派一架高速机压入 3km、命令被锁成员规避，都能主动打断部分或全部锁定。每名被锁单位必须收到独立提示，首弹发射后对应 F-22 暴露位置，玩家可以组织追击。F-22 编队不能把多机全部锁位堆到同一架玩家飞机上：单机玩家面对三机 F-22 时，每轮仍只产生 1 条锁；全队完成射后 EGRESS、进入下一轮攻击循环后才可再次锁它。

### 2.5 普通敌人的共同边界

- 普通敌机仍遵守导弹一击必杀：除显式精英/BOSS 外，最大 HP 不超过 75。
- T1/T2 常规机最多 1 枚有效热诱弹；T3 常规机也最多 1 枚，不使用 F-47/Poltergeist 的“热诱弹即命数”特权。
- 敌机武器 Tier 继续由真实玩家等级决定；`response_level` 只决定谁能出现。
- XP 统一使用普通空中单位公式；本扩池不创建高于王牌档的经验肥羊。
- 有人驾驶的 24 个新常规敌版全部允许进入普通敌方无线电白名单；同一时刻仍受全局无线电节流。
- icon/wing 使用敌方暖色域；不得复用玩家蓝色或 Allied 绿色。

### 2.6 敌版参数审计门

玩家科技树只提供**机型名单、轮廓和角色灵感**，不得成为敌版数值源。每个新敌版必须先选现有普通敌机
作为对标，再填写独立 `enemy_*.tres`；禁止复制、引用或按比例换算 `resources/player/` 下的任何参数资源。

#### 2.6.1 合法与非法基准

| 用途 | 允许作为普通敌版基准 | 禁止作为普通敌版基准 |
|---|---|---|
| 低价/早期 | F-4E、F-86、J-7、F-104、A-7、Q-5 | 玩家同名机、教程/演出临时覆写 |
| 标准主力 | MiG-23、MiG-29、F-4、F-100、常规 F/A-18 | F-15/F-16/Mirage 2000 的王牌事件实例覆写 |
| 高端主力 | Su-27、Su-35、MiG-31 | F-47、Poltergeist、AceSupport、YF-23、Cre |
| 特殊机制 | 可借普通敌机本体基线，再单独增加已写入 spec 的机制 | AF-03 电磁炮特批、MQ-X、Mother Goose、任何 BOSS/王牌数值 |

一个敌版可以分别选择不同对标，例如“飞行性能看 Su-27、雷达看 MiG-23、热诱弹看 F-100”；
但每一栏都必须写明对标对象和差异，不能写“参考玩家版”。
“允许作为基准”也不代表可以整份照抄：F-4E 的 4200px 雷达等现存离群值只能描述 F-4E 自己，
不能反向扩大低价机走廊；新敌版必须按字段选择落在走廊内的普通敌机对标。

#### 2.6.2 普通常规战斗机数值走廊

以下走廊来自当前普通敌机实际值，是新敌版的默认硬门。Token 指**单架**成本。
低于某档下界可以作为明确弱点，但必须在独立 spec 说明；超过上界则必须命中特批规则，不能用“机型先进”口头放行。

| 单架 Token | 基础 HP | radar_range | lock_time | 热诱弹 |
|---:|---:|---:|---:|---|
| 2–3 低价机 | `32–45` | `2200–3000px` | `3.0–4.0s` | `0`；若特殊批准为 1 枚，则 `fail_chance >= 0.65` |
| 4–6 标准机 | `45–60` | `3200–3800px` | `2.8–3.5s` | `0–1` 枚；有则 `fail_chance 0.45–0.55` |
| 7–8 高端机 | `55–70` | `4200–4600px` | `2.5–3.2s` | 最多 `1` 枚；`fail_chance 0.10–0.20` |
| 9–10 顶级常规机 | `60–75` | `4200–4600px` | `2.5–3.5s` | 最多 `1` 枚；`fail_chance 0.10–0.15` |

共同硬规则：

- 普通敌机在等级缩放后仍执行 `max_hp <= 75`；不得借“第五代”“重型机”突破一发导弹击毁约定。
- 普通敌机 `radar_half_angle` 使用当前敌人走廊 `20°–35°`。只有明确的传感器/指挥平台可放宽，
  且必须在独立 spec 写出近距、武器或机动代价。
- `radar_range > 4600px` 仅允许拦截专精，默认上限 `5200px`，并至少承担窄锥、较长锁定、无机炮、
  强制 EGRESS 中的一项明确代价。超过 `5200px` 视为 AF-03 级特批，不能出现在普通机型草案里。
- 热诱弹若存在，运行时必须强制 `burst_count = 1`、`max_flares = 1`、`enable_flare_reload = false`；
  BOSS/王牌的多命热诱弹资源绝不复用。
- 无热诱弹的普通基准不能因为玩家同名机带 flare 就自动补一枚；是否携带只看敌方 Token 档、现有敌人梯度与独立 spec。
- 机炮、导弹、火箭和弹药数量只从敌方 V-tier/普通敌方武器资源派生；不得引用玩家武器、玩家签名装备或玩家弹药基数。
- 速度、G、滚转、加速度等飞行字段也必须指定普通敌机对标；默认相对对标值浮动不超过 `±10%`。
  超出时必须由可感知身份和反向 tradeoff 支付，不能只因现实同名机或玩家版更强。

### 2.7 科技树外的特殊支援敌人

科技树 27 机负责“玩家熟悉机型的敌版”，但不垄断常规敌机池。少量拥有独立空间机制的原创支援机
可以作为 Schemer 加入 `ew` 桶，前提是每种都建立独立 enemy spec，且不挤占 27 机对应关系。

首个登记项为 [SNOWBLIND「雪幕」支援机](../enemies/snowblind.md)：Token 4、权重 0.45、
`response_level >= 8`、同场上限 1、战区累计上限 2、180s 冷却。它以 4000m 移动灰色雪幕隐藏圈内敌机，
直属飞机入圈后全队共享显形；本体逐字段采用 Sentinel 非战斗基线，无武器、无 flare、关闭战斗 AI，
隐藏期间跨边界双向停火。初始两架护卫分别从生成当刻
符合当前热度的任何常规战斗机中独立抽取，可同型或混编；各自照常支付 Token 并遵守上限。
其完整数值、视觉、AI 与验收只以独立 spec 为准。

## 3. 行为与公式（How）

### 3.1 原型状态机契约

```text
Gladiator: ACQUIRE → MERGE/BFM ↔ REPOSITION → MERGE/BFM
Lancer:    SETUP → ATTACK_PASS → EGRESS → RESET → SETUP
Schemer:   MECHANIC_SETUP → EXECUTE → EXPOSED/EGRESS → COOLDOWN → MECHANIC_SETUP
```

- Gladiator 的 `REPOSITION` 只为恢复能量/几何，仍留在交战空间，不得使用 Lancer 的长距离脱离完成一次攻击后清空战斗。
- Lancer 的 `EGRESS` 是硬相位：清攻击意图、保持高速拉开，达到安全距离或持续时间后才能再次 SETUP；被贴脸只允许防御规避，不允许进入无限 BFM。
- Schemer 必须在独立 enemy spec 写出四相的具体门槛和持续时间；特殊机制失效时退回 EGRESS/COOLDOWN，而不是获得 Gladiator 兜底。

### 3.2 数据驱动抽取

所有常规随机敌机登记为数据行：

```text
id, archetype, role, unlock_response_level, retire_response_level,
weight, token_cost, instance_cap, spawn_min, spawn_max,
formation, altitude_weights, ai_profile, special_profile
```

抽取顺序：

1. 读取 `response_level` 和当前 Token 余量。
2. 过滤未解锁、已退役、成本超额、达到实例上限、BOSS/事件专属的类型。
3. 按当前响应等级选择 role 桶。
4. 在 role 桶内使用 shuffle bag 抽机型；同一机型在至少 3 次其它常规中队生成前不得再次出现。
5. 一支中队只用一种机型；不在本阶段引入跨机型混编，以免身份难辨和指挥成本失控。
6. 按 `squad-xp-threat-balance` 的玩家 N 软权重抽单机/双机/3–4机，再由该行 `spawn_min/max`、Token 余量和实体上限裁剪；F-22 明确允许 1–3机。

现有普通敌机迁入同一注册表；专用事件/BOSS 生成函数保持独立，不通过常规表漏出。

### 3.3 档位轮换

- `response_level 1–4`：以旧式/低价机和 T1 敌版为主，允许少量 T2 轻型机提前露面。
- `response_level 5–9`：T2 成为主力，旧杂鱼权重降到 15%，但不完全退场。
- `response_level 10+`：T3 进入，旧杂鱼权重降到 5%；T3 不得连续刷出超过 2 支中队。
- 高警戒提高高级机“可出现性”，但不保证每波都是高级机；玩家仍需要看到轻重混合的战争场面。

### 3.4 事件资源与常规资源隔离

- F-15、F-16、Mirage 2000 的现有王牌事件配置保持事件层覆写；常规池使用独立、可等级缩放的基底。
- F-14 Poltergeist、F-47 Wraith、YF-23 支援等 BOSS/事件资源严禁直接加入常规池。
- F/A-18E 常规敌版与 CSG 弹射 F/A-18 分开；二者可共享轮廓实现，但参数、Token、归属和生命周期独立。
- 玩家 `.tres` 只能作为现实定位与视觉轮廓参考，不被敌方直接引用；敌我参数继续文件级解耦。

- 一个常规敌机注册表，承载全部随机池数据；选型器不再逐类型硬编码概率分支。
