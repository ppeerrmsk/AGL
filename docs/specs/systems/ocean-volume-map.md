# 海洋群岛三维地图生产

## 1. 设计意图（Why）

依据用户 2026-09-07 的海洋图三维化指令，继承沙漠和东京湾的固定机位基线、分区候选、几何审计、Visual 性能及回滚工作流。深蓝海域、灰绿岛屿、现有岸线和道路细节是视觉基线；基地装配楼、机库、细高发射塔与储罐必须各有轮廓。地图表现不改变任务、点击、飞机高度、伤害、海陆判定或海洋预览模式。

## 2. 数据定义（What）

- 地理和基地 SSOT：`resources/maps/ocean_islands_preview.aglmap`，16 栋原建筑、1 条原跑道，不新增玩法建筑或机场。
- 地表 SSOT：`basemap_tiles/ocean/manifest.json` 的三个 LOD；颜色、描边、颗粒参数直接读取原瓦片材质，不建立第二个纹理 LRU。
- 高程源：[Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)，Terrarium z11，按原图 Web Mercator UV 配准至已有 world rect；257² 高程样本，米值原样保存。来源 URL 和 SHA256 随资产记录。
- 地形显示：海面固定 0，天然地形 `max(elevation_m - 10, 0) × 0.12 px`，仅用于显示；不把概括 mountain/land polygon 拉成真地形。西北既有工程基地范围保留平面，防止旧机场与设施埋入新山体；工程整平区为 x=-11780…-8850、y=-7900…-5230，向外 180px 平滑接回天然高程。
- 建筑高度：`h_m × 0.5 px`，所有档位一致；16 栋身份按源数组顺序为装配楼、机库、机库、厂房、发射台、发射架、控制楼、仓库、机场机库、航站楼、塔台、仓库、4 座储罐。发射台和发射架原本嵌套，属于合法组合。
- 采用静态合批，近档保留几何构件，中档保留完整建筑主体和原高度，远档保留基地轮廓；沿用 0.10s 复核与 8% LOD 迟滞。近档建筑预算 12000 三角，运行时最多 17 个共享瓦片网格，地形归档预算 32MiB。
- 地表和建筑通过与东京湾相同的 38° 正交显示投影合成；以真实输出像素尺寸配置 SubViewport。静止且瓦片无变化时不重绘。无逐栋 Node/tick，无 TIME 波纹，无水面随机噪声。

基地构件尺寸以地图像素表示，主体墙 `#737f79`、屋面 `#92998e`。机库/仓库、控制楼和储罐复用现有静态建筑原型；海洋特有构件如下：

| 构件 | 几何与显示合同 |
|---|---|
| 装配楼 | 原足迹直棱柱；屋顶足迹内缩至 98%，抬高 0.01；门宽为长轴 60%、门高为主体高 84%，底沿 0.2，颜色 `#455c60` |
| 机库门 | 位于正侧边外沿 0.5002 倍宽处；门宽为长轴 80%，高度为主体高的 0.72×0.84，双面静态门板 |
| 发射台 | 原足迹主体高 h；顶部 86% 足迹薄面，高 h+0.01；底/面为 `#697975` / `#899088` |
| 发射架 | 四柱放于 72% 足迹的四角，柱截面 5×5，底 3、顶 h；近档 5 层横梁，远档 3 层，梁长为柱间距+5、宽 4、高 2；近档前 4 层有宽 1.6 的斜撑，顶不超过 h |
| 场坪/服务路 | 场坪为原足迹 110%、高度 0.04、`#78867b`；服务路高度 0.08，干线长为跑道 90%，绕行先向干线方向走 100，再沿长轴偏移 |
| 跑道 | 原机场多边形，高 0.12、`#475953`；两条边线长 96%、宽 3、侧向距中心 44% 跑道宽，高 0.16、`#bac2ad` |
| 跑道标记 | 中线 24 段，32×3.5，覆盖长轴 90%，高 0.17、`#d0d3be`；两端各 6 条入口线，46×7，间距 22，位于长轴 ±46%，高 0.18、`#c3c8b3` |

六级档位、迟滞和合成淡入淡出继承东京湾归档/投影合同。海洋 level 0/1 使用低档主体，level 2–5 使用完整构件；两档不改变原建筑高度。257² 高程构成同一 129² 固定几何采样面，再按 146 个原瓦片范围裁片；纹理 gutter 和裁片矩形由原 manifest 推导，不另设经纬坐标。

## 3. 行为与公式（How）

2026-09-18第二轮：海洋纹理成员表仅在Raster表现版本改变时重建，不再每100ms重复分配Dictionary与WeakRef；透明度和目标层顺序仍逐帧跟随。默认关闭的覆盖抑制试验不执行逐帧覆盖计算；从开启切到关闭立即恢复原mask。此项只减少CPU分配和读取，不修改材质、归档、层级或战斗负载，是否消除整帧尖峰仍由Visual实测决定。

重复底图提交抑制仅为显式 `AGL_OCEAN_COVERED_RASTER=1` 的诊断候选，默认关闭，不算正式性能优化完成。候选仅在完整不透明Strategic已绑定且视野处于保守内缩范围时置原Raster的visibility_layer为0；不停止owner、不隐藏源节点、不另建纹理缓存；关闭3D、源失效或覆盖资格不足立即恢复原mask。内缩距离为归档Strategic网格最大绝对高度的2倍加80地图像素。其依据是[Godot CanvasItem visibility_layer](https://docs.godotengine.org/en/stable/classes/class_canvasitem.html#class-canvasitem-property-visibility-layer)的渲染筛选，不是节点生命周期替换。原生分辨率和4×MSAA保持；2×MSAA实测无稳定收益，未接入默认路径。

2026-09-18交接优化：保持三档原资源和17平面/32MiB几何预算。Raster每次增删瓦片推进表现版本，海洋借用者在下一次绘制同步前立即消费版本变化；静止未变化不再枚举成员表。退役通过实例身份信号先同步释放唯一借用，再由owner断纹理/复用槽。透明层优先级跟随实际目标层z_index（Strategic=-100，目标=-80，其余=-90），不得固定Detail永远置顶导致缩远淡入失效。源退出和桥接退出断订阅、清资源，不增加纹理LRU或运行时构网。自动反例走正式增删入口和0秒同步；完整边缘/快滚/帧时间补验按[本轮计划](../../audits/2026-09-18-desert-ocean-lod-acceptance.md)，旧勾选仅代表R4历史验收。

离线下载 → 配准高程 → 同一固定三角曲面按原瓦片矩形裁剪 → 预构建资源 → 正式 MapFeatureRenderer 接入。所有地图 LOD 裁自同一高程曲面，保留相同接缝法线和高度。运行时借用原 RasterBasemapRenderer 的纹理、UV、渐变 alpha 与颜色参数，只绑定已构建 ArrayMesh。

只在源路径恰为内置海洋文档且 tile key 为 ocean 时默认接入；资源缺失或指纹不符则保留原图。显式 `AGL_OCEAN_VOLUME=off/0/false/2d` 回退。编辑器校验数据与构建源码指纹，编译脚本的导出包只校验同一数据指纹。Tab 保留同源 Strategic 地图和原跑道，不额外解码地图。退出/换图清除本节点持有资源和弱引用，不污染东京湾/沙漠状态。

工程服务路只用于显示：跑道两侧各距半宽外 105px 设置宽 20px 干线；建筑出口宽 18px，以原足迹边界为起点，尝试沿跑道方向 0、±120、±240、±360px 偏移的直角绕行。所有路面角点留在原基地岛内，不得穿过其他原建筑，发射架使用既有发射台。路面颜色 `#849083`；不进入玩法道路或导航数据。

地形光照采用离线 257² RGBF 连续法线纹理（单一共享资源，无新增瓦片缓存）。整平后的高程经过二维 1-2-1 核平滑、中心差分得到未归一化法线；按原全图 UV 采样，横向分量乘 6，片元归一化后与 `normalize(-0.4,0.8,-0.5)` 点积。地表明暗乘数为 `1+clamp((dot-0.780720058)×2,-0.45,0.24)`，平坦海面恰为 1。连续光照不依赖地图三角形边缘，几何高度及原道路纹理保持同源。

## 4. 结构与组成（Structure）

海洋专属高程与结构归档、纯离线 builder、海洋合成层和共享纹理桥接。复用现有固定三角曲面、静态建筑工厂及东京湾投影/合成生命周期；不把沙漠工业布局、道路或材质参数套到海岛。
