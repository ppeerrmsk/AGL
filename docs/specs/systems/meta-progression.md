# 局外成长（Meta-Progression）—— 局内/局外彻底分层

> ⚠ **历史草案，禁止继续派生实现。** 局外武器 loadout 已被明确否决。当前局外权威为
> [career-archive](career-archive.md)、[career-shop](career-shop.md)、
> [doctrine-unlocks](doctrine-unlocks.md) 与
> [aircraft-signature-progression](aircraft-signature-progression.md)；特殊武器纯局内，见

## 1. 设计意图（Why）

roguelite 元进度（Hades 式）。分层的轴是 **"槽位装备 vs 玩法深度"**（不是"重 vs 轻"）：

- **局外（meta，持久，花功勋）= 槽位 / 装备 loadout**：解锁/强化机型挂什么**武器装备**（签名武器、装备槽、硬件）。一旦解锁，该机型**每一局开局就自带**。定义这架机的"硬件底子"，是长线变强主轴。
- **局内（in-run，roguelike，每局清零）= 提升玩法深度的内容**：影响**这一局战术打法**的机制 / 技能。**不是**"不痛不痒的小数值"——（副导弹只是早期举例，具体内容用户仍在推敲）。
- **完全分开**：局内升级永不写盘、不影响局外；局外解锁只定"这局飞机的 loadout 底子"，不在局内被消耗/回滚。

### 1.1 运行循环（用户 2026-06-28）

- 每局**从初始机体开始**，局内沿进化树往上换机型（进化留局内 §5）。
- 局外对各机型的成长（loadout 解锁/强化）让你**进化到该机型时它已是强化版** → 进化过程更平滑、越肝越顺。
- 局外**不跳过**进化，只把沿途各机型的底子垫高。

## 2. 分层定义（What）

| 层 | 作用域 | 管什么（轴 = 槽位装备 vs 玩法深度） | 持久化 |
|---|---|---|---|
| **局外 meta** | 跨局持久 | 机型**槽位装备 / 武器 loadout**（签名武器、装备槽、硬件） | 写盘（`user://`，复用功勋账本 §4） |
| **局内 in-run** | 单局，清零 | **提升玩法深度的机制 / 技能**（塑造这局战术打法）+ **进化换机型** | 不写盘（roguelike，session-only） |

> 与 [squad-upgrade-ownership](squad-upgrade-ownership.md) 的关系：那份 spec 的"绑机型 41 技能 build"需**按"槽位装备 / 玩法深度"两类重切**——武器/装备/硬件 loadout（机炮弹药、载弹数、电磁炮、激光…）归**局外**；改变战术打法的玩法机制归**局内**。详见 §5。

## 3. 局外强化举例（用户给的）

| 局外强化 | 效果 | 结果 |
|---|---|---|
| 强化 **A-10** | 解锁火箭弹 | 之后每局开 A-10 都**自带火箭弹** |
| 强化 **X-02** | 解锁电磁炮 | 之后每局开 X-02 都**自带电磁炮** |

> 即"武器绑机型、不继承"（[aircraft-evolution §2.5](aircraft-evolution.md)）里"机型自带什么武器"，**由局外解锁决定**——没在局外解锁就没有；解锁了则该机型固有。
