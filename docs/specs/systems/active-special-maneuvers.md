# 玩家主动特殊机动：共享控制权与不可命中契约

> 玩家获得主动机动技能后，当前操控机按 R 执行一次清晰、短促、可预判的飞行动作；动作不靠普通无敌状态，而是在严格相位内暂时不参与新的命中结算。

## 1. 设计意图（Why）

- **体验目标**：给玩家一个需要读局势、选时机的主动飞行动作，而不是新的常驻机动数值 buff。位移、姿态、音画和敌弹穿过机体共同提供立即可读的反馈。
- **Litmus 自检**：符合“笨重 + 延迟快感”和“信息察觉优先于数值”；动作有明显起止、长冷却和位置后果，不把飞机永久变灵敏。
- **反模式规避**：
  - 不使用 `INVINCIBLE`、锁定免疫或动作结束后的尾保护；敌人仍可锁定、追踪和保持目标。
  - 不建立第二套飞行物理；共享协调器只在 ACTIVE 相位取得位移、高度和命中资格的有限主张。
  - 不允许靠切换僚机绕过冷却；技能冷却属于玩家小队共享资源。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 共享规则

| 字段 | 值 | 说明 |
|---|---|---|
| 输入 | `R` | 复用统一主动机动入口；只有当前操控机可开始新动作。 |
| 自动触发 | AI 僚机保留 | 当前操控机只响应 R；AI 僚机按威胁条件自动释放自己拥有的唯一 R 机动。 |
| 并发上限 | 每架飞机 1 个 | 同一飞机不能同时执行两个特殊机动。 |
| 冷却所有者 | 玩家小队共享 | 成功进入 ENTER 当帧开始计时；切换操控机不重置、不复制冷却。 |
| 冷却计时 | 正常游戏时间 | 暂停时冻结；死亡、切控和战区切换不缩短。 |
| R 技能互斥组 | `cobra_skill` / `evasion_herbst` / `manual_dodge` / `displacement_roll` / `vertical_break` | 五向双向互斥；正常卡池只能获得其中一个。Debug/旧档异常共存仍由统一入口按固定优先级只释放一个。 |
| HUD 只读状态 | 唯一技能 id、总冷却、Squad 共享剩余冷却 | 不建立技能选择 UI；取得技能后常驻显示，内部换算 0%→100% 可用度，禁止向玩家显示秒数或总冷却。 |
| 动作中切控 | 允许 | 起始飞机完成余下动作；新操控机不能绕过共享冷却再次释放。 |
| 动作中移动命令 | 最后输入覆盖 | 不立即抢走动作控制权，记录最新有效移动/高度命令，EXIT 后交还。 |
| 动作中攻击命令 | 保留最新命令 | 不清空锁定或战斗目标；EXIT 后按最新目标继续规划。 |

### 2.2 “不可命中”覆盖表

ACTIVE 窗口的语义是“新的命中不成立”，不是伤害乘零。命中源必须在生成命中特效、销毁弹体、引爆、写日志和调用伤害之前查询。

| 来源 | ACTIVE 窗口行为 |
|---|---|
| 机炮/普通子弹 | 穿过，不销毁弹体、不产生命中特效、不记命中。 |
| 火箭弹、空爆、爆炸 AOE | 不把该飞机加入本次新爆炸的受击集合。 |
| 导弹接触/近炸 | 导弹继续追踪，不引爆、不销毁、不丢失目标；窗口结束后可正常命中。 |
| 激光、光束、电磁炮 | 当帧不建立新命中，不写命中日志。 |
| 机体接触/碰撞伤害 | 不结算双方接触伤害。 |
| 已存在的持续状态/DoT | 继续计时并结算；动作不能清洗既有状态。 |
| 坠毁、越界、剧情清理、Debug 强制销毁 | 不豁免；必须能可靠终止飞机和动作。 |

### 2.3 边界与安全参数

| 字段 | 值 | 说明 |
|---|---|---|
| 安全评估频率 | 仅激活当帧 1 次 | 禁止动作期间每帧扫描全场。 |
| 敌机样本 | 激活当帧所有有效敌对空中单位位置 | 快照后不追踪移动目标，保证决定可复现。 |
| 方向评分 | `min_enemy_clearance_px + 0.75 × boundary_clearance_px` | 分别计算左右候选轨迹；取分数较高一侧。 |
| 平分裁定 | 右侧 | 无随机数，保证回放与测试稳定。 |
| 边界硬约束 | 整条候选轨迹必须在地图内 | 一侧越界则选另一侧；两侧均越界则拒绝激活且不进入冷却。 |

## 3. 行为与公式（How）

### 3.1 共享状态机

| 状态 | 时长/触发 | 效果 |
|---|---|---|
| READY | 技能可用、冷却为 0 | 当前操控机等待 R；AI 僚机等待威胁触发；不主张任何控制权。 |
| ENTER | 成功激活当帧 | 快照命令、目标、边界和候选敌机；选择方向；启动共享冷却；开启不可命中资格。 |
| ACTIVE | 由具体技能定义 | 具体技能独占位移/高度主张；锁定、目标引用和在飞武器继续存在。 |
| EXIT | 1 个物理帧 | 关闭不可命中；把控制权交还最新所有者；应用动作期间最后一条有效队列命令。 |
| COOLDOWN | 各技能定义 | 不能再次激活；飞机正常由玩家或 AI 控制。 |
| ABORT | 死亡、场景退出、Debug 中止 | 幂等关闭不可命中和控制权，不恢复已失效对象，不取消合法死亡。 |

### 3.2 控制优先级

从高到低：

1. 合法死亡、坠毁、剧情/Debug 清理；
2. 已在执行的主动特殊机动；
3. 紧急导弹规避；
4. 玩家显式移动、撤退、集合、编队命令；
5. 自动 BFM；
6. 巡航与无目标行为。

玩家在第 2 层期间发出的第 4 层命令不丢弃，而是进入“最后输入覆盖”队列。切控改变 EXIT 后的控制所有者，不改变正在执行的动作实体。

### 3.3 恢复规则

- 不能盲目恢复 ENTER 时的旧 `target_position`：若动作中收到新命令，以新命令为准。
- 若动作中完成切控，原飞机 EXIT 后交还 AI；不得恢复为旧的人类手动状态。
- 若目标在动作中失效，EXIT 时清空失效引用并让现有目标选择流程接管。
- 所有关闭操作幂等；死亡与场景退出可重复调用清理而不留下永久不可命中。

### 3.4 统一 R 槽与 AI 僚机双体现

- 五种 R 主动机动属于同一个互斥槽，正常卡池五选一，不增加主动技能选择 UI。
- 当前操控机只由玩家按 R 释放，不因威胁自动抢控制权。
- AI 僚机继续走自动威胁评估：来袭导弹进入各技能的触发距离，或后半球近距机炮威胁成立时自动尝试其已获得技能。
- 切控后身份立即反转：新受控机停止自动释放并听 R；旧受控机交还 AI 后恢复自动评估。正在执行中的动作不因身份反转中断。
- Debug/旧档异常同时拥有多项时，统一入口按 `vertical_break → displacement_roll → cobra_skill → evasion_herbst → manual_dodge` 顺序尝试；成功一个即停止。该顺序仅为损坏存档兜底，不是正常构筑语义。

## 4. 结构与组成（Structure）

- **共享协调器**：每架飞机持当前动作状态、控制权主张和幂等清理；不持全局单位列表的长期副本。
- **小队技能账本**：持已获得技能与共享冷却，切控时不复制。
- **命中资格查询**：CombatUnit 暴露按命中来源查询的统一入口；弹体/光束/碰撞在结算前调用，伤害入口保留最后一道防漏保护。
- **具体技能模块**：位移滚转和垂直越过只提交自己的轨迹/高度曲线，不各自复制输入、冷却、命中和清理逻辑。
- **Debug 可达性**：两个技能必须进入 F4 正式数据源清单，可绕过卡池门控强制授予，但仍尊重互斥与 `max_stacks=1`。
- **HUD 查询**：Aircraft 以 O(1) 公共只读 accessor 返回唯一 R 技能 id、总冷却与共享剩余冷却；不得由 HUD 扫描技能表、场景树或修改冷却。

## 5. 验收标准（Acceptance / Litmus）

- [x] 五种 R 技能在正常卡池双向互斥，持有任意一个后其余四个不再出现。
- [x] 当前操控机只响应 R；AI 僚机在导弹/后方机炮威胁下自动释放，切控后两种身份立即反转。
- [x] 冷却按玩家小队共享；连续切换 2 架僚机不能重复释放。
- [x] 动作中切控：原飞机完成动作，新飞机获得控制；两者均无永久控制锁或不可命中残留。
- [x] 动作中连续下两条移动命令，EXIT 后只执行最后一条。
- [x] 子弹、导弹、AOE、光束与机体接触在 ACTIVE 内不产生命中；锁定和在飞导弹不被清除，窗口结束后恢复正常。
- [x] 已存在 DoT、坠毁、越界与 Debug 销毁不被错误豁免。
- [x] 两侧轨迹都越界时激活失败且不消耗冷却；平分方向结果可复现。
- [x] F4 可直接授予、移除并触发两项技能；Debug 清单覆盖正式数据源。
- [x] 性能：激活时最多一次 O(N) 安全快照；无新增每帧全场扫描/容器分配；Sentinel + Lv15 压力样本 50 架存活、最后 1.01s 为 143 FPS。
- [x] i18n：技能名、描述、冷却与失败提示走 `tr()`，中英日三语齐全。
- [x] 文档：本 spec 与两个技能 spec 已登记 `_INDEX`，状态和重建标记一致。
- [x] 玩家仪表只显示唯一持有的 R 技能并在取得后常驻；成功发动后从 0% 充到 100%，不显示秒数/总 CD，切控不重置。
