# 进化科技树（具体名单）—— 5 档位 / 每步 ≥3 选 / 苏美欧系穿插 + 虚构超凡档

> 本文是 [aircraft-evolution](aircraft-evolution.md) §2.3 预留的"进化科技树子 spec"。父 spec 定**机制**（结算/换型/槽位继承），本 spec 定**具体名单 + 每架的进化出口**。
> ⏳ 机型名单、门槛等级、虚构机名字**都可调**；先落档存案免遗忘。

## 1. 设计铁律（Why + 硬约束）

1. **档位 = 现实世代**，同代机**平级**、互为横跨选项，**不是谁强化谁**（修正：F-22 / Su-57 / F-35 / J-20 同属档位 3，平级）。
2. **每架飞机进化必给 ≥3 个出口**：`本线深入 ×1 + 横跨邻类 ×2`（综合机如 F-15 可达更多）。
3. **只收能挂弹作战的机型**：纯侦察机（SR-71 / YF-12 / MiG-25R 等不挂弹）一律不入树。
4. **跨国系穿插**：苏 / 美 / 欧 / 中机型混编，进化中途可换系（玩法乐趣 > 血统考据）。
5. **顶端虚构超凡档**：六代机之上再留一档玩家"期待机"，纯虚构、可自由编名。

## 3.5 种类相邻环（横跨规则，✅ 用户定 2026-06-28：先试成环）

4 个种类排成一个**环**，每个种类只能横跨到环上**左右两个邻座**，不能直接跳到"对面"：

```
        制空
       /     \
   远程        电战
       \     /
        攻击
```
环序：**制空 — 电战 — 攻击 — 远程 —（回到制空）**

| 种类 | 可横跨的邻座 | 对面（够不着，要绕） |
|---|---|---|
| 制空 | 电战、远程 | 攻击 |
| 电战 | 制空、攻击 | 远程 |
| 攻击 | 电战、远程 | 制空 |
| 远程 | 攻击、制空 | 电战 |

- **每次进化 = 本线深入 ×1 + 横跨左右邻座 ×2 = 3 选**（正好满足 ≥3 铁律）。
- 想从制空玩到攻击（对面）→ 先横跨到电战或远程，再跨一步过去，**不能一步直达**。
- 例外：起手综合机 **F-15** 出口可更多（设计上让新手"自由"，见 §4 档位 1）。
- 这是"先试"的配置；觉得限制太死可改"全互通"（4 种类两两可跳）。

## 4.9 结算站界面规格（信息呈现，用户反馈 2026-07-20）

玩家在战区结算站要能一眼回答三个问题：**我现在开的是什么** / **那架好在哪** / **我差什么才能换过去**。
旧界面只有一行"机型｜种类·档位｜LV｜武器"，三个问题一个都答不了；本节把呈现规格定死。

### 4.9.1 三栏布局

| 栏 | 内容 | 宽度策略 |
|---|---|---|
| 左 | 进化树视图（自下而上，配色语义见 §4.x） | 吃剩余空间，**内套滚动容器** |
| 中 | 机体详情卡 | 固定 440 px，纵向滚动 |
| 右 | 三轴量表 + 强化三选一 | 固定 340 px |

**硬约束**：面板铺满视口（四边留白 32 px），**禁止按面板 size 手动居中**。
树宽 = `档位最大节点数 × (节点宽 + 间隔)`，T2 已 15 格 ≈1.6k px 且会随机型扩谱继续涨；
一旦超出视口，"居中"公式给出负坐标 → 整个界面向上/向左漂出屏幕（用户 2026-07-20 报的 bug）。
容纳超宽内容的唯一手段是**滚动容器**，不是重新算原点。

### 4.9.2 详情卡三段

1. **抬头** —— 机型名（种类色）+ 状态徽标（`当前机体` 金 / `可进化` 绿 / `未解锁` 灰）+
   `种类 · T档位 · LV门槛` + 武器清单 + 卡片标签 + 卡片描述。
   数据源全部来自树节点 + `PlayableAircraft` 档案，**加新机型不需要改界面代码**。
2. **机体特性** —— 关键属性表 8 行：结构强度 / 最大速度 / 加速 / 持续过载 / 滚转速率 /
   雷达范围 / 锁定时间 / 导弹挂载。值 = `base_params` 字段 × 档案倍率（与出生注入同一套生效口径）。
   看**非当前机**时每行追加**相对当前机的百分比增减**：改善=绿、劣化=红、差值 <0.5%=灰"—"。
   ⚠ 锁定时间是"越小越好"，方向必须翻转判定，否则更强的机会被标成红色。全项持平时显示"与当前机体持平"。
3. **进化需求** —— 逐条 `✓/✗ 名称 have / need`：等级门（`min_level`，回退档位默认）+
   全部三轴属性门（`gates`，语义见 [evolution-attribute-gates](evolution-attribute-gates.md)）。
   **已达标的门也要列出来**，只显示缺口会让玩家不知道总共要满足什么。全过时补一行"需求已满足"。

### 4.9.3 交互

- **任意已揭示节点**（当前机 / 爬线历史 / 当前机直接出口 / 跨局图鉴已拥有）点击即看详情——
  包括灰色够不着的：看不到需求就无从规划。剪影 `？？？` 节点仍不可点（迷雾未揭示）。
- 只有**真能进化**（直接出口 且 LV 达标 且 属性门全过）时才放行"进化到该机体"按钮；
  点灰机只换详情，不改选中态。
- 打开结算站时详情卡默认摊开**当前机**。

### 4.9.4 树连线与当前位置反馈

- 所有进化边使用**水平/垂直组成的直角折线**，从下方节点向上延伸；禁止恢复为节点中心间的自由斜线。
- 同一来源节点的多个出口共享来源档上方的水平线槽，形成“主干 → 横向分支 → 目标”的技能树总线；线槽在布局时一次性缓存，绘制时按远景 / 锁定 / 可进化 / 历史四种状态批量提交。
- 点击候选机时只显示临时白框；权威换型成功后，候选框清除，醒目的金色双层**当前机体框**迁移到新节点，同时刷新标题与详情卡。旧节点不得继续标为当前机体。
- 树仍是静态 UI：只允许在 `setup`、点击与换型成功时 `queue_redraw()`，禁止每帧重绘。
