# GPU 低多边形天气样板

## 1. 设计意图（Why）
2026-09-18 用户批准开始实现方案，并要求尽量使用 GPU。大片切面云层与贴地沙尘锋面共用既有三维视口；保持天气规则、单位可读性与严格 60 FPS。此为样板，不把未通过的性能门写成正式完成。

## 2. 数据定义（What）
### 当前正式 opt-in：密度体积（2026-09-27）

`AGL_WEATHER_VOLUME=on` 使用密度体积适配层；普通入口仍关闭。云空间块4000px，每块一个单位BoxMesh（尺寸2），X/Z半径为块宽一半。32×32 R8遮罩按像素中心采样权威 `_cloud_density_at`，峰值≤0.04时为空块；包含UGC mask。半高=380+240×峰值，中心高度=半高+140。固定形状种子=fract(sin(key·(12.9898,78.233))×43758.5453)，循环周期28+24×种子秒。保留样板的四椭球平滑并集、三频噪声侵蚀与点阵扫描；体密度额外乘smoothstep(0.015,0.32,遮罩采样值)。内部形变独立，整体位置严格跟随源风偏移，不使用样板的额外漂移速度。

64³共享NoiseTexture3D使用FastNoiseLite种子270927、频率0.075、4倍频、seamless；纹理异步就绪前不接管二维绘制。每块一份材质和1024字节密度图；最多96块，每帧最多构造2块。视图外扩1600px，0.5秒调度，位移>800px或缩放改变立即调度；跨度>28000×尺度升档，<10000×尺度降档。近档24步，远档16步；每步累积透射，透射<0.025提前结束。形变、散射近似与粒子位置在GPU计算，CPU同步源时钟和有限分块位置。

沙尘Box X半径=实际带宽/2+260、Y半径600、Z半径世界半宽，中心Y=580、X=权威中心。左右边曲线完全复用权威两正弦式，边缘720px羽化。按实际方向取前缘距离f，脊线exp(-((f-650)/750)²)，归一化高度=-0.50+1.28×脊线+0.12sin(z×0.003+相位)，18秒翻卷周期；沙尘材质不显示扫描点。128飞沙保留原权威可见范围裁剪，不做逐粒CPU更新。展示密度不改战斗权威，云体之间仍可能有抽象化缝隙。

### 旧壳体样板（保留几何回归入口）

2026-09-25 用户批准试做军事风格云带（概念A形态+C疏密）。云空间块宽4000，2×4个固定候选云团，X/Y间距2000/1000；中心以世界格点正弦偏移±180，采样权威密度d，d≤0.04跳过。每团为24分段、4环加上下封口的闭合壳体（192三角形），每块最多1536面。令格点g=(块X×2+x,块Y×4+y)、phase=sin(g·(12.98,78.2))；云团长轴半径(1150+300d)×(0.8+0.25cos(g.x×17.1+g.y×3.4))，短轴(300+100d)×(0.9+0.18phase)，旋转0.35+0.25phase弧度；径向三瓣/五瓣扰动分别0.20/0.08。四环尺度0.60/1/0.90/0.58，高度120/170/(300+100d)/(400+150d)，顶中心440+200d。高度归一化h后，明度=0.84+0.12h+0.04×max(0,normal·normalize(-0.4,0.8,-0.3))，RGB乘(0.98,0.99,1)。四环alpha=0/0.08/0.72/0.88，底中心0、顶中心0.94，顶点插值柔化单层壳边；背面剔除。不增加噪声纹理、多层全屏雾或逐粒CPU运动。

GPU风漂仍来自权威风偏移；起伏振幅12×顶点alpha、角速度0.35、X相位0.001。展示云团疏密是抽象表现，不能以云团之间的缝隙判断传感器遮蔽；天气战斗判定仍来自连续密度场。可见块外扩1200，缓存目标上限96，选择周期0.5秒，每帧最多构造2块；跨度超过28000×尺度升档，低于10000×尺度降档。缩远只扩大布局尺度，单块面数不增长。CPU剔除包围盒同步GPU风偏移并加24像素形变余量。

沙带沿既有中心、宽度和方向移动；横向16格、纵向64格；高度以推进侧曲脊表达，最高220，alpha上限0.16。飞沙固定128实例、每实例一个三角形，GPU使用实例种子与游戏时钟解析运动，无碰撞、无逐粒CPU tick。所有材质unshaded、无阴影、无额外灯光、无常驻新增视口、无实时体积雾。初始化复用既有预热器，三个32×32临时视口分别对普通云/沙带Mesh及飞沙MultiMesh实际绘制两帧后释放；Visual必须证明rendered=true，Headless跳过不算GPU预热通过。沙带网格在已配置启用时提前构造，不等局中首次风暴才构造。

## 3. 行为与公式（How）
WeatherSystem 保有云与沙尘密度、种子、UGC mask、时钟及战斗效果。三维天气只读取；游戏暂停时源天气不推进，慢动作通过源delta同步。配置初始化递增presentation_revision，消费者比较整数而非逐帧hash mask。密度块按云空间坐标缓存，节点变换承载风偏移并同步引擎剔除范围，shader负责内部形变。沙带从权威中心派生，不改变LOW-only。展示厚度不等同真实海拔，云层不得隐藏HUD或改变单位传感器状态。

AGL_WEATHER_VOLUME=off 保留原二维天气；初期通过 on 显式启用样板，性能和视觉闭合前不切正式默认。有效三维 owner 接管时仅停止旧二维绘制，释放时恢复；不停止源天气时间。弱引用读取按 Variant→TYPE_OBJECT→is_instance_valid。源释放后撤销几何，配置变更清空旧块。

## 4. 结构与组成（Structure）
独立 WeatherDensityPresentation 子节点由 volume_world_probe 持有，复用旧呈现基类的关闭回退、块选择和生命周期契约，与地图及机体共用 World3D、Camera3D 和投影基；各云块独立材质共享噪声，一份沙带材质、一份飞沙材质。CPU 只构造/调度分块与同步有限参数，GPU 执行连续形变。风暴没有活动时隐藏沙带与飞沙。透明三维视口使用预乘alpha合成，避免云边重复乘alpha变黑。

## 5. 验收标准（Acceptance）
- [x] focused：确定性轮廓、预算、天气高度边界和真实 owner 释放/恢复。
- [x] all：同步与生命周期全回归，wrapper 无运行时错误。
- [ ] Visual：三地图云系连通、沙带前缘、缩放/旋转/暂停、单位与地图可辨、无透明排序破面。
- [ ] 性能：同 seed/镜头/地图/人口/武器/UI A/B 各三次，C1 36 混合单位、C2 48 多战线，8/8 巡检；沙带活动专项、冷启动及完整局。avg/p1/worst/frames_below_60 分别记录，后者必须为 0，不删战斗演员。
- [ ] 净 CPU/GPU 增量目标分别 0.2/0.3ms；天气 ≤12000 面、飞沙128、资源目标8MiB；实际绘制批次需报告，分块优先保证裁剪而非假称单次 draw。
