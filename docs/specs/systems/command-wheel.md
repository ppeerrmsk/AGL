# 命令轮盘（长按左键 · 即时战术命令）

> 长按左键呼出扇形命令轮盘（marking menu），再拖向命令方向、松开执行：按住的**位置是参数**、激活后的拖动**方向是动词**。给 RTS 指挥提供战场内即时动词，与 Tab 战术地图（长程规划）分工。

## 1. 设计意图（Why）

- **体验缺口**：左键目前只有一个动词（点空地=移动、点敌机=攻击、双击=机炮冲锋），玩家无法表达"全队来这别打了""守住这里""打它但别死缠"。轮盘让同一个点击位置可以换动词，且全程不离开战场视角。承接 [[project_rts_direction]]。
- **操作语法（核心约定，用户定稿）**：**单点 = 只操控自机**——左键点敌/点地只对当前操控机生效，其余队员按各自 AI 逻辑判断；**轮盘 = 永远全队广播**——呼出轮盘即下达全体指令，用于紧急/关键时刻。这就是"跟随状态下开自己的飞机 vs 以指挥官身份带动全队"的 RTS 分工，两层输入语义绝不混用。
- **Litmus 自检**（DESIGN_PHILOSOPHY）：
  - "操控走位、不精确控速/控枪"——轮盘只下达意图（集合/防守/姿态），执行仍走飞机物理 + 既有 AI 战术层。
  - "物理优雅"——所有命令靠真实转弯/盘旋抵达与执行，无瞬移无伪造曲线。
- **反模式规避**：
  - 不新增命令权威：目标类命令写进 `commanded_target` 铁律通道（[[rts-command]]），紧急集合=批量触发铁律既有的"移动命令清除条款"，不引入凌驾铁律的新优先级层。
  - 不放微操：撒 flare 等保持自动化（分层规避策略）；低频状态切换留 HUD/战术地图，轮盘只收"高频 + 时间敏感 + 单击表达不了"的命令。
  - 已明确否决：**攻击移动**（敌人无阵线，"推进"无定义）、**无视目标**（右键取消已覆盖）。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 手势与呼出参数（`CommandWheelParams`，resources/command_wheel.tres，@export 可调）

以下 px 均为**屏幕像素**（UI 层），与世界坐标无关。

|---|---|---|

| `charge_visual_delay_s` | 0.08 s | 按住多久后开始显示蓄力圈——普通快速单击零 UI 噪音 |
| `dead_zone_radius_px` | 30 px | 中心死区；松开在死区内 = 取消，不执行 |
| `ring1_outer_px` | 110 px | 一环选择区外沿（30~110 为一环；指针进入扇区即高亮） |
| `ring2_gesture` | 悬停开关槽即弹出二级面板；指针拉出 176 px 进入选项区，按角度选项 | **二级面板（已启用，用户定稿）**：开关槽显式选值（开/关、爬升/低空、集火/分火、散开/紧密），拉到选项上松开=设为该值，直接在槽上松开=翻转；当前生效值带标记点 |
| `time_scale_in_wheel` | 0.3 | 轮盘呼出期间全局时间流速（子弹时间，不全停；松开/取消恢复 1.0） |

### 2.2 上下文判定

| 按下时命中 | 呼出 |
|---|---|
| 敌机 / 敌地面单位 | **攻击轮盘**（§2.4），按住的单位 = 命令目标 |
| 空地 / 海面 | **小队命令轮盘**（§2.3），按住的世界坐标 = 命令位置 |

### 2.3 小队命令轮盘槽位（按住空地）

| 方向 | 命令 | 类型 | 语义摘要 |
|---|---|---|---|
| 上 | **紧急集合** | 一次性广播 | 全队立刻中断一切任务（含攻击命令），飞往该点集合（§3.3） |
| 下 | **防守此区** | 队级持续任务 | 以该点为圆心守 3 km 警戒圈；全队到区后自主搜索、分头接战，持续清剿圈内全部敌人（§3.4） |
| 左 | **自动交战 开/关** | 状态开关 | 镜像 HUD 战术栏同一状态（§2.5） |
| 右 | **高度偏好 两态循环** | 状态开关 | **爬升 ↔ 低空** 循环（合并面板 3/4 两个 toggle 为一槽）。"默认"第三档评估后搁置（2026-07-12）：需给 AltitudePreference 加 NONE 且改动面横跨玩家高度自治全路径，收益存疑；playtest 想要再开 |
| 右下 | **自动发射 开/关** | 状态开关 | **队级广播（2026-07-12 定稿）**：轮盘切换写入全队成员 `missile_auto_fire`（轮盘=全队语法）；F 键保持只切自机——两入口作用域刻意不同 |
| 左下 | **撤离此区** | 一次性广播 | 全队立刻脱战，以按下点为圆心**径向散出**，直至距该点 ≥ 3 km（§3.7） |
| 左上 | **取消**（红色） | 轮盘取消 | 取消本次轮盘交互（如同没按过），**不**影响进行中的战斗/移动状态；两轮盘统一位置与配色 |
| 右上 | 预留 | — | 候选：侦察（待地图扩展/迷雾）、拖刀诱饵 |

- 开关槽位实时显示当前状态（ON 亮色 / OFF 灰暗 + 状态文字；三态槽显示当前态名），拖到槽位松开 = 翻转/循环到下一态。

### 2.4 攻击轮盘槽位（按住敌方单位）

**作用域 = 全队广播**：攻击轮盘的任何命令都让**全队**清掉各自当前目标，统一以所选姿态、按当前**火力分配状态**（§3.6：集火=全咬按下目标 / 分火=按下目标为锚点 1:1 分配集群）投入攻击。实现上 = 对每架机写入 `commanded_target` + posture，走铁律通道逐机持久（行为基础 = [[squad-cohesion]] 焦点开火）。

| 方向 | 命令 | 语义摘要 |
|---|---|---|
| 上 | **保持距离攻击**（游击） | 全队以 STANDOFF 姿态攻击：一击脱离循环（§3.5） |
| 下 | **突击**（狗斗） | 全队以 ASSAULT 姿态攻击：锚定缠斗不脱离 |
| 左 | **火力分配 切换** | 状态开关：**集火 FOCUS** ↔ **分火 SPREAD**（§3.6），跨命令持久 |
| 右 | **阵型纪律 切换** | 状态开关：FREE 自由散开 ↔ TIGHT 紧密队形（齐射），数值与行为归 [[formation-discipline]]。从小队命令轮盘移入——它决定的是"怎么打"，归攻击语境 |
| 左上 | **取消**（红色） | 取消本次轮盘交互，与小队命令轮盘同位同色 |

- 攻击轮盘四主向已满；单机猎杀等后续候选走对角扩展槽。

- **与单点的分工**（操作语法，§1）：左键单点敌机 = 只给**自机**下点名命令，僚机按各自 AI/可命中性评分行动；双击冲锋 = **自机**机炮突击（既有行为不变，不因轮盘改动）。

### 2.5 战术开关的双入口约定

- 轮盘开关与 HUD 战术栏是**同一状态的两个视图**（同源字段，非复制）；任一入口切换，另一入口即时同步。
- v1 保留双入口；**用户方向已定：长期把开关全部收束进轮盘**，验证顺手后战术栏按钮后撤（可保留纯状态显示），届时更新本 spec。

### 2.5.1 火力分配参数

| 字段 | 默认值 | 说明 |
|---|---|---|
| `fire_allocation` | `enum { FOCUS, SPREAD }`，默认 `FOCUS` | 队级状态，攻击轮盘左槽切换，跨命令持久（记住上次选择） |
| `spread_cluster_radius_px` | 2000 px（=1000 m，待调参） | SPREAD 各自接敌的**目标池**半径：按下目标为锚点，此范围内有效敌方进池 |
| `surround_min_axis_sep_deg` | 45°（待调参） | FOCUS 包围：相邻攻击机接近轴的最小方位分离角，杜绝追尾长蛇 |

### 2.6 明确搁置项

| 项 | 处置 | 原因 |
|---|---|---|
| 导弹优先 / 机炮优先（TACTIC_MISSILE_PRIORITY / TACTIC_GUN_PRIORITY） | **不进轮盘**，暂留战术面板，待用户检讨（大概率删除） | 姿态命令（突击/保持距离）+ 武器准则距离带竞选已覆盖"用什么武器"的意图；残留价值仅"省导弹"弹药经济，未来更宜并入 [[weapon-employment-doctrine]] 的弹药感知 |
| 二级分叉的占用者 | **已启用**：开关槽显式选项面板（§2.1） | 原候选（导弹/机炮左右分叉）仍搁置不进轮盘 |
| E 规避 | 不进轮盘 | 即时应激动作（自机被咬 + 护卫联动），有专键、按下即生效；撤离此区 = 空间版规避（区域 + 时限），两者语义不同不合并，但共享同一套规避态/加速注入 |

### 2.7 紧急集合参数

| 字段 | 默认值 | 说明 |
|---|---|---|
| 广播范围 | 全队（含未选中、被打散、追击中的僚机） | 与普通移动命令（只作用当前操控机/选中机）的核心区别 |
| `arrival_radius_px` | 600 px（=300 m，世界坐标） | 进入即视为到达 |
| 途中速度 | **全力加速**（用户定稿：所有人集体加速过来，尽可能快） | 与规避加力同语义；**必须注入 `effective_max_speed_kmh` / `effective_cruise_speed_kmh` accessor**（CLAUDE.md 机动性 buff 强制规范），到达即撤销 |
| 途中交战 | 抑制自动交战重锁；不主动接敌 | 求生规避仍高于本命令（有界 + flare 优先不脱队，见分层规避策略） |
| 到达后 | 重整编队；自动交战按 HUD 开关当前状态恢复 | |

### 2.7.1 撤离此区参数

撤离 = **一次性逃逸机动 + 限时禁入区**两部分。

| 字段 | 默认值 | 说明 |
|---|---|---|
| `evac_radius_px` | 1500 px（=3000 m；原 5 km 用户调参缩小，2026-07-05） | 撤离圈半径：圈内成员散出至圈外；圈本身成为限时禁入区 |
| `evac_duration_s` | 20 s（待调参） | 禁入区持续时间：期间 AI 自主决策不得重新进入撤离圈；到时自动解除 |
| 圈外成员 | 逃逸机动**不生效**（不打断其当前行为） | 用户定稿；但禁入约束同样约束它们（期间不得进圈） |
| 逃逸执行 | **直接等同规避模式**（用户定稿）：圈内成员进入规避态全力加速逃出——速度加力/flare 优先级语义与规避完全一致（同一 accessor 注入点），仅方向由径向出圈目标给定（不做威胁向机动） | 出圈即解除规避态 |
| 实装注记（2026-07-12） | 速度经 `command_sprint` 标志走同 accessor 通道注入 ×1.4（`COMMAND_SPRINT_MULT`，与规避加力同幅）；**未真正置 evasion_mode**——其威胁向机动几何会抢径向出圈方向；flare 反制由既有"被锁自动撒弹"逻辑覆盖 | 紧急集合途中同用此标志（到达 arrival_radius 逐机解除） |
| 逃逸途中交战 | 圈内逃逸者抑制自动交战、不主动接敌 | 求生规避仍更高（有界 + flare 优先）。圈外成员照常交战，但目标选择过滤圈内敌人 |
| 禁入约束对象 | **仅 AI 自主决策**（自动交战选目标 / 追击路径 / 编队巡航） | 玩家显式输入不受限：新单点/点名/广播按最新输入覆盖规则处理（§3.2） |
| UI | 禁入圈线框 + 剩余秒数，仅激活期间绘制 | 性能守则：激活期间才 redraw，平时零开销 |

### 2.8 防守此区参数

| 字段 | 默认值 | 说明 |
|---|---|---|
| `guard_radius_px` | 1500 px（=3000 m） | 警戒圈：敌方单位**进圈即进入清剿目标池**；不做圈外接近预测，防误开火 |
| `orbit_radius_px` | 500 px（=1000 m） | 空闲时绕圆心盘旋的半径；保证盘旋航迹不出警戒圈 |
| `leash_exit_mult` | 1.15 | 追击中的目标飞出 `guard_radius × 1.15` → 放弃、返回圈内（滞回防抖；比 rts-command 自动交战拴绳 1.5 更紧，防"防守被风筝走"） |
| 铁律交互 | 玩家点名命令凌驾防守任务 | 命令目标死后该机**回防守圈**而非回编队 |

### 2.9 交战姿态（posture，随 `commanded_target` 走铁律通道）

`enum EngagePosture { DEFAULT, STANDOFF, ASSAULT }`，作为字段挂在命令上，逐机持久、跨 1-4 切控不丢，清除时机与 `commanded_target` 相同。

**定义轴是交战几何，不是武器类别**——武器选择交给 [[weapon-employment-doctrine]] 距离带竞选，姿态只约束几何节奏，保证任意 loadout（含纯机炮机）都能执行：

| 姿态 | 几何节奏 | 武器竞选偏置 |
|---|---|---|
| DEFAULT | 既有 BFM engage 行为，不变 | 准则默认 |
| STANDOFF（保持距离） | 一击脱离循环：进入包络 → 输出 → 冷转脱离 → 再进入（§3.5） | 只允许远距离带武器参选；保持距离值 = **当选武器最佳包络带**（电磁炮远、导弹中），不写死数字 |
| ASSAULT（突击） | 锚定缠斗，咬住不脱离 | 偏置机炮 / QMAAM 近距带 |

## 3. 行为与公式（How）

### 3.1 手势状态机

| 状态 | 触发 | 效果 |
|---|---|---|
| IDLE | — | 正常点击语义（单击/双击/右键全部不变） |
| PRESS_PENDING | 左键按下 | 计时 + 记录按下点与命中上下文；`< hold_threshold_s` 内松开 → 按普通单击/双击处理；期间位移不提前激活轮盘 |
| WHEEL_ACTIVE | 长按达到 `hold_threshold_s` | 呼出对应轮盘 + `time_scale = 0.3`；指针方向实时高亮扇区；拉出 `ring1_outer_px` 且槽位有二级 → 展开左右分叉 |
| EXECUTE | 在扇区内松开 | 执行该命令，恢复 time_scale |
| CLICK 回退 | 在**死区内松开** | **回退普通单击**（用户定稿：点了地点就该去）——按按下瞬间参数回放移动/点名语义；中心文案显示"前往此处 / 攻击目标" |
| CANCEL | **左上取消槽松开** / 轮盘期间按右键 | 不执行任何命令、不影响进行中的战斗/移动状态，恢复 time_scale |

- 与右键长按急刹（[[rts-command]] v6）互不干扰：各自独立键位与阈值。
- 轮盘期间镜头与游戏继续以 0.3x 运行（不暂停），命令的位置参数取**按下瞬间**的世界坐标（子弹时间内世界仍在动，以按下点为准，防止松开时参数漂移）。

### 3.2 命令优先级总表（自上而下）

```
求生规避（有界，flare 优先不脱队）
  > 紧急集合 / 撤离此区（发令瞬间广播清除 + 完成前交战锁定；非常驻层级）
  > commanded_target 铁律（逐机，含姿态字段）
  > 防守此区 / 巡航等队级持续任务
  > 自动交战
```

**最新输入覆盖规则（用户定稿）**：任何新的玩家输入（单点 / 轮盘 / 战术地图）都**覆盖**接收者当前的移动型命令（普通移动、紧急集合、撤离、防守的移动部分）——轮盘命令不是锁，随时可被后续指令打断。覆盖按作用域执行：单点只覆盖**自机**的移动命令（其余僚机继续执行原广播命令），轮盘广播覆盖**全队**。

### 3.3 紧急集合（伪代码）

```
on regroup(point):
    for ac in 全队:
        ac.commanded_target = null          # 铁律既有清除条款："对本机另下移动命令"
        ac.clear_combat_target()
        ac.engage_locked = true             # 到达前抑制自动交战重锁
        ac.target_position = point
    # 途中：规避照常（有界）；不接敌
    on ac 进入 arrival_radius:
        ac.engage_locked = false
        归队重整编队；自动交战按 HUD 开关恢复
```

### 3.4 防守此区（队级区域清剿状态机）

> **用户增强定稿（2026-08-01）**：防守不再只是长机拦截一个入侵者，而是区域内的持续自主清剿任务。全队进入区域后主动搜索圈内全部敌人，分头接战；当前目标阵亡后自动领取下一个，直到圈内敌人全灭，再恢复盘旋守备。边界纪律保持不变：不获取圈外目标，现目标飞出范围即停止追击回防。

| 状态 | 触发 | 效果 |
|---|---|---|
| TRANSIT | 接令 | 全队巡航至圆心（同普通移动，途中不接敌） |
| ORBIT | 抵达 | 绕圆心 `orbit_radius` 盘旋（复用既有盘旋/编队行为） |
| CLEAR | 敌方进入 `guard_radius` | 建立圈内目标池；每架到区成员自主领目标，优先选择当前认领数最少者、并列取离自己最近者，避免全队浪费在同一目标上 |
| CHAIN | 当前目标阵亡 | 该机在下一个低频指挥 tick 自动领取池内下一目标；循环直到目标池清空 |
| RETURN | 当前目标飞出 `guard_radius × leash_exit_mult` / 目标池清空 | 放弃越界目标；有其它圈内敌人则立即换目标，否则返回 ORBIT |

- 清剿目标借用逐机 `commanded_target` 铁律通道保证玩家当前操控机与僚机都真正投入攻击，但由防守任务记录所有权；目标死亡、越界或命令结束时必须回收，不能残留成无限追击。
- 搜敌与分配只挂既有 `auto_engage_interval_s` 低频 tick；每 tick 一次 `CombatUnit.all_units` 建池，再做最多 9 架成员的轻量分配，不新增逐帧扫描。
- 新的移动/集合/点名命令覆盖防守任务（对被点名机是逐机覆盖，其余机继续防守）。

### 3.5 STANDOFF 一击脱离循环（单机状态机）

| 阶段 | 进入条件 | 行为 | 退出 |
|---|---|---|---|
| INGRESS | 循环起点 / EGRESS 结束 | 飞向目标至当选武器最佳包络带 | 进带 → FIRING |
| FIRING | 在包络带内 | 保持带内输出（走武器准则瞄准语义） | 打出一轮 / 带内滞留超 4 s（待调参）→ EGRESS |
| EGRESS | 输出完毕 | 冷转脱离，拉开至 `包络带外沿 × 1.5`（待调参） | 到位 → INGRESS |
| DRAG（防碰瓷） | 任意阶段目标压进 `带内沿以内` | **先拉开再回头**：向外脱离直至重回带内沿之外，不就地转缠斗 | 脱出 → INGRESS |

- **纯机炮机降级**：无远程武器时循环退化为 boom-and-zoom——高速掠袭单 pass 输出一梭即 EGRESS，绝不进持续转圈；姿态语义保持成立。
- **敌方复用**：本循环与 AF-03"BVR 打带跑"同构，实现时优先复用其代码与调参经验。

### 3.6 火力分配（FOCUS 集火 / SPREAD 分火）

用户定稿语义：**集火 = 全队打同一目标 + 包围战术；分火 = 允许各自接敌**。超杀不做 AI 自动干预——玩家显式选集火即接受超杀（命令是铁律），选择权在开关。

| 状态 | 语义 |
|---|---|
| FOCUS 集火（默认） | 全队 `commanded_target` = 按下目标，并执行**包围几何**：各机接近轴按方位扇区分离（相邻攻击轴 ≥ `surround_min_axis_sep_deg`），多角度合围，目标往哪转都有人有射击解。TIGHT 阵型时例外：整队单轴齐射，阵型纪律优先于包围（[[formation-discipline]]）。目标死亡 → 命令结束回归 |
| SPREAD 分火 | **各自接敌**：按下目标为锚点，`spread_cluster_radius_px` 内敌方构成目标池；各机在池内按可命中性评分**自主选择、自主切换**（复用既有自由僚机逻辑 + 队友超杀让路，**无中心分配器**）；池清空 → 命令结束回归 |

- FOCUS 包围轴分离只约束**接近方位**，不伪造位置——各机仍靠真实 BFM 转弯绕到自己的扇区（物理优雅）。
- **实装注记（2026-07-12）**：包围 = "进入门点"实现——距目标 >1.5 km 时追击点改到自己扇区的 1.3 km 门点，进入收敛距后回归正常 BFM；SPREAD 选目标 v1 用"少人打优先 + 距离"轻量代理（完整 engageability 评分器耦合 AIController，playtest 观感不足再深接）。
- 与 TIGHT 阵型正交兼容：FOCUS+TIGHT = 整队单轴齐射饱和；SPREAD+TIGHT = 齐射窗口内各机朝各自所选目标释放，一波清一片。
- 典型搭配（自由组合，互不锁定）：突击 + 分火 = 整队冲锋各咬面前一个；保持距离 + 集火（散开）= 多角度游击围猎；保持距离 + 集火 + 紧密 = 齐射饱和硬目标。

### 3.7 撤离此区（伪代码）

与紧急集合互为镜像：集合 = 向一点**收拢**，撤离 = 从一点**散出**（每机各自最近路径出圈）+ 限时禁入。

```
on evacuate(point):
    exclusion = { center: point, r: evac_radius_px, t_left: evac_duration_s }   # 全队唯一，重复发令则重置替换
    for ac in 全队:
        若 dist(ac, point) ≥ evac_radius_px: continue    # 已在圈外：逃逸机动不生效
        ac.commanded_target = null; ac.clear_combat_target()
        ac.engage_locked = true
        dir = (ac.position - point).normalized()          # 径向朝外 = 该机最快出圈方向
        若 dir ≈ 零向量（恰在点上）: dir = ac.heading 方向
        ac.target_position = point + dir × evac_radius_px × 1.1   # 10% 余量防出圈判定抖动
    on dist(ac, point) ≥ evac_radius_px:
        ac.engage_locked = false → 圈外恢复正常行为（自动交战按 HUD 开关）

exclusion 存续期间（t_left 递减）:
    AI 自主决策全部过滤禁入圈：自动交战不选圈内目标；追击目标遁入圈内 → 视同拴绳出界放弃；
    巡航/编队/防守路径不得穿圈（简化判定：目标点在圈内即拒绝，不做绕行寻路）
    玩家显式输入不受限（§3.2 最新输入覆盖）：单点 → 解除自机逃逸/禁入；新广播命令 → 终止整个 exclusion
    t_left ≤ 0 → 禁入解除，全队行为恢复正常
```

- 小队聚在一起时各机径向方向近似一致，实际观感是整队同向撤出；被打散时各走各的最短路径。
- 禁入是**决策层过滤**而非物理墙：不做绕圈寻路，只保证 AI 不把目标/航点设进圈内——够用且零寻路成本。
- 典型用途：躲 BOSS 大招 / 脱出 SAM 圈 / 放弃一片打不动的区域。

### 3.8 移动指示线约束（UI，硬规则）

- **移动指示线（自机到移动目标的那根线）任何时刻只对当前操控机绘制**；僚机——包括带广播命令、正在执行紧急集合/撤离/防守的僚机——**一律不绘制**移动线，且不得闪烁。
- 已知现状 bug 登记：指示线偶发持续闪烁、甚至出现在僚机身上。**实装阶段 1 之前须先修复**（轮盘会高频下发 target_position，若绘制条件不严，闪烁会成倍放大）。

### 3.9 交互反馈（范围圈 + 功能说明条 + 压暗背景，用户定稿）

- **范围圈只给空间语义命令**：悬停槽位时按命令语义绘制世界坐标范围圈（半透明填充 + 描边，随相机缩放）——撤离 = 按下点 3 km；防守 = 按下点 3 km 警戒 + 1 km 盘旋双圈；集合 = 按下点 300 m 到达圈；自动交战 = 以长机为心 1.5 km 搜敌圈。**火力分配 / 阵型纪律等模式开关不画圈**（无空间意义，用户定稿）。
- **功能说明条（tooltip）**：轮盘下方常驻说明条（视口边缘钳制），显示悬停项的教程文本（`WHEEL_TIP_*`，13 条三语：含"什么是游击/打带跑"等概念解释）；未悬停时解释中心默认行为（前往此处 / 攻击目标）。
- **UI 优先级**：轮盘 CanvasLayer=100，高于全部战场 UI（HUD=10 / 战术地图=15 / 战区提示=18 / 边界提示·教程·升级=20 / debug=30-31）；激活期间绘制**全屏压暗背景（黑 35%）**，边界警告等横幅统一淡出，轮盘 + 范围圈成为唯一视觉焦点（与 0.3x 子弹时间配套）。
- **指挥对象高亮**（用户定稿）：攻击轮盘期间按下的目标（敌机/地面单位通用）套高亮标记层——脉冲柔光圈 + 主环 + 4 段慢旋括环，与槽位高亮同色系（黄），跟随目标移动、随镜头缩放；屏幕空间覆盖实现（不改单位本体渲染），目标阵亡即消失。明确"我现在正针对这个目标下令"。
- **呼出蓄力指示圈**（用户定稿 2026-07-20，仿机场停靠引导灯）：按住 0.08 s 后在按点出现小圈——外圈 12 枚引导灯随蓄力进度顺时针依次点亮 + 进度弧 + 一段追逐流动的扫描光带；>80% 整体切高亮色预告"即将进入"；**转满（0.65 s）才呼出轮盘**。快速单击在静默期内结束，零 UI 噪音；按住期间移动指针不会提前激活，避免连点/双击误触。

## 4. 结构与组成（Structure）

- **输入/UI 层**：新模块 `CommandWheel`（scripts/rts/ 下，手势状态机 + 轮盘绘制 + 上下文判定），参数 Resource `CommandWheelParams`。遵守性能守则：轮盘仅激活期间 redraw，IDLE 零开销。
- **执行端**：全部走 `SquadCommandController` 扩展（`command_regroup` / `command_guard_area` / `command_attack(target, posture)`），survivor_mode 只转发。防守圈与 STANDOFF 循环的 AI 执行在 AIController 战术层。
- **状态同步**：三个开关直接读写既有 HUD 战术栏同源字段，无新状态。
- **复用**：`commanded_target` 铁律通道、`SquadCoordination` 编队传播、engageability 评分、AF-03 打带跑、既有盘旋行为。
