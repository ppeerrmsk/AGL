# 玩家恐惧与可装配的小队恐惧锥（Wraith 首发）

> 紫色锥形范围从施放机机头展开；在其中停留过久的玩家机或僚机会恐惧 5 秒，失去飞行控制、启动加力并尽可能远离施恐惧者。该能力可装配给不同小队，Wraith 是首个配置。

**设计状态**：2026-09-27 用户批准按本稿试装；模块、Wraith 装配、HUD 与 F4 已实现。自动回归通过，视觉/性能证据见 §5.1；完整局手感和平衡尚未定稿，不标记正式验收完成。

## 1. 设计意图（Why）

- 让 Wraith 成为首个主动恐惧玩家小队的敌人，以可避让的机头威胁区拆散编队并迫使玩家改变进攻方向。
- 惩罚持续暴露，不惩罚擦边；“预警 → 照射累积 → 远离来源 → 恢复”必须看得懂。
- 小队只装配配置和生命周期适配器，不复制 Wraith 专用逻辑；调度、照射判定、受害者逃逸和信息遮蔽分别持有自己的职责。
- 恐惧复用标准 FEAR 状态及免疫，不新增平行状态；新增玩家小队的控制与信息遮蔽消费规则。
- Litmus：符合信息可感知、正常物理的延迟手感、BOSS 独有机制、自动作战与 60 FPS 红线。不增加直接伤害、回血、机体属性或血量阶段。
- 对既有 Wraith“只通过执行误差调难度”的范围作显式扩展：本提案新增独立招式，但不改变 KNIGHT/SNIPER 角色或四相战术循环。批准后回写 Wraith 主 spec。

## 2. 数据定义（What）

所有距离先用世界平面米计算，绘制按 `PIXELS_PER_METER = 0.5` 转换。除恐惧 5 秒外均为建议初值。

| 参数 | 值 | 说明 |
|---|---|---|
| 恐惧时长 | **5.0 s** | 游戏时间，暂停时不流逝 |
| 锥体长度 | 3000 m / 1500 px | 从机头判定原点向前 |
| 锥体全夹角 | 60° | 左右各 30°，随真实航向转动 |
| 预警 | 1.0 s | 只显示边界，不累积 |
| 有效照射窗口 | 6.0 s | 在完整预警之后开始 |
| 连续暴露阈值 | 2.0 s | 每架受照飞机独立累积 |
| 离锥规则 | 立即清零暴露 | 不保留跨次照射的进度 |
| 并发上限 | 每个已装配小队 1 架 | Wraith 配置仅原四机，YF-23 支援不具有此招式 |
| 首次等待 | ENGAGED 后 10.0 s | 登场演出不计时、不释放 |
| 后续冷却 | 均匀随机 18.0–24.0 s | 从释放结束或中断时起算，每轮只采样一次 |
| 解控保护 | 3.0 s | 玩家小队单机对再次 FEAR 免疫；结束后才能重新积累 |
| 一次窗口触发上限 | 每目标 1 次 | 多目标可在不同时间达到阈值 |
| 调度决策频率 | 2 Hz | 选释放者；暴露检测例外为 10 Hz，满足移动锥体反馈 |
| 逃逸方向 | 施恐惧者位置指向受害者位置 | 来源存活时每 0.1 s 更新；已在远离则继续远离 |
| 逃逸引导距离 | 沿逃逸方向 3000 m | 受真实边界约束，尽可能增大与来源的距离 |

## 3. 行为与公式（How）

### 3.1 通用小队调度与 Wraith 首发配置

`等待 → 可释放 → 预警 1s → 照射 6s → 冷却 18–24s`。

1. 模块只从宿主提供的候选成员集合选施放者，不识别 Wraith 呼号、机型或 KNIGHT/SNIPER。Wraith 的适配器提供正式接战的原四架 F-47；只有本场生成前的历史击败次数 `prior_defeats >= 3` 才装配（第三次获胜后的下一场起），0/1/2 次不创建能力控制器。解锁由独立 Wraith 强化装配层读取本场快照并选择配置，通用配置、控制器和受害者模块不读取生涯档案。其它小队经自己的规则显式装配，默认不启用。本场胜利不追溯改变已生成的实例，YF-23 支援仍不装配。
2. 候选必须存活、非坠毁、可见、非光学隐形/传感器隐藏，且至少一架可受恐惧的玩家小队成员位于候选锥内。按原号机循环优先选择，跳过上次释放者；只剩一架合格时允许再次选择它。无候选保持就绪，2 Hz 重试，不空放。
3. 不强改释放者的航向或战术角色。锥体跟随真实机头与姿态在世界平面的投影；2D/3D 显示消费相同判定几何，范围不得随图标缩放改变。
4. 从预警开始到照射结束，释放者保持可见并暂缓自身隐形。攻击/其他来源强制隐藏、死亡、退场、场景终止或脱离正式接战都立即中断锥体、清空该轮暴露记录并进入冷却；其它 Wraith 可正常隐形。
5. 冷却及暴露都使用游戏时间，暂停不推进；无每帧随机释放概率。不同宿主控制器各自拥有冷却、施放者、随机数流和暴露记录，不共享可变 Resource；同一目标的 FEAR 状态、首次来源和解控保护仍为受害者侧单一权威。

令机头原点为 `o`，目标平面位置为 `p`，真实航向为 `h`，则：

`f = (sin(h), -cos(h))`，`v = p - o`。

当 `0 < length(v) <= 1500 px` 且 `dot(v / length(v), f) >= cos(30°)` 时在锥内；机头原点重合视为在内。外边界计入，锥外计时立即归零。虚拟高度不作额外门槛，避免可见覆盖却不生效。

只遍历当前玩家小队的存活飞机；无人机、`no_pilot`、`fear_immune`、`sig_status_immune`、已 FEAR 或解控保护中的飞机均不积累。边界判断和累计使用固定 0.1 s 游戏时间步，允许阈值触发最多一个采样周期误差，不把暂停或卡帧缺失时间一次性补算成照射命中。

到达 2.0 s 的目标通过带来源的公共 FEAR 入口提交施放机与时长，内部调用正式 `apply_status(FEAR, duration, "no_refresh")`。只有确认本次新状态被接受后，才能记录来源、激活逃逸/强制加力/读数遮蔽并发提示。免疫、已 FEAR 或保护期拒绝返回时不得写任何副作用。同一次窗口不再次尝试成功受控目标。逐目标异步累计不是圆形 AOE 广播，不触发玩家施恐惧的奖励或 SLOW 联动。

### 3.1.1 电战预算免疫合同

- 现有机体技能为 **JAS 39E「电战预算」**（`sig_gripen_e`），正式技能数据 `stat = sig_status_immunity`，效果注入设置 `Aircraft.sig_status_immune = true`。免疫 JAM / SLOW / FEAR 的行为权威见 [aircraft-signature-skills](aircraft-signature-skills.md)。机型名称本身不等于已经装备技能。
- 恐惧锥预筛选与正式施加时都必须尊重该标志及既有 `no_pilot` / `fear_immune`。不为 Wraith 或其他小队另写能绕过正式状态入口的免疫白名单。
- 持有者在锥内待满任意时长都不能进入 FEAR、逃逸意图、强制加力或读数遮蔽；仍可正常手动开启加力。可显示外部紫锥，但不显示本机恐惧累积条。
- 技能在暴露累计期间生效时，下次采样清除该机暴露且最终施加再次检查免疫；不产生“累计早于免疫所以仍命中”的竞态。正在 FEAR 时新获得技能是否清除既有状态遵循原技能合同，本模块不暗加净化能力。
- 回归必须从正式 `SurvivorPlayer.apply_upgrade` 授予技能开始，不能只在测试里把免疫 bool 置真；验证授予后的实际成员、切控与后来入队的技能重放。仍按技能现有归属规则授予，不因模块装配改动技能作用范围。

### 3.2 恐惧控制权

- 玩家小队中任何合法来源的 FEAR 均采用此控制消费规则；本招式提供固定 5 秒。既有玩家技能对敌机的 FEAR、BOSS 逃逸豁免与敌机解除后禁加力规则维持原契约。
- 恐惧归属于**飞机实体**，不归属于当前玩家引用或整个小队。触发当帧撤销该机急刹/拖拽与手动机动接管，保存实际施放机的 WeakRef 与位置快照；通过独立 FEAR 意图槽接管方向、目标速度和加力请求。来源为发出紫锥的飞机，不取其长机、受害者当前攻击目标或最近敌人。
- 优先级：死亡/退场/导演舞台隔离 → 战场硬边界安全约束 → FEAR → 普通事件飞行指令、急刹、规避、战术、编队和手动指令。恐惧不打断正式终态清理。
- 自由空间中 `escape_dir = normalize(victim_position - source_position)`；每次来源采样更新引导点为 `victim_position + escape_dir * 1500 px`。这使飞机尽可能远离造成恐惧的目标：原本正远离时保持逃离，来源在侧面时向远离它的一侧转弯，来源移动时相应修正逃逸方向，不执行固定反向掉头。
- 位置完全重合时优先沿上次有效逃逸方向，无历史时采用施放机当前机头方向（锥体向外方向）；无有效来源的新申请直接拒绝。来源成功施加后死亡/释放/改变阵营，使用最后一次合法位置快照逃逸至本轮结束，不访问已释放对象，也不改追另一个敌人。
- 接近边界时复用现有边界安全约束，在可行方向中优先增加与来源距离，必要时沿边界逃离；不得继续把引导点指到不可到达的边界外导致持续顶墙。转弯受有效 G、失速和正常滚转约束，不瞬间旋转或传送；掉头过程不保证每帧距离单调增加。
- 多个小队同帧达阈值时，第一次成功接受的 FEAR 固定本轮来源；后续申请不能刷新时长、替换来源或令飞机在来源间反复转向。解控保护结束后下一轮才允许重新认领来源。
- 恐惧期间拒绝该机移动、攻击航点、急刹、机动、升降高度与 E 取消命令；这些输入不排队到解控后执行。轮盘命令仍可影响未受恐惧成员，不能覆盖受恐惧成员的逃逸。
- 原 `commanded_target` 保留；不保存并恢复旧物理速度/旧航点快照。结束后撤销 FEAR 意图，由当前合法战术与编队重新决策，速度按正常积分连续变化。
- 允许数字键接管未恐惧僚机；原机继续恐惧并逃逸。接管受恐惧机仍受控。UI 遮蔽跟随当前操控机状态，换帅不清除任何飞机状态。

### 3.3 强制加力与共享电池

恐惧必须保证整段 5 秒强制加力，不能因 E 能量为零失效。为避免一架受控带动全队，增加本机的强制来源，仍通过统一加力窗口查询消费。

- 有效加力窗口 = 正常 E 激活快照所属来源 **或** 本机 FEAR 强制来源。来源边沿做统一启停，不能由两套逻辑分别覆盖同一 bool。
- 恐惧来源仅作用于受恐惧机，不主动消耗、充值或冻结小队电池。正常 E 窗口已激活时继续正常耗能；其耗尽不结束恐惧加力。没有正常 E 窗口时电池维持原被动充能规则。
- 强制窗口完整继承现有加力的有效顶速地板、加速度、100% 机炮闪避、90% 导弹甩脱、禁攻击、装备例外、加力技能与热诱弹暂缓。数值权威为 [afterburner-mode](afterburner-mode.md)，不复制另一套倍率。
- 因而该机制的主要惩罚是失去位置、攻击机会和情报；不得默默剥离防御收益来提高伤害压力。是否偏弱需 E4 实战判断。
- 与正常加力重叠时，技能计时与进入事件只认有效窗口的真实边沿，不重复装填、不双倍冷却、不重置雾隐计时。恐惧结束仅撤销恐惧来源，不取消仍有效的正常窗口。
- SLOW 的物理限速/禁喷焰、失速和坠毁约束仍优先于加力请求；FEAR 不清除这些状态。对玩家小队不套用敌机的解恐惧后 3 秒禁加力，改用本 spec 的 3 秒再次恐惧免疫。

### 3.4 看不清状态栏

- 当前操控机受恐惧时，遮蔽全部敌我世界单位状态栏的 HP、SPD、ALT、G、武器弹量、装填、状态详情与对应条形；同步遮蔽玩家仪表、小队条与 BOSS 条中重复的作战读数，避免旁路读出。
- 保留呼号/型号、阵营识别、机体/弹丸/地形轮廓、紫锥范围、暴露进度、FEAR/AB 状态码与 FEAR 倒计时。雷达位置和锁定逻辑维持原规则，不赋予识别隐形目标的能力。
- 紫色遮挡保持现有状态栏占位、水平屏幕轴和字体布局，不旋转、扭曲或抖动面板，不做全屏高成本模糊。遵循现有 UI 规范，不回写通用规范。
- 只有僚机恐惧而当前操控机正常时，仅该僚机的世界状态栏与小队详情读数遮蔽；不遮住玩家和其他敌人。
- 效果只改变信息呈现，不修改权威 HP、锁定、伤害、队伍身份或 AI 感知。解除、死亡换帅和场景退出当帧重新计算遮蔽范围。
- 本地化提示提案：zh `恐惧：失去控制，强制加力`；en `FEAR: Control lost, forced afterburner`；ja `恐怖：操作不能、強制アフターバーナー`。固定世界状态码 FEAR/AB 沿用战术英文例外。

### 3.5 生命周期与恢复

- 来源死亡/释放取消：未满暴露立即清零；已经接受的 5 秒恐惧独立到期，按最后合法来源位置继续逃逸。卸载一个小队的施放模块不清除其他小队暴露记录或受害者已接受的 FEAR；场景结束由统一终态清理全部状态。
- FEAR 到期或合法移除后，存活的玩家小队飞机获得 3 秒再次恐惧免疫。FEAR 激活中拒绝刷新/叠加；退出重进紫锥不能延长本轮恐惧。
- 受害者死亡、退场、换机替换、阵营离开玩家小队：清除控制来源、暴露、保护与遮蔽缓存，不把状态转移到新飞机。新入队成员从零开始。
- 暂停冻结全部游戏计时。场景退出清理所有来源、成员 WeakRef、绘制登记；新局不得残留。

## 4. 结构与组成（Structure）

- **配置资源 `SquadFearConeConfig`**：只存参数，不存计时/成员/WeakRef；字段覆盖范围、角度、预警/照射时长、暴露阈值、恐惧时长、首次等待、冷却上下界、并发上限与颜色。Wraith 初值就是 §2；默认未装配，挂载时验证范围/时长为正、角度位于 `(0, 180]`、冷却下界不高于上界。初版只支持并发 1，非法配置拒绝启用并记录错误，不能静默退化。
- **队级 `SquadFearConeController`**：每宿主一个实例，公共 `setup(config, host)` / `start()` / `update(delta)` / `stop()` / `dispose()`；宿主提供存活候选成员、目标小队、是否接战及暂停/退场状态。复用宿主既有 tick，2 Hz 调度、10 Hz 暴露检测，无全场逐机扫描。
- **宿主适配器**：只负责注册成员和生命周期、协调释放者可见性；禁止调用 Wraith 四相战术函数或硬编码 F-47。Wraith 独立配置资源在正式 engage 时启用，cleanup 时释放；后续另一小队只需配置和同样适配接口，不复制控制器。
- **公共 FEAR 受害者入口与运行时**：带来源的申请负责免疫/保护/已有状态裁决，返回本次是否接受；成功才保存来源上下文。FEAR 状态字典为时长权威，受害者运行时负责来源安全采样、逃逸意图和加力来源聚合。原有敌机 FEAR 的无来源入口保留原行为；新玩家小队施控来源必须带施放者，不能猜测 `combat_target`。
- 世界状态覆盖层和 HUD 使用共同的信息可读性查询，来源于当前操控机及各栏所属机体。切控走现有 `_set_player_aircraft` chokepoint。
- 紫锥单份批绘，几何由判定参数生成；预警/照射状态变化时更新样式，变换跟随飞机，不给每架飞机新增常驻 tick 子节点。

- **独立显示层**：锥体绘制只消费控制器暴露的几何/阶段快照；状态遮蔽消费受害者标准 FEAR 状态，不识别小队 ID。宿主换成其他小队时保持同一显示与输入路径。
