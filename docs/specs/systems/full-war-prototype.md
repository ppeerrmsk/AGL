# 全面战争可玩试验场

## 1. 设计意图（Why）

2026-10-04 用户授权按“大场面、刺激、有 RTS 感觉的全面战争攻战”推进初步制作及可直接访问测试入口。
本次交付独立东京湾试验场，保留原精确飞行、自动武器、真实海陆空伤害；Tab 指挥期间时间继续。
测试两个预设成型小队、有限增援与持续战线；不冒充三地图持久养成已经接通。
遵守 DESIGN_PHILOSOPHY 的操控主轴与真实反馈：玩家靠飞行与战术改变战局，战力条消费真实损失，增援不瞬移到点击位置。

## 3. 行为与公式（How）

主菜单“全面战争 // 测试”直接进入。玩家仅携第一王牌队；Tab选择任务区与增援，准备完成后实体从后方飞向所选区，不能在任务区瞬移。第二队同样先派遣、后接管。SAM固守；舰船由玩家派遣，本轮不实现任意海陆寻路。

面板有两队接管按钮；切换只更换操控所有权，不迁移或复制机体升级。旧队恢复AI，其他僚机继续既有编队。初版预设升级仅采用机体参数型加成，不承诺所有当前玩家专属技能已跨队兼容。数字1–4仍在当前队内切换。

条代表战争持续力而非两军比例：确认阵亡扣相应权重；空域控制施加持续压力。快照同时显示现存单位、资源、库存、排队与控制态。敌条归零胜利；己条归零或当前操控机被击毁失败（同时归零失败优先）。结算只触发一次；停止派遣与战局计时；测试局不结算功勋或写生涯。重试重新创建场景，返回恢复主菜单。

原型模块：战局账本（资源/队列/终态）→ 场景装配器（正式实体工厂/AI/控制切换）→ 即时指挥面板（只发意图/读快照）。无需修改共享AI的模式判断。

## 4. 边界

初始第一王牌位置为(-1700,5600)，航向北；第二队派遣后从所选区x、y=7300进入；战区中心(-2200,3200)、(600,3200)、(3400,3200)。普通空军从己方y=7300、敌方y=-900入场，敌方初始各批横向错开220px。舰船/地面使用有界地理搜索（25圈×16方位、半径步长160px、四向240px裕量）；地形无有效位置则拒绝生成，舰船派遣失败退款。新舰船从y=7600进入，前方海上阵位直线分32段验证不跨陆，否则保持海上入口防御。默认镜头zoom=0.13。复用已有建筑阴影几何缓存，可见集/颜色/偏移变化时失效，不改变建筑几何或碰撞。

不实现前两图产出存档、完整技能所有权重构、返航再出击、随机棋子商店。大场面数量与性能必须实测；不得以无敌、关闭伤害或只放装饰单位冒充实战。

仅试验场启用建筑楼顶屏幕误差预算0.5px：平移重绘门为min(64px世界距离, 0.5 / max(zoom最大分量×abs(perspective_k),0.0001))；缩放与视口大小变化立即重绘。普通模式保留4px世界距离门。实际建筑几何、颜色与碰撞不变；64px平移上界小于既有裁剪裕量。
