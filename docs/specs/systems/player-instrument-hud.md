# 玩家仪表 HUD

> 把生存模式右侧 TACTICS、玩家信息栏与旧僚机富文本框统一成不可点击、纯键盘驱动的模块化线框仪表；其它游戏内 HUD 保持原样。

## 1. 设计意图（Why）

- **体验目标**：在不改变火控、飞行与加力机制的前提下，让生命、速度、G、高度、热诱弹、自动化开关与武器优先具有清晰、可数、可扫读的座舱仪表反馈。
- **Litmus 自检**：符合“信息察觉优先于数值”；所有状态变化均有数字、反色、进度或闪烁反馈。本批只改变 HUD 表现，唯一行为修订是 T 跳过不存在的基础武器。
- **反模式规避**：不新增手动武器扳机；F 仍只控制现有导弹自动发射语义；不改其它 HUD；不把额外装备、技能或状态强塞进本批仪表。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 整体布局

| 字段 | 值 | 说明 |
|---|---|---|
| 锚点 | 右下角、经验条上方 | 复用旧 TACTICS + 玩家信息栏占位，可适度加宽 |
| 紧凑尺寸 | `326 × 408 px`，内容宽 `298 px` | 保持七僚机可完整落入 1600×900；重构只改变内部行结构，不扩大总占位 |
| 交互 | 无鼠标交互 | 不可点击、无 hover tooltip、鼠标事件穿透 |
| 操作键 | E / G / F / Q / T；C / V | 前五项控制玩家仪表状态；Q 恢复可见的高度偏好反馈，C/V 保留小队交战模式与武器偏好 |
| 模块顺序 | HP → SPD → 加力 → ENGAGE/FIRE 与 FLR/R → MSL/GUN | 每条信息行拥有独立局部矩形，可单独增减或调换顺序 |
| 默认强调色 | `#53D13A` | 主菜单可改；作用于本仪表文字、边框、星号与填充 |
| 预设色 | 绿 / 青 / 琥珀 / 白 | 另提供自定义色盘 |
| 反色文字 | 黑色 | 填充底色使用当前 HUD 强调色 |
| 闪烁节奏 | 每 0.5 秒切换一次 | 完整明暗循环 1.0 秒 |

### 2.1.1 僚机信息行

| 字段 | 规则 |
|---|---|
| 位置 | 玩家仪表正上方，右边缘与玩家仪表对齐，间距 6 px |
| 数量 | 每架当前存活僚机严格对应一行；无僚机时整组隐藏 |
| 排序 | 按固定 `squad_slot` 升序；阵亡造成的编号空缺不得压缩 |
| 外框 | 每行宽 `298 px`、主体高 `44 px`、黑色半透明底、2 px 当前 HUD 强调色描边；行间距 5 px，单行节奏 57 px |
| 顶部标签 | `112 × 20 px`，覆盖在外框上边缘；左端叠放 `28 × 26 px` 黑底强调色描边键帽，号机数字单独用 ExtraCondensed 21 px 强调；右段强调色实心底、黑字显示 `★ 代号`，仅有有效继任排序时显示 `★` |
| 行内信息 | 当前动作、击坠数、`HP 当前/最大`、`MSL 当前/最大`、`GUN 当前`、`FLR 当前` |
| 装填 | MSL/GUN/FLR 装填时把数值替换为整数百分比，并按统一 0.5 秒节奏明暗闪烁 |
| 缺失装备 | 对应字段内容透明，行宽与其它字段位置不塌缩 |
| 交互 | 僚机行纯显示、鼠标穿透；小队交战与武器偏好继续使用 C/V 键 |

对齐契约：每一行先建立自己的 `Rect2`，所有标签、重点数字、补充数字、填充和分隔线只使用该行左上角加固定偏移，不引用相邻行的基线、字宽或光学校正量。HP 右侧只放 G；SPD 行左侧切出 ALT 高度偏好块，右侧放速度数字与 KT/KM/H；Q 键帽移到外框左侧并与 E/G/F/T 共用同一竖列。自动化区左栏占内容宽度 `122/298`，武器名称列从内容宽度 `176/298` 处开始。

重点信息契约：每行只允许一个第一视觉焦点。数值行用“当前值大字 + 最大值/单位/总时长小字”；开关行用反色状态块；资源装填行用大号弹量，固定标签与进度只作补充。任何位数变化不得推动行边界或其它行内容。

### 2.2 飞行数据模块

| 项目 | 显示规则 |
|---|---|
| HP | `当前/最大`；当前值大字、最大值小字，均取整 |
| G | 只显示实时 G，保留 1 位小数；不显示结构上限；独占 HP 右侧补充区 |
| ALT | 只显示实际高度米数，取整；不显示档位、箭头或 `M` 后缀；占 SPD 左侧独立状态块 |
| STALL | 平时不占视觉内容；失速时显示并按统一节奏闪烁 |
| SPD | 大字整数；默认 kt；设置为 km/h 时显示 km/h 数值 |
| 单位标签 | `KT` 与 `KM/H` 同时保留，当前单位反色 |
| 换算 | `kt = km/h / 1.852` |
| 高度偏好 | ALT 状态块底部显示当前本地化状态：`爬升优先` 或 `低空优先`；Q 键帽位于面板外框左侧，与 E/G/F/T 键帽同列；按 Q 两态切换 |

- HP 行底部必须显示生命比例条；SPD 不伪造速度上限进度条。
- HP 与 SPD 各自拥有独立外框和左上角局部坐标系；G 只作为 HP 重点数字的固定补充。SPD 行从左到右固定分为 ALT 数值与高度偏好、速度数字、KT/KM/H 三部分；STALL 只能占速度/单位区，不进入 ALT 块。

### 2.3 加力模块

| 状态 | 文字 | 填充与动画 |
|---|---|---|
| 满能量、未开启 | 本地化 `AFTERBURNER` | 无填充、无闪烁 |
| 开启 | 本地化 `AFTERBURNER` | 反色进度按剩余能量从满向空收缩；填充色遵守统一比例阈值 |
| 未满、充能中 | 本地化 `AFTERBURNER` | 进度从空向满增长；文字全程按统一节奏闪烁；填充色遵守统一比例阈值 |
| 充满 | 本地化 `AFTERBURNER` | 回到普通未开启状态 |

现有“有能量即可启动、再按 E 提前关闭、耗尽自动结束”机制不变。

### 2.4 自动化与热诱弹模块

| 项目 | 关闭 | 开启 |
|---|---|---|
| G 自动接敌 | 本地化 `ENGAGE` 普通文字 | 强调色底 + 黑字反色 |
| F 自动开火 | 本地化 `FIRE` 普通文字 | 强调色底 + 黑字反色 |

- F 仍绑定现有 `missile_auto_fire`，不扩展成全武器总开关。
- 加力期间继续显示玩家保存的 ENGAGE/FIRE 开关状态，不显示临时有效性。
- FLR 数字显示 `当前/最大`，当前值是大字重点信息，最大值是小字补充信息。
- 数字资源与下面 10 个 `*` 是两个维度：数字表示可用投放次数；星号表示一次投放里的 10 枚视觉热诱弹。

ENGAGE 与 FIRE 是两条独立行；关闭时为黑底强调色字，开启时为强调色底黑字。两态始终保留完整边框与文字，不用透明度表达关闭。

### 2.5 十枚视觉热诱弹

| 字段 | 值 |
|---|---|
| 总视觉粒子 | 每次投放严格 10 枚 |
| 波数 | 保留 6 波 |
| 波间隔 | 0.12 秒 |
| 每波数量 | `2, 2, 1, 2, 2, 1` |
| 星号排列 | 两行，每行 5 个 |
| 熄灭 | 某波实际生成 N 枚时，同帧熄灭 N 个星号 |
| 短冷却 | 星号保持全灭；冷却结束后一次性全亮 |
| 资源耗尽长装填 | 数字保持 `0/最大`；10 个星号按装填进度逐个点亮 |
| 装填完成 | 第十个星号点亮后，数字才一次性更新为 `最大/最大` |

### 2.6 R 主动机动冷却行

| 字段 | 规则 |
|---|---|
| 技能数量 | 玩家永远只持有五种互斥 R 技能中的一个；HUD 不提供选择、轮换或多技能并列显示 |
| 出现条件 | 取得任意唯一 R 技能后立即常驻；未取得 R 技能时不显示该行 |
| 位置 | FLR 右栏下方；有技能时 FLR 固定缩短并让出一条独立常驻行 |
| 重点信息 | 整数充能百分比 `0%…100%`；技能本地化名称与 `R` 为固定补充 |
| 进度 | `charge_ratio = 1 - remaining / total`；成功发动时回到 `0%`，随后向 `100%` 填充，`100%` 表示可用 |
| 禁止显示 | 不显示剩余秒数、总冷却秒数或 `/总时长`；总冷却只允许作为内部比例分母 |
| 切控 | 冷却属于 Squad；切换操控机后继续显示同一唯一技能与同一剩余时间 |

五种唯一技能名称复用现有技能本地化 key。各技能总冷却仍由技能机制持有，HUD 不向玩家暴露该数值。

### 2.7 统一进度色阶

所有连续比例条统一按其“已填充比例”着色：

| 已填充比例 | 颜色 |
|---|---|
| `> 0.50` | 当前 HUD 强调色 |
| `> 0.20` 且 `≤ 0.50` | 警戒黄 `#F2D34F` |
| `≤ 0.20` | 危险红 `#FF493D` |

- HP/加力条的填充比例等于剩余资源比例，因此资源降低时依次进入黄、红。
- 武器装填与 R 冷却条的填充比例等于完成比例，因此从红开始，经黄回到强调色。
- 闪烁只改变填充明暗，不改变其所属色阶。

### 2.8 武器模块

固定保留 MSL 与 GUN 两行；其它武器与额外状态本批不安置。

| 列 | 显示 |
|---|---|
| 左列 | 对应当前可用弹量 |
| 中列 | 本地化 `PRIORITY`，只出现在玩家设置的优先武器行 |
| 右列 | 固定英文缩写 `MSL` / `GUN` |

| 状态 | 右侧名称格 |
|---|---|
| 优先 | 持续反色；显示的是玩家偏好，不是瞬时实际使用武器 |
| 装填 | 只在名称格内按装填进度从左向右填充，使用统一比例色阶，并按统一节奏闪烁 |
| 优先且装填 | `PRIORITY` 保持稳定；名称格继续显示装填进度与闪烁 |
| 武器不存在 | 行高、格子和边框保留；该行弹量、PRIORITY、名称内容透明度为 0 |

T 切换规则：两种都存在时切换；只存在一种时固定在可用武器且 T 无操作；两种都不存在时 T 无操作。

### 2.9 主菜单设置

| 设置 | 默认 | 持久化 |
|---|---|---|
| 速度单位 | KT | 保存到独立 HUD 设置文件 |
| HUD 色 | 荧光绿 `#53D13A` | 保存到独立 HUD 设置文件 |

- 速度单位按钮与 HUD 色按钮放在主菜单 AUDIO 旁。
- HUD 色面板提供绿、青、琥珀、白四个预设以及自定义 ColorPicker。
- 只有 `AFTERBURNER / ENGAGE / FIRE / PRIORITY` 走本地化；HP、G、ALT、STALL、SPD、KT、KM/H、FLR、MSL、GUN 固定不翻译。

### 2.10 字体

| 内容 | 字体 |
|---|---|
| 小型信息、字段名、单位、键帽、PRIORITY | Acumin Pro Regular |
| 大号数字、AFTERBURNER、ENGAGE、FIRE、FLR、MSL、GUN | Acumin Pro ExtraCondensed Semibold |
| 中文、日文、韩文本地化文本 | 明确使用项目当前主题默认字体（与现有系统中文 UI 一致），不再经 Acumin 混合 fallback |

两份 Acumin 字体资源随项目打包，不依赖运行机器已安装字体；固定数字、拉丁缩写与英文状态继续使用 Acumin。中文、日文、韩文本地化文本直接使用当前主题默认字体；本规则作用于玩家与僚机仪表。
紧凑版的可读性下限：僚机字段名保持 10 px，动作/数值保持 15–16 px，固定号机数字为独立 21 px 键帽；玩家小信息保持 12 px 以上，HP/SPD 主数字保持 50–52 px。以上均为逻辑像素，随项目 stretch 统一缩放。

## 3. 行为与公式（How）

### 3.1 显示刷新

- 复用生存 HUD 既有单次玩家引用净化结果，不扫描场景树。
- 只更新一个固定仪表实例；无每实体节点、无全场遍历。
- 动态数字可每帧赋值；只在闪烁相位、颜色或布局状态变化时改变样式。
- 继续保持最多 20Hz `queue_redraw`；R 冷却读取是当前玩家与 Squad 的 O(1) 查询。

### 3.2 热诱弹状态同步

```
release:
  flare_visual_emitted = 0
  queue 6 waves with counts [2,2,1,2,2,1]

spawn wave(count):
  create exactly count visual particles
  flare_visual_emitted += count

HUD lit stars:
  if long reload: ceil(reload_progress * 10)  # 最后 10% 已满星，正式完成帧才补数字
  elif release queue active or short cooldown active: 10 - flare_visual_emitted
  else: 10
```

长装填完成前数字不得提前补满；数字更新与正式资源补充发生在同一状态转移。

### 3.3 输入

```
E -> AfterburnerCharge.toggle(player)
G -> auto_engage_enabled = !auto_engage_enabled
F -> missile_auto_fire = !missile_auto_fire
T -> available = [MSL if params.missile, GUN if params.gun]
     if available.size == 2: toggle preference
     if available.size <= 1: no-op and keep/normalize preference to the sole available weapon
Q -> altitude_preference = PREFER_CLIMB ↔ PREFER_LOW; ALT/Q block updates in the same HUD refresh
C -> existing squad engage mode cycle
V -> existing squad weapon preference toggle
```

### 3.4 僚机快照与刷新

- 生存 HUD 只遍历当前玩家 `Squad.members` 的存活僚机，不做全场扫描。
- 每帧把僚机引用转换为只含显示值的字典快照；绘制控件不跨帧持有 Aircraft 引用。
- 僚机控件与玩家仪表相同，最多 20Hz 重绘；行数变化时立即改尺寸并重新锚定到玩家仪表上方。

## 4. 结构与组成（Structure）

- 独立玩家仪表控件：用独立行矩形构建 HP、SPD、加力、ENGAGE、FIRE、FLR/按需 R、MSL、GUN；每行只以自己的左上角为坐标原点。生存 HUD 只注入当前 Aircraft 与 AfterburnerCharge。
- 独立僚机仪表控件：消费生存 HUD 生成的显示快照，按存活僚机数绘制独立信息行；复用玩家仪表的强调色与 Acumin 双字体规范。
- 独立 HUD 偏好静态服务：加载/保存速度单位与强调色，不新增 AutoLoad。
- 热诱弹子系统在 Aircraft 上公开本次视觉投放进度，HUD 只读；队列仍由既有粒子更新函数消费。
- Aircraft 公开唯一 R 技能 id、总冷却与共享剩余冷却的 O(1) 只读查询；HUD 只用总冷却计算 0%→100% 充能，不显示时长且不修改技能状态。
- 主菜单只负责修改持久化偏好；其它主菜单结构与游戏内 HUD 不变。
