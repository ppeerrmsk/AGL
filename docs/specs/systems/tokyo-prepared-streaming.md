## 1. 设计意图（Why）

**当前质量约束（2026-10-31）**：WASD 与 SPACE 不得因运动速度使用低清纹理或超出原清晰度上限的远景层。普通建筑的几何概括授权不包含降低道路、河岸与地表纹理清晰度。以下 v3/v4 运动概括是已否决的历史实验合同，保留以解释代码及旧证据，不能用于默认游戏，也不能把实验清晰度范围当作新的验收标准。

2026-10-29 最新授权要求继续概括地图以消除任何 SPACE / 移动等待。预测仍有偶发未命中，新增独立运动概括候选：同源常驻根模型的正常首选范围仍到输出尺度 0.8，另明确允许到 10.0 的运动接管质量；近景细资源未齐时普通街区暂用概括表示，全部正式楼体沿用已验证原几何，后台继续细化。只有显式 `guard_prefetch` 候选且完整常驻资源、覆盖、96 MiB / 24 万面 / 16 页及真实联合预算均通过时才接管。不得伪称近景瞬时像素等价；必须记录接管次数、细化恢复和像素复核。旧包没有该质量合同，绝不自动获得放宽资格；普通 F5 不变。

运动接管后避免细节在几帧内来回跳变：概括层完整且合格时，逻辑屏幕相对移动速度超过 600 px/s 或对数缩放速度超过 0.15/s 则保持概括表示；跟随时扣除玩家本身的平移速度，防止正常跟飞永久停在概括层。速度回落后连续 150 ms 再提交已就绪细档。此门只控制细节恢复，绝不阻止镜头、输入或战斗；缺覆盖、失格和未启用候选均不得借此保留旧画面。

主动运动概括（v26）：显式候选的后台选择器在上述高速状态下主动优先完整常驻根模型，不再等到细节缺资源才接管；根资源必须实际全部就绪且联合预算成立，失败则沿原安全路径。运动期间不继续细树求解和预取，返回可复核的完整概括切面；稳定后恢复原选择器，正常跟飞仍显示细档。该选择只对带 `resident_motion_summary` 的新包生效，旧包与普通 F5 不变。

三轮重测再次出现 HLOD 父子页身份变化：相邻机位的最省字节切面不同，已预取的父页不能代替下一帧所选子页。显式候选改为优先固定最细空间分块；仅当完整可见叶块同时满足 16 页、24 万面和 96 MiB 时采用，半池查询不足则返回同一叶块切面的预算失败供全池重试。叶块本身无解或缺资源时仍回到原有求解器，不裁掉可见内容；普通默认路径不变。

2026-10-29 的早期 4K 诊断复现了 65 个地图受限样本：同一逻辑视野因输出像素比例进入中档，原 0.4 概括范围不足。独立 v3 将正常概括范围扩到 0.8，沿用同源普通街区体块与纹理及全部正式楼体。后续仍有等待，才进一步增加上述 v4 运动接管合同；v3 本身不获得超过 0.8 的显示资格。不同候选须分别验证 1080p / 4K，不把此前 0.4 候选结果当作新包通过。

2026-10-29 后续验收收紧：用户不接受 SPACE 和地图移动的等待。候选须逐帧区分正常呈现间隔、相机实际停止推进与地图准入造成的部分推进；不能以低于 50 ms 宣称无卡顿。先修复远景出口预测的位置/尺度时刻错配，并将空格返回预热覆盖到原 0.25 s 路径。预测仍不授予显示权，不改变镜头、战斗和预算；三轮实测及人工复核前保持显式候选。

跨块、缩放与转向期间保持地图完整和精度合格，同时避免主线程选页、桥接和预测造成的长帧。
依据开放世界成熟流送方法，将静态准备移到构建/Loading，将动态全树规划移到后台，主线程只做小切面验收和资源提交。
本规格覆盖静态资格准备、后台完整规划、实时接纳和物理阶段的显示请求合并；不将短路线性能改善外推为完整游戏已稳定达到 60 FPS。

- 不减少实际可见战斗、物理步频、碰撞精度、地图清晰度、分辨率或抗锯齿。

### 2.2 准备数据和所有权

准备缓存记录 schema、算法版本、来源路径/摘要、原始树拓扑和精确资格区间。
区间为 `(lower, upper]`，与 `scale > max_scale` 失格条件完全一致；没有混合资格的目录不复制多份树。
缓存无效或缺失只能在 Loading 重建；运行中的查询不得构造资格树或隐式读取缓存文件。

来源快照只在配置时建立：HLOD 目录与准备树、原生配置根树、纯费用/依赖描述符、固定层及已解析开关。
不把 Node、Resource、WeakRef、RID、Callable、Signal 或实际网格/图片对象传给后台规划。
无需复制原生组件文件的几何大数组；规划仅消费已验证身份、费用、包络与依赖。

每次请求包含序号、来源代次、状态修订、真实 canvas、逻辑视口、输出尺寸、相机运动、已提交/目标小切面、固定集和就绪键集合。
小切面的 entry 不携带无关后代树；逻辑视口和实际输出尺寸必须分别保存，不能混用。

返回缓存候选的四份资源身份集合以打包字符串数组传递，在后台恢复哈希集合。真正就绪与请求中身份不得混合；打包元素仍计入纯值数量上限，请求字节上限保持不变。预测中重复的同一网格/图片组合只保留首次优先级，切面快照仍独占，不能修改调用者的数据。

同目录HLOD交接可复用仍属于本overlay、节点全部有效且物理身份相同的页绑定；仅销毁离开目标的页、创建新进入的页。资格、覆盖、真正资源就绪及联合预算门仍先于任何显示修改，地表新租约仍须先预约。目录变化、原生路径、无效绑定与退出走完整清理，不允许因复用保留未计费的离屏页。

## 3. 行为与公式（How）

### 3.1 单任务规划

同一 overlay 最多一个后台规划任务；等待任务完成时只保留最新需求，不无限排队。
任务独占求解缓存，以请求序号作为 epoch；后台不读取 Engine 帧号、PerfBuckets 或可变全局预算缓存。
原选择优先级和完整树动态规划保持不变，包括原生偏好、桥接、裁旧页、预算收缩、预期尺度和预测。
任务内 CPU 计时在结果返回后统一并入后台统计，不能计入当帧主线程 CPU 根桶。

| 状态 | 主线程行为 |
|---|---|
| 准备中 / pending | 保留仍合格且覆盖完整的显示；继续资源领取和既有就绪目标提交；不在主线程重做后台动态规划，显示不安全时可按 §3.7 重组已有就绪缓存 |
| 有候选 | 核验代次、实际覆盖、精度、真实联合预算和当前状态，再更新请求 |
| 已证明无解 | 仅当结果对当前视野仍适用时记录无解；不能把过期结果用于清除新画面 |
| 退出 / 换源 | 停止提交需求与接收旧结果，回收任务后释放独占快照 |

### 3.2 就绪交接

顺序为 bytes available → decoded → engine/GPU ready → qualified/covered/budget valid → committed。
主线程每帧领取已完成任务，不因相机停止而遗漏结果；调用 wait 前必须已确认任务完成。
相机移动不自动否决旧请求，保护带内的候选只要通过当前精确验证仍可使用。
资源就绪、原生层掩码、共享组件去重、固定集抵扣、地面租约必须沿用原正确性门。
新目标提交前再次检查实时 ready；旧目标仍被保护至新目标完整绑定。后台快照不能代替实时资源凭据。

`anticipated_scale` 的提交不得再次触发主线程整树选择。后台完成资格准备，提交帧用真实覆盖和逐页资格证明；需要新规划时重新排队。
主线程诊断也不得运行 counterfactual 全树重算；此类比较进入纯规划测试或离线重放。

显示合同必须在该帧所有就绪提交之后再次检查，即使目标等于当前切面也不能跳过。
记录隐藏、预算超限、投影未覆盖、超过原有限缩放宽限的失格，以及处于原宽限内的失格；单纯 `visible=true` 不足以证明完整合格。

裁减旧页时保留当前与 0.25 s 平移前探视口的屏幕矩形包络，并对原完整目录证明覆盖，不能以裁后的子集自身作为完整性证明。
桥接允许在显示与真实联合预算内保留等大或稍大的切面，不要求每次交接都单调减少字节。
每档 HLOD 保护带先求原首选预算与完整显示预算；若完整显示切面可用但与旧图的真实联合费用超池，则在缩窄保护带前尝试共享资源加权求解。该次加权结果必须保持本档或更宽的保护带，不能用较窄结果抢占下一档正常求解；完整显示费用、联合费用、未来清晰度和当前覆盖仍分别核验。
缩远的 HLOD 显示查询与桥接额外考虑未来视野扩大，仍用真实当前尺度判定清晰度；已在未来尺度查询的预测分支不得再次外推。
方向性近景包络包含当前视口和按平移、缩放预测后的视口，没有全向边带，诊断中的 `spatial_guard_px` 必须为 0，另记方向向量及时间范围。
在 192/96/48 px 对称保护带均不可行时，依次尝试 0.35/0.175/0.0875 s 方向包络；未来视口在当前尺度下的尺寸为 `size × exp(clamp(-zoom_rate × horizon, -0.7, 0.7))`，取两视口矩形并集后仍按真实当前尺度选择同一配置。
已在未来尺度查询的原生预测分支只保留原平移保护，不再叠加缩放预测。相机平移速度用 0.10 s 时间常数平滑，权重为 `1 - exp(-delta / 0.10)`，不能按呈现帧固定插值而使 60 Hz 物理采样在高帧率下交替失真。
沿既有 160 px 单帧位移门识别冷进入或镜头瞬切时，同时清零平移速度、缩放预测速度和缩放方向历史。新视野仍走实际覆盖与资源接纳检查；不能把设置初始镜头时的尺度差外推为连续缩远，也不能仅把本帧平移样本归零而留下旧速度。
所有对称与方向包络均不可行时，退裸视野前可保留已提交的原生目标，但必须仍满足请求配置、当前清晰度、精确投影覆盖、页数、面数及本次字节预算。该门只允许实际显示查询复用，不适用于未来预测；保留后仍继续原有提前升档和预取流程，不把“旧图现在完整”当作未来完整的证明。
保留结果必须复制为 `native_retained` 且保护带为零，不能沿用旧查询的正保护带标记去抢占当前完整 HLOD。最终候选与目标资源身份相同时，即使不重绑或只有预取改变，也同步目标与对应已提交切面的阶段及保护带元数据；元数据刷新本身不触发资源请求、revision 或重绑，同时发生的预取身份变化仍走正常接纳、请求与修订流程。
已提交的原生切面若为方向包络、裸视野或仅保留当前覆盖、且显式记录全向保护带为零，则沿用快速缩放的 1/60 s 最小重采间隔。计时触发还要求 canvas 或输出尺寸变化；拒绝、修订或强制重规划仍可在停镜时重试。后台忙时仍只有一个任务和一个待更新标记。该规则不放宽覆盖、revision、页数、面数、字节或清晰度门，也不把预测方向包络当作转弯时的全向保护。

相机缩放方向按逐帧实际尺度判断。若缩远后反转、旧在途目标比完整合格的当前 HLOD 更早失格，则撤销旧降档事务，恢复当前资源保护、递增修订并重采最新需求。
下一呈现帧没有新的物理位移时不能让旧事务恢复提交；再次明确缩远仍可重新规划和交接。
求解前 `_pending_hlod_covers` 快速复用尚未提交 HLOD 目标时，所有目标均须通过既有 0.25 s 缩放预测清晰度门，不能仅检查带桥接标记的切面。后续同目录 retained/finishing 分支保留各自原有条件。该快速入口的限制可避免当前资格复用阻塞正常的提前升档；不延长显示宽限，也不改变当前清晰度阈值。

**运动中的提前细档保护带门。** 提前细档（`catalog_index` 按 PREFETCH_RATIO 选出的较细目录，按两倍尺度细化页资格）在宽视野下常被 16 页、面数或显示/联合预算挡掉全部对称保护带，只剩恰好盖住此刻视野的裸切面。该切面资源多为旧图子集、立即可提交，于是带保护带的旧图被替换；镜头每帧移动约 10 px 时一两帧后即失去覆盖，回退 loading cut，后续几轮仍只得裸切面，形成间隔约 0.13 s 的连续 old_view 隐藏段（C2 快速平移点 6.6–6.9 s、24.6–24.9 s 的实测机制）。

运动保护需求 `need = min(192, |pan_lead(v, scale, 0.25 s)| × scale)`（输出像素；与裁页同一 0.25 s 平移前探，v 为既有 0.10 s 平滑速度）。基础选页落在提前细档、候选保护带 `< need`，且实际尺度目录 `catalog_index(scale, false)` 存在、不同于所选目录且所选目录不是常驻基础层时，按实际尺度（不提前细化）为实际档选页；仅当该切面保护带严格大于细档候选、按当前放大速率外推 0.6 s 仍合格（换档前探窗：实际档到期前须留出裁旧页、装载细档与交接的时间；实测 60 Hz 下这一过程约 0.3 s，0.25 s 窗会在到期宽限内来不及换档）、在显示预算内，且已有显示时与旧切面的真实联合费用不超过交接余额，本次显示改用实际档（`selection_stage` 原样保留，另记 `motion_guard_need_px`）。细档资源照常由预测预取按未来尺度准备；静止（need=0）、缩远（基础选页本就是实际档）或细档保护带已满足 need 时，选择与原实现逐项一致。

该门不修改 PREFETCH_RATIO、逐页 max_scale、16 页、24 万面、96 MiB 显示或联合预算；实际档在当前尺度合格，代价是快速平移期间显示比提前升档低一档的合格目录。旋转角速度不计入 need。后台规划与同步兼容路径共用同一规则。

缩远时复用未完成的 HLOD 目标还须覆盖前探视野：以原 0.25 s 缩远预测得到的视口增长量 `padding`，使用 `max(96, max(padding.x, padding.y)/2)` 像素边距核验完整目录投影。当前视野仍覆盖但前探缺边的细档，不得继续占住下一档的准备窗口；同步路径与后台规划采用同一判定。

### 3.2.1 冷进入与同帧滚轮突发

- 没有已提交地图时，保护需求下限沿用既有 192 屏幕像素。提前细档若只剩裸视野，优先准备当前倍率正式合格且保护带更宽的切面；原画质资格、联合占用和预算检查全部保留。已有地图时继续使用运动预测需求。
- 滚轮目标仍按原步进完整累积，并钳制在 0.2–5.0。输入机位倍率使用 `dt=clamp(delta,0,1/30)`、阻尼权重 `1-exp(-10*dt)`，再把单帧倍率比限制在 `exp(-2*dt)..exp(2*dt)`；长帧不能越过目标，同帧大量输入不能立即跨越多个地图档位。普通滚轮仍响应，突发最终抵达完整目标。等待地图期间输入机位继续推进，显示只提交有完整合格地图的机位，因此一次接管可以包含等待期间累积的缩放量。
- 缩远预测遵守镜头可达下限，拒绝下限之外的提前降档目标；原生切面保留时仍检查 0.25 秒缩远增长包络，不能只凭当前视野继续沿用。
- 整块细化与旧块无法在同一池共存时，先尝试同 LOD 空间拆页，再逐块升级。每一步仍满足原资源联合预算、完整覆盖与真实倍率资格；超过 16 个根的中间态直接拒绝。
- 镜头与地图在其它呈现层更新前共同提交：新姿态缺少完整合格地图时保留上一完整姿态，保留滚轮目标和未呈现拖动，输入机位继续按比例推进，后台为待呈现机位准备；缩远仍先按显示机位完成逐块降档，并在已就绪中间档的资格边界接管后继续输入终点。联合缩放/拖动无法整步通过时按 1/2、1/4、1/8、1/16 顺序尝试同一输入段的安全小步，第一个严格通过后立即采用；未呈现输入完整保留并进入预测，不能提交新图后再回退旧机位。显示与输入不互相等待，反向输入立即截断旧方向；资源就绪后放行。不能冻结预测，也不能用隐藏地图完成移动。
- Loading 接管转交弱引用守卫；其它地图未配置守卫、地图隐藏或退出释放后正常继续操控。守卫阻挡的镜头仍视为运动需求，立即推进必要规划和提交；真正停镜仍保留原错峰。等待统计包括最后拒绝到实际放行的间隔，250 ms 响应目标单独记录，专项防卡住上限为 500 ms，并验收目标可达性，不能通过长时间卡住镜头消除隐藏计数。
- 不扩大原显示宽限，不改变地图包、画质门槛、战斗单位、96 MiB 显示预算、16 页与 240000 面限制。

### 3.3 工作粒度与范围

原 M20 的网格、纹理和摘要不改写，单帧上传粒度不变；北缘无法在原容量内选取的整叶由 §3.7 的独立无损分区包补齐。性能优化已停止，本次验收聚焦移动与缩放的显示连续性。
现有 GridNative 动态 subset 注册会写 Stream，不得直接放入纯 worker。当前 installed M20 不含该候选；其旧路径必须显式保留并标明尚未迁移，不将 M20 结论外推到 GridNative。

### 3.4 物理与绘制

同一单位的物理更新保持原顺序和次数。物理阶段的显示失效请求通过弱引用队列合并，在 process_frame 刷新。
跨帧请求读取先检查 Variant 类型、实例有效、树内和退出状态。批次先交换再消费，防止消费期间的新请求丢失。
覆盖 Aircraft/编队、Missile、GroundUnit 及覆写物理的防空/雷达单位、NavalUnit/挂点和相关地面控制路径。
事件改变权威状态的时刻不延后；显示合同通过真实场景逐帧采样验证，不用 Headless 的零绘制记录冒充 Visual 通过。

### 3.5 剩余慢帧的函数与系统归因

继续优化前，必须先区分原 CPU 根桶漏计、脚本具体函数、渲染后端与系统等待。诊断保持相同地图包、镜头路线、演员、物理频率、分辨率及抗锯齿；不得通过减少工作负载制造收益。
仅显式 bench 参数允许连接本机 loopback 远程 profiler；普通游戏与默认 bench 不开启。收集 Godot 原生脚本 profiler 的函数身份、调用数、self/total/internal 时间及引擎帧号，记录函数容量、截断风险和采集开销。脚本墙钟耗时与 OS 实际 CPU 时间分开报告；不能将函数 total 相加，也不能将 GPU 延迟读回冒充同帧执行时间。
独立诊断轮与无 profiler 对照保持同一源码。原始逐帧记录、来源摘要、采样配置及失败日志保存在外部证据目录；优化只针对函数与因果对照已确认的工作，保留现有战斗权威与画面合同。

轻量扩展计时只由 `-DeepTrace -ExtendedCpuTrace` 开启，普通游戏与默认 bench 关闭。补齐独立导弹、防空、轰炸任务、主场景物理剩余、玩家预测准备、尾迹更新、状态栏、天气/气氛绘制和三维机体准备；已有父桶中的重复部分及共享 event/audio 叶计时从新增根扣除。total/covered/shared 与具体绘制函数子桶只作诊断，不能再加入根总量；负差值显式标为无效，不能静默归零。系统 CPU 计数只在共同时间窗比较，函数墙钟包含线程等待，Godot 父类调用 self 重叠与后台线程聚合不能相加冒充主线程 CPU。

高射炮与防空导弹车覆盖基类的独立绘制回调必须单独计根，不能假设已由地面单位桶覆盖。逐帧结算、测试记录与渲染信号的诊断开销也单列；发生在帧首时钟之后的记录工作必须归入新帧，不能在随后清空桶时丢失或倒记上一帧。无法用同次记录或原生符号证明的剩余明确保留为未解析，不以引擎开销名义凑满总数。

热点候选必须保持尾迹位置、bank、宽度、颜色、淡入、完整采样点及抽点步长，预测线全部显示点、三层线宽/抗锯齿、渐变与箭头，以及狂化身份查询的安全引用和队伍/操控语义。任何候选均不得改变物理积分、决策频率、演员数量、相机或渲染质量设置；几何数组/生命周期 focused 通过后仍必须进行无探针对照。正确性通过不等于性能通过，未证实收益或出现退化的候选不得作为已验收优化进入当前实现。

本轮尝试的尾迹拓扑缓存、预测线逆变换复用/移除健康度拷贝、狂化关闭时提前返回，均通过对应等价检查，但六组前后与追加相邻对照未证明整体收益，已撤回生产改动。候选补丁、等价测试及全部成功/失败记录保存在仓库外诊断证据中；当前保留新增诊断和生命周期检查。

### 3.6 主线程重活错峰

镜头变换及输出尺寸与最近规划姿态一致时，同一呈现帧内，下列主线程地图工作最多执行一件：就绪交接（清旧、绑定与重新请求）、规划结果领取与准入、规划请求提交。含物理步的帧（本帧已执行至少一个物理步且未暂停）也优先让出。每类最多连续让出 2 帧，到达上限时照常执行；同类在帧内被执行即清零其让出计数。
让出只在当前已提交切面合格且精确覆盖当前视野时允许；交接在目标覆盖、资格与资源就绪等原有前置门全部通过后才考虑让出，地面租约在让出判定之后申请。旧切面覆盖核验本身有成本，只在本帧确实争用时才计算。画面不完整时一律立即执行，不得因此产生隐藏、未覆盖、超预算或宽限外失格帧。
流送节点以 process_priority=1000 领取本帧完成件，晚于 overlay 的选页阶段；最终显示检查在流送后、绘制前延后执行一次，先提交完整就绪目标，再核验当前显示。静止时保留 main 的物理步让出，实际相机移动时立即推进。曾试过的"overlay 重活帧顺延可见纹理"在全部对照轮次中从未触发，已撤回。
镜头变换或输出尺寸已偏离最近规划姿态时，立即推进规划准入、请求与已就绪交接；停镜后恢复上述错峰。全部实时覆盖、清晰度、联合预算、资源就绪和地面租约检查保留。
重纹理上传帧（上传累计达到原 1 ms 判定）不再整帧搁置网格：当前显示事务仍有未就绪、未失败的网格时，沿原管线宽度和原 1 ms 领取限制推进；仅剩后台工作时最多推进一项，并恢复管线宽度。仍使用原共享请求槽、纹理上传上限和物理内存计费。默认启用这项防饥饿交接，`AGL_TOKYO_MESH_PROGRESS=0` 只供显式旧调度诊断；公平图片槽等其他试验仍不默认开启。
领取正式原生网格时，若本次已核验文件 SHA，且同一路径、同一文件 SHA 与同一位置证明在本会话已核验通过，则复用核验结果，不重复回读、展开与哈希；首次或任一摘要不同时照原方式核验。文件字节相同则载入位置相同，因此这是同一证明的复用而非放宽。
请求阶段对已确认存在的资源路径复用存在性结果；未确认路径照常检查，缺失仍记失败。
正式地图由地图特征渲染器开启错峰；单元与生命周期测试直接驱动 overlay/流送时保持即时语义。
代价：就绪目标的交接平均推迟约 1 帧，待交接帧数增加；推迟期间显示的是仍合格、完整覆盖的旧切面。

### 3.7 同池连续交接与边缘覆盖

本节为地图闪回修复，不重新启动性能优化。交接的静态资源费用只在来源目录内索引一次，每次仍按当下显示与固定集扣除真实共享物理网格和纹理，换源即失效；不缓存当前预算或选页结论。60组实际慢交接输入逐项对照，选页、费用与接续链均与原费用计算一致，避免同一次补边被重复全目录计费拖迟。普通相机把可达的最远缩放以纯数值提供给地图；地图按实际输出/逻辑缩放换算预测边界，保持实测平移与缩放速度，只钳制预测终点和对应扫掠视野，不能为玩家无法到达的更远视野取消细页，也不能靠压低预测速度漏算到达边界前的视野扩张。演出接管时撤销普通滚轮边界，玩家恢复滚轮或演出归位后恢复；不改变实际相机、输入或电影层倍率。缩远时保留已提交混合页以及预备新切面的下一补边事务，都必须覆盖普通选页已有的 96 px 边缘；预测速度过零或转向时不能等到当前覆盖丢失才重新补边。同一目标的读取和上传先排当前可见页，再按 0.05 / 0.10 / 0.25 s 实际运动预测的入屏先后排边缘页，最后保留其余原目标；不能让空间编号靠前的远侧保护页占用马上入屏贴图的上传时段。该排序不扩大页集、不授予显示资格、不改变加载与上传限额。反向完整链只对当前实际显示身份展开；候选虽已达到画质资格，但尚未绑定时仍只携带已求出的反向首步与已知依赖，先发布当前必须完成的显示交接，避免反向递归延误补边。普通未绑定候选仍先证明继续缩远的预测覆盖。Loading 的既有 15 秒异步加载窗口从同步目录验证和规划快照完成后开始计时，避免初始化耗时导致尚未开始流送便取消并新建地图。保持原显示质量、战斗负载、96 MiB 同池、16 页、24 万面、I/O 槽、单帧上传与领取限额及原 100 ms / 1.10 倍清晰度宽限。

所有规划出口统一核验平移等待包络，既有接续元数据不能豁免；补边混合树也包含当前实际目录。每帧记录真实相机位移和输出尺寸变化；同帧后续调用不能把已发生的移动覆盖为静止。流送领取完成后、绘制前统一提交与核验。后台请求发出后，若唯一变化是请求中尚在途的目标恰好完整提交，则允许重验并接纳下一方案；除下述同目录严格子集裁页外，其他代际变化仍拒绝。旧画面安全时等待完整目标；旧画面不安全时，可先绑定目标中已经完整覆盖视野、合格且就绪的已有页，屏外保护页继续装载。子集必须向完整目录证明覆盖，不能从自身推导完整性。处于原宽限内的逐页交接即使整组已就绪，也只绑定完整可见子集，避免无关保护页占住最后接续的空间；宽限起点和期限保持不变。已绑定的同目录可见子集不重复清除和绑定；其余目标页继续装载，避免每帧递增规划版本而让后台补边结果持续失效。地面租约先申请成功，再释放旧绑定。

放大时在逐页在途事务的优先分支之前先做零 I/O 裁页，不能等联合池满才释放屏外旧页；已有升级接续同步裁到同一运动视野，按裁后资源重建预读清单，避免下一步把屏外页装回；裁后成为相同资源身份的空交接直接越过，但仍保留尚未形成可提交链的未来预读。预读只删除整条链已裁掉且没有任何接续继续使用的资源。裁页当次没有现成接续时准备同一到期点的细档接续，使释放旧页和请求新页成为同一事务，不能额外消耗一次后台往返才开始装载；已有接续保持身份和加载顺序，不能重选更远细档而取消必经中间页。原在途升级目标与请求一同保留，旧降档接续不能在反转后再次挂回。裁页结果必须仍对应当前显示来源；逐页交接只改动了屏外页时，允许重验同目录当前身份的严格子集，不能恢复任何已换掉的旧页或接纳其他过期规划；仅删除屏外页时，将已认证反向方案的来源身份同步收缩，实际启动仍重验覆盖、画质和费用。裁旧页用当前与预测视口的矩形并集，同时包含 0.25 s 平移和缩远；立即提交无需 I/O 的裁页，并在同一事务中发起已知接替切面；不能清除后再等一轮后台求解，也不能取消既有接替页请求。降档携带下一步纯值快照；放大按同一到期点准备完整接续，最多原 16 页，不串联历史事务，每一步重新核验真实预算。实际视野内纹理在原队列中优先，重排不增加请求或上传限额。紧凑桥接按接替切面实际所需空间求预算，禁止由保护带重试重新扩大该预算。缩远时桥接覆盖时间至少达到接替切面获得真实尺度资格的等待时间加原 0.05 s 加载余量；接替资源已经全部就绪时，只需覆盖到真实资格边界，不能为多余等待取消已就绪目标，不能为了腾空间采用提前失去覆盖的短桥接。压缩未来接替切面时使用其准备尺度，不能因当前倍率尚未到达降档资格而误判紧凑方案无解。规划用旧图原有 1.10 倍上限选择将来可装入的细档，不延长实际显示宽限。

Loading 将 7 份已认证目录的相同空间树交织成一个仅用于交接的选择目录，并预计算全部精确资格区间。逐页仍使用原几何、纹理、边界、摘要、物理资源身份和原资格上限；不新增烘焙资产。常规档位偏好和常驻层跳过该虚拟目录。选页展开当前与接替来源；跳过短中间档后，若等待后续档获得资格的边缘将缺失，也允许当前实际档参与补边。资格仍来自完整认证目录。新旧整档无法同时装入时，允许按空间页逐步交接，完整显示和真实联合费用分别复核。所有交接必须证明调用者给出的完整等待视野。逐页降档已经通过在途覆盖、资格与同池检查时，即使没有提前倍率标记，也作为正在完成的降档保留；不能在同一次规划后续又选粗档、再次裁旧并取消这笔接管。暂时只能容纳较窄接管切面时，同次规划附带提交后的扩边事务；可用原联合预算空余预读接续页，实际接续仍核验原池。不能只检查当前视口而忽略调用者已计入的缩远包络。裁出的虚拟子集必须去掉完整目录资格缓存，避免重新展开已裁页。

缩远提前准备下一档，仅允许在真实尺度合格后绑定。跳过短中间档须证明旧图覆盖直到后续档合格时的整个运动视野，并满足联合预算。若等待期间将缺边，则先补齐仍合格的细档边缘，同时继续预取接替资源。有效在途事务保持资源身份，不能每次预测都取消并重新装载；已经就绪、只等缩远资格边界的目标不能被未完成补边挤掉，新补边须证明当前显示、已就绪接替及自身三方同池共存，并优先保留已就绪资源，否则继续原接替；停止、反转或失覆盖时重新规划。已完成的逐页交接仍覆盖未来 0.25 s 运动时保留显示；只有当前切面无法与下一档在原联合预算内共享时，才压缩以恢复交接空间。半池是预留方式；已经足够共享的细页必须保留，不能继续整档降级并在反转时重装。整档压缩不能共存时先逐块释放不再需要的细页，每一步提交后重验剩余交接空间，不无条件继续到最粗切面。有效在途接替优先于旧切面保留；反转放大后不继续锁定即将到期的降档压缩事务。

反向放大时，更细档尚不能与旧图共存、只覆盖未来视野或保护带少于 96 px 时，先准备可用的中间档。中间档当前宽视野也放不下时，按旧档原到期尺度提前请求；提交仍重新检查实际视野与画质。准备倍率仅记录查询机位，不作为绑定下限；已完整覆盖当前视野、实际画质合格且资源就绪时立即提交，不能等倍率标签而耗尽旧图宽限。该事务只在继续放大、当前完整合格且上限高于旧图时保留，提交后立即继续细档准备。不能用 0.25 s 预测跳过必经档而取消即将接管的资源。所有压缩和回退之后再检查平移运动包络；未来窄视野不能挤掉仍需显示的当前边缘，必要时按空间页先补齐等待段，同时继续预取细档。旧图处于原有显示宽限时仍可接纳合格未来切面的补页请求；接纳只发起加载，提交仍独立检查实际覆盖与资格，宽限到期不延长。整档升级无法共存时先升级最早到期的空间页；降档混合页反转且预测会到期时，也直接续接已开始的事务，避免再走完整选档流程拖迟首步。已启动逐页升级后，若预测期限内的到期页可在原池内共同接替，则作为一笔事务完成；首次反向的平滑速度尚小时，至少准备至旧页原 1.10 倍期限，避免相邻到期点再次串行等待；比较完整接替与到期组接替的新增物理资源，保留已合格页，避免额外重装。整组放不下时才推进一块。首步已开始而剩余旧页尚未达到预定接替档资格时，即使平滑速度短暂偏低，也按剩余旧页原到期倍率规划接续；不能等下一次速度估计才启动。规划预先附带下一笔可行接续事务，提交时重验联合预算并同帧发起，不等待新一轮 worker；后续切面允许按旧页正常资格结束的机位预先装载，优先在正常资格边界准备；该视野仍无解时，可提前装载原宽限内的窄视野候选，提交依旧检查当下完整覆盖且不延长宽限。完整接替已能同池共存且旧图覆盖整个等待运动视野时，直接准备完整接替，避免耗时展开屏外逐页链；旧图无法安全等待时，才先逐笔推进当前完整表示，再在同一期限内完成剩余页。替换完整方案前必须证明有限接续的末步达到同一期限资格；首步完整但整链无法完成时保留原完整未来方案，包括虚拟空间目录求出的未来切面。未来候选超过半池时用真实增量费用求解，不能被同步 helper 的当前宽视野检查误拒，并包含原 0.25 s 位移在两个方向上的范围；查询必须独立通过未来画质门，不能被共享旧页的保护带回退替代。提交仍重验当时完整覆盖；已有可行完整接替时不为更低新增费用改成未完成升级的小步。同一到期点的接续最多覆盖原 16 页，末步完全合格后即停止，不随递归继续推高期限；不能因固定两步截断而让剩余旧页再次等待后台。预读清单去重且仍受原池限制，已知尾步依赖也排入原预读队列，紧随直接接替页；有空余才逐包接纳，原池与请求/上传额度不变，实际绑定仍逐笔提交。后台返回时若镜头已由缩远反向放大，新降档身份必须满足当前预测和旧页原到期倍率，否则拒绝并重采；已有在途与显示身份仍可补元数据。预读优先顺序改变也属于请求变化，不能被同目标去重忽略。后台接续信息晚于前一步提交时，同一显示身份的结果也必须立即启动接续，不能被重复目标的去重分支吞掉。部分升级只能原样继承已显示旧页的原宽限起点，新页必须当下合格，不能重置计时。纯裁页也可继承同一个到期点，但所有保留资源都须来自当前显示。目标包含已移出视野的过期页时，先按实际投影裁出当前可见成员，再核验完整目录覆盖、逐页资格或尚未耗尽的原宽限；原接续元数据继续保留，不让屏外已裁页阻挡屏内完整交接。纹理在两帧延迟释放队列中被再次请求时，原对象立即恢复使用而不重读重上传；相机移动时同帧启动可用图片读取，上传仍只在原流送循环按原限额执行。

北缘近景原包存在整叶选页的容量缺口。以下是未启用的历史候选记录，当前缺口见 §5.5。该候选使用既有无损分区流水线，将 LOD4 / LOD5 的 28 个非游戏建筑叶块分别细分至 4 层。离线从不同空间切线选定每个来源的固定布局，运行时每个来源只有一套细分。制作并回读 868 个分区包，保留 28 个原父页的身份、物理组件与费用，840 个子页参与原完整切面选择；三个层的三角角点与属性逐项守恒，正式游戏建筑、纹理、着色和几何形状均不变。新包 `m20_continuity_fixed` 复用原 M20 资产，并携带分区依赖与守恒证明；原 M20 内容不改写。安装后逐依赖摘要和资源回读检查通过，实际 16 页、24 万面与 96 MiB 门保持。

原生切面缩远时优先沿用仍合格的已显示档位，避免在中景切换前重复加载另一份近景。原生预测也先准备中景边界前的最后一段原生视野，在原 0.25 s 内保留 0.05 / 0.10 / 0.15 / 0.20 s 沿途切面。预测切面的可见细分子块以最多 512 次元数据遍历收集，小块优先，额外请求最多占原池内 1 MiB 且排在正常目标、预测切面和中景请求之后。加载时另建纯值父页索引；在原半池余额中最多再准备 2 MiB 小父页，以便缩远合页时使用原资源。它们不增加请求槽、单帧领取或上传额度，也不让未通过预算的候选获得显示资格。

后台结果未返回而旧近景失去覆盖时，可用当前缓存重组完整原生切面；到达原中景资格范围后，也可直接接替已经预取的完整中景切面。中景内部交接同样在清屏前尝试实际档、目标档及当前/目标来源的虚拟目录，最多三棵树；未占满候选名额时补入仍具真实画质资格的相邻粗档，目录偏好边界不能误排除已就绪缓存。当前显示安全时不重复重组。所有接替均重新证明当前完整覆盖、实际清晰度、资源就绪和真实联合预算，不同步加载文件、不保持过期截图。原生桥接保留仍在途的目标；中景接替成功后立即重新规划后续视野。

降档接替已在途时，保留门只要求覆盖至真实资格边界加 0.05 s 的等待段，最长仍为 0.25 s；不能为更远的预测视野取消即将完成的请求。提交后继续按真实运动更新保护带。缩远且当前交接已完成、当前切面完整覆盖预测视野时，可在原联合预算余量中预取旧页原到期倍率需要的细档，以接住快速反向放大；有在途交接、前方缺覆盖或联合费用不足时不执行。这段预测需求已有完整显示时，细档优先于重复准备粗档，但不提前绑定。整档无法在原池共存时，仍可预读可容纳的首个空间交接页，并把完整后续目标交给原资源池逐包接纳；首步已有缓存后不能停止预读，装不下的余页继续等待，不扩大联合预算。最后降档页在途时预先携带其提交后的反向预读身份；旧图仍受保护，提交释放空间后同次资源请求即可启动，无需多等一轮后台查询。反向预备按已显示来源持有：未显示目标的计划不得覆盖当前来源的有效计划，只有真正绑定后才接管；同身份元数据更新也须进入下一份 worker 快照。裁页同步收缩来源身份、接续与预读清单，不能只传计划而取消其尚在途的资源。缩远中间步骤同样准备反向资源，不能等待最后一笔降档已经提交；既有必经接续仍排在反向预读之前，所有请求继续受原池和原上传额度约束。在途降档按已认证的接管倍率准备反向资源，不必等待实际相机跨过该倍率；已知后续切面按其完整预测机位同步准备；这个提前阶段只保存已求出的首步和已知资源依赖，不递归展开完整反向链拖迟当前必经交接。真正显示后仍按原正常路径准备完整接续，当前必经资源始终列在前面。仅已认证接管机位可提前准备；普通显示仍先要求覆盖继续缩远的预测视野，不能让反向投机挤掉尚未计划的必经粗档。真实绑定仍独立核验当前完整覆盖、画质和同池预算。反向预备统一在规划出口执行，已稳定提交的粗档也必须执行，不能被常驻层或预测缓存的提前返回跳过；当前宽视野受页限约束而无法求出后续接替时，可提前求正常资格边界的完整未来视野并加载，实际显示仍独立核验当前覆盖。反向预备按原 16 页上限准备同一期限的完整链，先准备两笔当前交接，后续优先采用已经证明同期限合格的完整尾步，避免额外拆分拖迟首步，也不能按固定接续数量截断。运动包络暂时无法同池交接时，允许只预读原到期机位下能够同池容纳、画质合格的中心切面；该候选仅进入原资源队列，不成为可绑定的接续，实际显示仍需后续完整覆盖与资格复核。反向预取同时保存有界纯值交接方案，并把方案中所有已知后续页按先首步、再接续、最后一般预测的顺序交给原预读队列；不能只保存方案而漏掉尾页资源请求；真实反向帧先复核来源目录与页身份、当前覆盖、画质和真实联合费用，再启动准备好的首步，不等待第一份反向后台结果。反向方案晚于反转帧返回时，仍在放大且尚未启动交接的后续帧继续复核，不能错过唯一方向切换事件。元数据更新不能被显示身份去重吞掉；停用与退出清空方案。全部请求继续服从原 I/O、图片 worker、上传与显存限额。仅在当前目标已经过期时，若后续切面已全部就绪且当前完整覆盖、真实资格与当前显示联合预算都合格，直接选原有最多 16 步链中最远的可提交后续，只绑定一次，已经提交的相同资源身份不得重复改变规划代际或重发请求；不按每显示帧一页串行等待，不借用中间旧页的过期资格。仍合格的裁页目标必须先提交，以免跳步把刚释放的屏外宽切面重新装回。

缩远跳档的整档费用超过同池门时，先准备较早获得资格的中间档，让逐页腾空间在粗档到来前完成；等待与后续视野仍分别核验。跳过短中间档并非硬门：更细档超过原面数、页数或真实同池预算时，预备与接续都回试仍合格的实际中间档；细档自身虽合格但不能与旧图共存时，也须检查可完整共存的中间档；旧图保留判断采用同一候选范围，不能把细档无解变成空接续。已提前启动的未来切面，只要当前图能撑到准备倍率、目标未来覆盖与清晰度合格且镜头仍放大，就不能因反转初期速度低估而取消；停镜、反向或当前图提前到期仍重新规划；保留未来窄视野事务时也必须证明同一 0.25 s 平移前探，不能只检查缩放后的静止中心而锁住即将缺边的目标。普通完整切面在预测会到期时同样准备下一步；尚未提交的新切面按自身原到期点预先计算后续，不能用请求时的低倍率省掉加载期间即将需要的接续。平移时，当前切面在既有 0.6 s 前探窗内仍合格则暂缓更远的升级链，优先留出边缘换页空间，但不得删除已启动事务已计算的接续；反转时仍立即接手已经预备的方案，不丢弃或延迟已知资源。反向准备的终点越过提前区间重叠的短中间档；不能只达到旧档到期倍率，就把即将再次失格的中间档当成整链完成。无平移或临近到期仍按原到期点完成接续。完整中间档也保留原细档目标并传递有界后续事务，不能因其已完整而停止准备下一档；目标绑定继续核验真实覆盖与资格。

纯值 worker 的最大嵌套深度为 64，以容纳七档交织的 21 层树及字典/数组层；值类型、总元素数、请求字节数和所有资源预算不变。

同档新增的可见纹理瓦片首帧必须不透明，不逐瓦片淡入；透明首帧会让底层旧 PNG 显露，造成局部图像回退。跨档整层继续使用原 0.40 s 交叉淡入，旧层保持不透明，直到目标层完整覆盖且通过原画质与预算检查。

### 3.8 镜头移动与地图交接一致性

每次提交平移或缩放后的镜头姿态前，检查当前显示切面是否仍满足该姿态的清晰度资格与完整视野覆盖；若不满足，先尝试提交已就绪且通过同一资格、覆盖及联合预算门的目标切面。无合格切面时保留旧镜头与完整地图，继续把完整待呈现姿态和移动速度交给后台规划，直到候选可交接。缩远跨越目标资格边界时，镜头按真实中间姿态逐档交接。不得通过隐藏地图、切换到过期位图或扩大现有预算来放行镜头。

持续输入期间，后台请求姿态允许早于最新输入。接纳不能要求二者逐位相等：必须按最新待呈现姿态重新核验候选的完整覆盖和清晰度，反向离开覆盖时拒绝；当前显示完整合格才允许同池暂存。规划请求分别携带显示姿态和待呈现姿态，因预算等待时只裁去实际显示视野之外的旧页，不以尚未显示的位置误判旧页。

冷进入尚无运动历史时，若提前细档的裸视野超过原半池首选且保护带不足 48 px，沿用已有实际档资格和保护带选择，避免占满 96 MiB 后首次跟随即无法交接。资产、原清晰度阈值和各预算均不变。缩远进入较粗档后，优先准备该档的合格桥接，不继续扩大已退出范围的同档细页；真正跨档的在途中间档仍保留。

## 4. 结构与组成（Structure）

- PreparedCatalog：Loading/离线缓存与精确资格区间查询。
- MapPlanner：独占纯值来源、完整选择策略、候选/无解结果及后台计时。

镜头等待优先级：显式候选有尚未完成的镜头输入时，规划提交、结果接纳与已就绪资源绑定不再因旧画面完整而继续错峰让出。正常态保持原调度；线程数、I/O 并发、逐帧纹理上传配额、内存、面数及页数上限不变。修前聚焦测试记录三个交接阶段均被延后，修后通过。

保护带与输入终点保持：没有待处理镜头需求时，仅允许上述连续缩远跨档的受保护交接，不执行只覆盖裸视野的腾池压缩，避免完整保护切面与裸视野切面反复交替。缩远经过已准备档位的中间机位时，只约束本帧实际显示；后台需求和未显示输入继续保存原完整终点及其位置，反向输入按既有规则立即替换。不能把临时中间档写回最终需求，导致细档与远景资源反复取消、重载。

自由移动的在途目标保留：候选开启且相机没有待处理输入守卫时，正在加载的 HLOD 切面除了完整覆盖当前视野，还须覆盖原 0.25 秒平移与缩放包络，才可阻止后续规划。即将缺边的旧目标应继续规划前沿；资源提交仍独立核验当前完整性、资格和原联合预算。停镜、守卫等待与关闭候选保留原策略，不增大保护时长、不限制实际相机运动。聚焦反例同时覆盖当前完整但前方缺页、前方完整、停镜、等待与默认关闭分支。

反向放大同档分块：若实际显示的大父页与整套紧凑页仍不能在池内共存，按已认证的同档空间子树逐父页替换，其他页继续显示原资源。每步必须降低显示字节、保持实际姿态清晰且完整覆盖，旧新真实联合费用仍不超过 96 MiB。真实 64,100,240 字节反例两步降至 49,315,472 字节；回归同时要求远距返回在有限压缩步后继续沿输入路径推进。

同档空间细分的批量接管：在同一旧切面不变的前提下，累计多个彼此独立的父页细分，并按全部新页的真实增量费用核联合预算；能同池准备的分块一次请求和提交，I/O 并发及逐帧上传配额不变。空间子树先按实际视野筛可见根，超过 16 根的方案直接拒绝，最终仍独立复核完整覆盖、资格和物理费用。

中间步接纳核验：对终点及每个沿原输入路径插值的机位，在同一轮判断中同时核清晰度、完整覆盖与原 0.25 秒放大前探；终点的前探过期时继续检查下一较小机位。不能先以当下资格选中终点、再在循环外否决整个可行交接。新增 SceneTree 回归在修前失败、修后通过，并继续拒绝未标记中间步及当前显示未覆盖时的提前绑定。

在途显示压缩完整提交：已有尚未提交且明确标记为显示压缩的目标时，只要目标与旧图仍完整覆盖实际显示机位、目标更省内存且真实联合费用合格，先完成这次事务。待显示的输入终点改变不取消它；实际覆盖、清晰度或预算失效则立即回到正常规划。不能因压缩目标不覆盖远端输入而重复加载同一批页。

沿最新输入路径接纳已准备页面：完整输入切面在读取期间可变成最新路径上的中间步。显式候选为这类切面保留中间步标记，按最新路径的 7/8、3/4、5/8、1/2、1/4、1/8、1/16 位置依次核完整覆盖、当前清晰度与原 0.25 秒前探资格；有效在途切面先完成，不因最新终点略远而取消。控制器、规划器和接纳入口共用同一组比例，实际相机只提交已就绪且完整覆盖的最大可行一步，输入速度、缩放范围和预算不变。反向输入、未标记切面、缺覆盖及超预算仍拒绝；新增真实 SceneTree 反例在修改前失败。
