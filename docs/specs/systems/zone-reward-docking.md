# 战区奖励与停靠结算 —— 机场/航母着陆结算 + 三类实体奖励 + 逃跑护卫

> 玩家视角：打完战区不再"弹窗发奖"——全队当场满血，然后你得**飞到停靠点减速降落**才能
> 结算升级/进化；奖励本身是**有形的战场实体**：一艘南边开进来的友军航母、王牌旁边爆出的
> 新僚机、或挂上机的追加武器。Tab 地图上每个战区**预先亮出它给什么**，难度越高、王牌
> 等级越高，给得越好。

## 0. 与 aircraft-evolution（wip-design v2）的关系：本 spec 是它结算流的修订

用户 2026-07-06 决策，修订该 spec 两处（该文档同步加注）：

| v2 旧设计 | 本 spec 新设计 |
|---|---|
| Tab **原地**结算（"不强迫飞去某处"） | 攻克后**必须飞到停靠点减速**才能结算升级/进化（着陆仪式感） |
| 武器不进局内结算（06-28 决策"武器=机型自带"） | **追加武器**回归为战区奖励之一——但限**副系统类**（忠诚僚机/尾部炸弹/QMAAM 副槽），不动"主武器=机型自带"的原则 |

进化机制本身（宝可梦式/等级门槛/整机替换/ACE 触发规则）不变，仍归 aircraft-evolution + ace-system。

## 1. 设计意图（Why）

- **结算物理化**：与增援入场同一美学——出现有来路、奖励有实体、结算有仪式。降落读秒
  替代弹窗打断，飞行节奏不断。
- **奖励前置可见**：Tab 上看得到"这个区给航母/僚机/武器"→ 战区选择变成 build 决策
  （原则 9 局内成长爽点）。
- **航母/僚机是战场事件**（原则 7 战场热闹）：航母入场要护、僚机爆出即时壮大编队。
- **反模式规避**：不做隐形数值奖励（原则 3 信息察觉——三类奖励全部可见可感）；
  停靠不耗 game_time（不与 8 分钟阶段税冲突，等价旧 Tab 原地的时间语义）。

## 2. 数据定义（What）

### 2.1 攻克即时效果（无需停靠，当场生效）

| 项 | 旧 | 新 |
|---|---|---|
| 回血 | 仅玩家 +30 HP | **全队满血**（当前操控机 + 所有存活友机，含僚机/忠诚僚机） |
| 奖励发放 | 攻克瞬间 apply_upgrade（战区强卡） | **改为入库待结算**：奖励进"待领取"栏，停靠时领取/选择 |

### 2.2 停靠结算机制（升级/进化的唯一入口）

| 项 | 值/规则 |
|---|---|
| 停靠点类型 | **机场**（陆上停靠区）与 **友军航母**（海上，奖励召唤，§2.4） |
| 机场位置 | ✅ **固定常驻 3 处真实机场**（用户拍板）：**羽田**（湾西北，手画 HANEDA_AIRPORT 多边形质心）/ **木更津驻屯地**（烘焙 aero 质心 ≈(6844, 2381)）/ **調布飛行場**（≈(-10434, -12864)）。坐标实现时从地图数据取质心。**南半图无机场 = 航母奖励的价值区**（设计协同：南部战区打完时航母最香） |
| 着陆判定 | 进入停靠圈（半径 ~600 px）+ **减速至 ≤ 着陆阈值**持续 **1.0 s** → 判定"已停靠"。阈值**动态随机型** = `max(300 km/h, 失速基数 × 1.3)`（2026-07-06 playtest 修复：原固定 250 压在玩家机 1G 失速地板 ~252 之下物理减不到；提示文本跟随实际阈值） |
| 停靠后 | 打开结算 UI：领取待领奖励 + （达门槛时可选）进化 |
| 升级范围 | ✅ 本期停靠只接管**战区奖励 + 进化**；XP 升级流程维持现状不动（用户确认；按 RTS 方向废三选一的收束另启工单） |
| UI 引导 | 停靠圈上方提示"减速至 250 以下完成停靠"；HUD 有待领奖励角标 |
| 时间语义 | 停靠结算 UI 打开期间暂停（与现结算一致），飞行赶路**不暂停**（路程本身是代价） |

### 2.3 战区奖励表（预分配、Tab 可见、质量随难度与 ACE 等级）

战区开放时 roll 定奖励并显示在 Tab（替代现"奖励类别提示"，直接亮具体奖励 + 质量星）。

| 奖励 | 内容 | 权重（★ / ★★ / ★★★，待调参） |
|---|---|---|
| **航母增援** | §2.4；全局限 2 次登舰，次数用尽后不再进池 | 0 / 20 / 45 |
| **+1 僚机** | §2.5（ACE 升级 + 爆出僚机） | 40 / 45 / 40 |
| **追加武器** | §2.6（副系统三选一） | 60 / 35 / 15 |

ACE 等级修正（"等级越高的飞机奖励越好"）：
- +1 僚机：新僚机机型品质随 ACE 等级（⚑ 分叉 Q3 定机型规则）。
- 追加武器：ACE ≥ 8 时池子偏向高价值件（忠诚僚机/QMAAM），低等级偏尾部炸弹。
- 旧"战区强卡（evolved 技能）"：并入追加武器档位或退役 —— 随 Q2 一起定。

### 2.4 航母增援（沿用 aircraft-evolution §2.7 机制，改为限 2 次）

| 项 | 规则 |
|---|---|
| 入场 | 领取该奖励后，航母从**地图南边**驶入北上一段停泊（team 0，无护卫舰，CIWS 自卫，可被击沉） |
| 功能 | = 海上停靠点：着舰（§2.2 同判定）→ 回血 + 进化/升级 |
| 限次 | **全局 2 次登舰**（跨航母累计；被击沉视为机会流失，不补） |
| 复用 | carrier_ship 资产转 team0 + DockPoint 组件 |

### 2.5 +1 僚机（ACE 检测）

```
领取时：
  ace = 队内等级最高的飞机（并列取当前操控机优先；定义随 ace-system）
  ace 升 1 级（只推进化门槛，不加属性——与"等级不加属性"原则一致）
  在 ace 侧后 300px 爆出 1 架新僚机（出现特效 + 自动入队，squad 数量 +1）
  编队上限：9（squad-upgrade-ownership 上限），满编时该奖励自动降级为追加武器
新僚机机型：✅ **与 ACE 同型**（用户拍板——王牌带同型僚机，档案现成）
```

### 2.6 追加武器（副系统类，三选一）

| 件 | 效果 | 现有资产 |
|---|---|---|
| 忠诚僚机 | 无人机伴飞（拦截/直冲，kamikaze_intercept 路径） | A-10 实验忠诚僚机变体 |
| 尾部炸弹 | 尾后投放滞空雷 | ✅ = 现"漂浮雷"泛化到全机型可挂（用户拍板，资产现成直接上线） |
| QMAAM | 副导弹槽近距格斗弹 | weapons/qmaam（副槽机制完整） |

与 §0 原则的边界：三件全部是**副系统**（副槽/子机/后投），不占用也不改变机型主武器。

### 2.7 逃跑任务护卫（ADBS 丰富化）

| 项 | 规则 |
|---|---|
| 适用 | 教程/事件轰炸机（Tu-160 flee）、城区直升机（CH-47/AH-64 flee） |
| 编成 | 每个逃跑组附 **2~4 架战斗机护卫**（机型按当前有效等级选型，成建制小队） |
| 行为 | 随队伴飞（跟随 flee 航线）；玩家进入 ~3km 或攻击护航对象 → 护卫转向交战玩家；护航对象全灭/逃出 → 护卫转 EGRESS 飞离 |
| 计费 | 同 adds：不占 token、skip_far_cleanup、击杀给正常 XP（不给 adds 满级 XP） |

### 2.8 Tab 展示

- 战区圈旁：奖励图标（航母/僚机/武器）+ 名称 + 质量星；已领取显示"待停靠结算"状态。
- 停靠点在 Tab 与主地图上有专属标记：**机场=跑道方框、航母=蓝菱形**，均带深色描边衬底 +
  **名称标签**（深底亮字，和 HUD 数据标签同风格），保证在浅色底图上清晰可辨。

## 3. 行为与公式（How，摘要）

```
战区攻克:
  全队满血 → 奖励入"待领取" → HUD 角标 + Tab 状态更新
  (航母奖励: 立即触发航母入场事件，登舰即领)
停靠判定（每帧，仅玩家操控机）:
  in_dock_circle && speed <= 250km/h → 计时 1.0s → docked
  docked → 暂停 + 结算 UI（待领奖励 / 进化树 / 升级）
奖励 roll（战区开放时）:
  pool = §2.3 表按难度取权重；carrier 剩余次数==0 → 移出
  roll → 存 zone_data._rewards[id]（沿用现结构，类型从 upgrade dict 扩为 reward dict）
```
