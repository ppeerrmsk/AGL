# 战区奖励与停靠结算 —— 机场/航母着陆结算 + 四类奖励 + 逃跑护卫

> 玩家视角：打完战区不再"弹窗发奖"——全队当场满血，然后你得**飞到停靠点减速降落**才能
> 结算升级/进化；奖励本身是**有形的战场实体**：一艘南边开进来的友军航母、王牌旁边爆出的
> 新僚机、或挂上机的追加武器。Tab 地图上每个战区**预先亮出它给什么**，难度越高、王牌
> 等级越高，给得越好。

> ⚠ **2026-07-22 修订指针（[zone-reward-arsenal](zone-reward-arsenal.md)）**：本 spec §0
> "追加武器限副系统类"的边界已被扩——武器子池新增**火箭弹/电磁炮/激光/ESM 吊舱**（依据
> inrun-weapon-inventory 既定"特殊武器获取=战区奖励"方向）；§2.3 遗留的"旧战区强卡
> （evolved 技能）随 Q2 定"悬案落定为奖励第四类 **nextgen 次世代技术**。
> 奖励类别/武器子池的数值权威移交 zone-reward-arsenal，本 spec 保留停靠/结算机制权威。

## 0. 与 aircraft-evolution（现已 superseded）的关系：本 spec 取代其结算流

用户 2026-07-06 决策，修订该 spec 两处（该文档同步加注）：

| v2 旧设计 | 本 spec 新设计 |
|---|---|
| Tab **原地**结算（"不强迫飞去某处"） | 攻克后**必须飞到停靠点减速**才能结算升级/进化（着陆仪式感） |
| 武器不进局内结算（06-28 决策"武器=机型自带"） | **追加武器**回归为战区奖励之一；完整七件子池与数值由 `zone-reward-arsenal` 负责 |

进化名单与出口归 [aircraft-evolution-tree](aircraft-evolution-tree.md)，三轴门槛与当前操控机的玩家级成长归
[evolution-attribute-gates](evolution-attribute-gates.md)，特殊武器继承归
[inrun-weapon-inventory](inrun-weapon-inventory.md)。本 spec 只保留停靠、回血和奖励发放时序权威。

## 1. 设计意图（Why）

- **结算物理化**：与增援入场同一美学——出现有来路、奖励有实体、结算有仪式。降落读秒
  替代弹窗打断，飞行节奏不断。
- **奖励前置可见**：Tab 上看得到"这个区给航母/僚机/武器"→ 战区选择变成 build 决策
  （原则 9 局内成长爽点）。
- **航母/僚机是战场事件**（原则 7 战场热闹）：航母入场要护、僚机爆出即时壮大编队。
- **反模式规避**：不做隐形数值奖励（原则 3 信息察觉——三类奖励全部可见可感）；
  停靠不耗 game_time（不与战区阶段时间税冲突，等价旧 Tab 原地的时间语义）。

## 2. 数据定义（What）

### 2.1 攻克即时效果（无需停靠，当场生效）

> ⚠ **2026-07-24 修订（用户拍板）**：奖励与停靠**解耦**——僚机/武器/技能类奖励**攻克即领**（当场生效），
> 不再入"待领取"栏、不再需要飞去机场。**停靠点只保留进化 + 回血**（见 §2.2）。回血从"攻克即回"
> 移到"停靠时回"。航母奖励仍即时入场（登舰=海上停靠点，兼回血/进化）。

| 项 | 旧（2026-07-06） | 新（2026-07-24） |
|---|---|---|
| 奖励发放 | 攻克瞬间 apply_upgrade → 后改"入库待结算" | **攻克即领**：僚机/武器/技能当场发放（`_grant_reward_now`），与机场解耦 |
| 回血 | 攻克瞬间全队满血 | **移到停靠点**（§2.2）：飞到机场/航母停靠才全队满血 |

### 2.2 停靠结算机制（回血/进化入口）

| 项 | 值/规则 |
|---|---|
| 停靠点类型 | **机场**（陆上停靠区）与 **友军航母**（海上，奖励召唤，§2.4） |
| 机场位置 | ✅ **固定 3 处真实机场**（用户拍板）：**羽田**（湾西北，手画 HANEDA_AIRPORT 多边形质心）/ **木更津驻屯地**（烘焙 aero 质心 ≈(6844, 2381)）/ **調布飛行場**（≈(-10434, -12864)）。坐标实现时从地图数据取质心。**南半图无机场 = 航母奖励的价值区**（设计协同：南部战区打完时航母最香） |
| 机场次数（**2026-07-23 修订**） | ✅ **一次性使用**（用户拍板）：每个机场停靠一次即失效——标记从主图 + Tab **消失**、不再判定停靠。全图 3 机场 = 3 次陆上结算机会（+ 航母 2 次 = 全局 5 次）。**机场的 ALLY 防空驻军**（`_spawn_airfield_garrison` 部署的 SAM+AA）是**独立实体，原地保留**，不随停靠点消失（"友军保留"）。carrier **不受影响**（走自己的限 2 次登舰机制）。设计后果见 §9.1 |
| 着陆判定 | 进入停靠圈（半径 ~600 px）+ **减速至 ≤ 着陆阈值**持续 **1.0 s** → 判定"已停靠"。阈值**动态随机型** = `max(300 km/h, 失速基数 × 1.3)`（2026-07-06 playtest 修复：原固定 250 压在玩家机 1G 失速地板 ~252 之下物理减不到；提示文本跟随实际阈值）。**2026-07-24 修订：速度比较用 g 中和当量**（实测速度 ÷ `g^0.4`）而非绝对速度——飞机转弯拉 G 时物理最低速被抬到角点速度（500~790 km/h），绝对 300 判定使绕圈进近永远够不到；g 中和把"已减到本机当前 G 最低速"折回 1G 当量（≈231）再比阈值，直线/绕圈进近都能触发。超阈时进度不清零、改快速衰减（`HOLD_DECAY_MULT`）防 G 抖动打回原点。1G 直飞时 `g^0.4=1`，行为与旧实现一致 |
| 停靠后 | **全队满血** + 打开进化面板（达门槛时可选进化）。战区奖励已攻克即领，不在此领（2026-07-24 修订） |
| 结算范围 | ✅ 停靠只接管**进化 + 回血**；战区奖励改攻克即领（§2.1）；XP 升级流程维持现状不动（用户确认；按 RTS 方向废三选一的收束另启工单） |
| UI 引导 | 停靠圈上方显示按当前机型计算的动态着陆阈值，禁止写死 250 km/h |
| 时间语义 | 停靠结算 UI 打开期间暂停（与现结算一致），飞行赶路**不暂停**（路程本身是代价） |

### 2.3 战区奖励表（预分配、Tab 可见、质量随难度与 ACE 等级）

战区开放时 roll 定奖励并显示在 Tab（替代现"奖励类别提示"，直接亮具体奖励 + 质量星）。

> ⚠ **2026-07-24 修订（用户拍板，去重 + 航母保证）**：
> - **整局去重**：武器/技能/航母**每种整局只出现一次**（roll 到即永久移出池，`_used_reward_ids`）。
>   **僚机豁免** = 可重复出现的保底奖励（collectible 用尽后 roll 落到僚机）。取代旧"仅活跃战区去重"。
> - **航母整局保证**：pity 机制——第 `CARRIER_PITY_ROLLS`(=4) 次 roll 时航母若仍未自然出现 → **第 4 次当次**强制发，确保每局一定出现一次航母奖励。

奖励分为航母、僚机、武器、次世代四类。类别权重、七件武器子池、起始机型偏置和当前次世代清单全部以
[zone-reward-arsenal](zone-reward-arsenal.md) 为唯一权威，本 spec 不再复制数值表。

### 2.4 航母增援（沿用 aircraft-evolution §2.7 机制，改为限 2 次）

| 项 | 规则 |
|---|---|
| 入场 | 领取该奖励后，航母从**地图南边**驶入北上一段停泊（team 0，无护卫舰，CIWS 自卫，可被击沉） |
| 功能 | = 海上停靠点：着舰（§2.2 同判定）→ 回血 + 进化/升级 |
| 限次 | **全局 2 次登舰**（跨航母累计；被击沉视为机会流失，不补） |
| 复用 | carrier_ship 资产转 team0 + DockPoint 组件 |

### 2.5 僚机奖励

```
领取时（2026-07-24 修订：一次给 2 架）：
  current = 当前操控机
  在 current 侧后爆出最多 2 架同型新僚机（出现特效 + 自动入队）
  编队上限：9（squad-control-switching 的当前队伍合同）——能塞几架塞几架
  不提升王牌等级，不发战斗等级，不灌经验
```

**停靠补给僚机（2026-07-24 新增，用户拍板）**：与上方 roll 奖励**独立**——**每次停靠**
（机场 / 航母，航母不除外）**额外送 1 架**复制王牌机的僚机入队（`_on_dock_docked`）。满编 9
则跳过（不降级，纯福利）。机场一次性 3 处 + 航母 2 次登舰 = 停靠僚机来源；叠加 roll 奖励的 +2。

### 2.6 追加武器

完整七件武器为漂浮雷、忠诚僚机、QMAAM、火箭弹、电磁炮、激光阵列、ESM 吊舱；权重与行为均见
[zone-reward-arsenal §2.2–2.3](zone-reward-arsenal.md)。

### 2.7 逃跑任务护卫（ADBS 丰富化）

| 项 | 规则 |
|---|---|
| 适用 | 事件轰炸机（Tu-160 flee）、城区直升机（CH-47/AH-64 flee）。⚠ **开局教程轰炸机（3 架）豁免**——纯教学靶机，刷玩家面前练锁定/攻击，不带护卫（`spawn_bomber_flee(..., with_escort=false)`） |
| 编成 | 每个逃跑组附 **2~4 架战斗机护卫**（机型按当前有效响应等级选型，成建制小队；独立零 Token 候选池，不读取常规战场剩余 Token） |
| 行为 | **护航对象是移动编队长机**，护卫用 WEDGE、220m 基距近距伴飞（3 架运输机 + 4 护卫的最外槽位 <700m）；首架护航对象阵亡时优先换锚到下一架。玩家进入 ~3km → 至多 1s 自主扫描接敌；任一护航对象受击 → 全护卫同拍退出编队并进入 ENGAGE；护航对象全灭/逃出 → 护卫转 EGRESS 飞离 |
| 计费 | 同 adds：不占 token、skip_far_cleanup、击杀给正常 XP（不给 adds 满级 XP） |

### 2.8 Tab 展示

- 战区圈旁：奖励图标（航母/僚机/武器）+ 名称 + 质量星；攻克即领后显示“已领取”。
  停靠点的“可用/已使用”独立显示，不再把奖励伪装成待停靠领取。

  **名称标签**（深底亮字，和 HUD 数据标签同风格），保证在浅色底图上清晰可辨。

## 3. 行为与公式（How，摘要）

```
战区攻克:
  僚机/武器/技能奖励立即发放
  航母奖励立即触发航母入场事件
停靠判定（每帧，仅玩家操控机）:
  in_dock_circle && g中和速度 <= 动态阈值 → 计时 1.0s → docked
  docked → 全队回血 + 暂停 + 进化结算 UI
奖励 roll（战区开放时）:
  pool = §2.3 表按难度取权重；carrier 剩余次数==0 → 移出
  roll → 存 zone_data._rewards[id]（沿用现结构，类型从 upgrade dict 扩为 reward dict）
```

## 9.1 一次性机场设计后果（2026-07-23，待 playtest 复核）

机场从"无限次"改为"一次性"是显著的节奏改动，落地时记下的后果供 playtest 质询：

> ✅ **2026-07-24 更新**：奖励改攻克即领（§2.1）后，"多余奖励无处领取搁浅"的顾虑**已解除**——
> 奖励不再依赖停靠。停靠点现在只管**进化 + 回血**，下述"结算机会有限"仅对进化/回血成立。

- **结算机会变有限**：全局 3 机场 + 2 航母 = **5 次**结算机会。若一局攻克 > 5 个战区，
  多余次数只影响**进化 + 回血**能否兑现（奖励已即领，不受影响）。
- **后期无陆上停靠点**：3 机场用尽后，玩家只能靠航母（南半图、限 2 次）回血/进化。
- **当前未加兜底**（遵循"playtest 证明必要再补"）：若上述后果体感为负，候选补法——
  ①机场用尽后 game_time 到点前自动结算积压奖励 ②保留 1 处常驻机场 ③攻克战区数 > 停靠点
  数时给提示。**均未预置**，等 playtest 定夺。
- **不受影响项**：机场 ALLY 防空驻军（garrison）原地保留；友军航母机制不变。
