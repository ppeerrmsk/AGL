# 4 级金色技能递增概率 —— 三轴卡片隐性保底

> 普通三轴卡片连续没有出现 4 级金色技能时，下一次选卡会提高金色技能候选的抽取权重；
> 任一普通卡位刷出金色技能后立即清空累计进度，使 10 分钟战区阶段大约提供两次见金机会。

## 1. 设计意图（Why）

- **体验目标**：把完全独立的低概率抽取改成带记忆的随机——玩家仍不知道下一张是什么、仍可能提前走运，
  但不会频繁整局看不到一次高品质构筑拐点。
- **节奏目标**：现行 XP 曲线下，10 分钟战区平均收在 LV18～22，即自然触发 6～7 次三轴选卡；
  目标是在这 6～7 次事件里平均刷出约 2 次 4 级金色技能。
- **Litmus 自检**：只调局内构筑随机性，不增加永久数值膨胀；金卡出现时已有金框、徽章与入场闪光，
  玩家能感知结果，但累计进度本身不占 HUD，不制造第二条显式资源条。
- **反模式规避**：不直接塞固定金卡、不改变三轴各一张结构、不让 5 级红色次世代技能回流普通池，
  也不让独立的机型专属第四槽消耗普通三卡的累计进度。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 目标稀有度与作用域

| 项 | 值 | 说明 |
|---|---:|---|
| 目标稀有度 | `CLASSIFIED` | 五档中的第 4 档；颜色为金色。本文“传说/金卡”均指这一档 |
| 基础候选权重 | `0.08` | 沿用现行稀有度基础权重，不改全局基线 |
| 每次未出增量 | `2.0` | 每空一次，下一轮金卡候选增加 2 倍基础权重 |
| 初始未出次数 | `0` | 每局新建生存模式时清零，不跨局持久化 |
| 上限 | 无 | 10 分钟局内事件数有限；连续未出时概率持续上升，但不改成硬保底 |

只作用于**自然等级升级触发的普通三轴三张卡**（L3/6/9/…）。以下来源不参与累计、也不触发清零：

- 机型专属的独立第四槽；即使它本身是 `CLASSIFIED`，也不算普通三卡见金。
- “黑匣子回收”等额外奖励升级，因为它不是玩家升级事件。
- 战区奖励、debug 直接授予、进化结算以及 5 级红色 `NEXT_GEN` 技能。

### 2.2 累计状态

运行态只保存一个整数 `classified_pity_misses`：已经连续多少次自然三轴选卡没有刷出金卡。
它属于本局玩家升级流程，不写存档、不挂在飞机上、不随换机/换帅变化。

## 3. 行为与公式（How）

### 3.1 抽卡权重

一次自然三轴选卡开始时，三张卡共享同一个累计值 `m = classified_pity_misses`。
每个候选技能仍先经过机型、硬件、学说、前置、互斥、层数与普通池资格过滤；保底不能绕过可用性门。

金卡候选的最终权重：

```text
classified_multiplier(m) = 1 + 2.0 × m
classified_weight = 0.08 × classified_multiplier(m) × keyword_steering_multiplier
```

非金卡候选保持现行公式：

```text
weight = rarity_base_weight × keyword_steering_multiplier
```

因此金卡有效基础权重序列为：

| 连续未出 `m` | 本轮倍率 | 金卡有效基础权重 |
|---:|---:|---:|
| 0 | ×1 | 0.08 |
| 1 | ×3 | 0.24 |
| 2 | ×5 | 0.40 |
| 3 | ×7 | 0.56 |
| 4 | ×9 | 0.72 |

倍率逐**候选技能**生效，三轴仍各自在自己的家系池内抽一张，不跨轴替换卡位。

### 3.2 累计与清零

三张普通卡全部生成后再统一结算：

```text
if 普通三张卡中至少一张 rarity == CLASSIFIED:
    classified_pity_misses = 0
else:
    classified_pity_misses += 1
```

- 判定依据是**刷出**而非**选中**：玩家看到金卡但没选，累计仍清零。
- 同一轮刷出两张或三张金卡也只清零一次，不产生负进度或下轮奖励。
- 某轮没有任何合格金卡候选时仍算一次未出；以后候选重新变得可用时继承已累计倍率。
- 生成普通三卡后才追加机型专属第四槽，所以第四槽在结构上不能影响上述结算。

### 3.3 10 分钟标定

以当前普通、非专属初始技能池为样本，不计学说门控、硬件差异、已拿满移除与流派引导时：

| 连续未出 `m` | 本轮三卡至少一张金卡的估算概率 |
|---:|---:|
| 0 | 16.7% |
| 1 | 40.1% |
| 2 | 55.3% |
| 3 | 65.6% |
| 4 | 72.9% |

在同一静态池近似下：

| 自然选卡次数 | 对应等级 | 期望见金次数 | 至少见金 2 次的概率 |
|---:|---:|---:|---:|
| 6 | LV18 | 2.05 | 76.9% |
| 7 | LV21 | 2.43 | 89.2% |

实际局会因机型硬件、学说购买、前置技能、技能拿满和流派引导上下浮动；本表用于标定量级，
不承诺每局硬性出现两次。

## 4. 结构与组成（Structure）

- 稀有度基础权重仍由技能静态数据层统一持有；新增常量只描述 `CLASSIFIED` 每次未出的权重增量。
- 三轴单卡抽取函数接收本轮金卡倍率，三轴三次调用共用同一值。
- 自然升级入口负责在普通三卡生成后更新本局累计；奖励升级继续走基础倍率且不改累计。
- 累计值保留在生存模式本局状态中，沿用现有 EventLogger 导出调试，不增加玩家可见 UI 或 i18n 文本。

## 5. 验收标准（Acceptance / Litmus）

- [x] 新局累计为 0；第一轮金卡权重与改动前完全一致。
- [x] 连续 1/2/3 次未出后，下一轮金卡倍率严格为 ×3/×5/×7；其它稀有度权重不变。
- [x] 普通三卡任一位置刷出金卡后立即归零，即使玩家最终选择了非金卡。
- [x] 普通三卡无金卡时累计 +1；机型专属第四槽刷出金卡不会清零。
- [x] 奖励升级、战区奖励、debug 授予和 `NEXT_GEN` 均不读写该累计。
- [x] 固定种子统计回归：静态初始池抽 6 轮的平均见金次数落在 1.90～2.20，抽 7 轮落在 2.25～2.60。
- [x] 三轴结构不变：每轮仍最多各出一张斗士、骑士、策士普通卡；可用性过滤无绕过。
- [x] 性能：只在低频升级时点做三个池的加权抽取，无新增 `_process`、`_draw` 或实体级节点；
  `stress_40` 10 秒样本 146 FPS。
- [x] 已知 seam：机型专属第四槽在普通三卡结算之后追加；顺序有自动断言守门。
