# 圈外切入（CIRCLE_CUT —— 第三方支援射击几何）

> 队友被咬进转弯圈时，你的僚机不再挤进去凑成车轮战 ——
> 它绕到圈外的横切位，等敌机沿圆弧扫进火控窗，一梭横穿射击终结缠斗。

## 1. 设计意图（Why）

### 1.1 解决的现象

敌机 T 咬住友机 A 后，两机进入稳定转弯圈。第三方僚机 C 锁定 T 时走 LEAD_PURSUIT，
而机炮前置解**没有转弯率项**（只沿目标当前 heading 切线外推）——
对圈内目标，切线前置点永远落在圆外侧切向，C 追着它飞的结果就是**汇入同一个圆**：
三机车轮战，谁也打不着谁（用户 playtest 观察：友机"并在一起和被咬的飞机一起绕圈"）。

### 1.2 设计答案

真实空战教科书规则：**双机缠斗时，第三方永远不进圈**。圈内目标的轨迹是全场唯一
**完全可预测**的轨迹（稳定圆弧），因此圈外横切位是全场命中率最高的射击机会。

C 应该：解出 T 的转弯圆 → 站到圆外领先相位的横切位 → 在 T 沿弧线扫过机头时打提前量
落在**弧上**（而非切线上）的横穿射击。

### 1.3 敌我同享

本机制是**单机级 BFM 几何**，接在共享战术层，敌我自动同享：

- **友军**：僚机从"陪绕圈的观众"变成"处决者"——玩家被咬时，锁定咬人者的队友自动占外线。
- **敌军**：Wraith 的 PRESS 阶段免费获得执行层（KNIGHT 拖玩家进圈，另一架从圈外收网，
  见 [bosses/wraith-squadron](../bosses/wraith-squadron.md) §3）。普通敌机中队同理。

### 1.4 Litmus 自检

- **单杠杆**：只有一个触发条件（我的目标正在和我的队友缠斗）+ 一套几何。不做多档位。
- **效果即反馈**：僚机划出的外线弧线和横穿炮口焰本身就是反馈，不加任何 HUD 中介。
- **零回归**：触发条件不满足时行为与现状**完全一致**——这是一个只在特定态势出现的新分支，
  不修改任何既有 intent 的行为。
- **玩家命令铁律**：本机制只改**几何**，不碰目标选择。`commanded_target` 照常持有。

### 1.5 反模式规避

- ❌ 不做"多机环形站位编排"（那是队级编排层的事，本 spec 是单机几何）。
- ❌ 不做非物理强扭：站位靠真实 bank/盘旋飞到，禁止挪坐标（见编队物理优雅约定）。

## 2. 数据定义（What）

### 2.1 触发条件（全部满足才进入）

| 条件 | 值 | 说明 |
|---|---|---|
| 目标正在打我的队友 | `T.combat_target == 某队友 A`，且 `A ≠ 我` | T 的目标是我 → 我是防御方，走正常 BFM |
| 目标在稳定转弯 | `|T.bank| > 40°` 持续 ≥ **1.5 s** | 直飞/机动切换中的目标不适用本几何 |
| 距离相关 | 我与 T 距离 < **4000 m** | 太远轮不到谈切入几何 |
| 我不在被咬状态 | 没有敌机咬我六点 | 自卫优先 |

### 2.2 几何数值

| 参数 | 值 | 说明 |
|---|---|---|
| 转弯圆半径 | `R = V² / (g·tan|φ|)`（V=T 速度，φ=T bank） | 复用 lag_pursuit 已有公式 |
| 圆心 | `T.pos + perp(T.heading, 转弯方向) × R` | |
| 站位距离 | 距圆心 **1.8 R**（夹取 [1.5R, 2.2R]） | <1.5R 会被卷进圈；>2.2R 出机炮射程 |
| 站位相位 | 领先 T 当前相位 **+105°**（沿 T 转弯方向） | T 转 ~1/3 圈后正对我机头 |
| 站位速度 | `max(角点速度, T 速度 × 1.1)` | 保住机动性，不追极速 |
| R 有效范围 | 150 ~ 3000 m | 超界视为"不是稳定圈"，不触发 |

### 2.3 弧上前置解（横穿射击）

普通前置解假设目标直飞；本几何下目标在**已知圆**上做匀速圆周运动，前置点直接解在弧上：

```
ω = V_T / R                        # 目标角速度（rad/s）
t = dist(我, T) / 弹速             # 子弹飞行时间（一次迭代足够，圆弧曲率下二次迭代收益可忽略）
预测点 = 圆心 + rotate(T.pos - 圆心, ω · t · 转弯方向)
```

开火门：预测点进入机炮火控锥（沿用现有 5° 半角）且距离在射程内。
**本解仅在 CIRCLE_CUT 激活期间取代切线前置解** —— 这是对"前置解无转弯率项"缺陷的
局部修复，只修轨迹可预测的场合，不动通用路径。

### 2.4 滞回与退出

| 事件 | 行为 |
|---|---|
| `|T.bank| < 25°` 持续 ≥ **1.0 s** | 退出（目标已放平，圆不存在了），回普通 BFM |
| T 的目标切换为**我** | 立即退出（我成了防御方） |
| 队友 A 阵亡或脱离 | 退出 |
| 退出后再入冷却 | **2.0 s**（防 bank 抖动导致进出横跳） |

进入判定（bank>40° 计 1.5s）与退出判定（bank<25° 计 1.0s）之间的 15° 死区就是滞回带。

### 2.5 多机情形（v1 刻意从简）

多个僚机同时满足触发条件时，**各自独立解几何**，相位分配不协调
（碰撞概率低：站位半径 1.5~2.2R 有天然散布）。协调站位是二阶机制，
按设计哲学默认不做，playtest 证明拥挤再补。

## 3. 行为与公式（How）

### 3.1 状态流

```
普通 BFM（LEAD_PURSUIT 等）
      │  触发条件 §2.1 全满足（bank>40° 已持续 1.5s）
      ↓
  CIRCLE_CUT
      ├─ 阶段 a 占位：飞向圆外站位点（1.8R / 领先 105°），站位点随 T 每帧重解
      ├─ 阶段 b 待击：位置在 [1.5R, 2.2R] 环带内 → 机头转向弧上预测点
      └─ 阶段 c 开火：预测点入火控锥 → 横穿射击（弧上前置解 §2.3）
      │  任一退出条件 §2.4
      ↓
普通 BFM（2s 内不重入）
```

阶段 a/b/c 不是子状态机，只是同一几何下的自然连续行为（距离决定在做什么），
无需额外状态字段。

### 3.2 与现有系统的边界

| 系统 | 关系 |
|---|---|
| 武器竞选（weapon-employment-doctrine） | CIRCLE_CUT 是机炮几何；导弹在此态势下沿用既有 crank，不受影响 |
| 集火包围轴 ≥45°（command-wheel FOCUS） | 那是**进入前**的轴分配；CIRCLE_CUT 是**缠斗成形后**的持续几何。互补不冲突 |
| 超杀让路（fire discipline） | 照常生效：队友导弹在飞 → 我不压入，正好在外线等 |
| 速度治理（EngagementSpeedGovernor） | 王牌中队照常受治理；站位速度本来就在治理上限内 |
| 玩家命令铁律 | 不改 `commanded_target`；玩家点名目标的僚机在满足触发条件时同样用本几何去打**那个目标** |

## 4. 结构与组成（Structure）

- **独立模块**承载全部几何与触发判定（转弯圆解算 / 站位点 / 弧上前置 / 滞回计时），
  遵循模块化拆分约定：战术层只留一行竞选接线 + 一行几何调用。
- 作为一个新 intent 参与既有 intent 竞选；激活期间提供 `pursuit_pos`（站位点）与
  开火许可（弧上前置门）。
- 触发检测所需的"谁在打谁"读现有反向索引（engaging_me / combat_target），不新建索引。

## 5. 验收标准（Acceptance / Litmus）

- [ ] **三机 sim（核心）**：脚本化 T 咬 A 绕稳定圈，C 从 3000 m 外进入 ——
      C 稳态距圆心保持在 [1.4R, 2.3R]（**不汇入圆**，对照组无本机制时距圆心 ≈ R）。
- [ ] **横穿命中**：同 sim 中 C 的机炮命中数 > 0，且命中率 ≥ 无本机制对照组的 2 倍。
- [ ] **不误触发**：T 直飞（bank < 25°）或 T 的目标是我时，C 全程不进入 CIRCLE_CUT。
- [ ] **滞回有效**：T bank 在 35°~45° 抖动时，C 的进出切换 ≤ 1 次/10 s。
- [ ] **玩家可感**：生存模式中玩家被咬时，锁定咬人者的僚机可见地拉到外线并横穿开火。
- [ ] **敌方同享**：Wraith KNIGHT 咬住玩家时，另一架的切入走同一几何（日志可验证）。
- [ ] 性能：几何解算为纯代数（无扫描/无子节点），AI 分频内零可测开销；跑 Sentinel + Lv5+ 压测 FPS 掉幅 < 15
- [ ] 已知 seam 未触碰（见 architecture/known-seams.md）
- [ ] i18n：本机制无玩家可见文本（intent 名为内部词汇，不进 UI）——不适用
