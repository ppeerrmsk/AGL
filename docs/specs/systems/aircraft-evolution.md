> 玩家视角：打完一个战区，按 **Tab** 原地进入结算菜单——回血、查看你这架飞机的**进化科技树**（像宝可梦：到 4 级能进化成某型号、6 级能再进化成另一型号），并在「拿武器 / 拿红色顶级技能 / 进化」三者里**选一个**作为额外奖励。武器和装备是插在**飞机槽位**上的，换机型、换飞机都跟着你走，永不丢失。某些战区还会额外开来一艘**友军航母**当外援——你可以飞上甲板（右键减速降落）回血和进化，不耗时间、不用飞出地图。

> ⚠ 本 spec 为**高层骨架**（用户决策：先定骨架）。进化科技树的**具体型号/分支/各机型档案数值**另起子 spec（每个进化终点走 [playable-aircraft-workflow]）。本 spec 锁定：结算触发、奖励三选一、宝可梦式进化轴、槽位装备继承、航母外援变体这五块骨架。

## 1. 设计意图（Why）

生存模式废除了"经验满→三选一升级"roguelike 机制（见 [squad-upgrade-ownership §0]）。**等级不再直接加属性**——它只是进化的门槛。build 多样性的新来源是三块协同：**进化（换机型）+ 槽位武器/装备 + 红色顶级技能**。

核心转变：从"被动 roll 数值 build"→"打完战区主动在结算菜单做一次有分量的选择"。决策更少更重，贴 RTS 的"指挥+养成"基调。

**体验目标**：
- 打完战区 = 有仪式感的结算节点（Tab 原地、画面提示"已攻克本战区"），不打断飞行节奏、不强迫飞去某处。
- **进化 = 可感知的整机蜕变**（机型/属性/武器手感整套换，宝可梦式，原则 3 信息察觉拉满）。
- **装备永久跟随玩家**（槽位绑定）——好不容易拿到的电磁炮不会因换机消失，鼓励大胆进化/换机。
- 每局因"进化走哪条路线 + 拿了哪些槽位武器 + 哪些红技能"而不同 → 接续 build-focused 的局内故事性（原则 9）。

**Litmus 自检**（DESIGN_PHILOSOPHY）：
- **原则 3（信息察觉优先）**：✅ 换机型 + 装新武器是最强可感知变化。
- **原则 6（机型=现实×平衡中间值）**：✅ 进化终点机型按现实参考取中间值，不照抄不破区间。
- **原则 7（战场热闹）**：✅ 航母外援进场 = 视听密度事件 + 保护航母的战场张力。
- **原则 9（局内成长爽点）**：✅ 进化/装备是局内主轴，局外仍只解锁起手机型。
- **原则 10/11**：结算/进化是事件级交互；不碰每帧、不引入手动扳机。
- **⚠ 与 "build-focused roguelike" 定调的关系**：本系统**替换** "三选一 roll build" 为 "结算菜单三选一 + 宝可梦进化"。DESIGN_PHILOSOPHY 模式哲学段 + survivor-skills 整份图鉴需在进化树定稿后统一重写（用户决策：先保留哲学文档不动）。

**反模式规避**：
- ❌ 不让纯等级直接加属性（用户决策：升级无属性加成，只做进化门槛）。
- ❌ 不做"进化只是数值+X"的无感升级（原则 3）——必须整机蜕变可见。
- ❌ 不让装备因换机丢失（破坏养成投入感）——槽位绑定继承。
- ❌ 不照抄现实机型数据破坏 600–2200 区间（原则 6）。

## 2. 数据定义（What —— 骨架层）

### 2.1 结算触发（默认入口：Tab 原地结算）

| 项 | 规则 |
|---|---|

| 菜单组成 | ① 自动回血（§2.2）② 进化科技树（§2.3，可选）③ 额外奖励三选一（§2.4） |

### 2.2 自动回血

| 项 | 值 |
|---|---|
| 回血量 | 结算时给一定程度回血（具体量待调参，"一定程度"非满血） |
| 作用对象 | 默认全队（与进化"默认全队"一致；细节待定） |

### 2.3 宝可梦式进化轴（核心，具体树另起子 spec）

| 概念 | 定义 |
|---|---|
| **基底机型** | **F-15**（新建，取代 F-16 成为初始起手机）。详见 §2.6 |
| **等级 = 进化门槛**（不加属性） | 等级本身**不改任何属性**；它解锁进化档位。例：到 **4 级**可进化成型号 A；到 **6 级**可进化成型号 B（具体档位/型号 = 子 spec） |
| **进化 = 换机型** | 选定 → 该飞机**整机替换**为目标机型档案（属性/武器挂载点/手感/图标整套换），像宝可梦进化。不是叠 buff |
| **可延迟进化** | 玩家可**放弃本次进化机会**，保持当前形态，等级更高后再在结算菜单进化（科技树常驻可达） |
| **科技树展示** | 结算菜单里以科技树形式展示：当前形态 → 各等级可达的进化分支（已达级可选 / 未达级灰显门槛） |
| **F-16 的新定位** | F-16 从"初始主角"降格为 F-15 科技树上的一条进化分支 |
| 分支多样性 | 不同路线 = 不同机型性格（制空/截击/对地/多用途…），呼应"切换体验不同机" |

### 2.4 结算 = 升级 + 进化（✅ 用户定 2026-06-28，取代旧"三选一"）

**每打完一个战区给一次"升级 + 进化"机会**（非互斥三选一）；**航母**（§2.7）是第二个结算/进化点。进化的**触发与对象规则全归 [ace-system](ace-system.md)**：

| 项 | 规则 |
|---|---|
| **进化** | **ACE 强制手动**选路线 / **僚机默认自动跟随王牌**（详见 ace-system §2.3）。**结算点触发，战斗中不触发**（§2.4 ace-system）；等级只门控档位 |
| **升级（局内深度）** | 局内"提升玩法深度"的内容（仍 TBD，见 meta-progression §5）；红色顶级技能可作为其中一档 |
| ~~武器/装备~~ | ⚠ **已废**：武器=机型自带（局外 meta 解锁），不在局内结算发（§2.5 + meta-progression） |

> 旧"三选一（武器/红技能/进化）"作废：武器归局外 meta；进化与升级现在是结算时**都给**（不再互斥）。

### 2.5 武器绑机型、不继承（✅ 用户定 2026-06-28，取代旧"槽位继承"）

| 规则 | 说明 |
|---|---|
| 武器是**机型固有属性** | 每个机型自带它那套武器档案（A-10=机炮+火箭弹；F-14=远程导弹；X-02=电磁炮…），由机型 params 定义 |
| 换机型/进化时 | 直接用**新机型**的武器；旧机型武器（含电磁炮/激光）**消失**，不带走 |
| 用户原话 | "进化到 A-10 就配火箭弹；换到别的飞机之前的武器就没了，只能用新飞机的武器" |
| 与 squad-upgrade-ownership 的关系 | 同步：该 spec §2.6 取消 `inheritable`、HARDWARE 改为"机型自带特色武器"。**本条取代**旧的"装备绑槽位跟玩家继承" |

### 2.6 F-15 基底改制（连带改动，骨架确认）

| 事项 | 现状 | 改为 |
|---|---|---|
| 初始主角 | F-16（playable_f16.tres） | **F-15**（新建 playable_f15.tres + 档案）作为生存模式默认起手机 |
| F-16 | 独立主角档案 | 保留，改挂为 F-15 科技树的进化分支之一 |
| F-15 数值 | 不存在 | 按现实 F-15 取中间值（重型双发制空），走 [playable-aircraft-workflow]，子 spec 定数值 |

### 2.7 航母外援变体（特定战区奖励，非主入口）

某些战区额外给"一艘友军航母"作外援。与默认 Tab 结算**并存**（航母是锦上添花的第二处回血/进化入口，且在战区进行中即可用）。

| 项 | 规则 |
|---|---|
| 入场 | 航母从地图**南边**驶入，缓慢**向北**移动一段后停住 |
| 编成 | **独立友军单位，无护卫舰伴随**（team 0） |
| 防御 | 配 **CIWS** 拦截附近导弹 |
| 可被击毁 | 是。战场过乱时敌方 AI 会把它当目标尝试击沉 |
| 登舰 | 玩家飞到航母、在甲板上**降落**：用**右键减速**，速度慢到阈值才判定"停在甲板上"并开菜单 |
| UI 引导 | 甲板上方显示提示，要求玩家减速以完成登舰 |
| 功能 | 登舰后可**回血 + 进化**（同结算菜单的回血/进化部分） |
| 补给限次 | 航母补给**有使用次数上限**（用完不再提供） |
| 优势 | **不消耗游戏时间、不需要飞出地图**即可回血/进化 |

## 3. 行为与公式（How —— 骨架）

### 3.1 进化执行（整机替换；武器随机型换、不继承 §2.5）

```
on 玩家选定 route R（目标机型 M）+ 参与集合 S（默认全队，逐架可 opt-out）:
  for cur in S:
    切换 cur 的 PlayableAircraft 档案 / params → M 的档案（深拷贝，参照 survivor_playable_setup）
    武器 = M 自带的武器档案（旧机型武器含电磁炮/激光一律丢弃，§2.5）  # 不保存、不重插
    继承（不因换机丢失）：
      - 位置 / heading / 速度 / 高度（原地变身，不传送）
      - 当前 HP 比例（按新机 max_hp 折算，避免突变）
      - PER_TYPE 技能：用 M 的 TypeBuild（该局在 M 上养过则恢复，否则空；squad-upgrade-ownership §3.3）
    重置：
      - 武器/equipment 运行时状态（充能/CD 清零，换机重新起算）
    视觉：整机图标/线框换成 M；播放进化表现（待定）
```

### 3.2 等级门槛与延迟（宝可梦式）

```
科技树节点 = { 目标机型, 门槛等级 }
结算/航母菜单展示时：
  for 节点 in 当前形态的可达分支:
    if 玩家等级 >= 节点.门槛等级: 该分支可选
    else: 灰显 + 标注门槛等级
玩家可选"暂不进化" → 保持当前形态，下次结算/登舰再来（科技树常驻）
```
等级**只**用于门控进化，不参与任何属性计算。

### 3.3 与操控切换的衔接

- 进化动的是参与集合 S 里的每架实例；各机 squad_slot（号机号）不变，leader 角色不变。
- 不同架可进化成不同机型（分化小队角色）→ 喂"切换体验不同机"（squad-control-switching）：切到不同号机 = 不同机型手感 + 不同槽位武器。
- 进化/换机后槽位装备继承 → 玩家切到任意一架，它身上的武器是"这架自己槽位里的"，符合直觉。
- 护卫 AI（squad-ai-escort）读 effective_*() / combat_target，不关心机型，进化后照常工作。

### 3.4 航母外援生命周期

```
特定战区奖励触发 → 航母从南侧驶入 → 北上一段 → 停泊（team 0 友军）
存在期：CIWS 自动拦截来袭导弹；可被敌方击沉（被击沉则外援提前结束）
玩家登舰：飞近甲板 → 右键减速 → speed < 着舰阈值 → 判定停在甲板 → 开菜单（回血/进化）
补给次数用尽 或 航母被击沉 或 玩家选择离开 → 航母功能结束/驶离
```

## 5. 验收标准（Acceptance / Litmus —— 骨架级）

- [ ] **Tab 结算**：战区完成按 Tab → 提示"已攻克" → 菜单含回血 + 科技树 + 三选一；原地不耗时间、不飞出图。
- [ ] **宝可梦进化**：到达门槛等级（如 4/6 级）→ 科技树对应分支可选；选则整机换型；未达级灰显门槛。
- [ ] **可延迟**：选"暂不进化"→ 保持当前形态；更高级后再次结算/登舰仍可进化。
- [ ] **等级不加属性**：升级本身不改任何飞行/武器属性（验证升级前后 params 一致，只解锁进化档）。
- [ ] **三选一互斥**：每次结算只能拿 武器/红技能/进化 之一。
- [ ] **槽位继承**：在 A 机拿到电磁炮 → 进化/换成 B 机 → 电磁炮仍在 B 机槽位、可用（换机不丢）。
- [ ] **F-15 基底**：默认起手机为 F-15；F-16 经科技树达成。
- [ ] **默认全队 + 逐架开关**：默认全队进化同一路线；可勾掉某几架使其保持原形态（可分化不同号机为不同机型）。
- [ ] **航母外援**：特定战区航母从南入场北上停泊；CIWS 拦导弹；可被击沉；右键减速到阈值登舰开菜单；甲板 UI 提示减速；补给限次；不耗时间不飞出图。
- [ ] 性能：结算/进化/登舰均事件级；航母复用现有舰体渲染；Sentinel + Lv5+ FPS 掉幅 < 15。
- [ ] 已知 seam：换档案不破坏 player_ref / squad / AIController 引用（实例不销毁，只换 params/视觉/槽位）；登记 known-seams。
- [ ] i18n：结算菜单/科技树/机型名/航母提示走 tr() 三语。
