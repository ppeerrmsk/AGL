# 单机熟练度、科技树迷雾与机体研发许可

> 每一架常用飞机都能留下独立战绩，并以五段克制的微调成长到约 **+15% 战斗效能**；
> 科技树按实际探索逐层揭示，功勋只购买特殊变体的“研发资格”，不直接卖纵向战力。

## 0. 本轮设计裁决

| 议题 | 裁决 |
|---|---|
| 小队击杀归属 | 直属小队成员击杀，计入**击杀发生时玩家当前操控机型**；现有同型编队下等价于全队共同练这架机 |
| 分机经验 | 每个 `node_id` 单独记录击杀、熟练经验与 M0～M5 等级；进化后只启用新机型自己的熟练加成，旧机加成不继承、不叠路线 |
| 功勋存档 | 同时保存可花余额与“生涯累计获得”；消费只减余额，不倒扣生涯资历 |
| 全局评价轴 | **累计功勋**决定无战力的生涯军衔与高级研发项目上架；分机经验只练对应机体。两者不相加，避免同一局 XP 被重复计算 |
| 战力上限 | M1～M5 每级 3 点效能预算，满级目标为同机 M0 的 **12%～16%**，名义中心值 15%；单项属性累计不超过 6% |
| 功勋墙 | 只锁横向变体、试验机和秘密终端，不锁某一角色进入下一档的唯一通路；购买后满足局内路线条件时**必定可选**，不再掷概率 |
| 树的可见性 | 首次只看当前机、已经驾驶过的节点与当前机直接出口；更远档位折叠为未知路线，不在开局展示 43 架全表 |
| 既有起手机 | F-15 恒解锁；A-6E 保持 30 地面击杀；幻影 III 保持 2000 功勋采购；F-14 需要首次击败 Ladon 战斗群且 A-6E/幻影 III 均已解锁，从规则上保证它是最后获得的起手线 |

## 1. 设计意图（Why）

- **常用有回响**：玩家重复使用一架飞机时，战绩、熟练等级和少量属性都会留下，换路线则开始练另一套，不存在“全账号一加、所有飞机一起膨胀”。
- **强化克制但可读**：不做每级 `+0.3%` 的无感成长；每级只动一个能在详情卡上明确比较的字段，并在结算时直接报出旧值与新值。
- **定位不被抹平**：斗士优先 G、滚转、加速与机炮；骑士优先雷达、速度、锁定与导弹节奏；策士优先锥角、锁定、热诱弹与隐身。攻击机、舰载机和原创机再按机体形象修正。
- **延长寿命不延长痛苦**：一架常用机的前 9 点效能预算在 M3 前取得，后两级只承担最后 6 点；玩家很快感到“这架练过”，全 M5 留给自愿收集者。
- **科技树保留惊喜**：玩家只能规划眼前一层；亲自驾驶一架机后，它的出口才永久加入图鉴。未知不是纯黑箱——一旦项目上架，就明确展示价格、前置和可通往的角色。
- **Litmus 自检**：符合设计哲学的局外成长节制、信息可察觉与构筑选择；不卖导弹数量、锁定目标数、复活次数或签名机制等离散大杠杆。
- **反模式规避**：无每日任务、连续登录、经验衰减、随机蓝图碎片、重复购买、失败掉经验或付费后再抽一次的二次随机。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 三套互不混算的持久量

| 量 | 粒度 | 用途 | 是否消费 |
|---|---|---|---|
| 可用功勋 `merit.balance` | 全局 | 商店购买 | 是 |
| 累计功勋 `merit.lifetime_earned` | 全局 | 生涯军衔、上架门槛、档案评价 | 否，只增不减 |
| 熟练经验 `mastery_xp[node_id]` | 每机型 | M0～M5 属性成长 | 否，只增不减 |
| 指挥击杀 `command_kills[node_id]` | 每机型 | 机体战绩展示，不直接作为等级真源 | 否，只增不减 |

**不采用** `累计功勋 + 熟练经验 = 一个总等级`。当前功勋本来就由局内 XP 结算而来，直接相加会把同一场战斗重复计价。全局档案并列显示“生涯资历”和“机队熟练度”，但只有累计功勋决定军衔。

### 2.2 熟练经验来源

熟练经验使用敌人的**基础威胁值**，不含 `+ 当前等级 × 8`、局内 XP 技能、机体 XP 特性、策士里程碑和编队 XP 稀释。因此玩家可以用自己喜欢的编队练机，但不能用 XP build 把局外成长成倍放大。

| 来源 | 熟练经验 | 是否增加指挥击杀 |
|---|---:|---:|
| MQ-109 / MQ-110 | 25 | +1 |
| F-4E | 32 | +1 |
| 普通常规空中单位 | 40 | +1 |
| Sentinel / AH-64 | 50 | +1 |
| CH-47 | 40 | +1 |
| Tu-160 | 80 | +1 |
| F-47 / 普通王牌档单位 | 100 | +1 |
| 地面单位 | 25 | +1 |
| 正式局胜利结算 | 200（等价 5 个标准击杀） | +0 |
| 战区任务直接 XP、BOSS 演员、BOSS 阶段残敌、ALLY 击杀、自然坠毁、Debug/bench | 0 | +0 |

熟练经验只在正式局写入。BOSS 阶段继续维持“击杀不产 XP”的既有契约；只在最终胜利时给当前机一次 200 熟练经验，避免 T4/T5 因登场太晚完全练不动。

### 2.3 五档阈值

下表为**累计值**。`1 标准击杀等价 = 40 熟练经验`；不同 Tier 用不同阈值补偿单局可驾驶时间差。

| Tier | M1 | M2 | M3 | M4 | M5 | 标准击杀等价 |
|---|---:|---:|---:|---:|---:|---|
| T1 | 600 | 1600 | 3200 | 5600 | 8800 | 15 / 40 / 80 / 140 / 220 |
| T2 | 480 | 1280 | 2560 | 4480 | 7200 | 12 / 32 / 64 / 112 / 180 |
| T3 | 360 | 960 | 1920 | 3360 | 5400 | 9 / 24 / 48 / 84 / 135 |
| T4 | 240 | 640 | 1280 | 2240 | 3600 | 6 / 16 / 32 / 56 / 90 |
| T5 | 160 | 400 | 800 | 1400 | 2240 | 4 / 10 / 20 / 35 / 56 |

设计节奏：M1 通常在第一次或第二次有效驾驶中出现；M3 约 2～5 次有效驾驶；M5 约 6～12 次。M3 已拿到 9/15 的效能预算，最后两级是长期偏爱证明，不是通关门槛。

### 2.11 功勋墙研发项目

功勋墙覆盖 9/43 架机体（约 21%），全部为旁支或秘密汇聚点；其余 34 架不需要机体许可。支付的是**永久研发许可**：之后任何正式局只要到达父节点并满足 LV/三轴门槛，该机就确定显示为可选，不再加额外随机率。

| 项目 id | 解锁机体 | 价格 | 上架条件 | 为什么适合放在墙后 |
|---|---|---:|---|---|
| `airframe_eagle_modernization` | F-15C + F-15E | 3,500 | 正式驾驶 F-15 完成 1 局 | 两种同族横向变体打包，避免向新玩家同时索两次钱 |
| `airframe_growler_conversion` | EA-18G | 3,000 | R1；已正式驾驶 F-14 | 舰载电子战特殊改型；F-14 仍有 4 条免费出口 |
| `airframe_s_mtd_trials` | F-15 S/MTD | 5,000 | R1；已驾驶 F-15C 或 F-15E | 变体之上的试验变体；T3 制空仍有 Su-35/F-22/Su-57 免费选择 |
| `airframe_black_widow_trials` | YF-23 | 7,000 | R2；已驾驶 F-22 或 F-15 S/MTD | 原型试飞项目；F-47 保持免费 T4 制空通路 |
| `airframe_gcap_joint_program` | GCAP | 7,500 | R2；已驾驶 Su-57 或 J-20 | 联合远程方案；MiG-41/J-36 保持免费远程通路 |
| `airframe_x02_classified` | X-02 | 10,000 | R3；已驾驶 Su-57、J-20、A-12 中任一 | 稀有 T3→T5 跨档入口，许可表达“拿到绝密项目资格” |
| `airframe_x90_carrier_swarm` | X-90 | 12,000 | R4；已驾驶 F-47、GCAP、X-44 中任一 | 空中母舰是特殊玩法终端，不承担唯一纵向路线 |
| `airframe_ax00_starweaver` | AX-00 | 16,000 | R5；已驾驶任一 T5 且已驾驶 3 架不同 T4 | 多路线汇聚的收藏压轴，不应只靠攒钱第一时间直购 |

全部项目合计 **64,000 功勋**。F-15C/F-15E 是一个项目两架许可，因此商品数 8、机体数 9。

现有经济还有约 **59,000 功勋**的其它长期消费（约 22,500 的后勤/支援、6,500 的学说、30,000 的 43 机专属许可）；加入本表后，全长期商店约 **123,000 功勋**。所以不应再同时添加可叠加数值零件或高价刷新税，否则中位玩家会从“持续有目标”跨成“永远还不起”。

**明确不进功勋墙**：FCAS（T4 唯一电战）、F/A-XX（T4 唯一攻击）、MiG-41/J-36（免费远程骨架）、F-47（免费制空骨架）、各线第一个 T3。任何一次改表后都必须重新审计“每个主要角色在每个 Tier 至少一条免费通路”。

### 2.12 科技树迷雾状态

| 状态 | 玩家看到什么 | 如何进入下一态 |
|---|---|---|
| `UNKNOWN` 未知 | 不画具体节点；在已知边界显示“未知路线 ×N” | 驾驶其任一父节点 |
| `REVEALED` 已揭示 | 名称、角色、Tier、基础参数、全部 LV/三轴要求 | 父节点已正式驾驶；免费机到此即具备局内资格 |
| `PROGRAM_LOCKED` 项目锁定 | 与已揭示相同，另显示项目名、价格、军衔/前置进度 | 项目上架且购买 |
| `LICENSED` 已许可 | 显示许可徽章；达到局内门槛时必定可选 | 在正式局进化成功 |
| `FLOWN` 已驾驶 | 永久显示完整节点、专属技能发现态、击杀与 M0～M5 | 终态，可继续练熟练度 |

渲染规则：开局只铺“当前节点 + 已驾驶节点 + 当前节点直接出口”；更远未知节点不占横向树宽，折叠成边界胶囊。进入新机后才展开下一层并缓存布局，避免一开始既泄露 43 机，又让 T2 的超宽树挤坏界面。

## 3. 行为与公式（How）

### 3.1 击杀归因

```text
正式局战区阶段发生合法敌方死亡
  → killer 属于玩家直属小队？否则结束
  → 读取死亡瞬间 current_player_aircraft.node_id
  → command_kills[node_id] += 1
  → mastery_xp[node_id] += mastery_base_xp(enemy_type)
  → 只置脏标记，不逐击杀落盘

正式局胜利结算
  → mastery_xp[current_player_aircraft.node_id] += 200
  → 与功勋、档案在同一结算事务中一次性落盘
```

“小队击杀算自己”的精确定义是**当前操控机型获得指挥战绩**，不是给全队每一种机型各复制一份。现有进化会把直属编队统一换型，因此通常与实际击杀机型一致；未来若出现混编，也不会让一次击杀被多机重复记账。

### 3.2 熟练加成应用

```text
spawn / evolution success / player_ref redirect
  → node_id 查 mastery level
  → 从本 spec 的五步表累加已获得 modifier
  → 百分比只乘机体档案基础值
  → 再进入现有 effective_* 与局内 skill/status 管线
```

- 熟练加成作用于当前玩家机型的直属同型编队，保持“这套机队练熟了”的 RTS 语义。
- 进化为新机后，旧机 modifier 全部卸下，只加载新机 M 等级；不允许沿 F-15→F-15C→F-15 S/MTD 把三套加成叠起来。
- 当前 HP 只在新上限下按比例保持；`HP3` 解锁不触发回血、复活或无敌。
- M 等级由 XP 阈值实时推导，不另存等级字段，避免调阈值后存档与显示漂移。

### 3.3 研发许可与局内进化

```text
进入机体 A
  → 永久标记 A = FLOWN
  → 揭示 A 的全部直接出口
  → 对需许可出口：只显示 PROGRAM_LOCKED，不可进化

购买项目
  → 扣可用功勋
  → 写入 MetaShop.owned
  → 涉及节点变为 LICENSED

局内结算站检查出口 B
  → direct edge && LV 达标 && 三轴达标
  → B 免费或已 LICENSED
  → B 确定可选；无额外随机抽签
```

未购项目绝不能把整条路线变成死局：同一父节点仍按现有树保留其它免费出口。购买也不代表“永久拥有为起手机”，只代表未来每局有资格从正式路线进化到它。

### 3.4 战力预算验收方法

“+15%”是跨属性预算，不是把五个百分比直接相加。每架机做同一套 M0 与 M5 对位矩阵：固定 AI、固定武器、固定敌人组合、至少 20 个种子，比较击杀时间、存活率与任务完成率。

| 结果 | 处理 |
|---|---|
| 综合效能 +12%～+16% | 通过 |
| < +12% | 优先提高该机最可见的身份字段，不加通用伤害 |
| > +16% | 优先削弱与签名技能形成乘法的那一步 |
| 单一 M 级导致 >5% 跳升 | 该步骤拆小或换成线性字段 |
| M5 改变机体角色/抹掉既有 tradeoff | 失败，即使综合值在区间内也回退 |

## 4. 流程时长评估

以下以当前正式局功勋约 **2,500～7,500/局**、完整一局约 **20～30 分钟**估算；价格仍需真实结算遥测校准。

| 玩家阶段 | 目标体验 | 预计时间 |
|---|---|---|
| 第 1 局 | 只认 F-15；看见一层出口；结算后可接近幻影采购或鹰式现代化 | 20～30 分钟 |
| 1～3 局 | 解锁第二起手线；至少买到一个变体项目；第一架常用机到 M1～M2 | 0.5～1.5 小时 |
| 4～10 局 | 四条角色线逐步展开；出现 EA-18G / S/MTD 等目标；常用机到 M3 | 2～5 小时 |
| 10～20 局 | 多条 T4/T5 路线、秘密项目与 R3～R4 | 5～10 小时 |
| 25～45 局 | 中位玩家发现大部分或全部 43 机；若同时购买现有长期商品，总消费接近 123,000 | 12～20 小时 |
| 单一爱机 M5 | 同一机型 6～12 次有效驾驶 | 3～6 小时 |
| 6 架爱机 M5 | 按不同路线重复游玩 | 20～40 小时 |
| 43 机全 M5 | 纯收藏尾部，不作为成就主线或内容门槛 | 约 100～180 小时 |

平滑性的关键不是把价格继续抬高，而是：**前 3 级熟练度给 60% 增幅、许可分批上架、每档都有免费骨架、秘密机用驾驶前置而非纯存钱**。如果遥测显示中位玩家连续 3 局都买不起任何当前可见项目，先降价或增加廉价项目，不提高功勋产量把所有旧商品一起冲垮。
