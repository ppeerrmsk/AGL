# 机炮高度差命中：设计与实施计划

> 2026-09-15 草案。用户要求重审高度系统并形成覆盖边界与各类强化的计划；本文件不代表机制或数值已获批准，也不表示代码已实现。推荐路线、候选参数、兼容矩阵与验收在下文分开列出。定稿前继续沿用已有玩法。

## 1. 设计意图（Why）

### 1.1 玩家体验

- 保留 2D 武器：弹丸沿平面飞行，已有前置量、碰撞、伤害、弹药、声音和真实弹幕继续成立。
- 高度接近时机炮可靠；高度差拉大后精度下降；高度差极大时不能靠地图投影重叠轻易互射。
- 高空打低空、低空打高空都按相对高度付出代价。首版不凭“占高”增加隐藏伤害或免费命中优势。
- 升降高度成为进入/离开机炮有效窗口的操作；保留自动开火和玩家高度命令的权限。
- 强化仍有可感知收益：瞄准辅助改善精度，重型机炮扩大平面交战范围，炮艇改善射界，贯穿改善多目标输出；任何一个都不能无说明地取消高度规则。
- Litmus：服务预判与走位；不削减命中后的伤害反馈；影响应能从弹道、火控状态与实战选择中察觉；新增成本保持轻量，满足严格 60 FPS。

### 1.2 当前实现审计（本次读取的工作区，不是历史版本）

| 项 | 已确认现状 | 本计划需要解决的问题 |
|---|---|---|
| 普通弹高度 | `spawn_bullet` 保存射手出膛高度，没有把高度写成目标高度 | 不能把问题误诊成弹丸自动追高 |
| 正式生存模式 | `flat_altitude_mode = true`；玩家和主要敌机使用 `flat_altitude` | 旧约 500m 开火/碰撞门均可被跳过，不能简单翻转总开关，连带改变火箭等武器 |
| 飞机射击 | 梭目标锁存、逐武器 tick 更新前置解；误差包含基础散布、飞行员、云、bank | 高度修正必须使用本梭实际目标，不能误读另一个 `combat_target` |
| 普通地面 AA | LOW/MID/HIGH 散布为 ×1/×1.8/×3；碰撞通常豁免高度 | 可借用精度下降的体验，但不能宣称其已有真实仰角或连续高度弹道 |
| 舰载 AA / CIWS | 独立发射路径；舰载 AA 当前不是上述地面 AA 三档散布；CIWS 有拦截、扫射、真弹与装饰弹 | 不可按“所有地面来源”一刀切继承同一合同 |
| 空爆 AA | 自有冻结火控解、引信和爆炸高度；当前空爆伤害检查高度差 1000m | 已有独立纵向约束，不叠普通机炮规则 |
| 高空防御 | 普通 Aircraft 受伤入口 HIGH 增加 0.20 闪避；一般闪避上限 0.85；Adds 与部分路由 BOSS 有特殊路径 | 不等于相对高度规则；新增高度资格必须位于共同碰撞入口，不能被特殊伤害分支绕过 |
| AI 高度 | 普通 AI 在 GUN 时可匹配目标；`use_tactical_preference` 玩家遵守高度偏好 | 玩家小队、编队与各类 AI 不能假定会自动跟高 |
| 玩家高位偏好 | 中心约 8400m，目标带 7600–9000m；LOW 2000m | 必须按这个真实控制范围验证所有敌方作战高度，避免不可解战斗 |
| 强化来源 | 除技能外还有机型档案、敌炮 V1–V8、三轴里程碑、状态与换机重放 | 不能只扫描卡片名称便宣称全覆盖 |

### 1.3 范围与非目标

首批改变普通航空机炮对 Aircraft 的交战与命中资格，包含对应炮舱/炮艇/贯穿弹、敌机与 BOSS 使用相同路径的普通炮。明确隔离地面/舰载防空、飞机对地、CIWS 导弹拦截、火箭、导弹、电磁炮、激光、炸弹、空爆弹与尾雷。

隔离不等于这些路径天然合理：§4.1 为每条路径登记现状、保留合同与后续决策。首批不得顺手改动它们的数值。项目旧 500m 非扁平玩法保留兼容用例；不以废弃沙盒替代正式生存验收。

## 2. 数据定义与待定决策（What）

### 2.1 路线比较与推荐

| 路线 | 优点 | 不足 / 裁决 |
|---|---|---|
| A：仅按高度扩大散布 | 与 AA 直觉一致，修改小、弹道可见 | 投影近乎重叠时散布来不及展开；低散布满强化可削弱惩罚；只拦新发射也挡不住在途误碰。不能独立满足本计划 |
| B：连续高度质量 + 轻度散布 + 一次性高度命中资格 | 保持 2D，能同时处理贴脸、贯穿、途中升降与远端误碰 | 会出现“平面穿过、纵向错开”；必须明确反馈，且不能逐帧重抽。**推荐作为对照原型** |
| C：弹丸完整虚拟 Z / 垂直速度 / 重力 / 俯仰解 | 可表达精确纵向弹道 | 扩大到新弹道系统，涉及火控、AI、碰撞及大量内容迁移；本轮不采用 |

路线 B 的高度资格是对未模拟纵向误差的游戏抽象，**不是已实现的物理弹道**。它也不是受击者的闪避技能。前一轮提出的“散布 + 极端高度拒射”在投影重叠和在途弹方面仍有缺口，因此这里补齐命中端方案。若用户不接受额外概率门，应改选并验证确定性的纵向包络方案，不能只删除该门后声称边界已解决。

### 2.2 候选原型参数（全部待定，非正式平衡值）

| 参数 | 原型起点 | 扫描 / 意义 |
|---|---:|---|
| 无惩罚高度差 `H_free` | 500m | 比较 500/1000m；容纳正常编队误差 |
| 完全不可达高度差 `H_stop` | 5000m | 比较 4500/5000/6000m；不得独立于敌人高度与玩家控制范围定值 |
| 额外散布半角上限 `A_height` | 1° | 比较 0/1/2°；0 仅用来隔离概率门影响，不自动成为最终方案 |
| 新梭允许最低质量 `Q_enter` | 0.10 | 比较 0.05/0.10/0.20，控制无效烧弹 |
| 在梭维持最低质量 `Q_keep` | 0.05 | 必须小于 `Q_enter`，防边界反复启停；冻结旧解梭另见 §3.4 |
| 高度质量的精度强化修正 | 无 | 瞄准辅助改善现有平面精度，不穿透纵向可达性 |
| 原 HIGH +0.20 闪避 | 首轮对照保留 | 单独比较移除/按来源重分配；不在同一实验里同时调整所有防御 |
| 导弹/CIWS 拦截高度参数 | 不新增 | 独立兼容策略，不能使用 `H_stop` |

公式中的距离、高度用米，角度内部用弧度；2D 像素统一通过 `CombatUnit.PIXELS_PER_METER` 换算。不得把图标缩放、3D 模型高度、相机 zoom 或 terrain mesh 高度写入此公式。

## 3. 行为与公式（How）

### 3.1 统一连续高度质量

```text
dh = abs(shooter_altitude_m - target_altitude_m)
t = clamp((dh - H_free) / (H_stop - H_free), 0, 1)
Q_height = 1 - t*t*(3 - 2*t)
spread_height = radians(A_height) * (1 - Q_height)
```

以候选 500/5000m 为例：

| 高度差 | 高度资格系数 Q（不是最终命中率） |
|---:|---:|
| 0–500m | 1.000 |
| 1500m | 0.874 |
| 2500m | 0.583 |
| 3500m | 0.259 |
| 4500m | 0.034 |
| ≥5000m | 0 |

- 质量对调攻守后相同；同高的 HIGH 对 HIGH 不受本项额外惩罚。
- LOW/MID/HIGH 边界没有跳变；规则不得查询高度档作为精度系数。
- `Q_height` 是纵向资格；实际命中还依赖 2D 瞄准、飞行时间、散布、碰撞、目标运动、免疫与既有闪避。不能把表中 0.259 直接当成玩家的实战命中率。
- 首版不把斜距直接替换现有平面射程。否则现有 1km 机炮对 3.5km 档差会全部失效，并隐式改变重型炮的收益。
- 不在此处乘伤害。高度导致打空；成功命中之后沿用正式伤害管线。

### 3.2 扫描、AI、开火和梭射

1. 统一纯函数提供高度质量、合法性和拒射原因；自动扫描、普通战术、编队机会火控、炮艇、`GUN_TAILED` 与提示共用。
   所有预览/评分/威胁查询均无随机和写状态副作用；一次性资格只在正式弹丸接触入口执行，不能把它放进会被多消费者反复调用的通用免疫查询。
2. 新梭同时满足既有敌对/感知/射程/前置角/弹药/状态/火力槽，以及 `Q >= Q_enter` 才提交。
3. 承诺目标仍按现有实例身份锁存。逐发所用高度和天气来自此目标；玩家新命令在下一梭生效，现有目标失格时按既有规则收束，不跳到别的目标续射。
4. 普通在梭：`Q >= Q_keep` 才继续；到 `Q = 0` 必须停止正常追瞄。中止清理剩余承诺，保留原冷却/装填纪律，不退款、不立即重启刷梭、不把未出弹算已射出。
5. 敌机 HOSTILE/FFA 的一机会一梭、梭后停火和 Encounter Lethal Slot 仍成立。定义“中止梭释放槽、消耗机会”的终态，避免槽长期占用或连续中止绕过停火。
6. 瞄准方向先按现有提前点/梭级偏差，再叠现有 bank 与天气散布、独立高度额外散布。高度项不能藏在 `gun_aim_error_enabled` 门内，否则普通敌机绕过。
7. 新射击使用当前有效参数；实际出膛弹快照参数，不追溯套用后来获得/失去的嗜血、增距、贯穿或换机强化。
8. 机炮不能用时，多武器 AI 按已有武器准则选择可用武器；玩家 T/V/F 权限继续有效。强制偏好 GUN 时不能暗发导弹。

### 3.3 出膛、在途与命中端

建议新增数据以值快照表达，字段名在实现阶段定：

- 发射用途/profile：普通航空对空、既有对地、AA 对空、CIWS 拦截等；不能仅靠 `is_ciws` 或仍活着的 source 类型推断。
- 射手出膛高度、当时适用的高度曲线参数、弹丸序号/独立随机种子；不快照一个可变目标高度来“贴着目标飞”。
- 已完成高度资格判定的候选身份及结果；沿用/扩展弹丸现有轻量命中记录，寿命结束清空，不建立全局永久表。

命中流程：

```text
现有网格候选 / 2D 碰撞
  -> 既有阵营、目标类型、隐形、不可命中规则
  -> 按发射 profile 选择高度策略
  -> 第一次可判定接触：用出膛高度与受击者此刻真实高度计算 Q_contact
  -> 对这个 bullet-target 对只判一次高度资格
  -> 成立才调用现有伤害 resolver、闪避、护甲、伤害路由、命中效果与击杀钩子
```

- 概率候选实现：`u = stable_uniform(shot_seed, target_spawn_identity)`，`u < Q_contact` 成立。种子不消费玩法全局 RNG，稳定身份不能把跨次运行的 Object instance ID 当作固定复现键；测试夹具须可注入 seed/身份。
- 高度拒绝时弹丸继续飞，不造成闪避滚转、不出命中火星、不增加 gun_hits、不触发受伤/击杀收益；同一弹对同一实体生命周期不得下一帧再抽。
- 第一次资格成功也只缓存资格，不绕过后来时刻的敌对/免疫/伤害规则；实体释放后新实体不继承旧缓存。
- 贯穿弹对每个不同目标分别判定；高度不符的第一架不能吞掉弹丸，也不能把后续不同高度目标自动视为命中。实际伤害去重沿用原记录语义。
- 出膛后目标爬升/俯冲：第一次接触采用当时目标高度；已错过的弹不会因随后降高而重抽。射手后来升降、死亡、软退场或切控不会改变出膛快照。
- 这是连续高度资格抽象，不声称计算了子弹在天空中的 Z 曲线。若以后要表达“瞄准高层的弹不能击中低层穿越者”，必须另立纵向弹道合同，不能临时把 target.altitude 写成 bullet.altitude。
- 平面寿命、速度、远端伤害衰减、建筑阻挡继续走现有合同；不额外增加随斜距的飞行衰减，也不自动扩大碰撞半径弥补失准。
- 无目标的合法旧调用也需显式 profile 与出膛高度；不能因没有 target 就豁免高度。坏高度数据（NaN/Inf）、曲线倒置、未知 profile：断言/日志并拒绝新伤害，避免 fail-open 变成跨高层命中。

### 3.4 高度动作、指令与威胁

| 情况 | 计划合同 |
|---|---|
| 玩家 LOW/HIGH 偏好 | 不自动越权跟高；显示“高度差导致机炮受限”的原因；调整高度后恢复正常解 |
| 普通 AI 追高 | 使用已有高度控制与 effective 物理能力；达不到目标高度则选其它合法机会/按任务继续，不永久锁住无解目标 |
| 编队 / 狂化僚机 / ALLY / FFA | 按各自正式命令与角色权限决定能否跟高；不以是否 `team == 0` 代替玩家小队或敌对判定 |
| 指名目标不可机炮攻击 | 保留命令与目标身份；炮艇可按已批准回退规则找合法机会目标；普通武器不自动夺走命令 |
| CLIMB 4s 反制 | 冻结已承诺梭的旧世界射向继续出弹，不被新 `Q_keep` 取消掉既有反制演出；这不豁免命中端高度资格，下一梭恢复正常重算 |
| 自然漂移 / 转弯掉高 / AI 追高 | 改变连续命中质量，但不武装玩家 CLIMB/DIVE 或免费反制窗口 |
| `GUN_TAILED` / 僚机 GunEvasion | 用真实机炮包络过滤不可能的新威胁；已发射/已承诺梭按 `Q_keep` 与冻结状态处理，不能因为进入阈值较高而立刻漏警 |
| 威胁失效 / 恢复 | 保留当前 evasion 承诺及退出迟滞；不因每 tick 的高度小波动连续抢占导航 |
| 失速恢复 / 受限机型 | 不伪造 CLIMB/DIVE，不突破真实高度/G/速度能力去满足射击门 |
| 暂停 / 慢动作 / 演出 | 冷却与动作仍用正式游戏时间；随机资格与帧率、时间缩放无关 |

在定稿前生成“玩家可维持高度 × 当前全部敌机/任务/BOSS 的可受伤高度”矩阵。纯机炮配置必须存在现有操作可进入的有效窗口；若某正式必打目标完全不可达，优先修改候选曲线或明确的遭遇合同，禁止临时给 BOSS 任意高度豁免，也不能默认所有玩家随时有导弹。

## 4. 结构与兼容矩阵（Structure）

### 4.1 全部生产发射路径与目标类型

| 路径 / 对象 | 首批处理与边界 |
|---|---|
| Aircraft 普通机炮 / 自动扫描 / 直接 GUN / 编队机会火控 | 全接同一航空对空 profile，敌我一致；逐个核查提前返回与 LOD 分支 |
| 双翼机炮吊舱 | 两发独立 shot seed，共享同梭目标/高度语义；真实炮口位置不变；高度项不能只加左管 |
| 炮艇对空 | 360° 仅指水平射界，不是纵向豁免；仍吃航空对空规则 |
| 炮艇对地 / 指名舰船或 MountTarget | 首批保留既有攻击能力与目标优先；依据实体/伤害宿主分类，不因代理继承层级误套空对空 |
| 普通机炮误碰地面/舰船 | 首批保留已存在的资格和船体倍率，不扩大自动索敌池；这是显式兼容边界，不宣传成全武器高度重构 |
| 普通 GroundUnit / AAGunUnit 对空 | 保留现有散布和象征性射击；发射 profile 必须随弹保存，射手死亡不能导致高度豁免消失 |

## 6. 实现计划（Task Pipeline）

| 阶段 | 工作与交付物 | 完成门 |
|---|---|---|
| P0 盘点与基线 | 再核所有发射调用、实际技能源/机型/敌机高度与旧伤害路径；生成覆盖表、未解高度矩阵、同 seed 基线 | 不存在未归类发射路径；已知漂移单列，定稿 D1–D7 |
| P1 纯规则与数据合同 | 统一质量/profile/快照/一次性资格、稳定 seed；用现有字典/网格实现，不加每弹 Node | 纯函数、实际碰撞与 source 释放用例通过；profile 不靠活对象推断 |
| P2 火控与 AI 接线 | 自动扫描、梭射、机会火控、炮艇、GUN_TAILED、GunEvasion、武器选择和拒射原因共用规则 | 新/残梭、冻解反制、命令优先及无解目标处理都闭合；无永久不开火回路 |
| P3 强化与生命周期 | §4 所有强化与目标域，换机/换帅/晚入队/场景退出、F4/F6 审计 | 属性作用域不变、无共享资源污染，focused + gauntlet 通过 |
| P4 表现与调参 | 候选矩阵与 A/B，旧 HIGH 闪避独立实验，用户可读反馈 | 确认正式数值，修订受影响 spec 的旧约定；没有隐藏“碰到却命中成功”反馈 |
| P5 集成收尾 | 默认 all、Visual C1/C2/S1/BOSS、三图完整局、静态校验 | §5 必需证据齐全才标 done；缺 Visual/完整局保持 in-progress |

实施成本要求：纯函数 O(1)，沿现有低频扫描、逐发出弹与网格候选运行；不加全场扫描、不增 Aircraft/Missile 子节点；只在首次有效接触建立资格记录，弹结束清空。测试锁遵守 bench wrapper，临时材料入 tmp，不与其他任务同时写运行项目并启动 Godot。

### 6.2 回退与失败处理

实现阶段可用单一测试配置比较旧/新高度策略；不得留下生产各调用点各自开关。回退仅回退本批新增策略及配套文案，不重置用户进度/机型/技能资源，不更改全局 `flat_altitude_mode`。在途弹沿生成时 profile 收尾；如需跨版本存档迁移，另写兼容用例。

若性能或体验不通过，按证据优先缩减资格记录成本、复用低频数据、调整曲线与拒射门；不能删真实战斗对象/反馈通过性能，也不能任意给予玩家或 BOSS 隐藏高度免疫来修补不可解内容。
