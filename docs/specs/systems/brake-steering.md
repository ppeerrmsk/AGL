# 急刹拖拽转向

> 玩家按住右键急刹时，可像压住一根横向操纵杆一样左右拖拽，靠各机真实低速机动性能微调机头或持续盘旋，为近距机炮创造射击窗口。

## 1. 设计意图（Why）

- **体验目标**：保留右键持续减速和失速软地板，同时给玩家一个低带宽、可持续的机头控制入口。短距离拖拽用于微调机炮轴线；把鼠标保持在一侧用于持续左/右盘旋。玩家仍是在操纵一架有重量、有滚转延迟、有 G 与失速限制的飞机，而不是直接旋转图标。
- **战斗定位**：强化机炮与近身狗斗。动作只改变飞行几何，不放宽机炮射程、射界或自动开火门；玩家靠减速、压坡和持续盘旋把目标带入既有机炮锥。
- **机型定位**：不按“斗士”标签硬加隐藏倍率。低失速、高持续 G、高滚转率、强减速的近战机自然更快进入紧盘旋并更快调整机头；高速、低 G 或高失速的截击机仍能使用，但转向建立更慢、低速盘旋半径更大。
- **Litmus 自检**：
  - 符合“笨重 + 延迟快感”：输入只给目标坡度，实际滚转、G、速度与航向继续走统一飞行物理。
  - 符合“全武器自动开火”：不增加扳机键；机炮仍由既有射界与距离条件自动开火。
  - 符合“信息察觉优先于数值”：不同机体的压坡速度、刹入低速的时间和盘旋半径直接可见，不做不可感知的后台伤害加成。
- **反模式规避**：禁止直接改 `heading`、瞬时设定 `bank_angle`、给斗士轴硬乘转向倍率，或另造不受预测/物理约束的“鼠标偏航速度”。

## 2. 数据定义（What —— 全部数值，权威源）

### 2.1 手势参数

| 字段 | 值 | 说明 |
|---|---:|---|
| `BRAKE_STEER_DEADZONE_PX` | `12 px` | 从右键按下点计算的水平死区；吸收单击抖动。按项目 UI 逻辑像素解释，不随 HUD 单独缩放。 |
| `BRAKE_STEER_FULL_PX` | `110 px` | 水平位移达到该值时为满舵；更远位移继续钳在满舵。由首轮实机反馈从 180 px 缩短，使普通鼠标移动无需大幅甩动。 |
| `BRAKE_STEER_CURVE` | `smoothstep(0, 1, x)` | 中位附近细、外侧迅速建立坡度。 |
| `BRAKE_STEER_MAX_G_USAGE` | `1.0` | 满舵最多使用本机当前 `effective_max_g`，不使用结构瞬时 G 上限。 |
| 垂直位移 | 忽略 | 右键手势只消费水平轴，避免二维拖拽误解为世界航点。 |

### 2.2 运行时状态

| 字段 | 范围 / 初值 | 生命周期 |
|---|---|---|
| `brake_steer_anchor_screen` | 右键按下时的屏幕坐标 | 每次右键按下重建，松开/失焦/切面板时清除。 |
| `brake_steer_accumulated_dx` | `[-110, 110] px`，初值 `0` | 捕获鼠标期间累计 `MouseMotion.screen_relative.x`；松开或其它清理路径归零。 |
| `brake_steer_input` | `[-1, 1]`，初值 `0` | 拖右为正、拖左为负；同一归一化输入广播给全部 `selected_aircraft`。 |
| `brake_steer_active` | `false` | 仅在战场内右键按住且当前没有被命令轮盘截获时为真。 |

### 2.3 机型差异的权威属性

| 属性 | 对急刹转向的作用 |
|---|---|
| `effective_max_g(ac)` | 决定当前可持续最大坡度；G 越高，满舵转向率上限越高。 |
| `base_roll_rate(ac)` | 决定从平飞压到目标坡度需要多久；滚转快的飞机微调响应更快。 |
| `params.deceleration × effective_decel_mult(ac)` | 决定多久刹入低速高转率区；只通过既有速度积分生效，不再额外乘转向倍率。 |
| `base_stall_kmh(ac)` | 决定拉 G 后的失速软地板与最小可持续盘旋速度；低失速机能形成更小盘旋半径。 |

## 3. 行为与公式（How）

### 3.1 输入状态机

| 状态 | 进入 | 行为 | 退出 |
|---|---|---|---|
| `IDLE` | 默认 | 沿用现有飞行/命令行为 | 战场内右键按下 → `BRAKING` |
| `BRAKING` | 右键按下未越过水平死区 | 立即执行既有取消命令；全体 selected 持续急刹、清追击航点并保持机头 | 水平位移越过死区 → `BRAKE_STEERING`；松开/失焦/左键操作/暂停或面板接管 → `IDLE` |
| `BRAKE_STEERING` | 水平位移越过死区，且飞机未失速 | 继续急刹；按归一化输入给出持续目标坡度。鼠标保持在一侧可连续转圈；移回死区则逐步拉平但仍急刹 | 飞机进入正式失速 → `STALLED_BRAKE`；其余同上 |
| `STALLED_BRAKE` | 急刹转向期间飞机进入正式失速 | 右键减速状态保留，但拖拽转向立即失效，目标坡度归零并完全交还既有失速恢复逻辑 | 正式失速状态与恢复保护均结束、右键仍按住 → 按当前鼠标位移返回 `BRAKING` / `BRAKE_STEERING`；松开等清理路径 → `IDLE` |

- 战术地图内右键仍只执行既有 `nav_cleared`，不进入急刹拖拽转向。
- 命令轮盘已经接管的手势优先；其间按右键仍只中止轮盘，不触发急刹或转向。
- 多选语义沿用既有急刹：全部 selected 接收相同的左/右归一化输入，但每架飞机按自己的物理属性产生不同坡度建立、转率与半径。
- 正式场景进入 `BRAKING` 时记录原鼠标模式并切换到 `MOUSE_MODE_CAPTURED`：系统光标锁定/隐藏，虚拟摇杆承担可见反馈。释放或任一清理路径恢复原鼠标模式；原模式不是捕获态时，把系统光标送回本次右键按下点。
- 机场进化/规划站属于面板接管路径：入口必须在玩家引用校验、暂停和面板显示之前先走统一急刹清理。即使玩家机已异常失效并提前返回，也必须恢复系统鼠标，不能把捕获态带进需要点击的科技树。

### 3.2 手势归一化

```text
dx = clamp(previous_dx + mouse_motion.screen_relative.x, -110, 110)
if abs(dx) <= 12:
    u = 0
else:
    x = clamp((abs(dx) - 12) / (110 - 12), 0, 1)
    u = sign(dx) * smoothstep(0, 1, x)
```

- `u = 0`：机翼逐步回平，继续急刹直行。
- `0 < abs(u) < 1`：微调；位移越大，目标坡度越大。
- `abs(u) = 1`：持续满舵；只要鼠标保持在该侧，飞机可以连续盘旋，不存在“只转固定角度后停止”的排队航向。
- `is_stalled == true` 或正式失速恢复保护仍在持续时：无论鼠标位移多大，供物理消费的有效 `u` 都强制为 `0`。

### 3.3 物理映射

```text
sustained_bank_limit = acos(1 / effective_max_g)
target_bank = sign(u) * sustained_bank_limit * smoothstep(0, 1, abs(u))
bank = 现有 roll_rate 积分追向 target_bank
heading_rate = GRAVITY * tan(bank) / speed
hard_brake_target_speed = base_stall_kmh * g_load^0.4 * 1.05
```

- **G 值的职责**：G 是坡度/持续转向能力上限，不是额外的鼠标灵敏度倍率。高 G 机满舵能达到更高坡度，但小拖拽仍保持细腻。急刹拖拽不消费普通航点转弯用于提前防失速的低速坡度帽，否则会在真正失速前自动收坡、违背“转向一直可用到失速”的输入承诺。
- **减速性能的职责**：减速率只决定多快进入低速高转率区。强减速机更快获得紧盘旋，弱减速机需要更长时间；不得把 `deceleration` 再乘进 `target_bank`，避免一次属性被重复奖励。
- **失速边界**：拖拽转向可以一直工作到飞机触发既有正式失速判定；一旦失速，拖拽转向立即失效并强制收回目标坡度，不能在失速中继续“拧机头”。右键直线急刹仍沿用 `stall × g^0.4 × 1.05` 软地板，不会自行失速；拖拽取得操纵权时，减速目标改用 `stall × 1.05` 的 1G 地板，让持续压舵抬升的真实载荷失速成为极限。失速/恢复期再回到当前 G 安全地板帮助恢复。小舵量可在载荷失速线以下持续盘旋，满舵则会更快进入失速。
- **恢复条件**：只有 `is_stalled` 已清除且既有失速恢复保护结束，拖拽转向才重新可用；不得另设更短的旁路计时器。若右键仍按住，恢复后按当前鼠标位置重新计算输入，不记忆失速前的排队转向。
- **统一物理**：航向仍只由协调转弯公式积分；不直接写 `heading`，不使用结构瞬时 G，不绕过滚转率、失速或 G 掉速。

### 3.4 屏幕反馈

- 右键按下时，以按下点为锚显示一套非交互、鼠标穿透的横向虚拟摇杆，并显示“减速中”；提示使用当前 HUD 强调色，只有文字区域使用 70% 黑底，摇杆圆环保持通透。
- 手势活跃期间系统鼠标不可在屏幕上漂移；战场 hover 同步冻结，避免捕获态固定在窗口中心的 `global_position` 误选单位。摇杆帽承担相对移动的全部可见反馈。
- 摇杆帽的左右位移直接映射最终归一化 `brake_steer_input`，不另读原始鼠标距离：中心为 0，圆环两侧为 ±1。拖拽生效后显示“左转/右转 + 百分比”，确保后续灵敏度调整不会令视觉与实际输入分离。
- 按下点靠近屏幕边缘时，摇杆中心夹紧到完整可见区域，并以细线连接原始按下点；不得让标签或圆环被裁掉。
- 当前操控机正式失速或处于恢复保护时，摇杆转为危险红，摇杆帽归中并显示“失速 / 转向锁定”；“减速仍在进行、拖拽转向暂不可用”的状态必须可辨。
- 摇杆提示下方在手势活跃期间分项显示当前操控机的即时速度（`speed × 3.6`，整数 `km/h`）、机炮剩余/常规容量（`ammo / params.gun.max_ammo`）与当前有效机炮射程（`effective_gun_range_m()`，整数 `m`）。文案必须显式写出“机炮弹药”和“射程”，不得用“机炮 + 单个数字”让射程与余弹混淆；无限弹药或嗜血免费弹药期间以 `∞` 取代弹量分数，无机炮时明确显示“无机炮”。数值只在取整结果或弹药状态变化时触发覆盖层重绘。
- 当前操控机急刹期间，同时复用正式 `draw_gun_cone` 在机头前绘制实际机炮参考射界：普通机炮使用 `effective_gun_range_m()` 与 `effective_gun_cone_half_angle_deg()` 的真实扇形；炮艇沿用其真实 360° 射程环。射界随飞机航向旋转，松开急刹即隐藏；不得另造近似范围、修改火控判定或为其它友机常驻显示。
- 松开右键、失焦、暂停/面板接管、切控或场景退出时，提示与急刹状态同一清理路径同步隐藏，不能残留。
- 覆盖层为 HUD 单实例、无 `_process`、无实体扫描；只在按下、有效舵量变化、失速锁定变化、取整后的飞行数值/弹药变化与释放时更新状态/重绘。唯一的运行时失速/速度/弹药/射程读取复用生存模式既有主循环，且只在右键手势活跃期间读取当前操控机。机炮射界复用飞机本身既有绘制入口，不新增实体扫描或子节点。

### 3.5 机炮与目标语义

- 右键按下仍执行既有“取消玩家命令与巡航航点”；拖拽转向不会重新建立 `commanded_target` 或 `target_position`。
- 该取消入口同时清除既有 `combat_target`：减速期间不会继续追踪或发射导弹攻击先前点名目标。普通机炮/机炮吊舱仍以无点名自动扫描攻击机头视野内合法目标；炮艇仍走独立 360° 被动扫描。
- 机炮继续使用既有自动扫描、提前点、射程与机头锥判定。急刹转向只帮助玩家把机头带进开火几何，不强制开火、不延长射程、不增加伤害。
- **普通机炮**：右键取消 `combat_target` 后，当前操控机仍须运行既有 `auto_gun_scan`，对视野/机头锥内合法空中目标自动反应并发射。`hard_brake` 与拖拽输入不得成为扫描或梭射执行层的静默条件；高坡度仍可沿用既有玩家机炮散布惩罚。
- **机炮吊舱**：继续复用同一自动扫描与梭射许可，只在单发执行层生成左右翼挂两道朝前火线；急刹拖拽不得降级为单管、改变弹耗或阻断出膛。
- **炮艇模式**：继续作为全队独立 360° 被动炮塔通道运行。右键清除点名目标后，必须回退到最近合法 Aircraft / GroundUnit；不得因 `combat_target == null`、BRAKE 控制源、主武器模式或拖拽坡度静默。
- 失速与其恢复保护、导弹规避、Cobra、Herbst 等正式机动继续优先；这些状态结束且右键仍按住时，急刹转向才可恢复。释放右键时必须原子清除急刹与转向输入，不能留下坡度命令。

## 4. 结构与组成（Structure）

- **输入与生命周期所有者**：生存模式输入层记录右键按下锚点、更新归一化水平输入，并在松开、失焦、暂停、切控和场景退出路径统一清理。
- **控制意图**：沿用 `ControlIntent.SOURCE_BRAKE`。该源继续拥有速度/AB 最高优先级，并新增只在 `brake_steer_input != 0` 时生效的受限坡度主张；不伪造世界航点。
- **飞机状态**：`Aircraft` 只保存急刹转向的瞬时归一化输入，不保存屏幕坐标。
- **飞行物理**：安全坡度、滚转积分、G、航向、速度与预测均复用统一 helper；实飞和预测不能出现两套公式。
- **表现**：`SurvivorHUD` 持有一个默认隐藏的 `BrakeSteeringOverlay` 单实例。它锚定右键按下点，消费输入层已经算好的舵量、当前操控机的正式失速/恢复状态、即时速度、剩余/最大机炮弹药、免费弹药状态与有效机炮射程；不反向参与操纵判定。飞机本体通过既有 `AircraftRenderer.draw_gun_cone` 消费 `hard_brake + 当前操控机` 显示门，绘制真实机炮扇形/炮艇环。Debug/F9 仍可记录输入、目标坡度、实际 G 与转率用于调参。

## 5. 验收标准（Acceptance / Litmus）

- [x] 右键按住不拖动：与现有急刹完全一致，取消命令、保持机头并按本机减速率收敛到失速软地板。
- [x] 右键按住后向右/左轻拖：飞机分别小幅右/左压坡；回到 12 px 死区后平滑回平，但减速持续。
- [x] 右键按住并保持中等侧向舵量：在未失速时可持续同向盘旋至少一整圈，不会在固定航向处停转。
- [x] 持续满舵不会被普通航点的低速安全坡度帽提前拉平；若能量不足则一直转到正式失速，随后立即失去拖拽转向。
- [x] 松开右键、左键下新命令、窗口失焦、暂停/面板接管、切换操控机与场景退出均清除急刹转向，不残留 `hard_brake` 或转向输入。
- [x] 右键期间系统鼠标锁定且不触发错误 hover；相对移动可累计到满舵、反向拉回中心。松开及全部清理路径恢复原鼠标模式，并把可见光标送回按下点。
- [x] 右键急刹期间进入机场进化/规划站时，入口先原子清除急刹、转向与鼠标捕获；即使玩家引用失效导致面板入口提前返回，系统鼠标仍恢复可见可点。
- [ ] 多选时所有 selected 同向转弯；高滚转/强减速/低失速/高持续 G 机比相反属性机更快建立紧盘旋，差异来自真实属性而非类别隐藏倍率。
- [x] 健康飞机仅直线急刹时仍收敛到当前 G 对应的 `stall × g^0.4 × 1.05` 软地板，不会由右键减速本身主动坠机。
- [x] 转弯 G、能量损失或其它状态令飞机进入正式失速后，拖拽输入立即失效、目标坡度归零；失速恢复期间持续拖动也不能改变机头。
- [x] 正式失速状态和恢复保护均结束后，若右键仍按住，转向按当前鼠标位置恢复；不存在失速前转向排队或一解除就瞬时跳头。
- [x] 右键取消清除旧 `combat_target` / `commanded_target`；导弹不再攻击旧点名目标。机炮仍只在既有距离与机头锥内自动开火，急刹转向本身不直接造成开火、伤害、射程或命中率变化。
