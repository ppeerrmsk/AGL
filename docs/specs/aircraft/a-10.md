# A-10 "Warthog"（可选主角机 · 亚音速对地攻击机）

> **2026-08-20 当前权威状态**：A-10 是 43 机谱系的 T2 节点，正式玩家参数为
> `resources/player/player_a10.tres`，自带底线武器机炮 + 导弹 + 热诱弹，**不自带火箭**。
> `a10_rocket.tres` 仍作为战区奖励武器存在，取得后才可挂载；旧 `playable_a10_base.tres`、
> `playable_a10_drone.tres` 与战区支援 A-10 同样不得烤入火箭。下方火箭数值仅描述奖励武器本身。

> （原始概念）厚甲高血、无导弹无热诱弹的攻击机。签名武器是机翼 Hydra 70 火箭巢——自动扫描 ±35° 锥、
> 8 发双侧涟发、近段直飞后渐进展开扇面，近炸 + AOE，容错极高的"糊脸"武器。另有漂浮雷副武器；实验装载可换装忠诚僚机无人机。
> 定位：低空战力、贴脸输出、不靠锁定。

## 1. 设计意图（Why）

- **体验目标**：提供一个**反"制空狗斗"**的玩法——不锁定、不打导弹，靠厚甲冲进去用火箭巢
  扇形糊脸。把"对地攻击机"的硬朗、容错、近身感做出来。
- **Litmus 自检**（docs/DESIGN_PHILOSOPHY.md）：
  - 武器**全自动开火**（扫描锥触发），不要求玩家手动按键瞄准 → 过"操作极简、点地图即可"。
  - 厚甲 + 高容错火箭 = 清晰的"我很肉、我贴脸"身份，与制空机型形成对比 → 过"机型各有性格"。
- **反模式规避**：无导弹是**刻意的身份限制**（不是缺功能）——换来厚甲 + 强火箭，构成取舍而非短板。
