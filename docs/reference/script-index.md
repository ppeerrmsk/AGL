> 本节内容原在 CLAUDE.md，2026-05-05 移出。

**模式归属图例**：`[共享]` = 共享层；`[沙盒]` = 只在沙盒模式（**沙盒已废弃**，仅调试留存，验证不必再跑它）；`[生存]` = 只在生存模式（主玩法）。
