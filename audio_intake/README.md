# AGL 音频素材收件区

这里存放尚未接入游戏的音乐、音效、无线电人声和参考素材。目录根部的 `.gdignore` 会阻止 Godot
扫描这些大文件；`export_presets.cfg` 的正式导出与增量补丁过滤器也显式排除整个 `audio_intake/`，
原始素材默认不会进入 Git 或游戏包。正式筛选、转码并登记后的游戏文件仍放在 `../audio/`。

## 最省事的用法

1. 把新文件放进 `00_unsorted/`，可以一次放很多，不必先改名。
2. 同批最好附一张来源截图、下载页面文本或订单/许可文件；也可以把 Suno 项目链接写进文件名旁的文本文件。
3. 告诉 Codex“整理 audio_intake 这一批”。Codex 负责试听与技术检查、去重、用途匹配、重命名、
   填写 `catalog.csv`，并提出第一批接入建议。
4. 只有确认采用的派生文件才会复制到当前正式目录 `../audio/music/` 或 `../audio/sfx/`，按实际用途接入
   `AudioManager` 的 Music / SFX / UI / Radio 资源表；原始母版保留在收件区，不会被覆盖。

## 目录说明

| 目录 | 放什么 |
|---|---|
| `00_unsorted/` | 默认投放口；不知道类别时全部放这里 |
| `10_music/` | Suno 等生成的完整音乐、stem、循环候选 |
| `20_sfx/` | 武器、命中/击毁、飞机、环境、UI 与奖励音效 |
| `30_radio/` | 无语义含混人声纹理、处理试听稿、蜂鸣与底噪 |
| `40_reference/` | 只作风格参考、不准备直接打包的音频或链接说明 |
| `90_hold_rejected/` | 待定、重复、质量不足或许可不清的素材；不直接删除 |

细分目录按 AGL 的实际使用状态与声音家族建立。允许先放错位置，`catalog.csv` 的匹配结果才是本批
处理状态的记录。

王牌战专属曲母版放在 `10_music/ace_battle/`。当前四首已制作成
`audio/music/ace_battle_01.ogg`～`04.ogg`：非 BOSS 王牌中队血条浮现时随机抽一首 one-shot，
该曲自然播完或中队终止后淡入普通歌单，本次遭遇不续播第二首。

## 素材原则

- 音乐尽量下载无损 WAV；Suno 曲目保留项目链接、生成日期和当时的会员档位证明。
- 世界音效优先保留干净、无音乐、无对白、少混响的 WAV 母版。AGL 的远距指挥室味由 SFX Bus 统一加工，
  不要在生成阶段提前烤死电话频带或无线电失真。
- 无线电声音不是台词配音：只制作**听起来像人在通信、但完全听不清词句**的无语义含混人声纹理。
  屏幕上的本地化文字单独负责语义；同一套声音跨中文、英文、日文复用，不做三套语言音频。
- 含混人声、蜂鸣、静电与开关噪声分别保留母版，方便运行时统一过滤和混音；处理后仍能听出具体单词的
  候选不合格。
- 不使用来源不明、无法确认游戏商用许可的文件；不仿冒或克隆未授权真人声音。
- 高频声音以家族处理：候选通过后至少比较多个变体，避免连续触发疲劳。

## Codex 每批交付

- 清单：文件、来源/许可、时长/声道/格式、重复项与质量问题；
- 匹配：推荐的地图、战斗阶段、武器/事件触发点、Bus 和优先级；
- 缺口：当前声音家族还少哪些近/远、轻/重、友/敌或 A/B/C 变体；
- 样板：先接一个真实触发点试听，通过后再扩展到整组；
- 验收：实际 Survivor 链路、混战层级、音量设置、静音和发布包检查。

## 2026-08-22 正式库基线

`catalog.csv` 已登记当前 12 首已接入音乐和 13 个世界音效，方便新素材直接与现状比较：

- 普通战斗有 2 首轮播；F-47、Wraith、Hyper-A/Black Star 当前复用 1 首 BOSS 曲；CSG 与 Mother Goose
  各有专属双曲/双层素材。
- 主菜单使用 `main_menu.ogg` 循环播放；进入正式战局时等功率交给普通战斗双曲歌单。
- 机炮、导弹发射、爆炸和玩家引擎已有第一批素材；两个导弹掠过和两个备用引擎已注册但暂无正式触发。
- UI 音效表为空；Radio 已有播放入口，但 `radio_beep.wav` 素材尚未到位。
- 现有 13 个 WAV 都是 48kHz 立体声，多数长于普通 one-shot 目标长度。它们保持原样作为母版，正式扩展前
  需要按定位听感、尾音和循环用途制作单声道/裁切派生，不能覆盖原文件。
- 旧素材的来源与许可证明未在仓库内登记，`catalog.csv` 统一标为 `needs_license_evidence`，发布前补齐。
